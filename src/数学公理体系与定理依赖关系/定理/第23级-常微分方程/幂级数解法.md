# 幂级数解法

## 介绍

幂级数解法是求解线性微分方程的一种重要方法，适用于方程的解在常点（ordinary point）附近可以展开为幂级数的情形。该方法由牛顿（Newton）和莱布尼茨（Leibniz）在 17 世纪开创，后经柯西（Cauchy）和富克斯（Fuchs）等人系统发展。幂级数解法的基本思想是：假设解可以表示为幂级数 $\sum_{n=0}^\infty a_n (x - x_0)^n$，代入微分方程后通过比较系数确定 $a_n$。这一方法不仅可以求解许多初等函数无法表达的微分方程（如 Airy 方程、Bessel 方程等），也为后续研究奇异点附近的 Frobenius 方法奠定了基础。

## 分析

**前置依赖**：幂级数理论、收敛半径、解析函数、线性微分方程。

**数学内涵**：
- 点 $x_0$ 称为方程 $y'' + p(x)y' + q(x)y = 0$ 的**常点**，如果 $p(x)$ 和 $q(x)$ 在 $x_0$ 处解析。
- 在常点附近，解可以表示为幂级数 $\sum_{n=0}^\infty a_n (x - x_0)^n$，且收敛半径至少等于 $p(x)$ 和 $q(x)$ 的幂级数收敛半径的最小值。
- 代入方程后，通过比较同次幂系数得到递推关系，从而确定所有系数。

**结构**：
1. 假设解为幂级数形式。
2. 代入微分方程。
3. 合并同次幂项，令系数为零。
4. 得到递推关系，求出通项公式。

## 思考过程

幂级数解法的核心想法是：如果微分方程的系数是解析函数，那么解很可能也是解析的（至少在常点附近）。这一想法在柯西的解析理论中得到了严格证明。

实际操作中，我们将幂级数代入方程，利用幂级数的逐项可微性，将微分方程转化为关于系数的代数递推关系。通过求解这些递推关系，可以逐步确定所有系数。由于递推关系通常只涉及少数几项，我们可以得到通项公式，或者至少可以计算足够多的项来近似解。

## 证明过程

**定理**（幂级数解法）：设 $p(x)$ 和 $q(x)$ 在 $|x - x_0| < R$ 内解析，则二阶线性齐次微分方程
$$y'' + p(x)y' + q(x)y = 0$$
在 $|x - x_0| < R$ 内存在解析解，可表示为幂级数
$$y(x) = \sum_{n=0}^\infty a_n (x - x_0)^n$$
且收敛半径至少为 $R$。

**证明**：

### 1. 幂级数展开

设 $p(x) = \sum_{n=0}^\infty p_n (x - x_0)^n$，$q(x) = \sum_{n=0}^\infty q_n (x - x_0)^n$，收敛半径 $\geq R$。

假设解的形式为 $y(x) = \sum_{n=0}^\infty a_n (x - x_0)^n$，则
$$y'(x) = \sum_{n=1}^\infty n a_n (x - x_0)^{n-1} = \sum_{n=0}^\infty (n+1) a_{n+1} (x - x_0)^n$$
$$y''(x) = \sum_{n=2}^\infty n(n-1) a_n (x - x_0)^{n-2} = \sum_{n=0}^\infty (n+2)(n+1) a_{n+2} (x - x_0)^n$$

### 2. 代入方程

代入 $y'' + p(x)y' + q(x)y = 0$：
$$\sum_{n=0}^\infty (n+2)(n+1) a_{n+2} (x - x_0)^n + \left(\sum_{n=0}^\infty p_n (x - x_0)^n\right)\left(\sum_{n=0}^\infty (n+1) a_{n+1} (x - x_0)^n\right) + \left(\sum_{n=0}^\infty q_n (x - x_0)^n\right)\left(\sum_{n=0}^\infty a_n (x - x_0)^n\right) = 0$$

### 3. 比较系数

利用 Cauchy 乘积，$(x - x_0)^n$ 的系数为：
$$(n+2)(n+1)a_{n+2} + \sum_{k=0}^n p_k (n+1-k) a_{n+1-k} + \sum_{k=0}^n q_k a_{n-k} = 0$$

由此得到递推关系：
$$a_{n+2} = -\frac{1}{(n+2)(n+1)}\left(\sum_{k=0}^n p_k (n+1-k) a_{n+1-k} + \sum_{k=0}^n q_k a_{n-k}\right)$$

### 4. 解的确定

给定任意初始值 $a_0 = y(x_0)$ 和 $a_1 = y'(x_0)$，利用递推关系可唯一确定所有系数 $a_n$。因此存在唯一的解析解满足给定的初值条件。

### 5. 收敛性

可以证明（通过比较判别法或 Cauchy 估计），这样得到的幂级数的收敛半径至少为 $R$。$\square$

**示例**（Airy 方程）：$y'' - xy = 0$。设 $y = \sum_{n=0}^\infty a_n x^n$，代入得
$$\sum_{n=2}^\infty n(n-1)a_n x^{n-2} - \sum_{n=0}^\infty a_n x^{n+1} = 0$$
整理得 $a_2 = 0$，且对 $n \geq 1$，
$$(n+2)(n+1)a_{n+2} = a_{n-1}$$
可得 $a_{3n} = \frac{a_0}{2\cdot3\cdot5\cdot6\cdots(3n-1)(3n)}$ 等。解在整个实轴上收敛。
