# 几何级数求和公式

## 介绍

几何级数求和公式（Geometric Series Summation Formula）是级数理论中最基本的求和公式，给出了等比级数收敛时的和值。该公式由欧拉等数学家系统研究，是幂级数展开、傅里叶分析和生成函数等理论的基础工具。几何级数求和公式在物理、工程、金融和计算机科学中有着广泛应用。

## 分析

**前置依赖**：等比数列求和公式、极限

**定理内容**：设 $r$ 为实数，则几何级数 $\sum_{n=0}^\infty r^n$ 当 $|r| < 1$ 时收敛，且
$$\sum_{n=0}^\infty r^n = \frac{1}{1-r}$$

当 $|r| \ge 1$ 时，级数发散。

**数学内涵**：
几何级数是最简单的无穷级数，其收敛性完全由公比 $r$ 决定。当 $|r| < 1$ 时，部分和 $S_n = 1 + r + r^2 + \cdots + r^n = \frac{1-r^{n+1}}{1-r}$ 随 $n \to \infty$ 趋于 $\frac{1}{1-r}$，因为 $r^{n+1} \to 0$。该公式揭示了无穷过程（无穷求和）可以用有限表达式封闭表示，体现了级数理论的深刻思想。

**证明策略**：先求有限项部分和（等比数列求和公式），再取极限 $n \to \infty$。

## 思考过程

考虑前 $n+1$ 项部分和 $S_n = 1 + r + r^2 + \cdots + r^n$。两边乘以 $r$ 得 $rS_n = r + r^2 + \cdots + r^n + r^{n+1}$。两式相减得 $(1-r)S_n = 1 - r^{n+1}$，因此 $S_n = \frac{1-r^{n+1}}{1-r}$。当 $|r| < 1$ 时，$r^{n+1} \to 0$，故 $S_n \to \frac{1}{1-r}$。

## 证明过程

**定理**：几何级数 $\sum_{n=0}^\infty r^n$ 当 $|r| < 1$ 时收敛于 $\frac{1}{1-r}$，当 $|r| \ge 1$ 时发散。

**证明**：

**第一部分：$|r| < 1$ 时的收敛性**

考虑前 $n+1$ 项部分和：
$$S_n = 1 + r + r^2 + \cdots + r^n$$

两边乘以 $r$：
$$rS_n = r + r^2 + r^3 + \cdots + r^{n+1}$$

两式相减：
$$S_n - rS_n = 1 - r^{n+1}$$
$$(1-r)S_n = 1 - r^{n+1}$$

由于 $r \neq 1$（$|r| < 1$ 时自动成立），
$$S_n = \frac{1 - r^{n+1}}{1 - r}$$

当 $n \to \infty$ 时，由于 $|r| < 1$，有 $\lim_{n\to\infty} r^{n+1} = 0$，因此
$$\lim_{n\to\infty} S_n = \lim_{n\to\infty} \frac{1 - r^{n+1}}{1 - r} = \frac{1}{1 - r}$$

故级数收敛，且 $\sum_{n=0}^\infty r^n = \frac{1}{1-r}$。

**第二部分：$|r| \ge 1$ 时的发散性**

当 $|r| \ge 1$ 时，通项 $r^n$ 不趋于 $0$（$|r^n| \ge 1$），由级数收敛的必要条件（通项趋于 $0$）可知级数发散。

特别地，当 $r = 1$ 时，$S_n = n+1 \to \infty$；当 $r = -1$ 时，$S_n = 1, 0, 1, 0, \ldots$ 振荡，极限不存在。

$\square$
