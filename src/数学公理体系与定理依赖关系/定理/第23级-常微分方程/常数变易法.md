# 常数变易法

> **一句话大白话**：有了齐次方程的通解后，回答"右侧加了'外力'怎么办"：把解表达式里**原来固定的常数，变成随 $x$ 变化的函数**，代回方程把待定函数解出来——从"安静解"升级出"受迫解"。
>
> **小例子**：解 $y''+y=\sin x$，先得齐次解 $y=C_1\cos x+C_2\sin x$，把 $C_1,C_2$ 换成 $u_1(x),u_2(x)$ 代入，解出 $u_1,u_2$ 积分即可得到特解。

## 介绍

常数变易法（Method of Variation of Parameters）是求解非齐次线性常微分方程的一种重要方法，由法国数学家拉格朗日（Lagrange）在 18 世纪提出。该方法的核心思想是：将齐次方程解中的常数替换为待定函数，代入非齐次方程后通过积分确定这些函数，从而得到非齐次方程的特解。常数变易法不仅适用于一阶线性微分方程，也适用于高阶线性微分方程和线性微分方程组。它与待定系数法相比，适用范围更广（不要求非齐次项具有特殊形式），但计算可能更复杂。

## 分析

**前置依赖**：线性微分方程理论、齐次解、Wronskian。

**数学内涵**：
- 考虑一阶线性 ODE：$y' + p(x)y = q(x)$。
- 齐次方程 $y' + p(x)y = 0$ 的通解为 $y_h = Ce^{-\int p(x)dx}$。
- 常数变易法假设非齐次方程的解具有形式 $y = u(x)e^{-\int p(x)dx}$，代入原方程求解 $u(x)$。
- 对于高阶线性 ODE，方法类似：将齐次解中的常数替换为函数，利用 Cramer 法则求解。

**结构**：
1. 先求齐次方程的通解。
2. 将常数替换为待定函数。
3. 代入非齐次方程确定待定函数。
4. 得到非齐次方程的通解。

## 思考过程

常数变易法的想法非常自然：齐次方程的通解已经包含了所有的"自由度"（一个任意常数），而非齐次方程比齐次方程多了一个"外力"项 $q(x)$。为了描述这个外力的影响，我们允许这个"常数"随着 $x$ 变化——即将它替换为一个函数 $u(x)$。

代入原方程后，会出现一个关于 $u'(x)$ 的简单方程，直接积分即可得到 $u(x)$。这就是常数变易法的核心：将求解微分方程转化为求解一个更简单的积分。

## 证明过程

**定理**（常数变易法）：一阶线性非齐次微分方程
$$y' + p(x)y = q(x)$$
的通解为
$$y = e^{-\int p(x)dx}\left(\int q(x)e^{\int p(x)dx}dx + C\right)$$

**证明**：

### 1. 求解齐次方程

齐次方程 $y' + p(x)y = 0$ 是可分离变量的：
$$\frac{dy}{y} = -p(x)dx$$
积分得
$$\ln|y| = -\int p(x)dx + C$$
故齐次方程的通解为
$$y_h = Ce^{-\int p(x)dx}$$

### 2. 常数变易

设非齐次方程的解具有形式
$$y = u(x)e^{-\int p(x)dx}$$
其中 $u(x)$ 是待定函数。

### 3. 代入非齐次方程

计算导数：
$$y' = u'(x)e^{-\int p(x)dx} - u(x)p(x)e^{-\int p(x)dx}$$

代入原方程：
$$[u'(x)e^{-\int p(x)dx} - u(x)p(x)e^{-\int p(x)dx}] + p(x)[u(x)e^{-\int p(x)dx}] = q(x)$$

化简得：
$$u'(x)e^{-\int p(x)dx} = q(x)$$

### 4. 求解 $u(x)$

$$u'(x) = q(x)e^{\int p(x)dx}$$
积分得：
$$u(x) = \int q(x)e^{\int p(x)dx}dx + C$$

### 5. 得到通解

$$y = e^{-\int p(x)dx}\left(\int q(x)e^{\int p(x)dx}dx + C\right)$$

其中 $C$ 是任意常数。$\square$

**高阶线性微分方程的推广**：对 $n$ 阶线性非齐次方程
$$y^{(n)} + a_1(x)y^{(n-1)} + \cdots + a_n(x)y = f(x)$$
设齐次解为 $y_1, \ldots, y_n$，令特解为 $y_p = \sum_{i=1}^n u_i(x)y_i(x)$，其中 $u_i(x)$ 满足方程组
$$\begin{cases}
u_1'y_1 + u_2'y_2 + \cdots + u_n'y_n = 0 \\
u_1'y_1' + u_2'y_2' + \cdots + u_n'y_n' = 0 \\
\vdots \\
u_1'y_1^{(n-1)} + u_2'y_2^{(n-1)} + \cdots + u_n'y_n^{(n-1)} = f(x)
\end{cases}$$
由 Cramer 法则可解得 $u_i' = \frac{W_i(x)}{W(x)}$，其中 $W(x)$ 是 Wronskian，$W_i(x)$ 是将 $W(x)$ 的第 $i$ 列替换为 $(0, \ldots, 0, f(x))^T$ 所得的行列式。积分即得 $u_i(x)$。
