# 第120级-博弈论

本目录收录以下定理：

- [Nash均衡的存在性定理](./Nash均衡的存在性定理.md)
- [极小化极大定理](./极小化极大定理.md)
- [Shapley值的公理化刻画](./Shapley值的公理化刻画.md)
- [Nash讨价还价解](./Nash讨价还价解.md)
- [子博弈完美均衡的存在性](./子博弈完美均衡的存在性.md)
- [角谷不动点定理](./角谷不动点定理.md)：把一个凸紧集合“连续地”（允许多值、但取值是凸的且图像封闭）映回到它自己，一定存在一个点被映到自身——这就是集值版本的 Brouwer 不动点定理。
- [凸优化的可行与有界](./凸优化的可行与有界.md)：一个优化问题要么真有解、要么"没得玩"——"能否满足约束"（可行性）与"目标会不会一路掉到负无穷"（有界性）这两件事都有可检验的证书：可行性由 Farkas 引理给出，有界性由对偶问题的可行性刻画。
- [凸集与投影定理](./凸集与投影定理.md)：给定一个闭凸集合和一个集合内外的点，集合里存在**唯一**一个离它最近的点（投影），而且这个点由一条"夹角不小于直角"的不等式刻画。
- [欧氏空间中的紧性与 Heine-Borel 定理](./欧氏空间中的紧性与Heine-Borel定理.md)：在欧氏空间里，"紧"就是"有界且闭"——不会跑到无穷远，也不会漏掉自己的极限点，这两个条件合起来正好等价于紧致。
