# 诱导公式

## 介绍

诱导公式是三角函数中最基本的变换公式，描述了通过角度变换（如加减 $\pi/2$、$\pi$、$2\pi$ 等特殊角）后，三角函数值的变化规律。具体包括：$\sin(\pi/2 \pm \alpha) = \cos\alpha$、$\sin(\pi \pm \alpha) = \mp\sin\alpha$、$\cos(\pi \pm \alpha) = -\cos\alpha$ 等。这些公式可以将任意角的三角函数转化为锐角三角函数，是三角恒等变换和化简的基础工具。

## 分析

**前置依赖**：单位圆对称性、和角公式。

**定理内容**：对任意实数 $\alpha$，

- $\sin(\pi/2 + \alpha) = \cos\alpha$，$\sin(\pi/2 - \alpha) = \cos\alpha$
- $\cos(\pi/2 + \alpha) = -\sin\alpha$，$\cos(\pi/2 - \alpha) = \sin\alpha$
- $\sin(\pi + \alpha) = -\sin\alpha$，$\sin(\pi - \alpha) = \sin\alpha$
- $\cos(\pi + \alpha) = -\cos\alpha$，$\cos(\pi - \alpha) = -\cos\alpha$
- $\sin(2\pi - \alpha) = -\sin\alpha$，$\cos(2\pi - \alpha) = \cos\alpha$

**数学内涵**：
- 诱导公式本质上是单位圆上点对称性（关于原点、坐标轴、直线 $y=x$ 对称）的代数表达。
- 所有诱导公式可以统一为"奇变偶不变，符号看象限"的口诀。
- 诱导公式可以通过和角公式直接推导，也可通过单位圆的几何直观理解。

**证明策略**：
- 几何法：利用单位圆上点的对称性。
- 代数法：利用和角公式代入特殊角。

## 思考过程

诱导公式的核心在于理解单位圆上角度变化对应的坐标变换。以 $\sin(\pi/2 - \alpha) = \cos\alpha$ 为例：在单位圆上，点 $(\cos(\pi/2 - \alpha), \sin(\pi/2 - \alpha))$ 实际上是点 $(\cos\alpha, \sin\alpha)$ 关于直线 $y=x$ 的对称点，因此横纵坐标互换，即 $\cos(\pi/2 - \alpha) = \sin\alpha$，$\sin(\pi/2 - \alpha) = \cos\alpha$。

"奇变偶不变，符号看象限"这一口诀高度概括了所有诱导公式：当角度变化为 $\pi/2$ 的奇数倍时，函数名变为余函数（正弦变余弦，余弦变正弦）；当为偶数倍时，函数名不变。符号则由原角所在象限决定。

## 证明过程

**定理**（诱导公式）：对任意实数 $\alpha$，

$$
\sin(\pi/2 + \alpha) = \cos\alpha,\quad \sin(\pi/2 - \alpha) = \cos\alpha
$$
$$
\cos(\pi/2 + \alpha) = -\sin\alpha,\quad \cos(\pi/2 - \alpha) = \sin\alpha
$$
$$
\sin(\pi + \alpha) = -\sin\alpha,\quad \sin(\pi - \alpha) = \sin\alpha
$$
$$
\cos(\pi + \alpha) = -\cos\alpha,\quad \cos(\pi - \alpha) = -\cos\alpha
$$

**证明**（利用和角公式）：

在和角公式中代入 $\beta = \pi/2$：

$$
\sin(\pi/2 + \alpha) = \sin(\pi/2)\cos\alpha + \cos(\pi/2)\sin\alpha = 1 \cdot \cos\alpha + 0 \cdot \sin\alpha = \cos\alpha
$$

$$
\cos(\pi/2 + \alpha) = \cos(\pi/2)\cos\alpha - \sin(\pi/2)\sin\alpha = 0 \cdot \cos\alpha - 1 \cdot \sin\alpha = -\sin\alpha
$$

同理，代入 $\beta = \pi$：

$$
\sin(\pi + \alpha) = \sin\pi\cos\alpha + \cos\pi\sin\alpha = 0 \cdot \cos\alpha + (-1) \cdot \sin\alpha = -\sin\alpha
$$

$$
\cos(\pi + \alpha) = \cos\pi\cos\alpha - \sin\pi\sin\alpha = (-1) \cdot \cos\alpha - 0 \cdot \sin\alpha = -\cos\alpha
$$

其余公式类似可得。$\square$

**证明**（几何法——单位圆对称性）：

在单位圆上，角度 $\alpha$ 对应点 $P(\cos\alpha, \sin\alpha)$。

- $\pi/2 - \alpha$ 对应点 $Q(\cos(\pi/2 - \alpha), \sin(\pi/2 - \alpha))$，它是 $P$ 关于直线 $y = x$ 的对称点，故坐标互换：$\cos(\pi/2 - \alpha) = \sin\alpha$，$\sin(\pi/2 - \alpha) = \cos\alpha$。
- $\pi + \alpha$ 对应点 $R(\cos(\pi + \alpha), \sin(\pi + \alpha))$，它是 $P$ 关于原点的对称点，故坐标取反：$\cos(\pi + \alpha) = -\cos\alpha$，$\sin(\pi + \alpha) = -\sin\alpha$。

$\square$
