# 学习路线总览

本教程按学习阶段与难度递进编排，共 **9 个学习阶段、151 个层级**。同一阶段内，不同数学分支的平行主题同步学习，体现各分支之间的内在联系。总体递进路线如下：

```
第一阶段  初等数学 ────────────────────────────────── 第 1-8 级
    ↓
第二阶段  微积分与线性代数 ────────────────────────── 第 9-16 级
    ↓
第三阶段  核心理论（分析·代数·拓扑·ODE·概率·离散·逻辑）─── 第 17-30 级
    ↓
第四阶段  进阶理论（分析·代数·几何·拓扑·PDE·动力系统）─── 第 31-52 级
    ↓
┌─────────────────────────────────────────────────────┐
│                第五阶段·第六阶段                      │
│  ┌─────────────────┐  ┌─────────────────────────┐    │
│  │ 高阶专题 I       │  │ 高阶专题 II              │    │
│  │ 分析·几何·统计   │  │ 代数·数论·离散数学       │    │
│  │ 第 53-71 级      │  │ 第 72-91 级              │    │
│  └─────────────────┘  └─────────────────────────┘    │
└─────────────────────────────────────────────────────┘
    ↓
第七阶段  应用数学 ────────────────────────────────── 第 92-121 级
    ↓
第八阶段  数学基础深化 ────────────────────────────── 第 122-130 级
    ↓
第九阶段  现代数学前沿 ────────────────────────────── 第 131-151 级
```

各阶段包含的具体层级如下：

- **第一阶段 · 初等数学**（第 1-8 级）：算术、代数、几何、三角、解析几何、排列组合与概率初步
- **第二阶段 · 微积分与线性代数**（第 9-16 级）：集合论、极限、单/多变量微积分、级数、线性代数
- **第三阶段 · 核心理论**（第 17-30 级）：实变/复变、抽象代数、拓扑、ODE、概率与统计、数论、图论、逻辑
- **第四阶段 · 进阶理论**（第 31-52 级）：泛函分析、测度论、微分几何、代数拓扑、PDE、动力系统
- **第五阶段 · 高阶专题 I**（第 53-71 级）：分析、几何与统计的专门化主题
- **第六阶段 · 高阶专题 II**（第 72-91 级）：代数、数论与离散数学的专门化主题
- **第七阶段 · 应用数学**（第 92-121 级）：概率统计深化与各应用数学分支
- **第八阶段 · 数学基础深化**（第 122-130 级）：公理集合论、模型论、递归论、证明论、范畴论
- **第九阶段 · 现代数学前沿**（第 131-151 级）：现代数学前沿领域与交叉应用
