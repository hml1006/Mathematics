# 第59级-几何分析

> 一句话级别概述：用非线性偏微分方程研究几何结构（曲率流、极小曲面、调和映射与正质量），是微分几何与偏微分方程的前沿交汇。

## 级别简介

几何分析结合黎曼几何与椭圆型/抛物型方程，研究度量在曲率流下的演化、面积临界超曲面与调和映射的存在正则性，以及广义相对论中的质量正性。核心方向包括平均曲率流、Yamabe 问题、正质量定理与几何不等式。

## 本级别定理

- [Gromov-Hausdorff 收敛](./Gromov-Hausdorff收敛.md)：度量空间序列收敛与塌缩的测定。
- [Yamabe 问题](./Yamabe问题.md)：找共形度量使数量曲率常值。
- [平均曲率流](./平均曲率流.md)：超曲面沿平均曲率方向的演化。
- [曲率估计与单调公式](./曲率估计与单调公式.md)：几何流中的微分估计与单调量。
- [极小曲面理论](./极小曲面理论.md)：面积临界超曲面的存在与正则性。
- [正质量定理](./正质量定理.md)：渐近平空间中质量度量非负。
- [调和映射存在性](./调和映射存在性.md)：能量极小调和映射的存在与正则。

## 前置知识

依赖黎曼几何（曲率张量、测地线、比较定理）、椭圆型偏微分方程与正则理论、非线性泛函分析的变分法，以及李群李代数提供的对称工具。

## 后继用途

为 Ricci 流与 Poincaré 猜想（Perelman）、高维几何流、谱几何及广义相对论的整体分析提供基础。

## 关键定理速览

- Yamabe 问题：共形几何与非线性方程可解性的典范。
- 平均曲率流：几何流工具，用于证明球面定型定理。
- 正质量定理：广义相对论能量正性的几何证明。
- 调和映射与极小曲面：以变分判据产生几何对象。
