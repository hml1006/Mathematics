# ZFC集合论公理

## 概述

ZFC 集合论是数学的基础公理体系，由 Zermelo-Fraenkel 集合论（ZF）加上**选择公理（Axiom of Choice, AC）**组成。它构成了现代数学的基石，几乎所有数学对象都可以在 ZFC 框架内定义和推导。

ZFC 公理体系的目的在于：用严格的形式化语言刻画"集合"这一基本概念，避免朴素集合论中出现的悖论（如 Russell 悖论），为数学提供一个稳固、无矛盾的基础。

## 发展历史

- **1908年**：Ernst Zermelo 提出第一版集合论公理，旨在证明良序定理
- **1922年**：Abraham Fraenkel 和 Thoralf Skolem 独立提出替换公理模式，完善了 ZF 体系
- **1930年**：ZFC 公理体系基本定型
- **1963年**：Paul Cohen 证明选择公理和连续统假设的独立性

## 公理之间的关系

- **外延公理**定义了集合相等的标准，是集合论中最为基本的约定
- **空集公理**确保了集合论至少有一个对象
- **配对公理**、**并集公理**、**幂集公理**提供了构造新集合的基本操作
- **无穷公理**保证了无限集合的存在，使自然数集的构造成为可能
- **分离公理模式**和**替换公理模式**是一阶逻辑公式的无穷族，分别限制了子集和像集的合法存在
- **正则公理**禁止了非良基集合（如 x∈x），使 ∈ 关系成为良基关系
- **选择公理**独立于 ZF 系统，是数学中最具争议也最具威力的公理

## 一致性

Gödel 第二不完全性定理表明，ZFC 的一致性不能在 ZFC 内部证明，但 ZFC 在数学实践中被广泛接受为一致的基础框架。
