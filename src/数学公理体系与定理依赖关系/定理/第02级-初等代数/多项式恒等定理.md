# 多项式恒等定理

> **一句话大白话**：多项式"很较真"——只要在足够多的点上取值一样（次数加一个点就够），它就真的完全一样，连系数都对得上。
>
> **小例子**：两个一次多项式 $px+q$ 如果取 $x=0$ 和 $x=1$ 时的值都相等，那它们就是同一个式子；反之一个非零的 $n$ 次多项式最多只有 $n$ 个根，绝不会平白多出一个。

## 介绍

多项式恒等定理是代数学中的一个基本结论：如果两个次数不超过 $n$ 的多项式在 $n+1$ 个不同的点上取值相等，那么它们必然恒等（即所有对应系数相等）。这一结论是多项式理论的基石，也是拉格朗日插值法、多项式逼近等数值方法的理论依据。它揭示了多项式作为函数的"刚性"——多项式函数的取值完全由其在足够多点上的取值唯一确定。

## 分析

**前置依赖**：因式定理、数学归纳法。

**定理内容**：设 $f(x)$ 和 $g(x)$ 是两个次数不超过 $n$ 的多项式（系数属于某个数域）。若存在 $n+1$ 个互不相同的数 $x_0, x_1, \ldots, x_n$ 使得 $f(x_i) = g(x_i)$ 对所有 $i = 0, 1, \ldots, n$ 成立，则 $f(x) \equiv g(x)$（即 $f$ 和 $g$ 的所有对应系数相等）。

**数学内涵**：
- 该定理的等价表述是：一个非零的 $n$ 次多项式至多有 $n$ 个不同的根。
- 这反映了多项式作为代数对象的离散确定性——不同于一般函数，多项式的值在足够多的点确定后即完全确定。
- 定理的证明依赖于因式定理：若 $a$ 是多项式 $h(x)$ 的根，则 $(x-a)$ 整除 $h(x)$。

**结构**：
1. 考虑差多项式 $h(x) = f(x) - g(x)$，其次数不超过 $n$。
2. $h(x)$ 有 $n+1$ 个不同的根 $x_0, \ldots, x_n$。
3. 由因式定理，$h(x)$ 可被 $(x-x_0)(x-x_1)\cdots(x-x_n)$ 整除，但此乘积次数为 $n+1$，故 $h(x) \equiv 0$，即 $f \equiv g$。

## 思考过程

多项式恒等定理的直观理解是：一个 $n$ 次多项式由 $n+1$ 个系数决定，因此提供 $n+1$ 个独立的方程（即 $n+1$ 个点的函数值）应该足以唯一确定这些系数。这类似于线性代数中 $n+1$ 个未知数需要 $n+1$ 个方程来求解。

证明的思路非常直接：如果两个多项式在 $n+1$ 个点上相等，那么它们的差 $h(x) = f(x) - g(x)$ 在这些点上为零。如果 $h(x)$ 不是零多项式，那么它的次数 $\deg(h) \leq n$，但它却至少有 $n+1$ 个不同的根。由因式定理，每个根对应一个一次因式，那么 $h(x)$ 至少被 $n+1$ 个互质的一次因式的乘积整除，这个乘积的次数为 $n+1$，因此 $h(x) \equiv 0$，矛盾。

## 证明过程

**定理**：设 $f(x)$ 和 $g(x)$ 是次数不超过 $n$ 的多项式。若存在 $n+1$ 个互不相同的数 $x_0, x_1, \ldots, x_n$ 使得 $f(x_i) = g(x_i)$（$i = 0, 1, \ldots, n$），则 $f(x) \equiv g(x)$。

**证明**：

令 $h(x) = f(x) - g(x)$。则 $h(x)$ 的次数不超过 $n$，且对每个 $i = 0, 1, \ldots, n$，有 $h(x_i) = f(x_i) - g(x_i) = 0$。

若 $h(x) \not\equiv 0$，设 $\deg(h) = m \leq n$。由因式定理，$x - x_0$ 整除 $h(x)$，即 $h(x) = (x - x_0)h_1(x)$，其中 $\deg(h_1) = m-1$。由于 $h(x_1) = 0$ 且 $x_1 \neq x_0$，有 $h_1(x_1) = 0$，故 $x - x_1$ 整除 $h_1(x)$。重复此过程，得到

$$
h(x) = (x - x_0)(x - x_1)\cdots(x - x_{m-1})h_m(x)
$$

其中 $h_m(x)$ 是常数多项式（次数为 $0$）。由于 $h(x_m) = 0$，若 $h_m(x) \neq 0$，则 $x_m$ 必为 $x_0, \ldots, x_{m-1}$ 之一，矛盾。故 $h_m(x) \equiv 0$，从而 $h(x) \equiv 0$。

但更直接地，由于 $h(x)$ 有 $n+1$ 个不同的根，而 $h(x)$ 的次数不超过 $n$，由因式定理，$h(x)$ 可被 $\prod_{i=0}^n (x - x_i)$ 整除（该乘积次数为 $n+1$）。若 $h(x) \not\equiv 0$，则 $\deg(h) \geq n+1$，与 $\deg(h) \leq n$ 矛盾。故 $h(x) \equiv 0$，即 $f(x) \equiv g(x)$。$\square$

---

**推论**：一个非零的 $n$ 次多项式至多有 $n$ 个不同的根。
