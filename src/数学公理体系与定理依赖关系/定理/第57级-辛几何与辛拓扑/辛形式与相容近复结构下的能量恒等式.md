# 辛形式与相容近复结构下的能量恒等式

> **一句话大白话**：若近复结构 $J$ 与辛形式 $\omega$ 相容，那么一条 $J$-全纯曲线用辛形式"量出的面积"和用度量"量出的能量"完全相等；而且对任何曲线，辛面积总不超过度量能量，取等号当且仅当曲线是全纯的。

> **小例子**：$\mathbb C^n$ 上取标准 $\omega_0=\frac{\sqrt{-1}}{2}\sum_kdz_k\wedge d\bar z_k$ 与标准 $J_0$。若 $u:\Sigma\to\mathbb C^n$ 全纯，则第一分量写 $u_1(w)$ 后 $u^*\omega$ 的系数恰为 $|(u_1)_w|^2+\cdots$，与 $\frac12|du|^2\,dA$ 逐点相等。而对 $u(w)=\bar w$（反全纯），辛面积变成 $-\frac12|du|^2\,dA$，符号相反——所以全纯与反全纯的方向由 $\omega$ 区分。

## 一、定理介绍

> **前置依赖**：辛流形基本理论、Cauchy-Riemann方程、Gromov单调性引理、Stokes定理流形形式

设 $(M,\omega)$ 是辛流形，$J$ 是与 $\omega$ **相容**的近复结构，即

$$g(X,Y):=\omega(X,JY)$$

是对称正定的（从而 $g$ 是 $M$ 上的 Riemann 度量，且 $J$ 是 $g$-等距）。相容三元组 $(\omega,J,g)$ 称为一个**近 Kähler 结构**，Kähler 流形就是 $J$ 可积、$\omega$ 闭的情形。

能量恒等式说的是：对伪全纯曲线 $u:(\Sigma,j)\to(M,J)$（即 $\bar\partial_Ju=0$），其**辛能量**与**度量能量**逐点相等：

$$u^*\omega=\tfrac12|du|_g^2\,dA_j,\qquad\text{于是}\qquad E(u):=\int_\Sigma u^*\omega=\tfrac12\int_\Sigma|du|^2\,dA .$$

两个后果使这条恒等式成为辛拓扑的枢纽。其一，左端是闭形式 $\omega$ 沿 $u$ 的拉回，由 Stokes定理只依赖同调类 $[u_*[\Sigma]]$，所以 $J$-全纯曲线的能量被拓扑量 $\langle[\omega],[u]\rangle$ 控制，模空间因而是"能量受控"的（这正是 Gromov 紧性定理的前提，也是 Gromov单调性引理中比较两个不同半径能量的依据）。其二，上式右侧是度量下的面积（当 $\Sigma$ 是 Riemann 面、$u$ 是浸入时），所以**$\omega$ 标定（calibrate）了所有 $J$-全纯曲线**，它们在各自同调类中面积最小。Gromov 正是用这一点建立了伪全纯曲线与辛嵌入、非挤压定理之间的联系。

## 二、原理思路

1. **逐点线性代数**：$J$-全纯性只是一个逐点的一阶条件：$du\circ j=J\circ du$。因此在一点只需验证恒等式对线性映射成立，与整体形状无关。

2. **取标准标架**：在 $M$ 的切空间取 $g$-正交规范标架使 $J$ 化为标准复结构；在 $\Sigma$ 上取等温坐标使 $j$ 化为 $90^\circ$ 旋转。此时 $du$ 成为一个"复线性"的矩阵（或反复线性，取决于定向），恒等式化为一个矩阵计算。

3. **不等式的来源**：$\omega(du\,\partial_s,du\,\partial_t)=\langle du\,\partial_s,J\,du\,\partial_t\rangle_g\le|du\,\partial_s|\,|du\,\partial_t|$（Cauchy–Schwarz），再用 $2ab\le a^2+b^2$。等号成立的条件是 $du\,\partial_t=J\,du\,\partial_s$，即全纯性。

4. **整体化**：逐点等式两边都是 $2$-形式，在等温坐标下面积元为 $dA$，故可直接对 $\Sigma$ 积分；再用 Stokes定理把左端化为拓扑量。

## 三、定理的严格表述

**设定**：设 $(M^{2n},\omega)$ 是辛流形，$J$ 是 $\omega$-相容近复结构，$g=\omega(\cdot,J\cdot)$ 为相应 Riemann 度量。设 $(\Sigma^2,j)$ 是 Riemann 面，$u:\Sigma\to M$ 是光滑映射，$\omega$ 沿 $u$ 的拉回记为

$$u^*\omega\quad(\text{a }2\text{-form on }\Sigma).$$

记 $E_\omega(u)=\int_\Sigma u^*\omega$（**辛能量**），$E_g(u)=\frac12\int_\Sigma|du|_g^2\,dA_j$（**度量能量**，$dA_j$ 为 $j$ 对应的面积元）。

**定理（能量恒等式）**：若 $u$ 是 $J$-全纯的，即 $du\circ j=J\circ du$，则

$$u^*\omega=\tfrac12|du|_g^2\,dA_j,\qquad\text{从而}\qquad E_\omega(u)=E_g(u).$$

**定理（标定不等式）**：对任意光滑映射 $u:\Sigma\to M$，

$$u^*\omega\le\tfrac12|du|_g^2\,dA_j\quad(\text{逐点，作为 }2\text{-形式})，$$

等号处处成立当且仅当 $u$ 是 $J$-全纯（或 $J$-反全纯，取决于 $\Sigma$ 的定向）。因此

$$E_\omega(u)\le E_g(u),$$

即 $J$-全纯曲线在给定辛能量的前提下使度量能量（面积）达到最小。

**推论 1（拓扑不变性）**：因 $d\omega=0$，$u^*\omega$ 是闭形式，其积分只依赖 $u$ 的同调类：若 $u,u'$ 同伦且诱导相同的 $H_2$ 类，则 $E_\omega(u)=E_\omega(u')$；特别地 $E_\omega(u)=\langle[\omega],[u_*[\Sigma]]\rangle$。于是 $J$-全纯曲线满足

$$E(u)=\langle[\omega],[u]\rangle,$$

能量是纯拓扑量。

## 四、证明过程

**步骤 1：逐点化归为标准形式。**

固定 $p\in\Sigma$、$m=u(p)\in M$。在 $T_mM$ 取 $g$-正交规范基 $e_1,\ldots,e_{2n}$ 使 $Je_{2k-1}=e_{2k}$（相容性保证这样的基存在：$J$ 是 $g$-正交的且 $J^2=-\mathrm{id}$）。在 $p$ 附近取 $\Sigma$ 的等温坐标 $w=s+it$，即 $j\partial_s=\partial_t$、$j\partial_t=-\partial_s$，度量局部为 $\lambda^2(ds^2+dt^2)$（$\lambda>0$），相应地

$$dA_j=\lambda^2\,ds\wedge dt .$$

以下在点 $p$ 处计算（所有量均在该点取值）。

**步骤 2：$J$-全纯性写成标架关系。**

$J$-全纯条件 $du\circ j=J\circ du$ 作用于 $\partial_s$ 给出

即在切空间中 $du(\partial_t)=du(j\partial_s)=J\,du(\partial_s)$，两个偏导向量相差一个 $J$。

**步骤 3：计算 $u^*\omega$。**

按定义 $u^*\omega(\partial_s,\partial_t)=\omega\bigl(du(\partial_s),du(\partial_t)\bigr)$。用步骤 2 与 $g=\omega(\cdot,J\cdot)$ 的相容性：

$$\omega\bigl(du\,\partial_s,\,du\,\partial_t\bigr)=\omega\bigl(du\,\partial_s,\,J\,du\,\partial_s\bigr)=g\bigl(du\,\partial_s,du\,\partial_s\bigr)=\bigl|du\,\partial_s\bigr|_g^2 .$$

另一方面，由 $\{\partial_s,\partial_t\}$ 关于度量 $\lambda^2(ds^2+dt^2)$ 正交且模长均为 $\lambda$，$|du|_g^2$ 定义为 $\sum$ 对规范正交标架的收缩，直接计算得

$$|du|_g^2=\lambda^{-2}\bigl(|du\,\partial_s|_g^2+|du\,\partial_t|_g^2\bigr)=\lambda^{-2}\cdot2\bigl|du\,\partial_s\bigr|_g^2,$$

最后一步用步骤 2 与 $J$ 的等距性：$|du\,\partial_t|_g=|J\,du\,\partial_s|_g=|du\,\partial_s|_g$。于是

$$\tfrac12|du|_g^2\,dA_j=\tfrac12\cdot\lambda^{-2}\cdot2|du\,\partial_s|_g^2\cdot\lambda^2\,ds\wedge dt=|du\,\partial_s|_g^2\,ds\wedge dt.$$

与 $u^*\omega(\partial_s,\partial_t)\,ds\wedge dt=|du\,\partial_s|_g^2\,ds\wedge dt$ 比较，得

$$u^*\omega=\tfrac12|du|_g^2\,dA_j .$$

由于 $p$ 任意，恒等式在整个 $\Sigma$ 上成立。$\square$

**步骤 4：标定不等式与等号条件。**

对任意（不必全纯的）$u$，仍有 $u^*\omega(\partial_s,\partial_t)=\omega(du\,\partial_s,du\,\partial_t)=g(du\,\partial_s,J\,du\,\partial_t)$。由 Cauchy–Schwarz 与 $J$ 的等距性

$$u^*\omega(\partial_s,\partial_t)\le|du\,\partial_s|_g\cdot|J\,du\,\partial_t|_g=|du\,\partial_s|_g\cdot|du\,\partial_t|_g\le\tfrac12\bigl(|du\,\partial_s|_g^2+|du\,\partial_t|_g^2\bigr).$$

再用步骤 3 的关系 $\tfrac12(|du\,\partial_s|^2+|du\,\partial_t|^2)=\tfrac12|du|_g^2\cdot\lambda^2$，把上式写成形式等式

$$\omega(du\,\partial_s,du\,\partial_t)\,ds\wedge dt\le\tfrac12|du|_g^2\,dA_j,\qquad\text{即}\qquad u^*\omega\le\tfrac12|du|_g^2\,dA_j .$$

等号成立要求两次不等式的等号都成立：第一次要求 $du\,\partial_t$ 与 $J\,du\,\partial_s$ 同方向且模长相等；第二次要求 $|du\,\partial_s|=|du\,\partial_t|$。二者合起来给出 $du\,\partial_t=J\,du\,\partial_s$，即 $du\circ j=J\circ du$，即 $u$ 全纯（若 $\Sigma$ 定向取反则为反全纯）。$\square$

**步骤 5：积分与拓扑不变性。**

对步骤 3 的逐点等式在 $\Sigma$ 上积分得 $E_\omega(u)=E_g(u)$。其次，因 $\omega$ 闭（$d\omega=0$），$u^*\omega$ 也闭（$d(u^*\omega)=u^*(d\omega)=0$）且 $u^*\omega$ 是 $\Sigma$（二维）上的顶形式，故由 Stokes定理，其积分在 $u$ 的连续形变（同伦）下不变，只依赖 $u_*[\Sigma]\in H_2(M;\mathbb R)$：

$$E_\omega(u)=\int_\Sigma u^*\omega=\int_{u_*[\Sigma]}\omega=\langle[\omega],[u_*[\Sigma]]\rangle .$$

于是对 $J$-全纯曲线，能量 $E(u)=\langle[\omega],[u]\rangle$ 由同调类决定，从而在模空间中一致有界；这正是 Gromov紧性定理能够对模空间的曲线作统一分析的起点，也是 Gromov单调性引理中把"圆盘上的能量"与"固定几何量"相比较的依据。此外，对参数域的分解 $\Sigma=\bigsqcup_kA_k$，$E_\omega(u)=\sum_k\int_{A_k}u^*\omega$；由步骤 3–4，每一项 $\ge0$（当 $u$ 全纯时恰等于该块上的度量能量）。故 $E$（作为集合函数）是**可加的**，从而在半径单调递减的圆盘上有 $E(u|_{D_r})$ 随 $r$ 递减且 $\lim_{r\downarrow0}E(u|_{D_r})=0$（对能量有限的曲线）。这给出"能量集中在有限个点"的精确含义，也是可去奇点定理与气泡分析的能量侧输入。$\square$

## 五、应用与意义

能量恒等式把辛能量与度量能量等同起来，是 Gromov 理论中一切能量估计的起点：模空间中曲线的能量由同调类 $\langle[\omega],[u]\rangle$ 控制，故只有有限多种可能的气泡结构；标定性质说明 $J$-全纯曲线在其同调类中面积最小，这是 Gromov 非挤压定理与辛容量理论的核心论证，也是 Floer 同调、Gromov–Witten 不变量与镜像对称中"计数全纯曲线"的合法性来源。
