# 乌雷松引理

## 介绍

乌雷松引理（Urysohn's Lemma）是点集拓扑学中关于正规空间的基本定理，它断言在正规空间中，任意两个不相交的闭集可以被一个连续函数分离。具体来说，若 $A$ 和 $B$ 是正规空间 $X$ 中的两个不相交闭集，则存在连续函数 $f: X \to [0, 1]$ 使得 $f(A) = 0$ 且 $f(B) = 1$。这一结论看似直观，但其证明巧妙地利用了正规性公理和有理数的稠密性。乌雷松引理是度量空间理论中的乌雷松嵌入定理（任何正规空间可嵌入到 Hilbert 立方体）的基础，也是蒂茨扩张定理的前提。

## 分析

**前置依赖**：正规空间的定义（任意两个不相交闭集有不相交开邻域）、拓扑空间、连续函数。

**数学内涵**：
- 乌雷松引理将拓扑性质（正规性）与分析性质（连续函数的存在性）联系起来。
- 定理的证明通过构造一族开集 $\{U_r\}_{r \in \mathbb{Q} \cap [0,1]}$，使得 $A \subseteq U_0$，$B \subseteq X \setminus U_1$，且当 $r < s$ 时 $\overline{U_r} \subseteq U_s$。
- 然后定义 $f(x) = \inf\{r \in \mathbb{Q} \cap [0,1] \mid x \in U_r\}$，可证明 $f$ 连续且满足 $f(A)=0$，$f(B)=1$。

**结构**：
1. 利用正规性递归构造开集族 $\{U_r\}$。
2. 验证该开集族满足闭包包含关系。
3. 定义函数 $f$ 并证明连续性。
4. 验证边界条件。

## 思考过程

乌雷松引理的证明是拓扑学中最精巧的构造之一。基本想法是：利用正规性，我们可以将闭集"逐渐分离"。具体来说，如果 $A$ 和 $B$ 是不相交闭集，由正规性存在开集 $U$ 使 $A \subseteq U \subseteq \overline{U} \subseteq X \setminus B$。这相当于将 $A$ 和 $B$ 分离了一层"壳"。

如果我们记 $U_1 = X \setminus B$，$U_0 = U$，则 $A \subseteq U_0 \subseteq \overline{U_0} \subseteq U_1$。现在对 $U_0$ 和 $X \setminus U_1$（注意这两个集合不相交且闭）再次应用正规性，可以得到 $U_{1/2}$ 使得 $A \subseteq U_0 \subseteq \overline{U_0} \subseteq U_{1/2} \subseteq \overline{U_{1/2}} \subseteq U_1$。如此反复，可以对所有二进有理数构造开集。

更一般地，对有理数 $r \in [0,1]$ 构造开集 $U_r$，使得 $r < s$ 时 $\overline{U_r} \subseteq U_s$。然后定义 $f(x) = \inf\{r \mid x \in U_r\}$，这实际上是在度量 $x$ 与 $B$ 的"距离"——如果 $x$ 越靠近 $A$，则需要越小的 $r$ 才能包含 $x$。

## 证明过程

**定理**（乌雷松引理）：设 $X$ 是正规拓扑空间，$A, B \subseteq X$ 是不相交的闭集。则存在连续函数 $f: X \to [0, 1]$，使得 $f(A) = 0$，$f(B) = 1$。

**证明**：

### 第一步：构造开集族

令 $U_1 = X \setminus B$，则 $A \subseteq U_1$ 且 $U_1$ 是开集。由正规性，存在开集 $U_0$ 使得
$$A \subseteq U_0 \subseteq \overline{U_0} \subseteq U_1$$

设 $\mathbb{D} = \left\{\frac{k}{2^n} \mid n \in \mathbb{N}, 0 \leq k \leq 2^n\right\}$ 是 $[0,1]$ 中的二进有理数集。我们递归地构造开集 $\{U_r\}_{r \in \mathbb{D}}$ 满足：
1. $A \subseteq U_0$，$\overline{U_0} \subseteq U_1$。
2. 对 $r < s$，$\overline{U_r} \subseteq U_s$。

假设已对分母为 $2^{n-1}$ 的二进有理数构造完成。对 $r = \frac{2k+1}{2^n}$，考虑 $p = \frac{k}{2^{n-1}}$ 和 $q = \frac{k+1}{2^{n-1}}$，则 $p < r < q$ 且 $\overline{U_p} \subseteq U_q$。由正规性，存在开集 $U_r$ 使得
$$\overline{U_p} \subseteq U_r \subseteq \overline{U_r} \subseteq U_q$$

由归纳法，对所有 $r \in \mathbb{D}$ 构造完成。

### 第二步：定义函数

对 $x \in X$，定义
$$f(x) = \inf\{r \in \mathbb{D} \mid x \in U_r\}$$

其中约定 $\inf \varnothing = 1$。由于 $A \subseteq U_0$，对 $x \in A$ 有 $f(x) = 0$。对 $x \in B$，$x \notin U_1$，故 $x \notin U_r$ 对任意 $r \leq 1$，从而 $f(x) = 1$。因此 $f(A) = 0$，$f(B) = 1$。

### 第三步：证明连续性

只需证明对任意 $a \in (0, 1)$，集合 $f^{-1}([0, a))$ 和 $f^{-1}((a, 1])$ 是开集。

首先，$f(x) < a$ 当且仅当存在 $r \in \mathbb{D}$ 使得 $r < a$ 且 $x \in U_r$。因此
$$f^{-1}([0, a)) = \bigcup_{r < a,\ r \in \mathbb{D}} U_r$$
这是开集的并，故为开集。

其次，$f(x) > a$ 当且仅当存在 $s \in \mathbb{D}$ 使得 $s > a$ 且 $x \notin U_s$。由于 $\mathbb{D}$ 稠密，存在 $t \in \mathbb{D}$ 使得 $a < t < s$，则 $\overline{U_t} \subseteq U_s$，从而 $X \setminus \overline{U_t}$ 是包含 $x$ 的开集且 $f$ 在其上大于 $a$。因此
$$f^{-1}((a, 1]) = \bigcup_{s > a,\ s \in \mathbb{D}} (X \setminus \overline{U_s})$$
也是开集。

由于 $[0, a)$ 和 $(a, 1]$ 构成 $[0, 1]$ 的子基，$f$ 连续。$\square$
