# 圆的标准方程

## 介绍

圆的标准方程是解析几何中描述圆的基本形式：圆心为 $(a, b)$、半径为 $r$ 的圆的方程为 $(x - a)^2 + (y - b)^2 = r^2$。该方程是圆的定义（到定点距离等于定长的点的轨迹）在坐标平面中的代数表达。

## 分析

**前置依赖**：两点间距离公式。

**定理内容**：圆心为 $C(a, b)$、半径为 $r$ 的圆的方程为 $(x - a)^2 + (y - b)^2 = r^2$。

## 思考过程

圆的定义在几何中非常简单：**到定点（圆心）的距离等于定长（半径）的所有点的集合**。将这个定义翻译成代数语言，就是解析几何中建立曲线方程的标准方法——轨迹法。

设在平面上有一动点 $P(x, y)$，它满足到定点 $C(a, b)$ 的距离恒等于 $r$。根据两点间距离公式，这一几何条件可以立即写为 $\sqrt{(x - a)^2 + (y - b)^2} = r$，两边平方后便得到标准方程 $(x - a)^2 + (y - b)^2 = r^2$。

**标准方程与一般方程的互化**是学习圆的重要内容。将标准方程展开可得：
$$
(x - a)^2 + (y - b)^2 = r^2 \implies x^2 + y^2 - 2ax - 2by + (a^2 + b^2 - r^2) = 0
$$
令 $D = -2a$，$E = -2b$，$F = a^2 + b^2 - r^2$，即得一般形式 $x^2 + y^2 + Dx + Ey + F = 0$。

反过来，对一般方程通过**配方法**可以化为标准方程：
$$
x^2 + y^2 + Dx + Ey + F = 0 \implies (x + \frac{D}{2})^2 + (y + \frac{E}{2})^2 = \frac{D^2 + E^2 - 4F}{4}
$$
由此可读出圆心为 $(-\frac{D}{2}, -\frac{E}{2})$，半径为 $r = \frac{1}{2}\sqrt{D^2 + E^2 - 4F}$。当 $D^2 + E^2 - 4F = 0$ 时，方程表示一个点（半径为 0 的退化圆）；当 $D^2 + E^2 - 4F < 0$ 时，方程不表示任何实图形（虚圆）。

## 证明过程

**证明**：设 $P(x, y)$ 是圆上任意一点，由圆的定义，$P$ 到圆心 $C(a, b)$ 的距离等于半径 $r$。由两点间距离公式得 $\sqrt{(x - a)^2 + (y - b)^2} = r$，两边平方即得 $(x - a)^2 + (y - b)^2 = r^2$。$\square$

**一般形式**：$x^2 + y^2 + Dx + Ey + F = 0$，其中 $D = -2a$，$E = -2b$，$F = a^2 + b^2 - r^2$。
