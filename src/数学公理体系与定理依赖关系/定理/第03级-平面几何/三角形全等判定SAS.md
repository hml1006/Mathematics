# 三角形全等判定 SAS

> **一句话大白话**：两个三角形"两边和它们夹着的角"对应相等，那它们就全等——就像固定住两条边和夹角，第三边就被唯一"咬死"了。
>
> **小例子**：$\triangle ABC$ 与 $\triangle DEF$ 中若 $AB=DE$、$\angle A=\angle D$、$AC=DF$，则两三角形全等。（注意：光有"两边加一边的对角"SSA 可不行哦。）

## 介绍

SAS（Side-Angle-Side，边角边）全等判定定理是三角形全等的基本判定定理之一：如果两个三角形的两边及其夹角分别对应相等，则这两个三角形全等。SAS 判定在 Hilbert 公理体系中常被作为合同公理直接给出（即"若两个三角形有两边及其夹角对应相等，则其余对应角和边也对应相等"），其他全等判定（SSS、ASA）可以由此推导出来。

## 分析

**前置依赖**：合同公理。

**定理内容**：在 $\triangle ABC$ 和 $\triangle DEF$ 中，若 $AB = DE$，$\angle A = \angle D$，$AC = DF$，则 $\triangle ABC \cong \triangle DEF$。

**数学内涵**：
- SAS 是三角形全等判定中最基本的条件之一，它在很多公理体系中直接作为公理出现。
- 夹角必须是两条边的夹角——如果对应的是"两边及其中一边的对角"（SSA），则不能判定全等（存在"ambiguous case"）。
- SAS 判定定理是"三角形稳定性"的体现：固定两条边及其夹角，则第三边唯一确定。

**证明策略**：
- 在 Hilbert 公理体系中，SAS 是合同公理的一部分，不需要证明。
- 如果从更基本的公理出发，可以通过叠合法证明：将 $\triangle ABC$ 移动到 $\triangle DEF$ 上，使 $A$ 与 $D$ 重合，$B$ 与 $E$ 重合，$AC$ 与 $DF$ 重合，则 $C$ 与 $F$ 重合。

## 思考过程

SAS 判定的直观理解是：固定两条线段的长度和它们之间的夹角，这两条线段的终点之间的距离就被唯一确定了。因此，如果两个三角形有两边及其夹角相等，那么第三边也必然相等，从而两个三角形全等。

在 Hilbert 公理体系中，SAS 是作为合同公理（公理 III-5）直接给出的，其表述为：若两个三角形有两边及其夹角对应相等，则其余两边也对应相等。因此，在 Hilbert 体系中 SAS 是一个公理而非定理。

## 证明过程

**定理**（SAS 全等判定）：若两个三角形的两边及其夹角分别对应相等，则这两个三角形全等。

**证明**（叠合法）：

设 $\triangle ABC$ 和 $\triangle DEF$ 满足 $AB = DE$，$\angle A = \angle D$，$AC = DF$。

将 $\triangle ABC$ 平移旋转，使 $A$ 与 $D$ 重合，且 $AB$ 与 $DE$ 重合（由于 $AB = DE$，$B$ 与 $E$ 重合）。

由于 $\angle A = \angle D$，射线 $AC$ 与射线 $DF$ 重合。又 $AC = DF$，故 $C$ 与 $F$ 重合。

因此 $B$ 与 $E$ 重合，$C$ 与 $F$ 重合，即 $\triangle ABC$ 与 $\triangle DEF$ 完全重合，故 $\triangle ABC \cong \triangle DEF$。$\square$

---

**注**：在 Hilbert 公理体系中，SAS 是作为合同公理给出的，因此该定理的证明依赖于公理假设。在欧几里得《几何原本》中，SAS 是第一个证明的全等定理（命题 I.4），其证明使用了"叠合法"。

**SSA 反例**：两边及其中一边的对角对应相等不能保证全等。例如，在 $\triangle ABC$ 中，$AB = 5$，$AC = 3$，$\angle B = 30^\circ$，这样的三角形有两个可能（一个锐角三角形和一个钝角三角形），它们不全等。
