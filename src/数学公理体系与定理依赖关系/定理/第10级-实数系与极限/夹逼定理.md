# 夹逼定理

> **一句话大白话**：中间的数列被上下两个数列夹住，而上下的都逼近同一个数，那中间的也只能跟着逼近同一个数——像三明治被两片面包稳稳夹住。
>
> **小例子**：因为 $-\frac1n\le\frac{\sin n}{n}\le\frac1n$，左右两边都趋于 $0$，所以 $\lim_{n\to\infty}\frac{\sin n}{n}=0$。

## 介绍

夹逼定理（Squeeze theorem）是极限理论中判定数列极限的重要工具：若 $a_n \leq b_n \leq c_n$ 且 $\lim a_n = \lim c_n = L$，则 $\lim b_n = L$。该定理不要求 $b_n$ 的表达式，只需将其夹在两个已知极限的数列之间即可。

## 分析

**前置依赖**：极限定义。

## 思考过程

夹逼定理（也称"三明治原理"或"迫敛性"）的直观理解非常自然：如果数列 $b_n$ 被夹在 $a_n$ 和 $c_n$ 之间，而 $a_n$ 和 $c_n$ 都趋近于同一个极限 $L$，那么 $b_n$ 也被迫趋近于 $L$——就像三明治的馅料被两片面包夹住一样。

在求极限的实践中，夹逼定理具有极高的实用价值。许多无法直接计算极限的数列，可以通过寻找合适的放缩不等式，将其夹在两个已知极限的数列之间来求解。经典应用包括：

- $\lim_{n\to\infty} \frac{\sin n}{n} = 0$（由 $-\frac{1}{n} \leq \frac{\sin n}{n} \leq \frac{1}{n}$ 得证）
- $\lim_{n\to\infty} \sqrt[n]{n} = 1$（通过二项式展开放缩）
- 重要极限 $\lim_{x\to 0} \frac{\sin x}{x} = 1$ 的证明也依赖于夹逼原理

## 证明过程

**证明**：对任意 $\varepsilon > 0$，$\exists N_1$，$n > N_1$ 时 $|a_n - L| < \varepsilon$，即 $L - \varepsilon < a_n < L + \varepsilon$。$\exists N_2$，$n > N_2$ 时 $|c_n - L| < \varepsilon$，即 $L - \varepsilon < c_n < L + \varepsilon$。取 $N = \max(N_1, N_2)$，则 $n > N$ 时 $L - \varepsilon < a_n \leq b_n \leq c_n < L + \varepsilon$，故 $|b_n - L| < \varepsilon$。$\square$

## 课堂问答

**老师**：被两条趋于同一个数的数列夹在中间，中间那个就一定收敛吗？

**学生**：结论：若 $a_n \le b_n \le c_n$ 且 $\lim a_n = \lim c_n = L$，则 $\lim b_n = L$。它不需要知道 $b_n$ 的表达式，只要用已知极限的两串把它夹住即可，故又称三明治原理或迫敛性。

**老师（追问）**：把这个"三明治"变成 $\varepsilon$ 论证。

**学生**：对任意 $\varepsilon > 0$，存在 $N_1$ 使 $n>N_1$ 时 $L - \varepsilon < a_n < L + \varepsilon$，存在 $N_2$ 使 $n>N_2$ 时 $L - \varepsilon < c_n < L + \varepsilon$。取 $N = \max(N_1, N_2)$，则 $n>N$ 时 $L - \varepsilon < a_n \le b_n \le c_n < L + \varepsilon$，故 $|b_n - L| < \varepsilon$。当心的误区是只验证 $a_n \le b_n \le c_n$ 就下结论，却漏掉"两边极限相等"这一关键前提。

**老师（拓展）**：典型应用有哪些？

**学生**：由 $-\frac1n \le \frac{\sin n}{n} \le \frac1n$ 立即得 $\lim \frac{\sin n}{n} = 0$；$\lim \sqrt[n]{n} = 1$ 靠二项式放缩；重要极限 $\lim_{x\to 0}\frac{\sin x}{x} = 1$ 的几何证明也依赖它。它是"放缩法"求极限的主力工具——若左右极限不同，中间数列可能根本不收敛，如用 $-1 \le \sin n \le 1$ 就什么都得不到。
