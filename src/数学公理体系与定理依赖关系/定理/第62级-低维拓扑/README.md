# 第62级-低维拓扑

本目录收录以下定理：

- [Alexander 多项式](./Alexander多项式.md)
- [Dehn 手术定理](./Dehn手术定理.md)
- [Heegaard 分解](./Heegaard分解.md)
- [三维流形基本定理](./三维流形基本定理.md)
- [三角剖分与 Turaev–Viro 不变量](./三角剖分与Turaev-Viro不变量.md)
- [四维流形理论](./四维流形理论.md)
- [曲面映射类群](./曲面映射类群.md)
- [Uhlenbeck紧性定理](./Uhlenbeck紧性定理.md)：只要一族联络的"弯曲程度"（曲率的 $L^2$ 范数）被一致控制，就能通过规范变换把它们局部摆正，使其在一个个小区块上规矩收敛，至多在有限个点上曲率浓缩成"泡泡"炸开。
- [Biedenharn-Elliott恒等式](./Biedenharn-Elliott恒等式.md)：把四份角动量按两种不同的次序先两两"合并"成中间态，再用翻译系数（6j 符号）把两种次序互相转换，两条路必须给出同一个结果；这条"结合律"写成等式就是五边形恒等式。
- [映射类群的 Dehn 扭转生成定理](./映射类群的Dehn扭转生成定理.md)：曲面上的每个"对称"（保定向同胚的同痕类）都能拆成有限个基本动作——沿简单闭曲线把曲面切开、扭转一圈再粘回去。
- [双曲化定理](./双曲化定理.md)：一个闭的三维流形，只要它"不可约、不含环面、基本群无限"，就一定是双曲流形——可以赋予一个体积有限的完备双曲度量。三维流形的大多数都是双曲的。
- [规范群与 Uhlenbeck 紧性定理](./规范群与Uhlenbeck紧性定理.md)：曲率能量有界的连接列，经过适当的规范变换后，会"除有限个点之外"收敛；没能收敛的那些点正是曲率能量像气泡一样集中的地方。这使杨–米尔斯模空间可以被紧化。
- [JSJ 分解与环面定理](./JSJ分解与环面定理.md)：三维流形先沿球面切成"素数块"，再在每块里沿本质环面一直切到"要么规整（Seifert 纤维化）、要么空旷（再无本质环面，配双曲几何）"为止；这套环面分割在同痕意义下是唯一的。
