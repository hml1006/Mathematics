# 稳定性不等式

> **一句话大白话**：极小曲面既然是"面积最小"的曲面，那么把它沿法向任意推一推，面积都不能变小；把这条二阶条件写成积分不等式，就得到稳定性不等式，它用 $\int|\nabla\varphi|^2$ 去控制曲率项 $\int|A|^2\varphi^2$。

> **小例子**：$\mathbb{R}^3$ 中的平面与悬链面都是稳定的极小曲面，取定一个截断函数 $\varphi$ 后，稳定性不等式立即给出局部 $\int |A|^2$ 的估计，从而可以推出"稳定极小曲面必为平面"（Schoen 刚性定理）。

## 一、定理介绍

> **前置依赖**：极小曲面理论、第二变分公式与 Jacobi 算子、第一与第二基本形式、Riemann 曲率张量与 Ricci 曲率、Bochner 公式。

稳定性不等式（stability inequality）是极小曲面二阶变分理论的核心结论。极小曲面是面积泛函的一阶临界点（平均曲率 $H \equiv 0$）；20 世纪 60 年代 Simons 系统研究了面积泛函的二阶变分，得到著名的 Simons 恒等式与第二变分公式，其中法向变分对应的二阶导数为
$$A''(0) = \int_\Sigma \bigl(|\nabla\varphi|^2 - (|A|^2 + \mathrm{Ric}_M(N,N))\varphi^2\bigr) \, d\mu.$$
"面积最小"（或局部最小、稳定）意味着对一切法向变分都有 $A''(0) \ge 0$，这就直接等价于稳定性不等式。Simons 用它处理极小锥的分类（Bernstein 问题的解决正是建立在稳定极小锥不存在于 $n \le 7$ 之上）。

Schoen–Yau 在 1979 年证明正质量定理时，把稳定性不等式与共形技巧结合起来，得到三维流形中稳定极小曲面的曲率估计，进而由曲率积分推出拓扑与几何限制。Fischer-Colbrie 与 Schoen 随后把这些想法提炼为"稳定极小曲面在非负曲率环境下必为平面或全测地"的刚性定理族。这条不等式因此成为极小曲面理论、几何流奇点分析与广义相对论中最常被调用的工具之一，其动机是：把"面积最小"这一全局极小性转化为一个局部可用的、只涉及梯度与曲率的解析估计。

## 二、原理思路

1. **先做二阶变分**：对极小曲面 $\Sigma \subset M$ 取法向变分 $F(x,t) = x + t\varphi(x)N(x)$，$\varphi \in C_0^\infty(\Sigma)$。计算诱导度量 $g_{ij}(t)$ 的展开，得到面积 $A(t) = \int \sqrt{\det g(t)}\,dx$ 关于 $t$ 的二阶导数。

2. **利用极小性消去一阶项**：一阶变分为 $A'(0) = -\int 2H\varphi\, d\mu$。因 $H\equiv 0$，$A'(0)=0$，所以二阶项即为面积的局部行为。

3. **把二阶项改写为"梯度减去曲率"**：二阶变分中出现的导数项经分部积分化为 $\int|\nabla\varphi|^2$，剩余的零阶项由 Gauss 方程化为 $-(|A|^2+\mathrm{Ric}(N,N))$。

4. **由稳定性（最小性）得不等式**：$A''(0)\ge 0$ 即为 $\int|\nabla\varphi|^2 \ge \int(|A|^2+\mathrm{Ric}(N,N))\varphi^2$；在 $\mathrm{Ric}\ge 0$ 时进一步得到 $|A|^2$ 的 $L^2$ 控制，再配合共形测试函数得到刚性结论。

## 三、定理的严格表述

**定义（稳定极小超曲面）**：设 $\Sigma^n$ 是 Riemann 流形 $(M^{n+1},g)$ 中的极小超曲面（$H\equiv 0$），单位法向量为 $N$。若对一切 $\varphi\in C_0^\infty(\Sigma)$ 有 $A''(0)\ge 0$（即面积泛函在 $\Sigma$ 处取局部极小），则称 $\Sigma$ 是**稳定**的。

**定理（第二变分公式）**：设 $\Sigma^n \subset M^{n+1}$ 为极小超曲面，$F(x,t)=x+t\varphi(x)N(x)$ 为法向变分，则
$$A''(0) = \int_\Sigma \Bigl(|\nabla\varphi|^2 - \bigl(|A|^2 + \mathrm{Ric}_M(N,N)\bigr)\varphi^2\Bigr) \, d\mu,$$
其中 $|A|^2$ 为第二基本形式的平方模长，$\mathrm{Ric}_M(N,N)$ 为环境流形沿法方向的 Ricci 曲率。

**定理（稳定性不等式）**：若 $\Sigma$ 稳定，则对一切 $\varphi\in C_0^\infty(\Sigma)$,
$$\int_\Sigma |\nabla\varphi|^2 \, d\mu \;\ge\; \int_\Sigma \bigl(|A|^2 + \mathrm{Ric}_M(N,N)\bigr)\varphi^2 \, d\mu.$$

**推论 1（欧氏空间情形）**：若 $M=\mathbb{R}^{n+1}$，则 $\mathrm{Ric}_M\equiv 0$，于是
$$\int_\Sigma |A|^2\varphi^2 \, d\mu \le \int_\Sigma |\nabla\varphi|^2 \, d\mu.$$

**推论 2（三维流形中的稳定曲面）**：若 $\dim\Sigma = 2$ 且环境三维流形满足 $\mathrm{Scal}_M \ge 0$，则对某个常数 $C$（由共形变换给出）成立
$$\int_\Sigma |A|^2\varphi^2 \, d\mu \le C\int_\Sigma |\nabla\varphi|^2 \, d\mu,$$
并由此导出 $\int_\Sigma |A|^2\, d\mu < \infty$ 与刚性结论。

## 四、证明过程

**步骤 1（写出变分的诱导度量）。** 设 $\{e_i\}$ 为 $\Sigma$ 上的局部切标架，变分 $F(x,t) = x + t\varphi(x)N(x)$。则
$$\partial_t F = \varphi N, \qquad \partial_i F = e_i + t(\partial_i\varphi) N + t\varphi\, \nabla^{\Sigma}_i N = e_i - t\varphi\, A_i{}^j e_j,$$
最后一步用了 Weingarten 公式 $\nabla_i N = -A_i{}^j e_j$（$A$ 为第二基本形式）。于是 $t=0$ 附近的诱导度量
$$g_{ij}(t) = \langle \partial_i F, \partial_j F\rangle = \delta_{ij} - 2t\varphi A_{ij} + t^2\bigl(\varphi^2 (A^2)_{ij} + \partial_i\varphi\,\partial_j\varphi\bigr).$$

**步骤 2（面积的一阶与二阶展开）。** 记 $G(t)=\det(g_{ij}(t))$，则
$$G(0)=1, \qquad G'(0) = -2H\varphi = 0,$$
最后一步用了 $\mathrm{tr}\,A = H\equiv 0$。又由 $\det$ 的导数公式与 $\mathrm{tr}(A^2)=|A|^2$（对称矩阵），
$$G''(0) = 2\Bigl(|\nabla\varphi|^2 + \varphi^2|A|^2\Bigr) + 2\bigl(\mathrm{tr}\,A\bigr)^2 - 4\varphi^2 |A|^2 \Big|_{H=0} = 2|\nabla\varphi|^2 - 2\varphi^2|A|^2.$$
由 $A(t)=\int\sqrt{G(t)}$ 与 $\frac{d^2}{dt^2}\sqrt{G}\big|_{0} = \tfrac12 G''(0) - \tfrac14 G'(0)^2$，代入得
$$A''(0) = \int_\Sigma \Bigl(|\nabla\varphi|^2 - |A|^2\varphi^2\Bigr) d\mu.$$

**步骤 3（补上环境曲率的贡献）。** 上面的计算只用到 $\Sigma$ 自身的第二基本形式。若把 $\Sigma$ 放到 $M$ 中，度量的二阶变化里还包含法向曲率的贡献：由 Gauss 方程
$$\mathrm{Rm}_M(X,Y,Z,W) = \mathrm{Rm}_\Sigma + \langle A(X,Z),A(Y,W)\rangle - \langle A(X,W),A(Y,Z)\rangle$$
对法向 $N$ 取迹，可得额外项 $-\mathrm{Ric}_M(N,N)\varphi^2$。合并即得第二变分公式
$$A''(0) = \int_\Sigma \Bigl(|\nabla\varphi|^2 - \bigl(|A|^2 + \mathrm{Ric}_M(N,N)\bigr)\varphi^2\Bigr) d\mu.$$

**步骤 4（稳定性推出不等式）。** 若 $\Sigma$ 稳定，则对一切 $\varphi\in C_0^\infty(\Sigma)$ 有 $A''(0)\ge 0$，代入上式并移项即得
$$\int_\Sigma |\nabla\varphi|^2\, d\mu \ge \int_\Sigma \bigl(|A|^2 + \mathrm{Ric}_M(N,N)\bigr)\varphi^2\, d\mu.$$
在 $\mathbb{R}^{n+1}$ 中 $\mathrm{Ric}\equiv 0$，故此式化为 $\int |A|^2\varphi^2 \le \int|\nabla\varphi|^2$。$\square$

**步骤 5（刚性结论的机制）。** 在 $\dim\Sigma=2$ 时取共形测试函数 $\varphi = e^{f}\eta$（$f$ 是 $\Sigma$ 上的某个共形因子，$\eta$ 为截断函数），把 $\int|\nabla\varphi|^2$ 展开后用 Gauss–Bonnet 与 $\mathrm{Scal}_M\ge 0$，可把不等式整理成只含 $|A|^2$ 与 $\int|\nabla\eta|^2$ 的形式，从而得到局部 $L^2$ 曲率界。令截断半径趋于无穷，得 $\int_\Sigma |A|^2 < \infty$；进一步用 Simons 恒等式 $\Delta |A|^2 = -2|A|^4 + \cdots$ 与极大值原理推出 $|A|\equiv 0$，即 $\Sigma$ 是全测地的（在 $\mathbb{R}^3$ 中即为平面）。$\square$

## 五、应用与意义

- **正质量定理**：Schoen–Yau 在三维渐近平坦时空中取稳定极小曲面，用稳定性不等式结合 Gauss–Bonnet 推出排除不可定向/非球面等情形，最终证明 ADM 质量非负，这是广义相对论能量正性的几何证明。

- **Simons 锥与 Bernstein 问题**：稳定性不等式用于证明低维极小球面不存在，配合单调性公式给出 $n\le 7$ 时整体极小图必为平面（Bernstein 定理）的几何测度论证明。

- **极小曲面刚性**：Fischer-Colbrie–Schoen 分类了非负曲率三维流形中的稳定极小曲面，得到"完备稳定极小曲面在 $\mathbb{R}^3$ 中必为平面"等经典结果。

- **曲率估计与几何流**：稳定性不等式是稳定极小曲面局部曲率估计（$\varepsilon$-正则性）的出发点，也用于平均曲率流与 Ricci 流奇点分析中的稳定/自相似解研究。

- **谱与几何**：Jacobi 算子 $L=\Delta + |A|^2 + \mathrm{Ric}(N,N)$ 的首个特征值的非负性正是稳定性，其与 $\Sigma$ 的谱几何、Fredholm 性质密切相关。

## 课堂问答

**老师**：稳定性不等式的形式与几何含义是什么？

**学生**：对稳定极小超曲面 $\Sigma$、一切 $\varphi\in C_0^\infty(\Sigma)$，有 $\int_\Sigma|\nabla\varphi|^2\,d\mu\ge\int_\Sigma\left(|A|^2+\mathrm{Ric}_M(N,N)\right)\varphi^2\,d\mu$。它把"面积泛函在 $\Sigma$ 处取局部极小"这一二阶条件翻译成用梯度控制曲率的解析估计。

**老师（追问）**：它从哪来？二阶变分中的导数项怎么就变成 $\int|\nabla\varphi|^2$？

**学生**：取法向变分 $F(x,t)=x+t\varphi(x)N(x)$，由 Weingarten 公式得诱导度量 $g_{ij}(t)=\delta_{ij}-2t\varphi A_{ij}+t^2\left(\varphi^2(A^2)_{ij}+\partial_i\varphi\partial_j\varphi\right)$。极小性 $H=\mathrm{tr}\,A=0$ 给 $G'(0)=0$，于是 $\frac12G''(0)=|\nabla\varphi|^2-\varphi^2|A|^2$，再由 Gauss 方程补上环境的 $-\mathrm{Ric}_M(N,N)\varphi^2$，得 $A''(0)=\int\left(|\nabla\varphi|^2-(|A|^2+\mathrm{Ric}_M(N,N))\varphi^2\right)d\mu$；稳定性即 $A''(0)\ge0$。

**老师（拓展）**：它如何服务于正质量定理与刚性定理？

**学生**：在 $\mathbb R^{n+1}$ 中 $\mathrm{Ric}\equiv0$，不等式化为 $\int|A|^2\varphi^2\le\int|\nabla\varphi|^2$；取共形测试函数 $\varphi=e^f\eta$，令截断半径趋于无穷得 $\int_\Sigma|A|^2<\infty$，再配合 Simons 恒等式与极值原理推出 $|A|\equiv0$，即平面。Schoen–Yau 用这套估计证明三维渐近平坦时空 ADM 质量非负。常见误区是把 $H=0$ 当作"最小"：那只是一阶临界，稳定性是强有力的额外二阶条件。
