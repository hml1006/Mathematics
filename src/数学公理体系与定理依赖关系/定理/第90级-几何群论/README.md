# 第90级-几何群论

本目录收录以下定理：

- [增长函数的拟等距不变性](./增长函数的拟等距不变性.md)
- [双曲群的Cartan-Hadamard定理](./双曲群的Cartan-Hadamard定理.md)
- [Svarc-Milnor引理](./Svarc-Milnor引理.md)
- [群的拟等距分类](./群的拟等距分类.md)
- [Stallings端定理](./Stallings端定理.md)
- [Dehn函数的性质](./Dehn函数的性质.md)
- [Gromov多项式增长定理](./Gromov多项式增长定理.md)
- [Gleason–Yamabe 定理](./Gleason–Yamabe定理.md)：若一个拓扑群"局部看起来像欧氏空间"（局部紧、连通、有限维），那它其实就是一个 Lie 群——局部欧氏性强制出光滑结构。
- [拟测地线稳定性引理](./拟测地线稳定性引理.md)：在双曲空间里，"走得大致笔直"的路线（拟测地线）一定全程贴着真正的直线走，偏离量只取决于误差参数，而不随距离增长。
- [Montgomery–Zippin 定理](./Montgomery-Zippin定理.md)：只要局部紧群 $G$ 连续、可迁（或正常且余紧）地作用在连通、有限维的局部紧空间上，$G$ 就"本质上"是 Lie 群——病态的"小子群"现象被连通性排除，群的结构退化为 Lie 群（或 Lie 群的逆极限）。
- [Nielsen 实现定理](./Nielsen实现定理.md)：曲面映射类群里的任意有限子群，都能被"真正几何地实现"——存在同构的有限群通过曲面的自同胚起作用；映射类群中的有限阶对称性不是纯形式代数关系，而是真能画出来的对称。
