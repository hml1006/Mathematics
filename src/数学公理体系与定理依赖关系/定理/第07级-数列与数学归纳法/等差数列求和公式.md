# 等差数列求和公式

> **一句话大白话**：求等差数列前 $n$ 项和，只要“首项加末项”乘以项数再除以 $2$，像把首尾凑对一样。
>
> **小例子**：高斯算 $1+2+\cdots+100$，每对首尾都是 $101$，共 $50$ 对，故和为 $50\times101=5050$，也就是 $\frac{100(1+100)}2$。

## 介绍

等差数列求和公式是数列理论中最基本的公式之一：首项为 $a_1$、公差为 $d$ 的等差数列的前 $n$ 项和为 $S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)d}{2}$。该公式的推导体现了"倒序相加"的巧妙思想，也是数学归纳法应用的经典例题。

## 分析

**前置依赖**：数学归纳法。

**定理内容**：对等差数列 $\{a_n\}$，首项 $a_1$，公差 $d$，前 $n$ 项和 $S_n = \sum_{k=1}^n a_k = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)d}{2}$。

## 思考过程

高斯在小学时便以惊人巧思计算 $1 + 2 + \cdots + 100$，其方法是将首尾配对：$(1+100) + (2+99) + \cdots + (50+51)$，每对和均为 $101$，共 $50$ 对，得 $5050$。这一经典故事揭示了等差数列求和的本质——**对称性**。等差数列中任意一项与对称项之和恒等于首项加末项，这正是"倒序相加法"的直观来源。

具体而言，将前 $n$ 项和 $S_n$ 按正序写出，再按倒序写出，两式相加后每对 $(a_k + a_{n-k+1})$ 均相等（因为 $a_k + a_{n-k+1} = a_1 + a_n$），从而 $2S_n = n(a_1 + a_n)$。这一推导无需任何高级工具，仅凭代数变形即可完成，是数学中"对称性简化计算"的典范。

从几何视角看，等差数列的每一项可视为等距散布在数轴上的点，其前 $n$ 项和对应一个阶梯形的面积；而倒序相加相当于将两个相同的阶梯形拼合为一个矩形，矩形的高为 $a_1 + a_n$，宽为 $n$，故面积（即 $2S_n$）为 $n(a_1 + a_n)$。这一几何直观与代数推导完美呼应。

等差数列求和公式不仅是初等数学的基础工具，更是数学归纳法训练的首选例题——初学者可借此体会"猜想—验证—证明"的完整思维链路。

## 证明过程

**证明**（倒序相加法）：

$$
\begin{aligned}
S_n &= a_1 + (a_1 + d) + \cdots + [a_1 + (n-1)d] \\
S_n &= a_n + (a_n - d) + \cdots + [a_n - (n-1)d]
\end{aligned}
$$

两式相加，每对之和为 $a_1 + a_n$，共 $n$ 对，得 $2S_n = n(a_1 + a_n)$，故 $S_n = \frac{n(a_1 + a_n)}{2}$。

代入 $a_n = a_1 + (n-1)d$ 得 $S_n = na_1 + \frac{n(n-1)d}{2}$。$\square$
