# Polya 问题解决理论

> **一句话大白话**：解数学难题不是靠灵光一闪，而是一条有章法的四步路：先想清楚问题是什么 → 定个解题计划 → 认真执行 → 回头检查并多想一步。每一步配一把"启发式小工具"，照着走就能显著提高解题成功率。
>
> **小例子**：已知两数和为 $20$、积为 $96$，求两数。第一步想清"未知量是两个数、条件是和与积"；第二步定计划——用韦达定理解 $t^2-20t+96=0$；第三步因式分解得 $t=8$ 或 $12$；第四步回代验证 $8+12=20$、$8\times12=96$，还可推广"已知和与积即解 $t^2-st+p=0$"。

## 一、定理介绍

> **前置依赖**：启发式策略、问题表征（认知科学）、认知负荷理论、元认知、实证研究方法（元分析）。

Polya 问题解决理论（Polya's Problem Solving Theory）由 George Polya 在《怎样解题》（How to Solve It, 1945）中系统提出，把数学问题解决组织为一个四阶段启发式框架：理解问题、制定计划、执行计划、回顾反思。它既是对解题实践的经验总结，也逐步获得认知心理学与实证研究（Chi、Schoenfeld、Silver、Hembree 等）的支持，成为数学教育中问题解决教学的理论基石。

## 二、原理思路

四阶段的核心在于"理解≠看懂，计划≠死排公式"：理解的优劣决定问题表征的质量，而问题表征又决定能否选对启发式策略。它把解题者从"乱撞公式"引导到"系统化地使用启发式策略"。实证上，专家先做定性分析（识别问题深层结构），新手却急于套公式；高成就者解题后自觉回顾反思，低成就者却跳过——四阶段正是在这些对比中被验证为可训练的能力结构。

## 三、定理的严格表述

**定理（Polya 四阶段框架）**：数学问题解决可分解为如下四阶段，且系统训练每一阶段的启发式策略能显著提高问题解决能力。

1. **理解问题（Understanding the Problem）**：问清未知量、已知数据、条件，检定条件是否充分/矛盾/多余；用画图、引入符号、复述、分解条件来建立问题表征。
2. **制定计划（Devising a Plan）**：寻找已知与未知的联系，必要时构造辅助问题；可类比、寻找类似问题、分解、特殊化、一般化、逆向思考。
3. **执行计划（Carrying Out the Plan）**：逐步执行并逐部检查每一步的正确性与合理性，依靠程序性知识与自动化基本技能（Arithmetic 自动化）降低认知负荷。
4. **回顾反思（Looking Back）**：验证结果（可用不同方法）、尝试推广、记录心得；此阶段促进深层理解与知识联结。

## 四、证明过程

**论证（用启发式策略与认知分析）**：

**阶段1（理解问题）**：确立未知量、已知数据与条件，条件充足性分析。利用画图、符号化、分解等策略建立问题表征。认知依据：成功的解题者花更多时间构建更丰富、更准确的问题表征；Chi（1981）显示专家先定性分析问题的类型与深层结构，新手则急于找公式。

**阶段2（制定计划）**：在已知与未知间架桥。启发式库：寻找类似问题、类比相关定理、分解、特殊化、一般化、逆向思考。认知依据：Schoenfeld（1985）表明优秀解题者拥有丰富的启发式策略库并能按题型灵活调用，而明确的策略教学能提升解题能力。

**阶段3（执行计划）**：逐步执行并检查每一步。认知依据：执行依赖程序性知识；Sweller 的认知负荷理论指出工作记忆有限，自动化基本技能（算术、代数变换）可释放工作记忆用于高层推理。

**阶段4（回顾反思）**：验证（多样方法）、推广、提炼小结。认知依据：Silver（1982）发现高成就学生解题后自发回顾反思而低成就学生很少，反思促成更深入的概念理解。

**多元实证支持**：Hembree（1992）等元分析表明系统教授问题解决策略可显著提高数学成绩，效应量达中等以上；该框架已被广泛采用为问题解决教学的理论基础。$\square$

## 五、应用与意义

Polya 四阶段框架为数学教育中问题解决教学提供了可操作路线：既是诊断学生解题卡点的分析工具，也是课程与教材设计的组织原则。其对"元认知""回顾反思"的强调深化了数学学习的深层理解，并延伸到人工智能中的启发式搜索与算法设计思想。作为本级的核心成果，它把"会解题"从天赋降格为可训练的策略能力，奠定了数学教育科学化的理论基础。
