# 第136级-生物统计学

> 一句话级别概述：生物统计学把统计推断方法应用于生物医学数据，重点处理生存分析、诊断试验与证据综合，是循证医学与流行病学的统计基础。

## 级别简介

生物统计学将概率与统计工具用于分析生物与医学研究数据。核心方向包括生存分析的 Kaplan-Meier 估计与 Cox 比例风险模型、Log-rank 检验、诊断试验的 ROC 评价，以及 Meta 分析对多项研究证据的定量综合。

## 本级别定理

- [Cox比例风险模型的部分似然估计](./Cox比例风险模型的部分似然估计.md)：半参数生存回归的估计方法。
- [Kaplan-Meier估计的一致性](./Kaplan-Meier估计的一致性.md)：删失情况下生存函数估计收敛。
- [Log-rank检验的渐近分布](./Log-rank检验的渐近分布.md)：组间生存曲线比较的检验。
- [ROC曲线下面积（AUC）的统计性质](./ROC曲线下面积（AUC）的统计性质.md)：诊断准确度的评价指标。
- [Meta分析中的随机效应模型](./Meta分析中的随机效应模型.md)：多研究效应的综合估计。

## 前置知识

本级别依赖概率论与数理统计（极大似然、假设检验、渐近理论）、随机过程中的计数过程，以及生存分析中风险函数与删失的基本概念。

## 后继用途

为计量经济学实证、数据科学的医学应用、临床流行病学与循证医学决策提供统计基础。

## 关键定理速览

- Cox 比例风险模型：生存数据分析的半参数回归标准工具。
- Kaplan-Meier 估计的一致性：生存曲线估计的大样本收敛性质。
- ROC 曲线下面积（AUC）：诊断试验分辨能力的核心度量。
- Log-rank 检验：不同组生存分布比较的主要方法。
