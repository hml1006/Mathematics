# 第85级-序理论

本目录收录以下定理：

- [Dilworth定理](./Dilworth定理.md)
- [Mirsky定理](./Mirsky定理.md)
- [Knaster-Tarski不动点定理](./Knaster-Tarski不动点定理.md)
- [Birkhoff表示定理](./Birkhoff表示定理.md)
- [Sperner定理](./Sperner定理.md)
- [LYM 不等式](./LYM不等式.md)：在 $[n]$ 的所有子集里挑一族互不包含的集合（反链），那么它们"占据"最大链的比例之和不会超过 $100\%$——把每个集合 $A$ 按 $\binom{n}{|A|}^{-1}$ 记一次权重，总权重至多 $1$。
- [下确界与上确界](./下确界与上确界.md)：一个集合若有上界，其中"最小的那个上界"就叫上确界；若有下界，其中"最大的那个下界"就叫下确界。它们未必属于集合本身，但一旦存在就唯一。
