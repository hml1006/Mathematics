# C*-代数定义与基本性质

## 一、定理介绍

C*-代数是泛函分析中的一个核心概念，它是 Banach 代数的一种特殊形式，具有对合运算且满足 C*-恒等式。C*-代数的概念最早由 Gelfand 和 Naimark 在 1943 年引入，用于研究算子代数。C*-代数在量子力学、调和分析、非交换几何等领域有广泛应用，是现代数学物理的基础工具之一。

C*-代数的基本思想是将 Hilbert 空间上有界线性算子的代数性质抽象出来。典型的例子包括：Hilbert 空间上的有界线性算子代数 $B(H)$、局部紧 Hausdorff 空间上连续函数在无穷远处消失的代数 $C_0(X)$、以及群 C*-代数等。

## 二、原理思路

C*-代数的定义基于以下几个关键要素：

1. **代数结构**：首先是一个结合代数，具有加法、数乘和乘法运算
2. **拓扑结构**：是一个 Banach 空间，具有完备的范数
3. **对合运算**：存在一个映射 $* : A \to A$，满足 $(x^*)^* = x$、$(xy)^* = y^*x^*$、$(\lambda x + y)^* = \bar{\lambda}x^* + y^*$
4. **C*-恒等式**：$\|x^*x\| = \|x\|^2$

C*-恒等式是最关键的性质，它将对合运算与范数结构紧密联系起来。这个等式保证了 C*-代数具有非常好的性质，例如：
- 自伴元素的谱是实的
- 正规元素的谱半径等于其范数
- C*-代数同态自动连续且范数不增

## 三、定理的严格表述

**定义 1（C*-代数）**：设 $A$ 是一个复数域 $\mathbb{C}$ 上的结合代数，如果满足以下条件，则称 $A$ 为 C*-代数：

1. $A$ 是一个 Banach 空间，即具有完备的范数 $\|\cdot\|$
2. $A$ 是 Banach 代数，即 $\|xy\| \le \|x\|\|y\|$
3. $A$ 上定义了对合运算 $* : A \to A$，满足：
   - $(x^*)^* = x$（对合性）
   - $(xy)^* = y^*x^*$（反乘法性）
   - $(\lambda x + y)^* = \bar{\lambda}x^* + y^*$（共轭线性）
4. 满足 C*-恒等式：$\|x^*x\| = \|x\|^2$，对所有 $x \in A$

**定义 2（自伴元素与正规元素）**：设 $A$ 是 C*-代数，$x \in A$
- 若 $x^* = x$，称 $x$ 为自伴元素（或 Hermitian 元素）
- 若 $x^*x = xx^*$，称 $x$ 为正规元素
- 若 $x^*x = I$ 且 $xx^* = I$，称 $x$ 为酉元素

**定理 1（基本性质）**：设 $A$ 是 C*-代数，则以下性质成立：

1. **范数唯一性**：C*-代数的范数由代数结构唯一确定，即 $\|x\| = \sqrt{\|x^*x\|}$
2. **自伴元素谱的实性**：若 $x = x^*$，则 $\sigma(x) \subset \mathbb{R}$
3. **正规元素谱半径**：若 $x^*x = xx^*$，则 $r(x) = \|x\|$，其中 $r(x) = \max\{|\lambda| : \lambda \in \sigma(x)\}$
4. **C*-子代数**：若 $B \subset A$ 是 C*-子代数（对 $*$ 运算封闭的闭子代数），则 $B$ 本身是 C*-代数
5. **同态连续性**：若 $\phi : A \to B$ 是 C*-代数同态，则 $\|\phi\| \le 1$（即同态自动连续且范数不增）

**定理 2（Gelfand-Naimark 半范数性质）**：设 $A$ 是 C*-代数，$x \in A$，则
$$\|x\| = \sup\{|\phi(x)| : \phi \text{ 是 } A \text{ 的状态}\}$$
其中状态是指满足 $\phi(x^*x) \ge 0$ 且 $\phi(1) = 1$（若 $A$ 有单位元）的连续线性泛函。

## 四、证明过程

**定理 1 的证明**：

**步骤 1：范数唯一性**

由 C*-恒等式 $\|x^*x\| = \|x\|^2$，对任意 $x \in A$，有
$$\|x\|^2 = \|x^*x\| = \|x^*\|\|x\|$$
因此 $\|x^*\| = \|x\|$。

对任意正整数 $n$，考虑 $x^*x$ 的幂次：
$$\|(x^*x)^{2^n}\| = \|(x^*x)^{2^{n-1}}\|^2 = \cdots = \|x^*x\|^{2^n} = \|x\|^{2^{n+1}}$$

由谱半径公式 $r(x^*x) = \lim_{n\to\infty} \|(x^*x)^n\|^{1/n}$，可得
$$r(x^*x) = \lim_{n\to\infty} \|(x^*x)^{2^n}\|^{1/2^n} = \lim_{n\to\infty} \|x\|^{2^{n+1}/2^n} = \|x\|^2$$

由于谱半径由代数结构决定，范数由 $\|x\| = \sqrt{r(x^*x)}$ 唯一确定。

**步骤 2：自伴元素谱的实性**

设 $x = x^*$，要证 $\sigma(x) \subset \mathbb{R}$。设 $\lambda = \alpha + i\beta \in \sigma(x)$，其中 $\alpha, \beta \in \mathbb{R}$。

考虑元素 $y = x - \alpha I$，则 $y$ 也是自伴的，且 $i\beta \in \sigma(y)$。

对任意 $t \in \mathbb{R}$，考虑 $(y + itI)^*(y + itI) = (y - itI)(y + itI) = y^2 + t^2I$。

由 C*-恒等式：
$$\|y + itI\|^2 = \|(y + itI)^*(y + itI)\| = \|y^2 + t^2I\|$$

由于 $y^2 + t^2I$ 是正元素（可以证明），$\|y^2 + t^2I\| \le \|y\|^2 + t^2$。

因此 $\|y + itI\|^2 \le \|y\|^2 + t^2$，即 $\|y + itI\| \le \sqrt{\|y\|^2 + t^2}$。

另一方面，由于 $i\beta \in \sigma(y)$，$y + itI$ 在 $t = -\beta$ 时不可逆，故
$$\|y - i\beta I\| \ge r(y - i\beta I) \ge |\beta|$$

但这与 $\|y - i\beta I\| \le \sqrt{\|y\|^2 + \beta^2}$ 矛盾，除非 $\beta = 0$。因此 $\sigma(x) \subset \mathbb{R}$。

**步骤 3：正规元素谱半径**

设 $x^*x = xx^*$，要证 $r(x) = \|x\|$。

首先，$r(x) \le \|x\|$ 总是成立。

对正规元素 $x$，有 $\|x^2\|^2 = \|(x^2)^*x^2\| = \|(x^*)^2x^2\| = \|(x^*x)^2\| = \|x^*x\|^2 = \|x\|^4$。

因此 $\|x^2\| = \|x\|^2$。

归纳可得 $\|x^{2^n}\| = \|x\|^{2^n}$。

由谱半径公式：
$$r(x) = \lim_{n\to\infty} \|x^n\|^{1/n} = \lim_{n\to\infty} \|x^{2^n}\|^{1/2^n} = \lim_{n\to\infty} \|x\|^{2^n/2^n} = \|x\|$$

**步骤 4：同态连续性**

设 $\phi : A \to B$ 是 C*-代数同态。对任意 $x \in A$，
$$\|\phi(x)\|^2 = \|\phi(x)^*\phi(x)\| = \|\phi(x^*x)\|$$

由于 $\phi$ 是代数同态，$\|\phi(x^*x)\| \le \|\phi\|\|x^*x\| = \|\phi\|\|x\|^2$。

但这给出 $\|\phi(x)\|^2 \le \|\phi\|\|x\|^2$，即 $\|\phi(x)\| \le \sqrt{\|\phi\|}\|x\|$。

因此 $\|\phi\| \le \sqrt{\|\phi\|}$，即 $\|\phi\| \le 1$。$\square$

## 五、应用与意义

C*-代数的基本性质在算子代数理论中具有基础性作用：

1. **量子力学的数学基础**：C*-代数提供了量子力学中可观测量代数的严格数学框架。自伴元素对应可观测量，其谱对应测量值的可能结果。

2. **调和分析**：局部紧 Abel 群的群 C*-代数同构于其 Pontryagin 对偶群上的连续函数代数，这是 Pontryagin 对偶性的 C*-代数表述。

3. **拓扑不变量**：通过 C*-代数的 K-理论可以定义拓扑不变量，用于研究流形的拓扑性质，这是非交换几何的核心思想。

4. **指标定理**：Atiyah-Singer 指标定理的 C*-代数证明展示了算子代数与微分几何的深刻联系。

5. **统计力学**：C*-代数动力学系统为量子统计力学提供了严格的数学框架，KMS 态描述了热平衡态。

6. **分类问题**：C*-代数的分类（特别是单纯 C*-代数）是当代研究的核心问题，与动力系统和非交换几何密切相关。

C*-代数理论将代数、分析、拓扑和几何有机地统一在一起，是现代数学中最丰富和活跃的研究领域之一。
