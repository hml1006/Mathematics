# 第58级-复几何

> 一句话级别概述：研究复流形（尤其紧 Kähler 流形）的复结构、Hodge 理论、嵌入消没与对偶，是代数几何与微分几何交汇的核心领域。

## 级别简介

复几何考察复流形上的复结构与 Kähler 度量，研究其调和形式、层上同调与消没性质。核心概念包括 Kähler 恒等式、Hodge 分解、Calabi-Yau 流形、正线丛的射影嵌入与 Serre 对偶。

## 本级别定理

- [Calabi-Yau 定理](./Calabi-Yau定理.md)：紧 Kähler 流形上 Ricci 平坦 Kähler 度量的存在。
- [Hodge 分解定理](./Hodge分解定理.md)：紧 Kähler 流形上同调的标准分解。
- [Hodge 定理（复形式）](./Hodge定理复形式.md)：调和形式历遍每个上同调类。
- [Kodaira 嵌入定理](./Kodaira嵌入定理.md)：正线丛决定射影嵌入。
- [Kodaira 消没定理](./Kodaira消没定理.md)：正线丛高次上同调全为零。
- [Kähler 恒等式](./Kähler恒等式.md)：Kähler 流形上 Laplace 算子组合分解。
- [Serre 对偶定理](./Serre对偶定理.md)：凝聚层上同调的配对计算。

## 前置知识

依赖微分流形与黎曼几何（曲率、联络）、代数拓扑的 de Rham 上同调、层论与层上同调、以及多变量微积分与调和分析工具。

## 后继用途

为 Calabi-Yau 空间、镜像对称、代数几何与弦理论紧化、以及几何朗兰兹纲领提供复解析基础。

## 关键定理速览

- Hodge 分解与 Kähler 恒等式：奠定 Kähler 流形 Hodge 理论的根基。
- Kodaira 嵌入与消没：用正线丛刻画射影性质与上同调消失。
- Serre 对偶：凝聚层上同调求值的核心对偶工具。
- Calabi-Yau 定理：构造 Ricci 平坦 Kähler 度量的存在性定理。
