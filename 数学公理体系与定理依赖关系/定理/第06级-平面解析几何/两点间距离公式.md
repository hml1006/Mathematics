# 两点间距离公式

## 介绍

两点间距离公式是解析几何中最基本的公式：平面中两点 $P_1(x_1, y_1)$ 和 $P_2(x_2, y_2)$ 之间的距离为 $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$。该公式是勾股定理在坐标平面中的直接应用，是整个解析几何的基石，也是所有后续几何度量（如点到直线距离、圆方程、圆锥曲线等）的基础。

## 分析

**前置依赖**：勾股定理。

**定理内容**：平面中两点 $P_1(x_1, y_1)$ 和 $P_2(x_2, y_2)$ 之间的距离为 $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$。

**数学内涵**：该公式是勾股定理在坐标系中的代数化表达，将几何距离问题转化为代数计算。

## 思考过程

两点间距离公式本质上体现了笛卡尔解析几何的核心思想——**用代数方法研究几何问题**。在引入坐标系之前，距离是一个纯粹的几何概念，依赖尺规作图来度量。笛卡尔坐标系的创立改变了这一局面：通过将平面上的点与有序实数对 $(x, y)$ 一一对应，几何图形被转化为代数方程，几何关系被转化为代数运算。

具体到距离公式，其推导思路来源于勾股定理：在直角三角形中，斜边的平方等于两直角边的平方和。在坐标平面中，给定两点 $P_1(x_1, y_1)$ 和 $P_2(x_2, y_2)$，我们可以构造一个以 $P_1P_2$ 为斜边的直角三角形——过 $P_1$ 作水平线、过 $P_2$ 作竖直线，两线交点即为直角顶点。两条直角边的长度恰好是 $|x_2 - x_1|$ 和 $|y_2 - y_1|$，这正是坐标差绝对值的几何意义。

这一公式的价值在于它将"距离"这一几何概念完全代数化了。从此，我们不再需要直尺和圆规，只需代数运算就能计算任意两点间的距离。这为后续的圆方程、圆锥曲线、点到直线距离等所有解析几何问题提供了基础工具。可以说，**两点间距离公式是解析几何大厦的第一块基石**。

## 证明过程

**证明**：过 $P_1$ 作 $x$ 轴的平行线，过 $P_2$ 作 $y$ 轴的平行线，两线交于 $Q$，则 $Q(x_2, y_1)$。在 $\triangle P_1QP_2$ 中，$\angle P_1QP_2 = 90^\circ$，$P_1Q = |x_2 - x_1|$，$QP_2 = |y_2 - y_1|$。由勾股定理得 $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$。$\square$
