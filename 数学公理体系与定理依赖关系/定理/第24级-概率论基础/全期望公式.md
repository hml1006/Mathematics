# 全期望公式

## 介绍

全期望公式（Law of Total Expectation）是概率论中关于条件期望的基本定理，它断言 $E[E[X|Y]] = E[X]$。这一公式是条件期望理论中最基本的结果之一，它将无条件期望分解为条件期望的期望。全期望公式在概率论和统计学中有广泛应用，例如在随机过程理论中计算复合分布的期望、在贝叶斯统计中计算后验期望、在精算科学中计算保险赔付的期望等。

## 分析

**前置依赖**：条件期望的定义、期望的性质、测度论基本概念。

**数学内涵**：
- 对随机变量 $X$ 和 $Y$，$E[X|Y]$ 是 $Y$ 的函数，定义为给定 $Y$ 时 $X$ 的条件期望。
- 全期望公式：$E[E[X|Y]] = E[X]$。
- 更一般地，对 $\sigma$-代数 $\mathcal{G} \subseteq \mathcal{H}$，$E[E[X|\mathcal{H}]|\mathcal{G}] = E[X|\mathcal{G}]$（塔性质）。
- 全期望公式是塔性质的特例（取 $\mathcal{G} = \{\varnothing, \Omega\}$）。

**结构**：
1. 利用条件期望的定义。
2. 对 $E[X|Y]$ 取期望，利用重期望性质。

## 思考过程

全期望公式的直观理解非常自然：要计算 $X$ 的期望，我们可以先根据 $Y$ 的不同取值分情况讨论（计算 $E[X|Y=y]$），然后对这些条件期望按 $Y$ 的分布加权平均。即 $E[X] = \int E[X|Y=y] f_Y(y) dy$（连续情形）或 $E[X] = \sum_y E[X|Y=y] P(Y=y)$（离散情形）。

这就像"分而治之"的策略——将复杂问题分解为若干子问题，分别求解后再汇总。

## 证明过程

**定理**（全期望公式）：设 $X$ 是随机变量，$E[|X|] < \infty$，$Y$ 是任意随机变量（或随机向量）。则
$$E[E[X|Y]] = E[X]$$

**证明**：

### 测度论证明

设 $(\Omega, \mathcal{F}, P)$ 是概率空间，$\mathcal{G} = \sigma(Y) \subseteq \mathcal{F}$ 是由 $Y$ 生成的 $\sigma$-代数。

条件期望 $E[X|\mathcal{G}]$ 是 $\mathcal{G}$-可测随机变量，满足对任意 $A \in \mathcal{G}$，
$$\int_A E[X|\mathcal{G}] dP = \int_A X dP$$

取 $A = \Omega \in \mathcal{G}$，得
$$\int_\Omega E[X|\mathcal{G}] dP = \int_\Omega X dP$$

即 $E[E[X|\mathcal{G}]] = E[X]$。由于 $E[X|Y] = E[X|\sigma(Y)]$，结论成立。

### 离散情形直接证明

若 $Y$ 是离散随机变量，取值为 $y_1, y_2, \ldots$，则
$$E[X|Y] = \sum_i E[X|Y = y_i] I_{\{Y = y_i\}}$$

两边取期望：
$$E[E[X|Y]] = \sum_i E[X|Y = y_i] P(Y = y_i) = \sum_i \left(\int x f_{X|Y}(x|y_i) dx\right) P(Y = y_i)$$
$$= \int x \left(\sum_i f_{X|Y}(x|y_i) P(Y = y_i)\right) dx = \int x f_X(x) dx = E[X]$$

$\square$

**推论**（塔性质）：对 $\sigma$-代数 $\mathcal{G} \subseteq \mathcal{H} \subseteq \mathcal{F}$，
$$E[E[X|\mathcal{H}]|\mathcal{G}] = E[X|\mathcal{G}]$$

**证明**：由条件期望的定义，对任意 $A \in \mathcal{G}$，
$$\int_A E[E[X|\mathcal{H}]|\mathcal{G}] dP = \int_A E[X|\mathcal{H}] dP = \int_A X dP = \int_A E[X|\mathcal{G}] dP$$
由 Radon-Nikodym 定理的唯一性，两边几乎必然相等。$\square$
