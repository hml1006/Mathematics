# 指数映射

## 介绍

指数映射 $\exp: \mathfrak{g} \to G$ 是连接李代数 $\mathfrak{g}$ 与李群 $G$ 的核心桥梁。它将李代数中的元素（切向量）映射到李群中的元素，是李群理论中"线性化"思想的具体实现。指数映射不仅具有深刻的几何意义，还在李群表示论、微分几何和数学物理中扮演着不可或缺的角色。

## 分析

**前置依赖**：李群的定义、李代数的定义、左不变向量场、单参子群、常微分方程解的存在唯一性。

**定理内容**：设 $G$ 是李群，$\mathfrak{g} = T_eG$ 是其李代数。对任意 $X \in \mathfrak{g}$，记 $\tilde{X}$ 为 $G$ 上由 $X$ 生成的左不变向量场（即 $\tilde{X}_g = (L_g)_*X$）。则存在唯一的单参子群 $\gamma_X: \mathbb{R} \to G$，使得 $\gamma_X(0) = e$ 且 $\dot{\gamma}_X(0) = X$。定义指数映射 $\exp: \mathfrak{g} \to G$ 为 $\exp(X) = \gamma_X(1)$。

指数映射具有以下性质：
1. $\exp(tX) = \gamma_X(t)$ 对任意 $t \in \mathbb{R}$。
2. $\exp(0) = e$，且 $d\exp_0: \mathfrak{g} \to \mathfrak{g}$ 是恒等映射。
3. 指数映射是光滑的，且在 $0$ 附近是局部微分同胚。
4. 对任意李群同态 $\varphi: G \to H$，有 $\varphi(\exp_G(X)) = \exp_H(\varphi_*X)$。

**数学内涵**：指数映射将李群上的单参子群与李代数中的元素一一对应。这种对应关系使得我们可以通过李代数（线性空间）来研究李群（非线性流形）的局部结构。指数映射的局部微分同胚性质确保了李代数在单位元附近完全刻画了李群的结构。

**证明策略**：利用常微分方程理论——左不变向量场 $\tilde{X}$ 是光滑向量场，由 ODE 解的存在唯一性定理，过 $e$ 点存在唯一的积分曲线 $\gamma_X(t)$。通过左不变性证明该积分曲线是单参子群。然后利用指数映射的构造，证明其光滑性和局部微分同胚性。

## 思考过程

指数映射的构造基于一个简单的观察：李代数 $X$ 确定了一个左不变向量场 $\tilde{X}$，这个向量场在 $G$ 上处处光滑。对左不变向量场求积分曲线，得到的曲线 $\gamma_X(t)$ 满足 $\gamma_X(0)=e$ 且 $\dot{\gamma}_X(0)=X$。

关键是要证明 $\gamma_X$ 是单参子群，即 $\gamma_X(s+t) = \gamma_X(s)\gamma_X(t)$。这利用了左不变向量场的性质：$\tilde{X}$ 在左平移下不变，意味着 $\gamma_X$ 在左平移下也保持形式。具体地，对固定的 $s$，曲线 $t \mapsto \gamma_X(s)^{-1}\gamma_X(s+t)$ 和 $t \mapsto \gamma_X(t)$ 满足相同的 ODE 和初始条件，由唯一性得两者相等。

指数映射的局部微分同胚性质来自 $d\exp_0 = \mathrm{id}_{\mathfrak{g}}$，这通过分析 $\exp$ 在 $0$ 处的微分得到。然后由反函数定理，$\exp$ 在 $0$ 附近是局部微分同胚。

## 证明过程

**定理**（指数映射）：设 $G$ 是李群，$\mathfrak{g} = T_eG$。

**(1) 单参子群的存在唯一性**：对任意 $X \in \mathfrak{g}$，定义左不变向量场 $\tilde{X}$ 为 $\tilde{X}_g = (L_g)_*X$。由常微分方程理论，存在唯一的积分曲线 $\gamma_X: (-\varepsilon, \varepsilon) \to G$ 满足 $\gamma_X(0) = e$ 且 $\dot{\gamma}_X(t) = \tilde{X}_{\gamma_X(t)}$。

**证明 $\gamma_X$ 是单参子群**：对任意 $s$ 使得 $\gamma_X(s)$ 有定义，考虑曲线
$$\alpha(t) = \gamma_X(s)^{-1}\gamma_X(s+t)$$
则 $\alpha(0) = e$，且
$$\dot{\alpha}(t) = (dL_{\gamma_X(s)^{-1}})_{\gamma_X(s+t)}\dot{\gamma}_X(s+t) = (dL_{\gamma_X(s)^{-1}})_{\gamma_X(s+t)}\tilde{X}_{\gamma_X(s+t)}$$
$$= (dL_{\gamma_X(s)^{-1}})_{\gamma_X(s+t)}(dL_{\gamma_X(s+t)})_eX = (dL_{\gamma_X(s)^{-1}\gamma_X(s+t)})_eX = \tilde{X}_{\alpha(t)}$$
故 $\alpha(t)$ 也是 $\tilde{X}$ 的积分曲线，且 $\alpha(0) = e$。由唯一性，$\alpha(t) = \gamma_X(t)$，即
$$\gamma_X(s)^{-1}\gamma_X(s+t) = \gamma_X(t)$$
因此 $\gamma_X(s+t) = \gamma_X(s)\gamma_X(t)$。由标准的 ODE 延拓论证，$\gamma_X$ 可延拓到整个 $\mathbb{R}$ 上。

**(2) 指数映射的定义**：定义 $\exp: \mathfrak{g} \to G$ 为 $\exp(X) = \gamma_X(1)$。由单参子群性质，$\gamma_X(t) = \exp(tX)$ 对任意 $t \in \mathbb{R}$。

**(3) 光滑性**：考虑映射 $\Phi: \mathbb{R} \times \mathfrak{g} \to G$，$\Phi(t,X) = \exp(tX)$。由 ODE 的解对参数的光滑依赖性，$\Phi$ 是光滑的。特别地，$\exp(X) = \Phi(1,X)$ 光滑。

**(4) 在 $0$ 处的微分**：对任意 $X \in \mathfrak{g}$，
$$d\exp_0(X) = \left.\frac{d}{dt}\right|_{t=0}\exp(tX) = \left.\frac{d}{dt}\right|_{t=0}\gamma_X(t) = X$$
故 $d\exp_0 = \mathrm{id}_{\mathfrak{g}}$。

**(5) 局部微分同胚**：由反函数定理，因为 $d\exp_0$ 是同构，$\exp$ 在 $0$ 附近是局部微分同胚。即存在 $0$ 的邻域 $U \subseteq \mathfrak{g}$ 和 $e$ 的邻域 $V \subseteq G$，使得 $\exp|_U: U \to V$ 是微分同胚。

**(6) 自然性**：对任意李群同态 $\varphi: G \to H$，对任意 $X \in \mathfrak{g}$，曲线 $t \mapsto \varphi(\exp(tX))$ 是 $H$ 中的单参子群，且
$$\left.\frac{d}{dt}\right|_{t=0}\varphi(\exp(tX)) = \varphi_*(X)$$
故 $\varphi(\exp(tX)) = \exp_H(t\varphi_*(X))$。取 $t=1$ 得 $\varphi(\exp_G(X)) = \exp_H(\varphi_*X)$。$\square$
