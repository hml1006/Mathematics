# 第63级-组合代数拓扑与拓扑数据分析

- [Mapper 算法：拓扑数据可视化方法](./Mapper算法.md)
- [离散 Morse 理论（Forman）](./Morse理论组合版本.md)
- [Čech 与 Vietoris-Rips 复形：点云拓扑重建](./Čech与Vietoris-Rips复形.md)
- [单纯复形与 simplicial 同调](./单纯复形与simplicial同调.md)
- [持久同调基本定理：barcode 分解定理](./持久同调基本定理.md)
- [欧拉示性数在网络分析中的应用](./欧拉示性数与网络分析.md)
- [持久同调的稳定性：bottleneck 距离下的稳定性](./稳定性定理.md)
- [单纯逼近定理](./单纯逼近定理.md)：两个多面体之间的任意连续映射，都可以先把定义域细分，再用一个"纯组合的"单纯映射与它同伦逼近——于是连续拓扑问题可以用有限组合数据来算。
- [主理想整环上的有限生成模结构定理](./主理想整环上的有限生成模结构定理.md)：在主理想整环上，每个有限生成模都能唯一地拆成"自由部分加若干循环挠模"，像整数唯一分解一样干净；整数、多项式、线性算子三套"标准形"其实是同一条定理。
- [区间分解定理](./区间分解定理.md)：随尺度变化的向量空间族（持久模）唯一地拆成若干"只在某段区间上活着"的区间模；这些区间就是 barcode，既足够刻画对象，又不会多也不会少。
- [Gabriel 定理](./Gabriel定理.md)：一个箭图（有限的有向图）上的"表示"只有有限多个积木块，当且仅当它的底图是 A、D、E 型 Dynkin 图；此时积木块与根系的正根一一对应。
