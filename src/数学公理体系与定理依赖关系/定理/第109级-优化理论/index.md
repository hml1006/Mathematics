# 第109级-最优化理论

本目录收录以下定理：

- [KKT条件的充分性与必要性](./KKT条件的充分性与必要性.md)
- [强对偶定理（Slater条件）](./强对偶定理（Slater条件）.md)
- [线性规划的对偶定理](./线性规划的对偶定理.md)
- [梯度下降法的收敛性](./梯度下降法的收敛性.md)
- [Newton法的局部二次收敛性](./Newton法的局部二次收敛性.md)
- [凸集分离定理](./凸集分离定理.md)：两个互不相交（或内部不相交）的凸集，总能被一张超平面像刀切豆腐一样分开，使它们分别落在这张平面的两侧。
- [强凸函数与 Hessian 界](./强凸函数与Hessian界.md)：一个二阶可微函数若"曲率被夹住"——每一点的 Hessian 都落在 $mI$ 与 $MI$ 之间——那它就同时具备两件好事：从下方被一个开口为 $m$ 的抛物面托住（$m$-强凸），从上方被一个开口为 $M$ 的抛物面罩住（$M$-光滑）。比值 $\kappa=M/m$ 就是条件数，直接决定一阶算法收敛的快慢。
- [范数与平行四边形恒等式](./范数与平行四边形恒等式.md)：什么时候一个"长度"是由内积（点乘）长出来的？判据只有一条——平行四边形恒等式：两条对角线的平方和等于四条边的平方和。满足它，内积就能被范数唯一还原（极化恒等式）；不满足（如 $\ell^1$、$\ell^\infty$ 范数），它永远不是内积的长度。
