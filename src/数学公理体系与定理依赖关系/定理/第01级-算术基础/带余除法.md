# 带余除法

> **一句话大白话**：整数除不尽也没关系，总能写成"商×除数 再加个比除数小的余数"，而且这么写是唯一的。
>
> **小例子**：$17 = 5\times3 + 2$，即 $17\div5$ 商是 $3$、余数是 $2$，而这个余数 $2$ 一定比除数 $5$ 小。

## 介绍

带余除法是数论中最基本的定理之一，它断言：对于任意整数 $a$ 和非零整数 $b$，存在唯一的一对整数 $q$（商）和 $r$（余数），使得 $a = bq + r$，且 $0 \leq r < |b|$。这一结论虽然简单，却是整个数论大厦的基石，它直接奠定了辗转相除法、最大公因数理论、同余理论以及模算术的基础。在计算机科学中，带余除法也是整数除法和取模运算的理论依据。

## 分析

**前置依赖**：Peano 公理（自然数的定义）、整数的定义、序关系。

**数学内涵**：
- 带余除法本质上是对除法运算的严格化描述。在日常生活中，"除法"常被理解为"均分"，但在整数范围内，并不是任意两个整数都能整除（即 $b$ 不一定能整除 $a$）。带余除法精确地描述了这种"除不尽"的情形——有余数。
- 定理的结论包含两个部分：**存在性**和**唯一性**。存在性保证了我们总能找到这样的 $q$ 和 $r$；唯一性保证了在给定 $a$ 和 $b$ 后，$q$ 和 $r$ 是被唯一确定的。
- 余数 $r$ 的范围 $0 \leq r < |b|$ 至关重要，它保证了余数的"最小非负性"。

**结构**：
1. 存在性：通过构造或数学归纳法证明 $q$ 和 $r$ 的存在。
2. 唯一性：假设存在两组不同的 $(q,r)$，通过反证法推出矛盾。

## 思考过程

带余除法的发现源于人类对"分配"和"度量"的直观经验。假如有 $a$ 个苹果，要分给 $b$ 个人，每人分 $q$ 个后，剩下的苹果数 $r$ 必然小于人数 $b$，否则就可以继续分。这个朴素的想法上升到数学层面，就得到了带余除法。

在严格的数学证明中，我们需要从 Peano 公理出发。对于自然数 $a$ 和正整数 $b$，我们可以考虑所有形如 $a - bq$ 的非负整数构成的集合，这个集合是非空的（因为 $q=0$ 时 $a \geq 0$），由良序原理，其中存在最小值 $r$，可以证明 $r < b$。对于负数和负除数的情形，可以通过符号调整归约到自然数情形。

## 证明过程

**定理**：对任意整数 $a$ 和 $b \neq 0$，存在唯一的整数 $q$ 和 $r$，使得 $a = bq + r$，且 $0 \leq r < |b|$。

**证明**：

### 1. 存在性

先考虑 $a \geq 0$ 且 $b > 0$ 的情形。

设集合 $S = \{ a - bq \mid q \in \mathbb{Z},\ a - bq \geq 0 \}$。显然 $0 \in S$（取 $q=0$ 时 $a \geq 0$），故 $S$ 是非空自然数集合。由良序原理，$S$ 有最小元 $r$。设 $r = a - bq$。

假设 $r \geq b$，则 $r - b = a - b(q+1) \geq 0$，且 $r - b \in S$，但 $r - b < r$，与 $r$ 的最小性矛盾。故 $r < b$。

因此存在 $q, r$ 使得 $a = bq + r$，$0 \leq r < b$。

对于 $a < 0$ 或 $b < 0$ 的情形，可通过符号调整化为上述情形：

- 若 $b < 0$，则 $-b > 0$。先对 $a$ 和 $|b|$ 做带余除法得 $a = |b|q' + r$，$0 \leq r < |b|$。令 $q = -q'$，则 $a = bq + r$。
- 若 $a < 0$ 且 $b > 0$，先对 $-a$ 和 $b$ 做带余除法得 $-a = bq' + r'$，$0 \leq r' < b$。若 $r' = 0$，则 $a = b(-q')$，取 $r=0$；若 $r' > 0$，则 $a = b(-q'-1) + (b - r')$，其中 $0 < b - r' < b$。

### 2. 唯一性

假设存在两组表示：

$$
a = bq_1 + r_1,\quad 0 \leq r_1 < |b|
$$
$$
a = bq_2 + r_2,\quad 0 \leq r_2 < |b|
$$

两式相减得：

$$
b(q_1 - q_2) = r_2 - r_1
$$

于是 $|b||q_1 - q_2| = |r_2 - r_1|$。

由于 $0 \leq r_1, r_2 < |b|$，有 $|r_2 - r_1| < |b|$。若 $q_1 \neq q_2$，则 $|q_1 - q_2| \geq 1$，于是 $|b||q_1 - q_2| \geq |b|$，矛盾。故 $q_1 = q_2$，进而 $r_1 = r_2$。

综上，存在唯一的 $q$ 和 $r$ 满足条件。$\square$
