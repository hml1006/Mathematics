# 长方体对角线公式

> **一句话大白话**：一个方盒子的对角“贯穿线”长，就是长宽高各自的平方加起来再开根号，勾股定理往三维长一截。
>
> **小例子**：长 $a=2$、宽 $b=3$、高 $c=6$ 的长方体，$d=\sqrt{2^2+3^2+6^2}=\sqrt{4+9+36}=\sqrt{49}=7$，正好是整数。

## 介绍

长方体对角线公式是立体几何中的基本公式：长、宽、高分别为 $a, b, c$ 的长方体，其体对角线 $d$ 满足 $d^2 = a^2 + b^2 + c^2$，即 $d = \sqrt{a^2 + b^2 + c^2}$。该公式是勾股定理在三维空间中的直接推广，在空间解析几何、物理学、工程学等领域有广泛应用。

## 分析

**前置依赖**：勾股定理。

**定理内容**：长、宽、高分别为 $a, b, c$ 的长方体，体对角线长度为 $d = \sqrt{a^2 + b^2 + c^2}$。

**数学内涵**：
- 该公式是勾股定理从二维到三维的自然推广，体现了欧几里得空间中距离度量的本质。
- 在 $n$ 维空间中，超长方体（$n$ 维矩形）的对角线长度公式为 $d = \sqrt{x_1^2 + x_2^2 + \cdots + x_n^2}$，是一般欧几里得距离公式的基础。
- 该公式与空间向量的模长公式一致：向量 $\vec{v} = (a, b, c)$ 的模长为 $|\vec{v}| = \sqrt{a^2 + b^2 + c^2}$。

**证明策略**：
- 两次应用勾股定理：先求底面对角线，再求体对角线。

## 思考过程

长方体对角线公式的推导非常直观。首先，底面的对角线 $d_1$ 满足 $d_1^2 = a^2 + b^2$（由勾股定理）。然后，体对角线 $d$、底面对角线 $d_1$ 和高 $c$ 构成一个直角三角形（体对角线是斜边），再次应用勾股定理即得 $d^2 = d_1^2 + c^2 = a^2 + b^2 + c^2$。

## 证明过程

**定理**（长方体对角线公式）：长、宽、高分别为 $a, b, c$ 的长方体，体对角线长度为 $d = \sqrt{a^2 + b^2 + c^2}$。

**证明**：

设长方体 $ABCD-A'B'C'D'$ 的长为 $AB = a$，宽为 $BC = b$，高为 $AA' = c$。考虑体对角线 $AC'$。

**第一步**：求底面对角线 $AC$ 的长度。

在底面矩形 $ABCD$ 中，$AB \perp BC$，由勾股定理：

$$
AC^2 = AB^2 + BC^2 = a^2 + b^2
$$

**第二步**：求体对角线 $AC'$ 的长度。

在 $\triangle ACC'$ 中，$AC$ 在底面内，$CC' \perp$ 底面，故 $CC' \perp AC$，即 $\triangle ACC'$ 是直角三角形，$\angle ACC' = 90^\circ$。由勾股定理：

$$
AC'^2 = AC^2 + CC'^2 = (a^2 + b^2) + c^2 = a^2 + b^2 + c^2
$$

因此

$$
d = AC' = \sqrt{a^2 + b^2 + c^2}
$$

$\square$

---

**证明**（向量法）：

以长方体一个顶点为原点建立空间直角坐标系，设三条棱的方向为坐标轴方向。则体对角线对应的向量为 $\vec{v} = (a, b, c)$，其模长为

$$
d = |\vec{v}| = \sqrt{a^2 + b^2 + c^2}
$$

$\square$

## 课堂问答

**老师**：长宽高分别为 $a,b,c$ 的长方体，体对角线多长？

**学生**：$d=\sqrt{a^2+b^2+c^2}$。理由：先由勾股定理得底面对角线 $AC^2=a^2+b^2$；再在直角三角形 $ACC'$ 中由 $CC'\perp$ 底面得 $AC'^2=AC^2+c^2=a^2+b^2+c^2$。两次勾股即得结论。

**老师（追问）**：为什么能直接"平方相加"，会不会漏掉交叉项？

**学生**：不会，因为三个方向两两垂直。$CC'\perp$ 底面保证 $\angle ACC'=90^\circ$，两次勾股都落在直角情形，故无交叉项。若是不垂直的斜平行六面体，对角线就要含 $2ab\cos\theta$ 之类的交叉项，公式失效。

**老师（拓展）**：这个公式更一般的身份是什么？

**学生**：它就是 $\mathbb{R}^3$ 中向量 $(a,b,c)$ 的模长 $|\vec v|=\sqrt{a^2+b^2+c^2}$，推广到 $n$ 维即欧氏距离 $d=\sqrt{\sum x_i^2}$。常见误区是把它写成 $a+b+c$（那是曼哈顿量）或 $\sqrt{a^2+b^2}+c$，后者一般并不等于体对角线长。
