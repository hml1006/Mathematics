# 特征函数唯一性定理

> **一句话大白话**：每个随机变量都有一个"身份证号"（特征函数），而且身份证号互不相同——知道了特征函数，就能唯一确定这个分布，反过来也一样，一一对应。
>
> **小例子**：正态 $N(\mu,\sigma^2)$ 的特征函数是 $e^{i\mu t-\frac12\sigma^2t^2}$，由它即可唯一还原出分布；若两个变量的特征函数处处相等，它们的分布必然相同。

## 介绍

特征函数唯一性定理是概率论中的基本定理，它断言随机变量的分布函数被其特征函数唯一确定。特征函数定义为 $\varphi_X(t) = E[e^{itX}]$，它是傅里叶变换在概率论中的对应物。这一定理是傅里叶变换理论在概率论中的直接应用，它保证了特征函数是研究分布函数的有效工具——通过分析特征函数可以推断分布的性质，而无需直接处理分布函数本身。该定理是中心极限定理、连续性定理等许多重要结论的基础。

## 分析

**前置依赖**：傅里叶变换理论、特征函数的定义、分布函数、反演公式。

**数学内涵**：
- 特征函数 $\varphi_X(t) = E[e^{itX}] = \int_{-\infty}^\infty e^{itx} dF_X(x)$，其中 $F_X$ 是 $X$ 的分布函数。
- 唯一性定理：若两个随机变量 $X$ 和 $Y$ 的特征函数相等（$\varphi_X(t) = \varphi_Y(t)$ 对所有 $t \in \mathbb{R}$），则 $X$ 和 $Y$ 同分布。
- 证明依赖于傅里叶变换的反演公式，该公式可以从特征函数恢复分布函数。
- 具体地，有反演公式：
  $$F(b) - F(a) = \lim_{T \to \infty} \frac{1}{2\pi} \int_{-T}^T \frac{e^{-ita} - e^{-itb}}{it} \varphi(t) dt$$

**结构**：
1. 介绍傅里叶变换和反演公式。
2. 利用反演公式从特征函数恢复分布函数。
3. 证明唯一性。

## 思考过程

特征函数唯一性定理的证明基于傅里叶分析中的反演公式。在傅里叶分析中，一个函数可以由其傅里叶变换通过反演公式恢复。类似地，在概率论中，分布函数可以由其特征函数通过反演公式恢复。

反演公式的基本形式为：
$$F(b) - F(a) = \lim_{T \to \infty} \frac{1}{2\pi} \int_{-T}^T \frac{e^{-ita} - e^{-itb}}{it} \varphi(t) dt$$
其中 $a < b$ 是 $F$ 的连续点。如果两个分布的特征函数相同，则反演公式给出相同的分布函数，因此分布相同。

## 证明过程

**定理**（特征函数唯一性定理）：设 $X$ 和 $Y$ 是随机变量，$\varphi_X$ 和 $\varphi_Y$ 是它们的特征函数。若 $\varphi_X(t) = \varphi_Y(t)$ 对所有 $t \in \mathbb{R}$ 成立，则 $X$ 和 $Y$ 同分布。

**证明**：

### 1. 反演公式

设 $F$ 是分布函数，$\varphi$ 是其特征函数。对任意 $a < b$，若 $a, b$ 是 $F$ 的连续点，则
$$F(b) - F(a) = \lim_{T \to \infty} \frac{1}{2\pi} \int_{-T}^T \frac{e^{-ita} - e^{-itb}}{it} \varphi(t) dt$$

### 2. 反演公式的推导

考虑积分
$$I_T = \frac{1}{2\pi} \int_{-T}^T \frac{e^{-ita} - e^{-itb}}{it} \varphi(t) dt$$

代入 $\varphi(t) = \int_{-\infty}^\infty e^{itx} dF(x)$，由 Fubini 定理交换积分次序：
$$I_T = \frac{1}{2\pi} \int_{-\infty}^\infty \left(\int_{-T}^T \frac{e^{-ita} - e^{-itb}}{it} e^{itx} dt\right) dF(x)$$

计算内层积分可得
$$\int_{-T}^T \frac{e^{it(x-a)} - e^{it(x-b)}}{it} dt = \int_{-T}^T \frac{\sin t(x-a)}{t} dt - \int_{-T}^T \frac{\sin t(x-b)}{t} dt$$

利用 Dirichlet 积分 $\int_{-\infty}^\infty \frac{\sin t}{t} dt = \pi$，可得
$$\lim_{T \to \infty} \int_{-T}^T \frac{\sin t c}{t} dt = \pi \cdot \text{sgn}(c)$$

因此
$$\lim_{T \to \infty} I_T = \frac{1}{2\pi} \int_{-\infty}^\infty \pi[\text{sgn}(x-a) - \text{sgn}(x-b)] dF(x)$$
$$= \frac{1}{2} \int_{-\infty}^\infty [\text{sgn}(x-a) - \text{sgn}(x-b)] dF(x)$$

当 $a < x < b$ 时，$\text{sgn}(x-a) - \text{sgn}(x-b) = 2$；当 $x < a$ 或 $x > b$ 时，该差为 $0$；当 $x = a$ 或 $x = b$ 时，该差为 $1$。因此
$$\lim_{T \to \infty} I_T = F(b-) - F(a) + \frac{1}{2}[F(b) - F(b-)] - \frac{1}{2}[F(a) - F(a-)]$$

若 $a, b$ 是 $F$ 的连续点，则 $F(b-) = F(b)$，$F(a) = F(a-)$，故
$$\lim_{T \to \infty} I_T = F(b) - F(a)$$

### 3. 唯一性

若 $\varphi_X = \varphi_Y$，则由反演公式，对任意 $a < b$ 都是 $F_X$ 和 $F_Y$ 的连续点，有
$$F_X(b) - F_X(a) = F_Y(b) - F_Y(a)$$

令 $a \to -\infty$，得 $F_X(b) = F_Y(b)$ 对所有连续点 $b$ 成立。由于分布函数在非连续点处的值由右连续性决定，$F_X = F_Y$ 处处成立。$\square$
