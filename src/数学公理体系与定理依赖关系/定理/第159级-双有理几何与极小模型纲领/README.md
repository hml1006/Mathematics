# 第159级-双有理几何与极小模型纲领

> 一句话级别概述：双有理几何研究允许爆破与收缩的等价类：极小模型纲领用锥定理与翻转，把任意簇化简到最小的代表，从而给高维簇分类。

## 级别简介

本级别从 Hironaka 奇点消解出发，建立 Mori 锥定理与收缩定理、Kawamata-Viehweg 消失与基点自由；随后进入翻转存在性（BCHM）与 MMP 的存在性、三维 MMP，最后以有界性定理收尾。

## 本级别定理

- [Hironaka 奇点消解定理](./Hironaka奇点消解定理.md)：特征零域上的代数簇可经一串容许的 blow-up 得到光滑簇，且除子处于简单正规交叉位置。
- [Mori 锥定理与收缩定理](./Mori锥定理与收缩定理.md)：$K_X$ 负的极值射线可由收缩态射压缩，收缩的类型（纤维/除子/点）由极值射线的性质决定。
- [Kawamata-Viehweg 消失定理](./Kawamata-Viehweg消失定理.md)：若 $D$ 是半丰沛 $\mathbb Q$-除子且 $D-\lfloor D\rfloor$ 的支撑为简单正规交叉，则 $H^i(X,K_X+D)=0\ (i>0)$。
- [Kawamata 基点自由定理](./Kawamata基点自由定理.md)：对 klt 对数对 $(X,\Delta)$，若 $K_X+\Delta$ 丰沛，则 $|m(K_X+\Delta)|$ 对某 $m$ 基点自由。
- [翻转的存在性（BCHM）](./翻转的存在性.md)：特征零域上 klt 对数对的收缩翻转（flip）存在，且由有限生成环的有限生成性推出。
- [极小模型纲领的存在性](./极小模型纲领的存在性.md)：特征零域上任意 klt 对数对可运行 MMP 并终止于极小模型或 Mori 纤维空间（BCHM）。
- [三维极小模型纲领](./三维极小模型纲领.md)：三维代数簇的翻转与极小模型存在（Mori 1988），由此得到三维双有理分类。
- [双有理几何中的有界性](./双有理几何中的有界性.md)：固定维数与体积下界，klt 簇构成有界族（Birkar），即只有有限多个形变族。

## 前置知识

代数几何（概形、相交理论、除子）、奇点理论、层上同调。

## 后继用途

为高维簇分类、模空间与有界性、以及极小模型纲领在特征 p 的推广提供基础。

## 关键定理速览

- Hironaka：特征零奇点可消解。
- KX 负极值射线可收缩。
- Kawamata-Viehweg 消失是基点自由的关键。
- BCHM：特征零 klt 对数对的翻转存在。
- 三维 MMP 由 Mori 完成。
