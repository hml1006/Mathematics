# 第88级-有限几何学

本目录收录以下定理。主教程第62级“射影几何”的对应内容在本库归入第88级；其中射影基本定理、Pappus、Pascal、Brianchon 与交比等条目均在本目录重新核对假设后表述。

- [有限射影平面的基本性质](./有限射影平面的基本性质.md)
- [Bruck-Ryser定理](./Bruck-Ryser定理.md)
- [仿射平面与射影平面的扩展](./仿射平面与射影平面的扩展.md)
- [Desargues定理](./Desargues定理.md)
- [有限广义四边形的基本性质](./有限广义四边形的基本性质.md)
- [Hasse–Minkowski 局部-全局原理](./Hasse–Minkowski局部-全局原理.md)：一个有理系数的二次方程（二次型）在有理数里有没有解，只要看它在每个"局部世界"（实数与所有 $p$ 进数）里有没有解就够了——局部处处有解，则整体必有解。
- [初等数论中的平方和定理](./初等数论中的平方和定理.md)：一个自然数能否写成若干平方数之和，有初等的判别法：两平方看质因数中 $4k+3$ 型素数指数是否为偶，三平方排除 $4^a(8b+7)$ 型，四平方则永远可以。
- [射影平面的对偶原理](./射影平面的对偶原理.md)：在射影平面里，"点"与"直线"地位完全对等——把命题中的点和线互换、把"在……上"与"经过"互换，得到的仍是成立的命题。
- [射影几何基本定理](./射影几何基本定理.md)：维数至少为二的射影共线同构由射影半线性映射诱导；域自同构为恒等时才是射影线性变换，而 $n+2$ 个一般位置点唯一确定一个射影线性标架对应。
- [Pappus定理](./Pappus定理.md)：两条线上各三点交叉连线所得的三个交点共线；在可坐标化平面中，这一构型等价于坐标除环的乘法交换，因此实、复射影平面及 $\mathrm{PG}(2,q)$ 中均成立。
- [Pascal与Brianchon定理](./Pascal与Brianchon定理.md)：非退化圆锥曲线内接六边形的三组对边交点共线；经无奇异配极对偶，外切六边形的三条主对角线共点，无穷远交点也包含在内。
- [交比不变性](./交比不变性.md)：四个有序共线点的交比在射影线性变换下不变，并由二阶行列式公式给出；一般半线性变换会把交比 $k$ 变为 $\sigma(k)$，不能漏掉域自同构。
