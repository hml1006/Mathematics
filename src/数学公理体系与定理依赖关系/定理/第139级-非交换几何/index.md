# 第139级-非交换几何

本目录收录以下定理：

- [Connes指标定理（局部指标公式）](./Connes指标定理（局部指标公式）.md)
- [非交换环面的基本性质](./非交换环面的基本性质.md)
- [非交换几何中的K-理论与指标](./非交换几何中的K-理论与指标.md)
- [非交换积分公式（Dixmier迹）](./非交换积分公式（Dixmier迹）.md)
- [非交换几何与标准模型](./非交换几何与标准模型.md)
- [McKean-Singer公式](./McKean-Singer公式.md)：把"热的扩散"（热核 $e^{-tD^2}$）按正负分次带符号求和，得到的数竟完全不随扩散时间 $t$ 变化——它只能由"零能量"部分（Dirac 算子的核，即零模）贡献，因此就等于指标。
- [谱作用原理](./谱作用原理.md)：物理的作用量不必事先写下来，它可以由 Dirac 算子的谱"自动生成"——把 $D$ 按能量尺度 $\Lambda$ 截断后求迹，展开就依次得到宇宙学常数、爱因斯坦-希尔伯特引力项、杨-米尔斯项与希格斯势。
