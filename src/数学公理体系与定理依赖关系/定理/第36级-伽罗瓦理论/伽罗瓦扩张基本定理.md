# 伽罗瓦扩张基本定理

> **一句话大白话**：一个扩张的中间域（介于基域和扩域之间的一切房子）和它的伽罗瓦群的子群正好一一配对——给定子群得中间域、给定中间域得子群，谁都能导回谁，像镜子的两面。
>
> **小例子**：扩张 $\mathbb{Q}(\sqrt{2},\sqrt{3})$ 的伽罗瓦群是四元克莱因群，它的每个子群对应一个中间域，如子群 $\{\sigma,\tau\}$ 对应定点域 $\mathbb{Q}(\sqrt{2})$。

## 介绍

伽罗瓦扩张基本定理（Fundamental Theorem of Galois Theory）是伽罗瓦理论的核心定理，由埃瓦里斯特·伽罗瓦在 19 世纪 30 年代建立。该定理建立了伽罗瓦扩张的中间域与其伽罗瓦群的子群之间的一一对应关系，将域论问题转化为群论问题。这一深刻的联系使得许多关于域扩张的难题可以通过群论方法解决，特别是多项式方程的根式可解性问题。

## 分析

**前置依赖**：域论、群论、域扩张、伽罗瓦群、正规扩张、可分扩张。

**数学内涵**：

**定理内容**：设 $L/K$ 是有限伽罗瓦扩张，$G = \operatorname{Gal}(L/K)$ 是伽罗瓦群。则存在以下一一对应：

$$
\{\text{中间域 } K \subseteq F \subseteq L\} \longleftrightarrow \{\text{子群 } H \subseteq G\}
$$

具体对应关系为：
- 对中间域 $F$，对应子群 $\operatorname{Gal}(L/F) \subseteq G$。
- 对子群 $H \subseteq G$，对应中间域 $L^H = \{x \in L \mid \sigma(x) = x, \forall \sigma \in H\}$（固定域）。

该对应具有以下性质：
1. **包含关系反转**：$F_1 \subseteq F_2 \iff \operatorname{Gal}(L/F_2) \subseteq \operatorname{Gal}(L/F_1)$。
2. **度数公式**：$[L:F] = |\operatorname{Gal}(L/F)|$，$[F:K] = [G:\operatorname{Gal}(L/F)]$。
3. **正规性**：$F/K$ 是正规扩张当且仅当 $\operatorname{Gal}(L/F) \trianglelefteq G$，此时 $\operatorname{Gal}(F/K) \cong G/\operatorname{Gal}(L/F)$。

**证明策略**：先证明 $L^{\operatorname{Gal}(L/F)} = F$ 和 $\operatorname{Gal}(L/L^H) = H$，然后建立双射。

## 思考过程

伽罗瓦基本定理的核心思想可以概括为"对称性"：域扩张 $L/K$ 的中间域对应于 $L$ 在 $K$ 上的自同构群的子群。每个中间域 $F$ 对应了那些保持 $F$ 中元素不变的自同构构成的子群；反过来，每个子群 $H$ 对应了被 $H$ 中所有自同构固定的元素构成的域。

这个对应之所以是"反序"的，是因为更大的中间域有更少的自同构（约束更多），而更小的中间域有更多的自同构（约束更少）。

伽罗瓦基本定理将域论问题转化为群论问题，这是数学中"对称性"思想的最高体现之一。

## 证明过程

**定理**（伽罗瓦扩张基本定理）：设 $L/K$ 是有限伽罗瓦扩张，$G = \operatorname{Gal}(L/K)$。则：
1. 映射 $F \mapsto \operatorname{Gal}(L/F)$ 和 $H \mapsto L^H$ 互为逆映射，建立了中间域和子群之间的一一对应。
2. $[L:F] = |\operatorname{Gal}(L/F)|$，$[F:K] = [G:\operatorname{Gal}(L/F)]$。
3. $F/K$ 是正规扩张 $\iff$ $\operatorname{Gal}(L/F) \trianglelefteq G$，此时 $\operatorname{Gal}(F/K) \cong G/\operatorname{Gal}(L/F)$。

**证明**：

### 1. 基本引理

**引理 1**：对任意子群 $H \subseteq G$，$L/L^H$ 是伽罗瓦扩张，且 $\operatorname{Gal}(L/L^H) = H$。

*证明*：$L/L^H$ 显然是可分扩张（因为 $L/K$ 可分）。由 Artin 引理，$[L:L^H] \le |H|$。另一方面，$H \subseteq \operatorname{Gal}(L/L^H)$，故 $|H| \le |\operatorname{Gal}(L/L^H)| = [L:L^H]$。因此 $[L:L^H] = |H|$，$H = \operatorname{Gal}(L/L^H)$。$\square$

**引理 2**：对任意中间域 $K \subseteq F \subseteq L$，$L/F$ 是伽罗瓦扩张，且 $\operatorname{Gal}(L/L^{\operatorname{Gal}(L/F)}) = \operatorname{Gal}(L/F)$。

*证明*：$L/F$ 是可分正规扩张（因为 $L/K$ 是伽罗瓦扩张）。故 $L/F$ 是伽罗瓦扩张。由引理 1，$\operatorname{Gal}(L/L^{\operatorname{Gal}(L/F)}) = \operatorname{Gal}(L/F)$。$\square$

### 2. 一一对应的建立

**定理 2**：映射 $F \mapsto \operatorname{Gal}(L/F)$ 和 $H \mapsto L^H$ 互为逆映射。

*证明*：

- 从中间域到子群再到中间域：对中间域 $F$，令 $H = \operatorname{Gal}(L/F)$，则 $L^H = L^{\operatorname{Gal}(L/F)} = F$（由引理 2 和伽罗瓦扩张的性质）。
- 从子群到中间域再到子群：对子群 $H \subseteq G$，令 $F = L^H$，则 $\operatorname{Gal}(L/F) = \operatorname{Gal}(L/L^H) = H$（由引理 1）。

因此两个映射互为逆映射，建立了一一对应。$\square$

### 3. 度数公式

**定理 3**：$[L:F] = |\operatorname{Gal}(L/F)|$，$[F:K] = [G:\operatorname{Gal}(L/F)]$。

*证明*：由于 $L/F$ 是伽罗瓦扩张，$[L:F] = |\operatorname{Gal}(L/F)|$。由塔定理：
$$
[L:K] = [L:F][F:K]
$$
又 $[L:K] = |G|$，故：
$$
[F:K] = \frac{|G|}{|\operatorname{Gal}(L/F)|} = [G:\operatorname{Gal}(L/F)]
$$
$\square$

### 4. 正规性与商群

**定理 4**：$F/K$ 是正规扩张 $\iff$ $\operatorname{Gal}(L/F) \trianglelefteq G$。此时有群同构 $\operatorname{Gal}(F/K) \cong G/\operatorname{Gal}(L/F)$。

*证明*：

（$\Rightarrow$）假设 $F/K$ 是正规扩张。对任意 $\sigma \in G$，$\tau \in \operatorname{Gal}(L/F)$，需证 $\sigma\tau\sigma^{-1} \in \operatorname{Gal}(L/F)$。对任意 $x \in F$，由于 $F/K$ 正规，$\sigma^{-1}(x) \in F$，故 $\tau(\sigma^{-1}(x)) = \sigma^{-1}(x)$，从而 $\sigma\tau\sigma^{-1}(x) = x$。因此 $\sigma\tau\sigma^{-1} \in \operatorname{Gal}(L/F)$，$\operatorname{Gal}(L/F) \trianglelefteq G$。

（$\Leftarrow$）假设 $\operatorname{Gal}(L/F) \trianglelefteq G$。设 $f(x) \in K[x]$ 是 $a \in F$ 的极小多项式，$\alpha$ 是 $f$ 的另一个根。由于 $L/K$ 是伽罗瓦扩张，存在 $\sigma \in G$ 使得 $\sigma(a) = \alpha$。对任意 $\tau \in \operatorname{Gal}(L/F)$，$\sigma^{-1}\tau\sigma \in \operatorname{Gal}(L/F)$，故 $\tau(\alpha) = \tau(\sigma(a)) = \sigma(\sigma^{-1}\tau\sigma(a)) = \sigma(a) = \alpha$。因此 $\alpha \in L^{\operatorname{Gal}(L/F)} = F$，$F/K$ 正规。

此时，限制映射 $G \to \operatorname{Gal}(F/K)$ 是满射，核为 $\operatorname{Gal}(L/F)$，由群同态基本定理得 $\operatorname{Gal}(F/K) \cong G/\operatorname{Gal}(L/F)$。$\square$

$\square$

**应用**：伽罗瓦基本定理将多项式方程的根式可解性问题转化为伽罗瓦群的可解性问题，是解决五次方程不可解性等经典问题的核心工具。$\square$
