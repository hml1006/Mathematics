# 连续统假设的独立性

> **一句话大白话**：连续统假设 $2^{\aleph_0}=\aleph_1$ 既推不出也推不倒"：Gödel 造出（可构成宇宙中）它对的模型，Cohen 用力迫造出它不对的模型——它既不能被证明也不能被否证，是独立命题。
>
> **小例子**：$2^{\aleph_0}$ 到底等于 $\aleph_1$、$\aleph_2$ 还是别的，ZFC 一律管不着：对任意"合理"的 $\kappa$ 都存在 ZFC 模型使 $2^{\aleph_0}=\kappa$。

## 介绍

连续统假设（Continuum Hypothesis，CH）的独立性是20世纪数学中最深刻的结果之一。CH由Cantor于1878年提出，断言 $\mathbb{R}$ 的基数严格介于 $\aleph_0$ 和 $2^{\aleph_0}$ 之间——即不存在基数 $\kappa$ 使得 $\aleph_0 < \kappa < 2^{\aleph_0}$，等价于 $2^{\aleph_0} = \aleph_1$。Hilbert将其列为23个问题中的第一个。Gödel于1938年证明CH在ZFC中不可反驳（即ZFC + CH一致），Cohen于1963年证明CH在ZFC中不可证明（即ZFC + $\lnot$CH一致）。合起来，CH独立于ZFC公理系统——这是力迫法诞生的第一个重大成果。

## 分析

**前置依赖**：ZFC公理系统、基数、共尾性、连续统函数、Gödel可构成宇宙、力迫法、泛型扩张。

**定理内容**：连续统假设CH独立于ZFC公理系统，即：
1. **一致性**：若ZFC一致，则ZFC + CH一致（Gödel，1938）。
2. **独立性**：若ZFC一致，则ZFC + $\lnot$CH一致（Cohen，1963）。

**数学内涵**：
- CH = $2^{\aleph_0} = \aleph_1$，GCH = $2^{\aleph_\alpha} = \aleph_{\alpha+1}$ 对所有 $\alpha$ 成立。
- Gödel的结果通过 $\mathbf{L}$（可构成宇宙）证明：在 $\mathbf{L}$ 中GCH成立，因此CH在ZFC中不可反驳。
- Cohen的结果通过力迫法证明：通过添加 $\aleph_2$ 个新实数，可以构造一个ZFC模型其中 $2^{\aleph_0} \geq \aleph_2$，因此CH在ZFC中不可证明。
- 事实上，$2^{\aleph_0}$ 可以是任意满足 $\text{cf}(\kappa) > \aleph_0$（Easton定理）的 $\kappa$。

**证明策略**：
1. **一致性**：构造 $\mathbf{L}$，证明 $\mathbf{L} \models \text{ZFC} + \text{GCH}$。
2. **独立性**：从ZFC的可数传递模型 $M$ 出发，用力迫法添加 $\aleph_2$ 个新实数。
3. 选择适当的偏序集 $\mathbb{P} = \text{Fn}(\omega_2 \times \omega, 2)$（有限部分函数），泛型扩张 $M[G]$ 添加了 $\aleph_2$ 个新实数，从而 $M[G] \models 2^{\aleph_0} \geq \aleph_2$。

## 思考过程

CH独立性的证明展示了数学公理化方法的深刻局限和力量。Gödel的 $\mathbf{L}$ 和Cohen的力迫法分别从"内"和"外"两个方向探索了ZFC的模型论可能性。$\mathbf{L}$ 通过最小化集合论宇宙使CH成立，而力迫法通过添加新实数使CH不成立。

值得注意的是，CH的独立性并不意味着CH"没有答案"。许多集合论学家认为，通过寻找新的、有说服力的公理（如大基数公理或决定性公理），可以最终确定 $2^{\aleph_0}$ 的值。例如，在Woodin的 $\Omega$-逻辑框架下，$2^{\aleph_0} = \aleph_2$ 被提出作为一种可能的"规范"答案。

## 证明过程

**定理**（CH的独立性）：CH独立于ZFC公理系统（假设ZFC一致）。

**证明**：

### 第一部分：CH的一致性（ZFC + CH一致）

### 1. Gödel可构成宇宙

在 $\mathbf{L}$ 中，对每个无穷序数 $\alpha$，$|\mathbf{L}_\alpha| = |\alpha|$。

### 2. $\mathbf{L}$ 中GCH成立

**引理**：在 $\mathbf{L}$ 中，对任意序数 $\alpha$，$\mathcal{P}(\omega_\alpha) \cap \mathbf{L} \subseteq \mathbf{L}_{\omega_{\alpha+1}}$，因此 $|\mathcal{P}(\omega_\alpha) \cap \mathbf{L}| \leq \aleph_{\alpha+1}$。

*证明思路*：对任意 $x \subseteq \omega_\alpha$，$x \in \mathbf{L}$，则存在某个 $\beta$ 使得 $x \in \mathbf{L}_\beta$。由 $\mathbf{L}$ 的构造性质，最小的这样的 $\beta$ 必小于 $\omega_{\alpha+1}$。因此 $\mathcal{P}(\omega_\alpha) \cap \mathbf{L} \subseteq \mathbf{L}_{\omega_{\alpha+1}}$，而 $|\mathbf{L}_{\omega_{\alpha+1}}| = \aleph_{\alpha+1}$。$\square$

由此得 $\mathbf{L} \models 2^{\aleph_\alpha} = \aleph_{\alpha+1}$，即GCH成立。特别地，$\mathbf{L} \models \text{CH}$。

### 3. 一致性结论

由Gödel第二不完全性定理，若ZFC一致，则 $\mathbf{L}$ 是ZFC的模型，故ZFC + CH一致。$\square$

### 第二部分：CH的独立性（ZFC + $\lnot$CH一致）

### 1. 力迫设置

设 $M$ 是ZFC的可数传递模型。取 $\mathbb{P} = \text{Fn}(\omega_2^M \times \omega, 2)$，即所有从 $\omega_2 \times \omega$ 到 $\{0,1\}$ 的有限部分函数，按反向包含序。这里 $\omega_2^M$ 是 $M$ 中 $\aleph_2$ 的序数表示。

### 2. 基数保持性

$\mathbb{P}$ 满足 $\aleph_1$-链条件（$\aleph_1$-c.c.），即 $\mathbb{P}$ 中没有大小超过 $\aleph_1$ 的反链。因此 $\mathbb{P}$ 保持所有基数（包括 $\aleph_1$ 和 $\aleph_2$）。

### 3. 添加新实数

对每个 $\alpha < \omega_2$，定义函数 $f_\alpha \in {}^\omega 2$ 为 $f_\alpha(n) = G(\alpha, n)$。由于 $G$ 是泛型的，$f_\alpha \notin M$ 对每个 $\alpha$ 成立。因此 $M[G]$ 至少包含 $\aleph_2$ 个不同的实数。

### 4. 基数不变性

由于 $\mathbb{P}$ 是 $\aleph_1$-c.c.的，$\aleph_1^M$ 和 $\aleph_2^M$ 在 $M[G]$ 中仍然是 $\aleph_1$ 和 $\aleph_2$。因此在 $M[G]$ 中，$|\mathbb{R}| \geq \aleph_2$，即 $2^{\aleph_0} \geq \aleph_2$，故CH不成立。

### 5. 独立性结论

若ZFC一致，则 $M[G] \models \text{ZFC} + \lnot\text{CH}$，故ZFC + $\lnot$CH一致。$\square$

**推论**：连续统假设CH独立于ZFC公理系统。$\square$
