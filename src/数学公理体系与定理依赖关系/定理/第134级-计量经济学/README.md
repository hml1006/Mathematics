# 第134级-计量经济学

> 一句话级别概述：计量经济学将统计学方法与经济理论结合，用观测数据识别与估计因果效应，是经济学实证研究的方法论基础。

## 级别简介

计量经济学研究如何从非实验数据中推断经济变量之间的数量关系与因果结构。其核心方法是各类估计量（OLS、GMM、IV、面板数据、DID）在大样本下的性质分析，包括一致性、渐近正态性与识别条件。

## 本级别定理

- [DID估计量的识别条件](./DID估计量的识别条件.md)：双重差分识别处理效应的前提。
- [面板数据固定效应估计的一致性](./面板数据固定效应估计的一致性.md)：固定效应估计在短面板下的一致条件。
- [工具变量估计的一致性](./工具变量估计的一致性.md)：IV法处理内生性时的一致条件。
- [GMM估计量的渐近性质](./GMM估计量的渐近性质.md)：广义矩估计的一致与渐近正态。
- [OLS估计量的一致性和渐近正态性](./OLS估计量的一致性和渐近正态性.md)：最小二乘估计的大样本性质。

## 前置知识

主要依赖概率论与数理统计（大数定律、中心极限定理）、线性代数，以及概率收敛与大样本理论的严格基础。

## 后继用途

为金融数学、经济数学、数据科学等方向的实证建模与因果推断提供方法基础。

## 关键定理速览

- OLS估计量的渐近理论：在标准假设下估计量一致且渐近正态，是回归推断的基础。
- 工具变量估计的一致性：提供处理内生性问题的识别策略。
- GMM估计量的渐近性质：统一框架下给出系统矩估计的大样本理论。
- DID估计量的识别条件：平行趋势假设下识别因果效应。
