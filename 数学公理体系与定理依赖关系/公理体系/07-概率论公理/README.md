# 概率论公理（Kolmogorov 公理）

## 概述

概率论公理由苏联数学家 Andrey Kolmogorov 在 1933 年提出，为概率论奠定了严格的测度论基础。Kolmogorov 公理将概率定义为满足特定性质的测度，使概率论成为数学分析的一个分支。

## 公理列表

| 编号 | 公理名称 | 简要描述 | 文档 |
|------|----------|----------|------|
| P1 | 非负性 | 任何事件的概率非负：P(E) ≥ 0 | [非负性](非负性.md) |
| P2 | 规范性 | 全样本空间的概率为 1：P(Ω) = 1 | [规范性](规范性.md) |
| P3 | 可列可加性 | 对互斥事件列，概率可加 | [可列可加性](可列可加性.md) |

## 历史意义

Kolmogorov 的公理化将概率论从"不确定性的计算"提升为严格的数学理论，为统计学、随机过程、信息论等领域提供了坚实的数学基础。
