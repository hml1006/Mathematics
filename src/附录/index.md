# 附录：数学符号速查表

> 本附录收录数学中常用的希腊字母、希伯来字母，以及各类数学符号及其典型含义，供学习过程中快速查阅。

### A. 希腊字母

| 大写 | 小写 | 英文名  | 中文名   | 作为数学符号的常见含义                                        |
| :--: | :--: | ------- | -------- | ------------------------------------------------------------- |
|  A  |  α  | alpha   | 阿尔法   | 平面角、显著性水平、α 粒子、α 射线                          |
|  B  |  β  | beta    | 贝塔     | 平面角、β 系数、第二类错误概率                               |
|  Γ  |  γ  | gamma   | 伽马     | 伽马函数 Γ(·)、欧拉常数 γ、黎曼曲率                        |
|  Δ  |  δ  | delta   | 德尔塔   | 增量 Δx、判别式 Δ = b² − 4ac、克罗内克 δ、狄拉克 δ 函数 |
|  E  |  ε  | epsilon | 艾普西隆 | 任意小的正数 ε > 0、单位元、列维-奇维塔符号 εᵢⱼₖ         |
|  Z  |  ζ  | zeta    | 泽塔     | 黎曼 ζ 函数 ζ(s)                                            |
|  H  |  η  | eta     | 伊塔     | 闵可夫斯基度量 η\_μν、效率 η、狄利克雷 η 函数            |
|  Θ  |  θ  | theta   | 西塔     | 平面角、极坐标角 θ、模形式 θ 函数                           |
|  I  |  ι  | iota    | 约塔     | 虚数单位 i 的替代（常用于张量指标）、微小量                   |
|  K  |  κ  | kappa   | 卡帕     | 曲率 κ、图论中图的连通度、冯·卡门常数                       |
|  Λ  |  λ  | lambda  | 兰布达   | 特征值 λ、拉格朗日乘子 λ、波长 λ、λ 演算                  |
|  M  |  μ  | mu      | 缪       | 均值 μ (期望)、测度 μ、μ 介子、磁导率、微 (10⁻⁶)         |
|  N  |  ν  | nu      | 纽       | 自由度 ν、频率 ν、泊松比                                    |
|  Ξ  |  ξ  | xi      | 克西     | 黎曼 Ξ 函数、典型值、随机变量                                |
|  O  |  o  | omicron | 奥密克戎 | 大 O 记号 O(·)、小 o 记号 o(·)                              |
|  Π  |  π  | pi      | 派       | 圆周率 π ≈ 3.14159、素数计数函数 π(x)、乘积符号 ∏         |
|  P  |  ρ  | rho     | 柔       | 密度 ρ、相关系数 ρ、曲率半径 ρ                             |
|  Σ  |  σ  | sigma   | 西格马   | 求和符号 Σ、标准差 σ、σ 代数、西格马有限                   |
|  T  |  τ  | tau     | 陶       | 圆周率 τ = 2π、切应力 τ、τ 函数 (除数函数)                |
|  Y  |  υ  | upsilon | 宇普西隆 | 粒子物理中的 Y 粒子、参数                                     |
|  Φ  |  φ  | phi     | 斐       | 黄金比例 φ ≈ 1.618、欧拉函数 φ(n)、调和函数、相位          |
|  X  |  χ  | chi     | 希       | 卡方分布 χ²、特征标 χ、示性函数 χ_A                       |
|  Ψ  |  ψ  | psi     | 普赛     | 波函数 ψ、角函数、双伽马函数 ψ(x)                           |
|  Ω  |  ω  | omega   | 欧米伽   | 角频率 ω、立体角 Ω、大 Ω 记号 Ω(·)、样本空间 Ω          |

### C. 数理逻辑符号

|  符号  | 含义                | 示例                          |
| :-----: | ------------------- | ----------------------------- |
|   ∀   | 任意 / 全称量词     | ∀x > 0, x² > 0              |
|   ∃   | 存在 / 存在量词     | ∃x 使得 x² = 2              |
|   ∄   | 不存在              | ∄x 满足 x² = −1 (在实数中) |
| ⇒ / → | 蕴含 / 推出         | A ⇒ B                        |
| ⇔ / ↔ | 等价 / 当且仅当     | A ⇔ B                        |
|   ∧   | 且 (逻辑与)         | A ∧ B                        |
|   ∨   | 或 (逻辑或)         | A ∨ B                        |
|   ¬   | 非 (逻辑非)         | ¬A                           |
|   ⊕   | 异或                | A ⊕ B                        |
|   ⊢   | 语法蕴涵 / 可推出   | Γ ⊢ φ                      |
|   ⊨   | 语义蕴涵 / 逻辑蕴涵 | Γ ⊨ φ                      |
|   ∴   | 所以                | ∴ 结论成立                   |
|   ∵   | 因为                | ∵ 已知条件                   |

### F. 微积分与分析符号

|            符号            | 含义                        | 示例                                                  |
| :-------------------------: | --------------------------- | ----------------------------------------------------- |

|         $\Delta$         | 拉普拉斯算子                | $\Delta f = \nabla^2 f$                             |

|         $\infty$         | 无穷大                      | $\lim_{x\to\infty}$                                 |

|         $f^{(n)}$         | $n$ 阶导数                | $f^{(n)}(x)$                                        |
|        $\partial$        | 偏导数                      | $\partial f/\partial x$                             |
|         $\delta$         | 变分、狄拉克$\delta$ 函数 | $\delta J$, $\delta(x)$                           |
|          $\sup$          | 上确界                      | $\sup S$                                            |
|          $\inf$          | 下确界                      | $\inf S$                                            |
|          $\max$          | 最大值                      | $\max f(x)$                                         |
|          $\min$          | 最小值                      | $\min f(x)$                                         |
| $\operatorname{ess\,sup}$ | 本质上确界                  | $\operatorname{ess\,sup} f$                         |

|  $\lceil \cdot \rceil$  | 向上取整 (ceil)      | $\lceil x \rceil$                                   |
|       $\{\cdot\}$       | 集合、小数部分       | $\{x, y\}, \{x\}$                                   |
