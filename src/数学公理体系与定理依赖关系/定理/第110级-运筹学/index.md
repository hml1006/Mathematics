# 第110级-运筹学

本目录收录以下定理：

- [线性规划强对偶定理](./线性规划强对偶定理.md)
- [最大流最小割定理](./最大流最小割定理.md)
- [Dijkstra算法的正确性](./Dijkstra算法的正确性.md)
- [动态规划的最优性原理](./动态规划的最优性原理.md)
- [分支定界算法的收敛性](./分支定界算法的收敛性.md)
- [Farkas 引理](./Farkas引理.md)：对一个线性方程组，"存在非负解"与"存在一个把右端项打成负数的对偶非负向量"这两件事恰好一件成立、另一件必然不成立。
- [凸锥与凸集分离定理](./凸锥与凸集分离定理.md)：凸锥是对正数倍和加法都封闭的凸集；对偶锥把所有与它"夹角不超过 90 度"的向量收集起来，而对于闭凸锥，把自己对偶两次就回到原锥。
- [剪枝准则](./剪枝准则.md)：在分支定界的搜索树上，如果一个子问题的最好可能值都比不上已经找到的那个解，那整棵子树就不用再算了，直接砍掉。
- [流量守恒定律](./流量守恒定律.md)：在网络中，除源点与汇点外的每个中间节点，流入的流量总和必须等于流出的流量总和，一滴水既不会凭空产生也不会凭空消失。
- [Kirchhoff电流定律](./Kirchhoff电流定律.md)：在一个电路网络的每个节点上，流进来的电流之和一定等于流出去的电流之和，电荷既不会在节点处堆积，也不会凭空冒出。
- [下界估计与对偶界](./下界估计与对偶界.md)：要说明一个最小化问题的答案"至少是某个数"，最省力的办法是造一个"托底问题"：它的目标值永远不超过原问题，却很好算。对偶理论把这件事做到极致——拉格朗日对偶的每一个可行解都自动给出一个下界，而最好的下界（对偶最优值）在凸问题里恰好等于原问题最优值。
- [线性规划放松与下界](./线性规划放松与下界.md)：整数规划难就难在"必须取整数"。那就先把这条要求扔掉，得到一个普通的线性规划——它的可行集更大、目标只会更小，所以它的最优值永远压在原问题最优值之下。这个"便宜又好算"的数，就是分支定界里那把剪枝的剪刀。
