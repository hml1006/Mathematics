- [Poincaré 引理](./Poincaré引理.md)：在一个没有"洞"的区域里，任何一个环路积分都为零的场必是某个函数的梯度；用形式语言说，闭形式一定是恰当形式。
- [Lebesgue 数引理](./Lebesgue数引理.md)：紧度量空间的每个开覆盖都有一个"统一的最小尺度"——只要一块地方足够小，它必然整个落进某个覆盖开集中。
- [细分引理](./细分引理.md)：只要把单纯复形反复做重心重分，格子就会越分越细；细到一定程度后，每个小单纯形都乖乖躺进预先给定的某个开集里。
- [CW 复形与胞腔逼近定理](./CW复形与胞腔逼近定理.md)：CW 复形之间任意连续映射，都能同伦地"拉直"成胞腔映射——它把 $n$ 维骨架送进 $n$ 维骨架，不会用低维骨架去填高维胞腔。
- [Alexander-Whitney 映射与 Eilenberg-Zilber 定理](./Alexander-Whitney映射与Eilenberg-Zilber定理.md)：乘积空间 $X\times Y$ 的链复形，与两个因子链复形的张量积复形，在链同伦意义下是"同一台机器"；Alexander–Whitney 映射与 Eilenberg–Zilber 映射就是这两台机器之间互为逆的一对翻译器。
- [acyclic models定理](./acyclicmodels定理.md)：想从一个只记录"连通分支"信息（$H_0$）的自然变换出发，造出整个链层次的"翻译器"（自然链映射），只要起点那一侧是被"标准模型"自由生成的、终点那一侧在模型上是无圈的，翻译器就一定存在，而且差一个自然链同伦是唯一的。
- [Brouwer不动点定理](./Brouwer不动点定理.md)：把一个实心圆盘（或高维实心球）连续地揉进它自己，无论怎么揉，总有一个点停在原地没被挪走。
- [Tietze延拓定理](./Tietze延拓定理.md)：在正规空间里，定义在一个闭子集上的连续函数，无论长得多古怪，总能被"顺出去"延拓成整个空间上的连续函数，而且取值范围还能保持在同样的区间里。
