# 第48级-数学物理

> 一句话级别概述：数学物理为量子力学、场论与统计物理等物理理论提供严格的数学框架，是几何、分析与算子理论的交汇前沿。

## 级别简介

本级别以严格数学研究物理理论的数学结构，涵盖无界自伴算子的谱理论、酉群的单参数刻画（Stone 定理）、Hamilton 力学与辛结构、Noether 对称性、Yang-Mills 规范方程，以及指标定理、Feynman 路径积分等现代工具。

## 本级别定理

- [Atiyah-Singer指标定理](./Atiyah-Singer指标定理.md)：椭圆算子指数拓扑表达式。
- [Feynman路径积分](./Feynman路径积分.md)：量子幅的积分表示。
- [Hamiltonian力学与辛几何](./Hamiltonian力学与辛几何.md)：相空间的辛结构。
- [Noether定理](./Noether定理.md)：对称性对应守恒律。
- [Stone定理](./Stone定理.md)：强连续单参数酉群的生成元。
- [Witten的Morse理论](./Witten的Morse理论.md)：变形拉普拉斯与拓扑不变量。
- [Yang-Mills方程](./Yang-Mills方程.md)：规范场论的运动方程。
- [无界自伴算子的谱定理](./无界自伴算子的谱定理.md)：度量算子的谱分解。
- [Poisson 括号与 Jacobi 恒等式](./Poisson括号与Jacobi恒等式.md)：Poisson 括号把两个物理量"配对"出第三个量，它衡量的是它们生成的流彼此"拧"得多厉害；Jacobi 恒等式则保证这种配对不会自相矛盾，让所有物理量井然有序地构成一个李代数的乘法表。
- [Lagrangian 力学与作用量原理](./Lagrangian力学与作用量原理.md)：自然界选择"最省力"的那条路径——真实运动是所有可能路径中让作用量（能量沿时间的累积）取驻值的特殊一条，而这条驻值路径恰好由 Euler–Lagrange 方程刻画。
- [Morse 函数与 Morse 引理](./Morse函数与Morse引理.md)：Morse 函数是"每个临界点都不退化"的光滑函数；Morse 引理说，在这种临界点附近总能换一套坐标，把函数变成最朴素的"二次型平方和"——就像把任意弯曲的碗在局部抚平成标准抛物面。
- [协变外微分与 Bianchi 恒等式](./协变外微分与Bianchi恒等式.md)：协变外微分是把普通外微分"搬"到带联络的向量丛上；对它连做两次就得到曲率。而 Bianchi 恒等式说的是一句极其省事的自洽性——"曲率本身是闭的"，两次作用得到的曲率满足必然的相容条件，绝不是巧合。
- [Sylvester 惯性定律](./Sylvester惯性定律.md)：一个实二次型无论用哪种坐标把它"配方"化成对角形，正项、负项、零项的个数都不会变——这三个数（惯性指数）是二次型的内在不变量。
- [Hadamard引理](./Hadamard引理.md)：一个光滑函数在原点附近总可以写成"常数项加上每个坐标乘一个光滑函数"的形式；Taylor 展开的余项不再只是"余项"，而是被显式写成了光滑因子。
- [变分法基本引理](./变分法基本引理.md)：如果一个连续函数与所有"任意小、任意光滑"的测试函数乘起来积分都是零，那这个函数只能处处为零；它是把积分形式的弱结论变回逐点结论的"橡皮擦"。
- [Schrödinger 方程](./Schrödinger方程.md)：量子态随时间的演化被一句话锁定——"能量算符就是时间导数"：$i\hbar\,\partial_t\psi=\hat H\psi$；波函数相位转得越快，能量就越高，比例系数是 $\hbar$。
- [分次Leibniz 法则](./分次Leibniz法则.md)：在"带次数"的代数里，奇次元素交换位置时要变号；因此求导算子作用到乘积上不再是简单分配，而是要多带一个符号 $(-1)^{\text{算子次数}\,\times\,\text{被越过元素的次数}}$——这就是分次 Leibniz 法则。
- [分部积分与基本引理](./分部积分与基本引理.md)：变分法里最关键的一道"手续"——先用分部积分把落在"变化率"上的导数搬到系数上（端点项因固定端点而消失），再用基本引理把"对一切测试函数积分为零"升级为"被积函数处处为零"，于是积分形式的驻值条件就变成逐点的微分方程。
- [变分原理与 Euler-Lagrange 方程](./变分原理与Euler-Lagrange方程.md)：一个泛函若在所有"允许的扰动"下取驻值，就等价于它的被积函数满足一组微分方程——Euler–Lagrange 方程；变分原理就是"整体取极值 $\Rightarrow$ 局部微分方程"的翻译机。

## 前置知识

本级别依赖前序级别的如下知识：泛函分析（谱理论与算子半群）、微分几何与李群（流形、对称性）、经典力学基础。

## 后继用途

数学物理为量子场论、共形场论、有限维量子物理及规范理论指数理论等后续方向提供基础，其算子代数与指标方法也渗透到拓扑与几何分析。

## 关键定理速览

- Stone定理：自伴生成子与强连续酉群的对应。
- 无界自伴算子的谱定理：量子力学的面上谱框架。
- Noether定理：对称性─守恒律的普遍原理。
- Atiyah-Singer指标定理：分析与拓扑的深层联系。
- Yang-Mills方程与Hamilton辛结构：场论与辛几何的桥梁。
