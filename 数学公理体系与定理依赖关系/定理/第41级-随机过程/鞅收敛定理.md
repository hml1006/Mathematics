# 鞅收敛定理

## 介绍

鞅收敛定理（Martingale convergence theorem）是鞅理论中最核心的定理之一，由 Joseph Doob 建立。它断言：在适当的有界性条件下，鞅几乎必然收敛到一个极限随机变量。该定理是随机过程理论中最重要的收敛结果之一，广泛用于概率论、数理统计、遍历理论、随机分析和金融数学等领域。

## 分析

**前置依赖**：条件期望、鞅的定义、停时、上穿不等式、Doob 分解。

**定理内容**：设 $\{M_n\}_{n\ge0}$ 是鞅（或下鞅）。

**下鞅收敛定理**：若 $\{M_n\}$ 是下鞅且 $\sup_n E[M_n^+] < \infty$（其中 $M_n^+ = \max(M_n, 0)$），则存在可积随机变量 $M_\infty$ 使得 $M_n \to M_\infty$ 几乎必然（a.s.）。

**鞅收敛定理**：若 $\{M_n\}$ 是鞅且 $\sup_n E[|M_n|] < \infty$，则 $M_n$ 几乎必然收敛到某个有限极限 $M_\infty$。

**$L^p$ 收敛定理**：若 $\{M_n\}$ 是鞅且 $\sup_n E[|M_n|^p] < \infty$ 对某个 $p > 1$，则 $M_n$ 在 $L^p$ 中收敛到 $M_\infty$。特别地，$L^2$-有界鞅在 $L^2$ 中收敛。

**数学内涵**：鞅收敛定理表明，鞅作为一种"公平博弈"模型，在期望有界的条件下，博弈过程几乎必然稳定下来。然而，极限的均方收敛需要更强的条件（如 $L^p$ 有界性）。

**证明策略**：证明的核心工具是上穿不等式（Doob's upcrossing inequality）。通过分析鞅越过一个区间的次数，证明该次数有限，从而鞅几乎必然收敛。

## 思考过程

鞅收敛定理的证明基于一个关键洞察：如果鞅不收敛，则它必然在某个区间 $[a,b]$ 上反复穿越（上穿）无限多次。通过证明上穿次数的期望有限，可以证明几乎必然不存在这样的区间，从而鞅收敛。

具体地，对下鞅 $\{M_n\}$，定义 $U_n[a,b]$ 为到时间 $n$ 为止从 $a$ 以下到 $b$ 以上的上穿次数。Doob 上穿不等式给出
$$E[U_n[a,b]] \le \frac{E[(M_n - a)^+]}{b-a} \le \frac{\sup_n E[M_n^+] + |a|}{b-a}$$
令 $n \to \infty$ 得上穿次数 $U_\infty[a,b]$ 的期望有限，故 $U_\infty[a,b] < \infty$ a.s.。这意味着鞅几乎必然不会在 $[a,b]$ 上无限穿越，从而极限存在。

## 证明过程

**定理**（Doob 上穿不等式）：设 $\{X_n\}$ 是下鞅，$U_n[a,b]$ 是 $X_1,\dots,X_n$ 从 $a$ 以下到 $b$ 以上的上穿次数，则
$$E[U_n[a,b]] \le \frac{E[(X_n - a)^+]}{b-a}$$

**证明**：定义停时序列 $\tau_1 = \inf\{k \ge 0 \mid X_k \le a\}$，$\sigma_1 = \inf\{k > \tau_1 \mid X_k \ge b\}$，依此类推。每次上穿得到的收益至少为 $b-a$。通过构造一个适当的变换，利用下鞅性质可得期望不等式。$\square$

**定理**（下鞅收敛定理）：设 $\{M_n\}$ 是下鞅且 $\sup_n E[M_n^+] < \infty$，则 $M_n$ 几乎必然收敛到有限极限 $M_\infty$。

**证明**：

**步骤 1**：定义 $U[a,b] = \lim_{n\to\infty} U_n[a,b]$（总体 $[a,b]$-上穿次数）。由 Doob 上穿不等式，
$$E[U[a,b]] = \lim_{n\to\infty} E[U_n[a,b]] \le \sup_n \frac{E[(M_n - a)^+]}{b-a} \le \frac{\sup_n E[M_n^+] + |a|}{b-a} < \infty$$
故 $U[a,b] < \infty$ 几乎必然。

**步骤 2**：设 $\Omega_0 = \{\omega \mid \liminf M_n(\omega) < \limsup M_n(\omega)\}$。若 $\omega \in \Omega_0$，则存在有理数 $a < b$ 使得 $\liminf M_n(\omega) < a < b < \limsup M_n(\omega)$，从而 $U[a,b](\omega) = \infty$。但 $P(U[a,b] = \infty) = 0$ 对每个有理数对 $(a,b)$ 成立，可数并仍为零测。故 $P(\Omega_0) = 0$，即 $\lim M_n$ 几乎必然存在。

**步骤 3**：证明极限有限。由 Fatou 引理，
$$E[\liminf M_n^+] \le \liminf E[M_n^+] \le \sup_n E[M_n^+] < \infty$$
故 $\lim M_n$ 几乎必然有限。$\square$

**定理**（鞅收敛定理）：若 $\{M_n\}$ 是鞅且 $\sup_n E[|M_n|] < \infty$，则 $M_n$ 几乎必然收敛到可积的 $M_\infty$。

**证明**：鞅既是下鞅也是上鞅。由下鞅收敛定理，$M_n$ 几乎必然收敛。由 Fatou 引理，$E[|M_\infty|] \le \liminf E[|M_n|] < \infty$，故 $M_\infty$ 可积。$\square$

**推论**（$L^p$ 收敛）：若鞅 $\{M_n\}$ 满足 $\sup_n E[|M_n|^p] < \infty$ 对某个 $p > 1$，则 $M_n$ 在 $L^p$ 中收敛到 $M_\infty$，且 $M_n = E[M_\infty \mid \mathcal{F}_n]$。
