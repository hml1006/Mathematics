# 决定性公理

## 介绍

决定性公理（Axiom of Determinacy，AD）是集合论中一条与选择公理（AC）相矛盾的重要公理，由Jan Mycielski和Hugo Steinhaus于1962年提出。AD断言：在 $\omega$ 上的每个无穷完全信息二人博弈都是确定的（即有一方有必胜策略）。AD与选择公理不相容（因为AC可构造一个不确定的博弈），但它在实数集上给出了一个非常规整的理论——在 $\text{ZF} + \text{AD}$ 下，所有实数的子集都是Lebesgue可测的、具有Baire性质和完美集性质。AD与大基数公理有深刻联系，特别是Woodin基数。

## 分析

**前置依赖**：ZFC公理系统、博弈论基础、无穷博弈、序数、基数、描述集合论、投影集、大基数公理。

**定理内容**（决定性公理AD）：对任意 $A \subseteq \omega^\omega$，考虑如下二人无限博弈 $G_A$：两名玩家轮流选择自然数 $n_0, n_1, n_2, \ldots$，如果最终序列 $\langle n_0, n_1, n_2, \ldots \rangle \in A$，则玩家I获胜，否则玩家II获胜。AD断言：对每个 $A \subseteq \omega^\omega$，博弈 $G_A$ 是确定的，即玩家I或玩家II有一方存在必胜策略。

**数学内涵**：
- AD蕴含所有实数的子集都是Lebesgue可测的，具有Baire性质，且要么可数要么包含一个完美集（即没有 Bernstein集）。
- AD与选择公理不一致：在ZFC中，存在一个不可测集，且存在不确定的博弈。
- 在 $\text{ZF} + \text{AD}$ 中，$\aleph_1$ 和 $\aleph_2$ 是可测基数，$\aleph_\omega$ 是强极限基数。
- AD的推论（投影决定性）与大基数公理有密切联系：若存在无穷多个Woodin基数，则 $\text{ZF}$ 中所有投影集都是确定的。

**证明策略**：
- AD本身是公理而非定理，它不能被ZFC证明或证否（在一致性意义上）。
- 但在大基数假设下，可以证明某些类的集合是确定的（如Martin定理：Borel集是确定的）。
- 证明AD与AC的矛盾：使用AC构造一个 $\omega^\omega$ 的良序，然后利用该良序构造一个不确定的博弈。

## 思考过程

决定性公理是"正则性"公理的极致形式——它断言所有实数集都不存在"病态"性质。在ZFC中，通过选择公理可以构造出各种病态集（不可测集、无Baire性质集等），但AD禁止了这些构造。AD的代价是放弃了选择公理，但保留了足够多的选择公理推论（如可数选择公理）以使经典数学不受影响。

AD与力迫法和内模型理论有深刻联系。Woodin的 $\text{L}(\mathbb{R})$ 模型理论表明：若存在无穷多个Woodin基数，则 $\text{L}(\mathbb{R}) \models \text{AD}$。这为AD相对于大基数公理的一致性提供了基础。

## 证明过程

**定理**（Martin，1975）：所有Borel集合 $A \subseteq \omega^\omega$ 都是确定的。

**证明**（概要）：

### 1. 博弈树

将博弈 $G_A$ 表示为树 $T$，其中 $T$ 是 $\omega^{<\omega}$ 的子树，使得 $A = [T_A]$ 是 $T_A$ 的无穷分支的集合。Borel集可以通过树上的开集、闭集及其可数交并构造。

### 2. 策略与获胜集

对博弈树 $T$，定义玩家I的获胜集 $W_I \subseteq T$ 为所有使得玩家I有必胜策略的位置。类似定义 $W_{II}$。目标是证明每个位置要么在 $W_I$ 中要么在 $W_{II}$ 中。

### 3. Borel归纳

对Borel集的复杂度进行归纳：
- 开集：由Gale-Stewart定理，开集是确定的。
- 闭集：由闭集的对偶性，闭集也是确定的。
- 对可数交/并操作：利用博弈的"展开"技术，将 $\bigcap_n A_n$ 或 $\bigcup_n A_n$ 的博弈转化为一个更复杂的但Borel秩更低的博弈。

### 4. 关键引理

若 $A = \bigcup_{n < \omega} A_n$ 且每个 $A_n$ 是确定的，则 $A$ 也是确定的。证明通过"策略窃取"（strategy stealing）论证构造。类似地，对可数交也成立。

### 5. 归纳完成

由于Borel集可以通过开集经可数交和可数并的迭代得到，归纳过程保证所有Borel集都是确定的。$\square$

**定理**（AD与AC的不相容性）：在ZFC中，存在一个不确定的博弈。

**证明**：

设 $\{x_\alpha\}_{\alpha < 2^{\aleph_0}}$ 是 $\omega^\omega$ 的一个良序（由AC保证）。构造 $A \subseteq \omega^\omega$ 如下：对每个 $\alpha < 2^{\aleph_0}$，若 $\alpha$ 是偶数则确保 $x_\alpha \in A$，若 $\alpha$ 是奇数则确保 $x_\alpha \notin A$。然后构造博弈 $G_A$，通过"对角线论证"证明 $G_A$ 不是确定的。

更精确地，用反证法：假设存在一个策略 $s$ 使得玩家I或II必胜。但构造 $A$ 时已经确保了每个可能的策略 $s$ 都会被某个 $x_\alpha$ 违反。$\square$

**推论**（AD的推论）：在 $\text{ZF} + \text{AD}$ 下，
1. 每个 $A \subseteq \mathbb{R}$ 是Lebesgue可测的。
2. 每个 $A \subseteq \mathbb{R}$ 具有Baire性质。
3. 每个 $A \subseteq \mathbb{R}$ 要么可数，要么包含一个完美集。
4. $\omega_1$ 和 $\omega_2$ 是可测基数。
5. 选择公理在 $\mathbb{R}$ 上不成立（但可数选择公理成立）。$\square$
