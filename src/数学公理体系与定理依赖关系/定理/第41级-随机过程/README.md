# 第41级-随机过程

> 一句话级别概述：随机过程研究随时间演化的一族随机变量，是概率论从静态分布走向动态模型的延伸，也是金融、物理与工程的数学内核。

## 级别简介

本级别研究依时间变化的随机现象，涵盖 Markov 链、Poisson 过程、Brown 运动等基本过程，以及鞅、Itô 积分与随机微分等核心工具，建立随机过程的构造、平稳性、连续性条件与收敛理论。

## 本级别定理

- [Brown运动的存在性](./Brown运动的存在性.md)：连续随机游走的构造。
- [Doob可选停止定理](./Doob可选停止定理.md)：停时下鞅期望不变。
- [Itô公式](./Itô公式.md)：随机微分的链式法则。
- [Itô积分](./Itô积分.md)：关于Brown运动的随机积分。
- [Kolmogorov-Chentsov连续性定理](./Kolmogorov-Chentsov连续性定理.md)：矩条件保证样本连续。
- [Kolmogorov扩张定理](./Kolmogorov扩张定理.md)：有限维分布构造随机过程。
- [Markov链平稳分布](./Markov链平稳分布.md)：长期演化的不变分布。
- [Markov链状态分类](./Markov链状态分类.md)：状态常返/周期结构。
- [Poisson过程](./Poisson过程.md)：独立增量计数过程。
- [鞅收敛定理](./鞅收敛定理.md)：有界鞅几乎必然收敛。
- [上穿不等式](./上穿不等式.md)：一个下鞅反复"从下往上穿越"一个区间 $[a,b]$ 的平均次数，被它在终点处"高出下界 $a$ 多少"所控制。
- [紧性准则](./紧性准则.md)：一族概率测度能在弱拓扑下抽出收敛子列，当且仅当"质量不会跑到无穷远"（胎紧）。
- [等距公式](./等距公式.md)：随机积分的二阶矩，等于被积函数平方后对时间与概率的双重积分——随机积分没有"额外放大"，它是一场精确的等距嵌入。
- [鞅差中心极限定理](./鞅差中心极限定理.md)：独立同分布并不是中心极限定理的必要条件——只要每步的"新信息"（鞅差）大小可控、条件方差稳定累积，总和照样乖乖变成正态。
- [鞅中心极限定理](./鞅中心极限定理.md)：把中心极限定理里"独立同分布"换成"鞅差"——每一步带来的新消息可以有依赖、可以异分布，只要这些新消息的条件方差稳定累积、没有单个巨块，总和的极限仍是正态分布。
- [Portmanteau定理](./Portmanteau定理.md)：概率测度的弱收敛有好几种等价说法——对一切有界连续函数积分收敛、开集的测度下极限不等式、闭集的测度上极限不等式、以及对"边界为 null 集"的集合测度收敛——它们是同一件事的五张面孔。
- [Ulam胎紧定理](./Ulam胎紧定理.md)：波兰空间上的每个概率测度都是"胎紧"的——无论精度要求多高，总能找到一个固定的紧集，把全部质量（除任意小的一点点之外）装进去；顺带地，每个 Borel 集都能被里面的大紧集和外面的大开集"夹"住。
- [单调类定理](./单调类定理.md)：要证明"某个 σ-代数里的所有集合/函数都有性质 P"，不必逐个验证——只要在好验证的"小集合系"（代数或 $\pi$-系统）上验证 P，再检查 P 对递增并、递减交（或对逐点有界单调极限）封闭，P 就自动对全体成立。
- [集合边界](./集合边界.md)：集合的边界就是那些"里外都挨着"的点——从它出发，无论走得多近，都能同时碰到集合内的点和集合外的点；它等于"闭包挖掉内部"。

## 前置知识

本级别依赖前序级别的如下知识：测度论与概率论（条件期望、独立性）、实分析（积分与收敛定理）以及初等概率统计。

## 后继用途

随机过程为随机分析、随机微分方程、金融数学（资产定价）以及排队论、信息论等应用级别提供理论工具，是第 96 级随机微分方程等后续方向的直接基础。

## 关键定理速览

- Kolmogorov扩张定理：由相容有限维分布构造随机过程。
- 鞅收敛定理：有界鞅几乎必然收敛并刻画停时。
- Doob可选停止定理：鞅在可停时下的期望保持。
- Itô公式：随机积分中的微分法则。
- Brown运动存在性与Kolmogorov-Chentsov定理：样本路径的构造与正则性。
