# 第68级-双曲型守恒律方程

本目录收录以下定理：

- [Euler方程](./Euler方程.md)
- [Glimm格式收敛性](./Glimm格式收敛性.md)
- [Riemann问题](./Riemann问题.md)
- [compensated compactness](./compensated-compactness.md)
- [守恒律方程基本理论](./守恒律方程基本理论.md)
- [波动方程与能量估计](./波动方程与能量估计.md)
- [熵条件](./熵条件.md)
- [Murat 引理](./Murat引理.md)：两个各自只弱收敛的向量场，如果一个的散度是紧的、另一个的旋度是紧的，那么它们的内积会弱收敛到极限的内积——补偿紧性由此把"弱收敛"升级为"乘积收敛"。
- [Kirchhoff 公式](./Kirchhoff公式.md)：三维波动方程的解可以显式写出来——时刻 $t$、位置 $x$ 处的值只取决于初值在以 $x$ 为心、半径 $ct$ 的球面上的积分（含时间的导数项），波以速度 $c$ 沿球面恰好经过，过后不留余波。
- [Euler-Poisson-Darboux 方程](./Euler-Poisson-Darboux方程.md)：把波动方程的解在球面上取平均，得到的函数满足一个带 $\frac{1}{r}$ 奇异系数的方程，这就是 Euler–Poisson–Darboux 方程；作代换 $z=r\bar u$ 后它退化为最普通的一维波动方程，于是可直接用 d'Alembert 公式求出显式解。
- [分布意义下的不等式](./分布意义下的不等式.md)：当解只有"弱解"那样粗糙、连导数点态都不存在时，仍可把不等式理解成"对每个非负试验函数积分后再比较"；这样定义的不等式叫分布意义下的不等式，它把熵条件这类物理要求变成可操作的数学判据。
- [分部积分与散度定理](./分部积分与散度定理.md)：散度定理说"区域内部散度的总和等于边界上流出量的总和"；把区域上的一重积分搬成边界积分（或反过来），就得到分部积分公式。它是把微分方程"转移导数"到试验函数身上的技术基础。
- [球面平均与散度定理](./球面平均与散度定理.md)：把函数在球面上取平均，就等于把它在球内取平均后再对半径求导；借助散度定理，球面平均把拉普拉斯算子变成一个只含半径、带 $\frac{1}{r}$ 系数的二阶导数——这是求解三维波动方程的关键一步。
