# 基本积分表

> **一句话大白话**：这张表就是把“求导公式”倒过来读——会求导就自然会积分，每个积分公式都能用“对右边求导等于被积函数”来验证。
>
> **小例子**：因为 $\frac{d}{dx}\left(\frac{x^3}{3}\right)=x^2$，所以 $\int x^2\,dx=\frac{x^3}{3}+C$。

## 介绍

基本积分表（Basic Integration Table）列出了微积分中常用函数的原函数公式，是积分运算的基础工具。这些公式均由导数基本公式逆向推导得到，结合微积分基本定理，可以快速计算定积分。基本积分表是学习高等数学、物理和工程学科的必备工具。

## 分析

**前置依赖**：导数基本公式、微积分基本定理

**定理内容**：以下为基本积分公式（$C$ 为任意常数）：

1. **幂函数**：
   $$\int x^n\,dx = \frac{x^{n+1}}{n+1} + C, \quad n \neq -1$$

2. **倒数函数**：
   $$\int \frac{1}{x}\,dx = \ln|x| + C$$

3. **指数函数**：
   $$\int e^x\,dx = e^x + C$$

4. **正弦函数**：
   $$\int \sin x\,dx = -\cos x + C$$

5. **余弦函数**：
   $$\int \cos x\,dx = \sin x + C$$

6. **反正切函数**：
   $$\int \frac{1}{1+x^2}\,dx = \arctan x + C$$

7. **反正弦函数**：
   $$\int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x + C$$

**数学内涵**：
基本积分表是微分运算的逆运算表。每个积分公式对应一个导数公式：$\frac{d}{dx}\left(\frac{x^{n+1}}{n+1}\right) = x^n$，$\frac{d}{dx}(\ln|x|) = \frac{1}{x}$，等等。这些公式构成了积分计算的基础，结合换元积分法和分部积分法，可以求解更复杂的积分。

**证明策略**：对右边函数求导，验证其导数等于被积函数。

## 思考过程

由微积分基本定理，若 $F'(x) = f(x)$，则 $\int f(x)\,dx = F(x) + C$。因此只需验证每个公式右边函数的导数等于被积函数。例如，$\frac{d}{dx}\left(\frac{x^{n+1}}{n+1}\right) = x^n$，$\frac{d}{dx}(\ln|x|) = \frac{1}{x}$。

## 证明过程

**证明**：对每个公式，验证 $\frac{d}{dx}(\text{右端}) = \text{被积函数}$。

**1. 幂函数积分**：
$$\frac{d}{dx}\left(\frac{x^{n+1}}{n+1} + C\right) = \frac{(n+1)x^n}{n+1} = x^n$$
因此 $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$（$n \neq -1$）。

**2. 倒数函数积分**：
当 $x > 0$ 时，$\frac{d}{dx}(\ln x + C) = \frac{1}{x}$
当 $x < 0$ 时，$\frac{d}{dx}(\ln(-x) + C) = \frac{1}{-x} \cdot (-1) = \frac{1}{x}$
因此 $\int \frac{1}{x}\,dx = \ln|x| + C$。

**3. 指数函数积分**：
$$\frac{d}{dx}(e^x + C) = e^x$$
因此 $\int e^x\,dx = e^x + C$。

**4. 正弦函数积分**：
$$\frac{d}{dx}(-\cos x + C) = \sin x$$
因此 $\int \sin x\,dx = -\cos x + C$。

**5. 余弦函数积分**：
$$\frac{d}{dx}(\sin x + C) = \cos x$$
因此 $\int \cos x\,dx = \sin x + C$。

**6. 反正切函数积分**：
$$\frac{d}{dx}(\arctan x + C) = \frac{1}{1+x^2}$$
因此 $\int \frac{1}{1+x^2}\,dx = \arctan x + C$。

**7. 反正弦函数积分**：
$$\frac{d}{dx}(\arcsin x + C) = \frac{1}{\sqrt{1-x^2}}$$
因此 $\int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x + C$。

$\square$

## 课堂问答

**老师**：一张积分表，凭什么说每条都对？

**学生**：因为它是导数公式倒过来读。由微积分基本定理，只要验证 $\frac{d}{dx}(\text{右端})=\text{被积函数}$ 即可。例如 $\frac{d}{dx}\left(\frac{x^{n+1}}{n+1}\right)=x^n$，就给出 $\int x^n\,dx=\frac{x^{n+1}}{n+1}+C$（$n\ne-1$）。每个不定积分都带一个任意常数 $C$。

**老师（追问）**：为什么 $\int\frac{1}{x}\,dx=\ln|x|$ 要加绝对值？

**学生**：因为当 $x<0$ 时 $\frac{d}{dx}\ln(-x)=\frac{1}{-x}\cdot(-1)=\frac{1}{x}$，所以正负两支能统一写成 $\ln|x|$。这正是 $n=-1$ 时幂函数公式失效的例外情形，不加绝对值就会丢掉 $x<0$ 的一半定义域。

**老师（拓展）**：这些公式能覆盖所有初等函数的积分吗？

**学生**：不能，它们只是"积木"。像 $\int e^{x^2}\,dx$、$\int\frac{\sin x}{x}\,dx$ 都没有初等原函数，必须靠换元、分部把问题化成基本表的形状。所以积分表要和两大积分技巧配合使用，而不是背了就能积一切。
