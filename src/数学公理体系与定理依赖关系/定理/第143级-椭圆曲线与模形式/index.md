# 第143级-椭圆曲线与模形式

本目录收录以下定理：

- [椭圆曲线的群律公式](./椭圆曲线的群律公式.md)
- [Hasse定理](./Hasse定理.md)
- [模形式的Hecke算子](./模形式的Hecke算子.md)
- [谷山-志村定理（模性定理）](./谷山-志村定理（模性定理）.md)
- [Fermat大定理的证明概要](./Fermat大定理的证明概要.md)
- [R=T定理](./R=T定理.md)：模形式的 Hecke 代数 $T$ 与 Galois 表示形变的普适环 $R$ 竟然是同一个环——于是"每个 Galois 表示形变都来自模形式"，模性可以被"提升"，费马大定理的证明由此收官。
- [Lefschetz迹公式](./Lefschetz迹公式.md)：一个映射"有多少个不动点"这种几何信息，可以完全由它在同调群上诱导的线性映射的迹算出来——迹不为零，就一定有不动点。
- [Langlands-Tunnell定理](./Langlands-Tunnell定理.md)：任何一个"奇"的、射影像为可解群的二维复 Galois 表示，都一定来自某个模形式——即 Artin 猜想在可解二维情形成立。
