- [对角化引理](./对角化引理.md)：系统里总能造出一句话，它说的正好是"我自己具有性质 $\varphi$"——想自指，先证明、再代入自己的编号，就能造出一个自指的等价式。
- [一致性公式](./一致性公式.md)：把"这个系统不会自相矛盾"这句话，用系统自己的算术语言写成一条公式——于是系统可以被问"你能证明自己无矛盾吗"，答案是不能。
- [代入引理](./代入引理.md)：公式里的自由变量可以"换成项"，就像把句子中的人名换成一段更长的描述；这条引理保证换完以后真假不变，前提是这种替换不会让自由变量被量词"抓走"（无变量捕获）。
