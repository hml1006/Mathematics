# 第142级-几何朗兰兹

本目录收录以下定理：

- [Beilinson-Drinfeld定理（几何Langlands对应）](./Beilinson-Drinfeld定理（几何Langlands对应）.md)
- [GL(1)的几何Langlands对应](./GL（1）的几何Langlands对应.md)
- [GLC的Kapustin-Witten对偶](./GLC的Kapustin-Witten对偶.md)
- [几何Langlands的范畴化](./几何Langlands的范畴化.md)
- [Hecke特征值的几何构造](./Hecke特征值的几何构造.md)
- [几何 Satake 等价](./几何Satake等价.md)：$\mathrm{D}\text{-}\mathrm{mod}(\mathrm{Gr}_G)$ 的 $\mathrm{Rep}(\check G)$-等变层范畴与 $\mathrm{Rep}(\check G)$ 等价，是几何 Langlands 的局部基石。
- [Hitchin 纤维化与可积系统](./Hitchin纤维化与可积系统.md)：Higgs 丛的 Hitchin 映射 $\mathrm{Higgs}\to\bigoplus H^0(X,K_X^{\otimes i})$ 给出完全可积系统，其纤维是 Jacobian 型的阿贝尔簇。
- [Whittaker 层与几何 Langlands](./Whittaker层与几何Langlands.md)：Whittaker 层给出几何 Langlands 的"谱侧"到"自守侧"的函子，其非零性等价于对应存在（Gaitsgory）。
- [Opers 理论](./Opers理论.md)：$\check G$-opers 参数化局部系统的"规范形式"，Hecke 特征值由 opers 给出，是几何 Langlands 谱侧的核心。
- [Arinkin-Gaitsgory 谱分解](./Arinkin-Gaitsgory谱分解.md)：几何 Langlands 的谱侧按奇异支撑分解，得到整体几何 Langlands 猜想的一个证明框架。
- [几何 Langlands 的量子化](./几何Langlands的量子化.md)：量子几何 Langlands 把对应提升到量子群/Yangian 层面，与 Kapustin-Witten 对偶的 $\hbar$ 形变相符。
