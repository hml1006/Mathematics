- [平面图与 Euler 公式](./平面图与Euler公式.md)：画在平面上、边互不相交的图，其顶点数 $V$、边数 $E$、面数 $F$ 之间有一条铁律 $V-E+F=2$（连通时）——多一个顶点就得多一条边或多一个面来"配平"。
- [面与面的边界](./面与面的边界.md)：把平面图画在纸上，除去边和顶点后剩下的每一"块"连通区域就是一个面；每一块的外沿由若干条边首尾相接围成，是一条闭合的走法（边界闭途径），同一条边最多给两块区域"当边"。
