# 岭回归的统计性质

> **一句话大白话**：普通最小二乘在某些变量高度相关时会"抖得厉害"，岭回归往目标里加一点惩罚把系数往回拉，用一点点偏差换来大幅降低方差，总体误差反而更小。
>
> **小例子**：两个解释变量几乎完全相同（共线），最小二乘的两个系数一高一低剧烈摇摆；岭回归会把它们都往中间压，虽然每个都有点"失真"，但组合起来预测更稳。

## 一、定理介绍

> **前置依赖**：最小二乘与回归模型、$L_2$ 范数与正则化、期望与方差、偏差-方差分解（MSE）、奇异值分解（SVD）

岭回归在最小二乘目标中加入 $L_2$ 惩罚，估计为 $\hat{\boldsymbol{\beta}}_{\text{Ridge}} = (\boldsymbol{X}^\top\boldsymbol{X} + \lambda\boldsymbol{I})^{-1}\boldsymbol{X}^\top\boldsymbol{Y}$。它以牺牲无偏性为代价减小方差，且存在适当的 $\lambda>0$ 使均方误差（MSE）小于 OLS。

## 二、原理思路

通过加入 $\lambda\boldsymbol{I}$ 使接近奇异的 $\boldsymbol{X}^\top\boldsymbol{X}$ 变为正定可逆，从而稳定解。偏差来自收缩因子 $\lambda(\boldsymbol{X}^\top\boldsymbol{X}+\lambda\boldsymbol{I})^{-1}\boldsymbol{\beta}$，方差则因每个奇异方向被压缩而下降。由 $\text{MSE} = \text{方差} + \text{偏差}^2$，在 $\lambda$ 从 0 微增时方差下降占主导，故 MSE 先降后升。

## 三、定理的严格表述

设 $\hat{\boldsymbol{\beta}}_{\text{Ridge}} = (\boldsymbol{X}^\top\boldsymbol{X} + \lambda\boldsymbol{I})^{-1}\boldsymbol{X}^\top\boldsymbol{Y}$，则：

1. **有偏性**：$\text{Bias}(\hat{\boldsymbol{\beta}}_{\text{Ridge}}) = -\lambda(\boldsymbol{X}^\top\boldsymbol{X}+\lambda\boldsymbol{I})^{-1}\boldsymbol{\beta}$。
2. **方差减小**：设 $\boldsymbol{X}$ 的奇异值为 $d_j$，则对任意 $\lambda>0$ 有
   $$
   \frac{d_j^2}{(d_j^2+\lambda)^2} < \frac{1}{d_j^2},
   $$
   故 $\text{Var}(\hat{\boldsymbol{\beta}}_{\text{Ridge}}) < \text{Var}(\hat{\boldsymbol{\beta}}_{\text{OLS}})$。
3. **MSE 更优**：存在 $\lambda>0$ 使 $\text{MSE}(\hat{\boldsymbol{\beta}}_{\text{Ridge}}) < \text{MSE}(\hat{\boldsymbol{\beta}}_{\text{OLS}})$。

## 四、证明过程

1. **偏差**：取期望得 $\mathbb{E}[\hat{\boldsymbol{\beta}}_{\text{Ridge}}] = (\boldsymbol{X}^\top\boldsymbol{X}+\lambda\boldsymbol{I})^{-1}\boldsymbol{X}^\top\boldsymbol{X}\boldsymbol{\beta} = \boldsymbol{\beta} - \lambda(\boldsymbol{X}^\top\boldsymbol{X}+\lambda\boldsymbol{I})^{-1}\boldsymbol{\beta}$。
2. **方差**：由 SVD $\boldsymbol{X} = \boldsymbol{U}\boldsymbol{D}\boldsymbol{V}^\top$ 得
   $$
   \text{Var}(\hat{\boldsymbol{\beta}}_{\text{Ridge}}) = \sigma^2\boldsymbol{V}\operatorname{diag}\!\Big(\frac{d_j^2}{(d_j^2+\lambda)^2}\Big)\boldsymbol{V}^\top < \sigma^2\boldsymbol{V}\boldsymbol{D}^{-2}\boldsymbol{V}^\top.
   $$
3. **MSE 分解**：$\text{MSE} = \operatorname{tr}[\text{Var}] + \|\text{Bias}\|^2$，由连续性，$\lambda$ 从 0 微增时方差下降占主导，故存在 $\lambda>0$ 使 MSE 更低。

## 五、应用与意义

岭回归是处理多重共线性、病态设计矩阵及高维（$p>n$）回归的主要方法之一。它保留全部变量、换取解的稳定性，代价是系数有偏且解释性变差；其超参数 $\lambda$ 通常由交叉验证选取。它是正则化思想与 $L_2$ 收缩理论在统计估计中的典范。
