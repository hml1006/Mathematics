# 稳定流形定理

> **一句话大白话**：在双曲不动点（鞍点）周围，初始点要么被不断拉向它、要么不断推开，而这两拨点各自连成光滑的曲面——"稳定流形"和"不稳定流形"，它们就像看门的分水岭。
>
> **小例子**：线性系统 $x'=x,\,y'=-y$ 在原点有鞍点，$y=0$ 轴是（拉进的）稳定流形、$x=0$ 轴是（推出的）不稳定流形；对非线性扰动，定理保证这两条曲线依然存在且光滑。

## 介绍

稳定流形定理（Stable Manifold Theorem）是动力系统理论中关于双曲平衡点附近轨道结构的基本定理。该定理断言：在双曲平衡点附近，存在光滑的稳定流形和不稳定流形，分别由所有正向趋近于平衡点和反向趋近于平衡点的轨道组成。这些流形与平衡点的稳定子空间和不稳定子空间在切空间水平上相切。这一定理为理解动力系统的局部行为提供了完整的几何描述。

## 分析

**前置依赖**：动力系统、平衡点、双曲性、常微分方程、线性化定理。

**定理内容**：设 $f: \mathbb{R}^n \to \mathbb{R}^n$ 是 $C^r$ 映射（$r \geq 1$），$p$ 是系统 $\dot{x} = f(x)$ 的双曲平衡点（即 $Df(p)$ 没有纯虚数特征值）。设 $E^s$ 和 $E^u$ 分别是 $Df(p)$ 的稳定子空间（对应特征值实部为负）和不稳定子空间（对应特征值实部为正）。则存在 $p$ 的邻域 $U$ 和 $C^r$ 嵌入圆盘 $W^s_{\text{loc}}(p)$ 和 $W^u_{\text{loc}}(p)$，使得：
- $W^s_{\text{loc}}(p)$ 在 $p$ 处与 $E^s$ 相切，且由所有在 $U$ 中正向趋近于 $p$ 的点组成。
- $W^u_{\text{loc}}(p)$ 在 $p$ 处与 $E^u$ 相切，且由所有在 $U$ 中反向趋近于 $p$ 的点组成。

**数学内涵**：
- $\dim W^s = \dim E^s$，$\dim W^u = \dim E^u$。
- 全局稳定流形 $W^s(p) = \bigcup_{t \geq 0} \varphi_{-t}(W^s_{\text{loc}}(p))$ 是 $\mathbb{R}^n$ 的浸入子流形。
- 在 $p$ 处，$T_p W^s = E^s$，$T_p W^u = E^u$。

**证明策略**：
1. 通过坐标变换将系统写为线性部分加非线性部分。
2. 利用图变换（graph transform）方法或 Hadamard 方法构造稳定流形。
3. 证明稳定流形是 $C^r$ 的并与 $E^s$ 相切。

## 思考过程

稳定流形定理的核心思想是：在双曲平衡点附近，非线性系统 $ \dot{x} = f(x)$ 的轨道结构与线性化系统 $\dot{y} = Df(p) \cdot y$ 的轨道结构是拓扑等价的（Hartman-Grobman 定理），但稳定流形定理进一步给出了光滑的等价性——稳定/不稳定流形是光滑浸入子流形。

证明的关键技术是图变换方法：将稳定流形表示为 $E^s$ 上的一个函数 $h: E^s \to E^u$ 的图像，然后通过 $h$ 的不变性质构造一个压缩映射，利用 Banach 不动点定理证明解的存在性。

## 证明过程

**定理**（稳定流形定理）：设 $p$ 是 $C^r$ 系统 $\dot{x} = f(x)$ 的双曲平衡点，则存在局部 $C^r$ 稳定流形 $W^s_{\text{loc}}(p)$ 和局部 $C^r$ 不稳定流形 $W^u_{\text{loc}}(p)$。

**证明**：

### 1. 标准化

通过平移设 $p = 0$，将系统写作：
$$\dot{x} = Ax + F(x)$$
其中 $A = Df(0)$，$F(0) = 0$，$DF(0) = 0$，且 $F$ 是 $C^r$ 的。

设 $\mathbb{R}^n = E^s \oplus E^u$，令 $x = (u, v)$，$u \in E^s$，$v \in E^u$，则
$$\begin{cases}
\dot{u} = A_s u + F_s(u, v) \\
\dot{v} = A_u v + F_u(u, v)
\end{cases}$$
其中 $A_s$ 的特征值实部为负，$A_u$ 的特征值实部为正。

### 2. 图变换方法

寻找稳定流形作为函数 $h: E^s \to E^u$ 的图像：$W^s = \{(u, h(u)) \mid u \in E^s\}$，其中 $h(0) = 0$，$Dh(0) = 0$。

不变性条件：若 $(u(t), v(t))$ 是解且 $v(0) = h(u(0))$，则 $v(t) = h(u(t))$ 对所有 $t \geq 0$ 成立。

### 3. 积分方程

由不变性条件和 $v(t) = h(u(t))$，代入系统得：
$$h(u) = \int_{-\infty}^0 e^{-A_u \tau} F_u(u(\tau), h(u(\tau))) d\tau$$
其中 $u(\tau)$ 满足 $\dot{u} = A_s u + F_s(u, h(u))$，$u(0) = u$。

### 4. 压缩映射

定义 Banach 空间 $\mathcal{B} = \{h \in C^1(\mathcal{U}, E^u) \mid h(0) = 0, Dh(0) = 0\}$，其中 $\mathcal{U} \subseteq E^s$ 是 $0$ 的邻域。定义算子 $\mathcal{T}$：
$$\mathcal{T}(h)(u) = \int_{-\infty}^0 e^{-A_u \tau} F_u(u_h(\tau), h(u_h(\tau))) d\tau$$
其中 $u_h(\tau)$ 是 $\dot{u} = A_s u + F_s(u, h(u))$ 的解。

对充分小的邻域 $\mathcal{U}$，$\mathcal{T}$ 是 $\mathcal{B}$ 上的压缩映射，因此存在唯一不动点 $h$。该不动点即为稳定流形的局部表示。

### 5. 光滑性

由不动点定理，$h$ 是 $C^r$ 的。类似地，通过反向时间系统可构造不稳定流形。$\square$

**推论**：稳定流形 $W^s(p)$ 和不稳定流形 $W^u(p)$ 在 $p$ 处横截相交，且 $\dim W^s(p) = \dim E^s$，$\dim W^u(p) = \dim E^u$。$\square$
