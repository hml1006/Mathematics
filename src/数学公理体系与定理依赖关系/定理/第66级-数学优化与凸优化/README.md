# 第66级-数学优化与凸优化

本目录收录以下定理：

- [Karush-Kuhn-Tucker条件](./Karush-Kuhn-Tucker条件.md)
- [内点法收敛性](./内点法收敛性.md)
- [凸优化对偶理论](./凸优化对偶理论.md)
- [凸函数与凸集](./凸函数与凸集.md)
- [极小极大定理](./极小极大定理.md)
- [梯度下降收敛性](./梯度下降收敛性.md)
- [线性规划基本定理](./线性规划基本定理.md)
- [变分不等式](./变分不等式.md)：变分不等式把"求函数的极小值"推广成"找一个点，使得任何可行方向上的代价都不再下降"——最优性由一个不等式而非等式来刻画。
- [支撑超平面定理](./支撑超平面定理.md)：任何一个凸集的边界点，都能被一张"刚好贴着"它的平面托住，使整个凸集都躺在这张平面的一侧，这张平面就是它的支撑超平面。
- [弱极小极大不等式](./弱极小极大不等式.md)：不管你怎么交换"先取最小还是先取最大"的顺序，先取最小值再取最大值得到的结果，永远不会超过先取最大值再取最小值，顺序换了只会让对方占便宜。
- [下降引理](./下降引理.md)：只要函数的"陡峭程度"变化得不太快，那么从一点出发做一阶近似、再加一个与步长平方成正比的惩罚项，就一定是函数真实值的上界，这给了梯度法可以依赖的"下坡保证"。
