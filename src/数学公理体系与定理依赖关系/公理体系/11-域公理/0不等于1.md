# 0 不等于 1

## 介绍

**0≠1 公理**规定：加法单位元（零元）与乘法单位元（幺元）是域中不同的元素。这条公理虽然简单，但至关重要，它排除了平凡环被视为域的可能性。

## 分析

该公理的形式化表述为：

0 ≠ 1

其中 0 是加法单位元（∀a∈𝔽，a+0=a），1 是乘法单位元（∀a∈𝔽，a·1=a）。

在抽象代数中，存在只有一个元素的环（平凡环），其中 0=1。如果允许这种环被视为域，将导致许多定理在"退化情况"下失效。0≠1 公理确保了域至少包含两个不同的元素（0 和 1）。

## 思考过程

这条公理看起来是技术性的，但它在数学中扮演着重要角色。在域论中，如果 0=1，那么对于任何 a∈𝔽，有 a = a·1 = a·0 = 0，因此整个域只有一个元素。这样的"退化域"会导致许多问题：
- 域扩张理论中，退化域无法扩张。
- 线性代数中，退化域上的向量空间维数概念不明确。
- 伽罗瓦理论中，需要域至少有两个元素来讨论群作用。

## 证明过程

公理不需要证明。其合理性体现在：
- 0≠1 是数学中"非平凡性"的基本要求，类似的约定存在于许多数学结构中（如要求群非平凡、拓扑空间非空等）。
- 在大多数实际应用中，域都包含无穷多元素（如 ℝ、ℂ）或至少两个元素（如 ℤ/2ℤ）。
- 如果不加这条公理，则平凡环会成为一个"退化域"，这会破坏许多定理的简洁陈述。
