# 素数定理

> **一句话大白话**：不超过 $\mathrm{x}$ 的素数个数约等于 $\mathrm{x}/\ln\mathrm{x}$——素数越往后越稀疏，但"密度"以稳定的比例衰减，且与黎曼 $\zeta$ 函数零点的分布精妙相连。
>
> **小例子**：$\pi(100)=25$，而 $\dfrac{100}{\ln 100}\approx 21.7$，相对误差约 $13\%$，且随 $\mathrm{x}$ 增大误差趋于 $0$。

## 介绍

素数定理（Prime Number Theorem, PNT）是解析数论中最著名的结果之一，描述了素数在自然数中的渐近分布规律。由 Hadamard 和 de la Vallée-Poussin 于 1896 年独立证明，其核心断言：不超过 $x$ 的素数个数 $\pi(x)$ 渐近于 $x / \log x$。素数定理的证明深刻依赖于 Riemann Zeta 函数的性质，特别是 $\zeta(s)$ 在 $\operatorname{Re}(s) = 1$ 上无零点这一事实。

## 分析

**前置依赖**：Riemann Zeta 函数、Euler 乘积、函数方程、复分析（围道积分）。

**定理内容**：
$$\pi(x) \sim \frac{x}{\log x}, \quad x \to \infty$$
即 $\lim_{x\to\infty} \frac{\pi(x)}{x/\log x} = 1$。

等价形式：$\pi(x) \sim \operatorname{Li}(x) = \int_2^x \frac{dt}{\log t}$（对数积分）。

**数学内涵**：
- 素数定理表明素数密度约为 $1/\log x$，即 $\pi(x+\Delta x) - \pi(x) \approx \Delta x / \log x$。
- 第 $n$ 个素数 $p_n \sim n \log n$。
- 误差项 $\pi(x) - \operatorname{Li}(x)$ 与 $\zeta(s)$ 的零点分布密切相关。

**证明策略**：
1. 引入 von Mangoldt 函数 $\Lambda(n)$ 和 Chebyshev 函数 $\psi(x) = \sum_{n\leq x} \Lambda(n)$。
2. 证明 $\pi(x) \sim x/\log x$ 等价于 $\psi(x) \sim x$。
3. 将 $\psi(x)$ 表示为 Perron 公式的围道积分：$\psi(x) = \frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} \left(-\frac{\zeta'(s)}{\zeta(s)}\right) \frac{x^s}{s} ds$。
4. 利用 $\zeta(s)$ 在 $\operatorname{Re}(s) \geq 1$ 上无零点（Hadamard-de la Vallée-Poussin 定理），移动积分围道。

## 思考过程

素数定理的证明是解析数论方法的典范。关键步骤是将素数计数问题转化为对 $\zeta(s)$ 的零点分布的分析。$\zeta(s)$ 在 $\operatorname{Re}(s) = 1$ 上无零点这一事实等价于 $\psi(x) \sim x$，而后者正是素数定理的解析等价形式。

Hadamard 和 de la Vallée-Poussin 证明 $\zeta(1+it) \neq 0$ 的论证利用了 $\zeta(s)$ 在 $s=1$ 处有极点的性质以及三角恒等式 $3 + 4\cos\theta + \cos 2\theta = 2(1+\cos\theta)^2 \geq 0$。这一观察至今仍是解析数论中最优美的技巧之一。

## 证明过程

**定理**（素数定理）：$\pi(x) \sim \frac{x}{\log x}$。

**证明**（概要）：

### 1. 等价形式

定义 Chebyshev 函数 $\psi(x) = \sum_{n \leq x} \Lambda(n)$，其中 $\Lambda(n)$ 是 von Mangoldt 函数（$\Lambda(p^k) = \log p$，否则为 0）。可以证明 $\pi(x) \sim x/\log x$ 等价于 $\psi(x) \sim x$。

### 2. 围道积分表示

由 Perron 公式，对 $c > 1$，
$$\psi(x) = \frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} \left(-\frac{\zeta'(s)}{\zeta(s)}\right) \frac{x^s}{s} ds$$

### 3. $\zeta(s)$ 在 $\operatorname{Re}(s) = 1$ 上无零点

**引理**（Hadamard-de la Vallée-Poussin）：对任意 $t \in \mathbb{R}$，$\zeta(1+it) \neq 0$。

*证明*：假设 $\zeta(1+it) = 0$。考虑不等式：
$$\zeta(\sigma)^3 |\zeta(\sigma+it)|^4 |\zeta(\sigma+2it)| \geq 1, \quad \sigma > 1$$

由 Euler 乘积，$\log \zeta(s) = \sum_p \sum_{m=1}^\infty \frac{p^{-ms}}{m}$，故
$$\log|\zeta(\sigma)^3 \zeta(\sigma+it)^4 \zeta(\sigma+2it)| = \sum_{p,m} \frac{1}{m p^{m\sigma}} \operatorname{Re}(3 + 4p^{-imt} + p^{-2imt})$$

而 $3 + 4\cos\theta + \cos 2\theta = 2(1+\cos\theta)^2 \geq 0$，故乘积 $\geq 1$。

若 $\zeta(1+it) = 0$，则当 $\sigma \to 1^+$ 时左边趋于 0，矛盾。$\square$

### 4. 移动围道

利用 $\zeta(s)$ 在 $\operatorname{Re}(s) \geq 1$ 上无零点且除 $s=1$ 外无极点，将积分围道从 $\operatorname{Re}(s) = c$ 左移到 $\operatorname{Re}(s) = 1$ 附近，得到主项贡献来自 $s=1$ 处的极点：
$$\psi(x) = x + o(x)$$

### 5. 结论

由 $\psi(x) \sim x$ 推出 $\pi(x) \sim x/\log x$。$\square$

**推论**：第 $n$ 个素数 $p_n$ 满足 $p_n \sim n \log n$。

**证明**：由 $\pi(p_n) = n$，代入 $\pi(x) \sim x/\log x$ 得 $n \sim p_n/\log p_n$，故 $\log p_n \sim \log n$，从而 $p_n \sim n \log n$。$\square$
