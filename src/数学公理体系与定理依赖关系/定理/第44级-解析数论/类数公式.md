# 类数公式

> **一句话大白话**：它把代数数域的"算术量"（类数、单位、判别式）和"解析量"（Dedekind $\zeta$ 函数在 $s=1$ 的留数）精确对齐——一端是数域有多"不唯一分解"，另一端是某条解析尾巴的高度。
>
> **小例子**：对虚二次域 $\mathbb{Q}(\sqrt{-d})$，$\zeta_K(s)$ 在 $s=1$ 的留数等于 $\dfrac{2\pi h}{w\sqrt{|d|}}$，其中 $h$ 是类数、$w$ 是单位根个数。

## 介绍

类数公式（Class Number Formula）是代数数论与解析数论交汇处的深刻结果，它将代数数域的理想类数（衡量数域中唯一因子分解偏离程度的整数不变量）与 Dirichlet L 函数在 $s=1$ 处的值联系起来。该公式由 Dirichlet 在 1839 年首先对二次域建立，后由 Dedekind、Hecke 等人推广到一般数域。类数公式不仅揭示了数域的代数结构与其解析性质之间的深刻联系，也提供了计算类数的有效方法。

## 分析

**前置依赖**：代数数域、理想类群、Dirichlet L 函数、Dedekind Zeta 函数、正则子。

**定理内容**：设 $K$ 是数域，$\zeta_K(s)$ 是 Dedekind Zeta 函数，则
$$\lim_{s \to 1} (s-1) \zeta_K(s) = \frac{2^{r_1} (2\pi)^{r_2} h_K R_K}{w_K \sqrt{|D_K|}}$$
其中：
- $r_1$ 是实嵌入个数，$2r_2$ 是复嵌入个数，$[K:\mathbb{Q}] = r_1 + 2r_2$
- $h_K$ 是理想类数
- $R_K$ 是正则子（regulator）
- $w_K$ 是单位根个数
- $D_K$ 是判别式

**数学内涵**：
- 对虚二次域 $K = \mathbb{Q}(\sqrt{-d})$（$d > 0$ 无平方因子）：
  $$h_K = \frac{w_K \sqrt{d}}{2\pi} L(1, \chi_{-d})$$
- 对实二次域 $K = \mathbb{Q}(\sqrt{d})$：
  $$h_K = \frac{\sqrt{d}}{\log \varepsilon} L(1, \chi_d)$$
  其中 $\varepsilon$ 是基本单位。

**证明策略**：
1. 定义 Dedekind Zeta 函数 $\zeta_K(s) = \sum_{\mathfrak{a} \subseteq \mathcal{O}_K} N(\mathfrak{a})^{-s}$。
2. 将 $\zeta_K(s)$ 分解为理想类的和。
3. 利用几何方法（Minkowski 定理）计算每个理想类的贡献。
4. 使用类数公式的解析形式推导。

## 思考过程

类数公式的深刻之处在于它将代数数论中的离散不变量（类数 $h_K$、正则子 $R_K$、单位根个数 $w_K$）与解析对象（Dedekind Zeta 函数在 $s=1$ 处的留数）联系了起来。对二次域而言，公式简化为 $L(1, \chi)$ 的表达式，而 $L(1, \chi)$ 又可以通过 Dirichlet 类数公式用有限和的形式计算。

从计算角度看，类数公式提供了计算类数的有效途径。例如，对虚二次域 $\mathbb{Q}(\sqrt{-d})$，类数公式直接给出 $h_K$ 的表达式，使得我们可以通过计算 $L(1, \chi_{-d})$ 的有限和来得到类数。

## 证明过程

**定理**（类数公式）：对虚二次域 $K = \mathbb{Q}(\sqrt{-d})$，$d > 0$，
$$h_K = -\frac{w_K}{2d} \sum_{a=1}^{d-1} \chi_{-d}(a) a$$

其中 $\chi_{-d}$ 是 Kronecker 符号 $\left(\frac{-d}{a}\right)$。

**证明**：

### 1. 由一般类数公式

对虚二次域 $K$，$r_1 = 0$，$r_2 = 1$，$w_K = 2, 4$ 或 $6$（取决于 $d$），$R_K = 1$（因为单位群有限）。一般类数公式给出：
$$\lim_{s \to 1} (s-1) \zeta_K(s) = \frac{2\pi h_K}{w_K \sqrt{d}}$$

### 2. Dedekind Zeta 函数的分解

对虚二次域，Dedekind Zeta 函数分解为：
$$\zeta_K(s) = \zeta(s) L(s, \chi_{-d})$$

其中 $\chi_{-d}(n) = \left(\frac{-d}{n}\right)$ 是 Kronecker 符号。

### 3. 留数计算

$\zeta(s)$ 在 $s=1$ 处留数为 1，故
$$\lim_{s \to 1} (s-1) \zeta_K(s) = L(1, \chi_{-d})$$

### 4. 计算 $L(1, \chi_{-d})$

利用 Dirichlet 的类数公式：
$$L(1, \chi) = -\frac{\pi}{q^{3/2}} \sum_{a=1}^{q-1} \chi(a) a$$
对本原实特征 $\chi$ 模 $q$（当 $-d$ 是基本判别式时，$q = d$ 或 $4d$）。

代入并整理得：
$$h_K = \frac{w_K \sqrt{d}}{2\pi} L(1, \chi_{-d}) = -\frac{w_K}{2d} \sum_{a=1}^{d-1} \chi_{-d}(a) a$$

$\square$

**例子**：对 $K = \mathbb{Q}(\sqrt{-5})$，$d = 5$，$w_K = 2$，$\chi_{-5}(n) = \left(\frac{-5}{n}\right)$。计算得
$$L(1, \chi_{-5}) = \frac{2\pi}{2\sqrt{5}} \cdot 2 = \frac{2\pi}{\sqrt{5}}$$
故 $h_K = 2$，即 $\mathbb{Q}(\sqrt{-5})$ 的类数为 2。$\square$
