# 第149级-拓扑量子场论

本目录收录以下定理：

- [2维TQFT的分类（Frobenius代数等价）](./2维TQFT的分类（Frobenius代数等价）.md)
- [三维Chern-Simons理论与Jones多项式](./三维Chern-Simons理论与Jones多项式.md)
- [Reshetikhin-Turaev构造](./Reshetikhin-Turaev构造.md)
- [扩展TQFT与∞-范畴（Lurie的Bordism假设）](./扩展TQFT与∞-范畴（Lurie的Bordism假设）.md)
- [TQFT与Donaldson不变量](./TQFT与Donaldson不变量.md)
- [Atiyah 的 TQFT 公理](./Atiyah的TQFT公理.md)：$d$ 维 TQFT 是协边范畴 $\mathrm{Cob}_d$ 到向量空间范畴的对称幺半函子，$Z(\emptyset)=\mathbb C$，$Z(M_1\sqcup M_2)=Z(M_1)\otimes Z(M_2)$。
- [Dijkgraaf-Witten 理论](./Dijkgraaf-Witten理论.md)：有限群 $G$ 与上同调类 $\alpha\in H^d(BG;U(1))$ 给出 $d$ 维 TQFT，$Z(M)=\sum_{[A]}\alpha([A])$。
- [因子化同调](./因子化同调.md)：因子化同调把 TQFT 推广为流形层，$E_n$ 代数与 $\mathrm{Disk}_n$ 代数的同调给出不变量（Ayala-Francis）。
- [Chern-Simons 微扰展开](./Chern-Simons微扰展开.md)：Chern-Simons 路径积分的微扰展开由 Axelrod-Singer 用 Feynman 图给出，与 WRT 不变量一致。
- [边界 TQFT 与拓扑边界条件](./边界TQFT与拓扑边界条件.md)：$d$ 维 TQFT 的边界理论由 $(d-1)$ 维模张量范畴描述，边界条件对应其中的对象。
- [Witten-Reshetikhin-Turaev 不变量](./Witten-Reshetikhin-Turaev不变量.md)：三维流形的 WRT 不变量由量子群 $U_q(\mathfrak{sl}_2)$ 的表示与手术表示给出，是 Chern-Simons 路径积分的严格化。
