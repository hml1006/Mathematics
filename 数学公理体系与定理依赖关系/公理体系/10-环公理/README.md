# 环公理

## 概述

环是抽象代数中重要的代数结构，它包含两种二元运算（加法和乘法），满足加法构成 Abel 群、乘法满足结合律、分配律将两者连接。环公理是域公理的弱化版本——环不要求乘法交换律，也不要求乘法逆元的存在。
