- [欧拉乘积公式](./欧拉乘积公式.md)：把所有整数的倒数幂之和，改写成"按素数逐项打包"的无穷乘积——整数的加法式求和，摇身一变成为素数的乘法式结构。
- [欧拉准则](./欧拉准则.md)：判断一个数 $a$ 是不是模奇素数 $p$ 的完全平方数，只需算一次幂 $a^{(p-1)/2}$：得 $1$ 就是，得 $-1$ 就不是。
- [Bertrand素数定理](./Bertrand素数定理.md)：随便给一个整数 $n>1$，在 $n$ 与 $2n$ 之间（严格大于 $n$、不超过 $2n$）一定还藏着一个素数——素数再稀疏，也不会稀疏到留下这么长的空档。
- [Legendre 公式](./Legendre公式.md)：想知道素数 $p$ 在 $n!$ 里"埋"了多少个因子，就数 $1$ 到 $n$ 中有多少个数是 $p$ 的倍数、多少个数是 $p^2$ 的倍数、多少个数是 $p^3$ 的倍数……层层加起来。
