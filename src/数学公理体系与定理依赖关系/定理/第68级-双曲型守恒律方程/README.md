- [Murat 引理](./Murat引理.md)：两个各自只弱收敛的向量场，如果一个的散度是紧的、另一个的旋度是紧的，那么它们的内积会弱收敛到极限的内积——补偿紧性由此把"弱收敛"升级为"乘积收敛"。
- [Kirchhoff 公式](./Kirchhoff公式.md)：三维波动方程的解可以显式写出来——时刻 $t$、位置 $x$ 处的值只取决于初值在以 $x$ 为心、半径 $ct$ 的球面上的积分（含时间的导数项），波以速度 $c$ 沿球面恰好经过，过后不留余波。
