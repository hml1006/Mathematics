- [Dedekind ζ 函数](./DedekindZeta函数.md)
- [Dirichlet 单位定理](./Dirichlet单位定理.md)
- [Fermat 大定理（Wiles 证明）](./Fermat大定理.md)
- [局部整体原理（Hasse-Minkowski 定理）](./Hasse-Minkowski定理.md)
- [p-进数与局部域](./p进数与局部域.md)
- [数域与整数环](./数域与整数环.md)

- [Poisson 求和公式](./Poisson求和公式.md)：把函数在所有整数点上的取值加起来，得到的和等于把它的傅里叶变换在所有整数点上的取值加起来——"实数上的周期化和"与"频率上的周期化和"是同一回事。
- [Chebotarev 密度定理](./Chebotarev密度定理.md)：在一个 Galois 数域扩张里，各个素理想按它们的 Frobenius 元素被"均匀地"分配给 Galois 群：某个共轭类 $C$ 有多大，占有该共轭类的素理想就有多大比例——素理想像雨点一样按群的大小均匀洒落。
- [Frey 曲线与 Ribet 水平降低定理](./Frey曲线与Ribet水平降低定理.md)：若 Fermat 方程 $a^p+b^p=c^p$ 真有一组解，就能把它"变"成一条怪异的椭圆曲线（Frey 曲线）；Ribet 定理说这条曲线的模形式水平可以被降到不能再降的 $2$，而权 $2$ 水平 $2$ 的模形式根本不存在——一撞就矛盾，解也就不可能存在。
- [Chevalley-Warning 定理](./Chevalley-Warning定理.md)：有限域上若干多项式方程，只要它们的次数加起来还没超过变量个数，就一定有公共零点，而且解的总数是域特征的倍数（模 $p$ 为零）——"方程不够多、次数不够高"就管不住解的存在性。
- [Carayol的局部-整体定理](./Carayol的局部-整体定理.md)：一个模形式的模 $\ell$ 伽罗瓦表示好不好，完全由它在一个个素数处的"局部表现"决定；局部的重量与水平组装起来就定出全局的重量与水平。
- [Tauberian定理](./Tauberian定理.md)：如果非负数列的 Dirichlet 级数在边界附近有简单的极点行为，那么它的部分和一定按线性速率增长；这是把解析信息翻译成计数结论的机器。
- [Minkowski 嵌入与数域判别式](./Minkowski嵌入与数域判别式.md)：把数域的每个元素"同时扔进所有实数与复数坐标系"，就得到一个 $n$ 维欧氏空间里的格子；这个格子的体积（的平方，去掉 $2$ 的因子）就是判别式，它衡量数域"有多扭曲"，也决定哪些素数会分歧。
