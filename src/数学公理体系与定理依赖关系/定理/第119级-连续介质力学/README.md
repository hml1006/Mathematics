# 第119级-连续介质力学

本目录收录以下定理：

- [Cauchy应力张量的存在性](./Cauchy应力张量的存在性.md)
- [变形梯度与应变张量的关系](./变形梯度与应变张量的关系.md)
- [运动方程（Cauchy第一运动定律）](./运动方程（Cauchy第一运动定律）.md)
- [本构方程的各向同性表示](./本构方程的各向同性表示.md)
- [超弹性材料的本构关系](./超弹性材料的本构关系.md)
- [对称函数的表示定理](./对称函数的表示定理.md)：一个对张量“怎么转动都不变”的函数，其实只看得见张量的主值；而主值又只能通过不变量（迹、迹的平方、迹的立方）被看见，所以任何各向同性的标量函数都只是这几个不变量的函数。
- [Reynolds输运定理](./Reynolds输运定理.md)：一个随流体一起运动的“体积块”里某物理量的变化率 = 这块体积内部该量自身随时间的变化（含内部产生）+ 从它表面被流体带出去的通量；即“总量变化 = 内部变化 + 表面通量”。
- [体积分局域化引理](./体积分局域化引理.md)：如果某个连续的量在每一个小体积上的积分都是零，那么它本身处处为零——因为积分就是取平均，把小体积缩到一点，平均值就收敛到该点的函数值。
- [对称张量的谱定理](./对称张量的谱定理.md)：实对称矩阵一定能被“旋转”成对角形——它有一组相互垂直的特征向量，特征值全是实数；所以对称张量的全部信息就是它沿三个正交主方向上的拉伸率（主值）。
- [Jacobi 行列式与 Jacobi 公式](./Jacobi行列式与Jacobi公式.md)：把一个可逆线性变换（或光滑坐标变换）的"体积缩放倍数"记成一个行列式，就叫 Jacobi（雅可比）行列式；**Jacobi 公式**则给出这个行列式随时间变化的求导法则：$\dfrac{d}{dt}\det A=\det A\cdot\operatorname{tr}\big(A^{-1}\dot A\big)$。
- [多重 Riemann 积分与换元公式](./多重Riemann积分与换元公式.md)：把一元积分"分割—求和—取极限"的想法搬到高维，就是多重 Riemann 积分；而**换元公式**说，做变量替换 $\boldsymbol x=\Phi(\boldsymbol u)$ 时体积微元要按 Jacobi 行列式缩放：$d\boldsymbol x=\lvert \det D\Phi\rvert \;d\boldsymbol u$。
- [热力学第二定律](./热力学第二定律.md)：孤立系统的熵不会自发减少——自然过程有方向，热从高温流向低温、摩擦生热却不会自动降温。数学上它被写成一条"耗散不等式"，强迫应力、热流等本构关系必须与自由能相容。
- [静态平衡方程](./静态平衡方程.md)：物体保持静止时，它内部每一小块受到的体力与面力必须恰好互相抵消，写成微分形式就是 $\nabla\cdot\boldsymbol\sigma+\rho\boldsymbol b=\boldsymbol 0$。
