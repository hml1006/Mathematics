# 有界变差函数

> **一句话大白话**：把函数来回上下抖动的"总幅度"累加起来，如果这个总数不炸天、是有限的，就称它"有界变差"——可以把它拆成一个上升段加一个下降段。
>
> **小例子**：$f(x)=x$ 在 $[0,1]$ 的全变差为 $1$，故有界变差；而 $f(x)=\sin\frac1x$（$x>0$）抖动无限次，全变差无穷大。

## 介绍

有界变差函数（Bounded Variation Function）是实分析中描述函数振荡程度的重要概念。函数 $f$ 在区间 $[a,b]$ 上的全变差定义为所有分划下函数值变化量之和的上确界。若全变差有限，则称 $f$ 为有界变差函数。有界变差函数在傅里叶分析、随机过程、微分方程等领域有广泛应用。Jordan 分解定理表明，有界变差函数可以分解为两个单调递增函数之差，这揭示了有界变差与单调性之间的深刻联系。

## 分析

**定义**：设 $f: [a,b] \to \mathbb{R}$，对分划 $P = \{x_0 = a < x_1 < \cdots < x_n = b\}$，定义

$$
V(f, P) = \sum_{i=1}^n |f(x_i) - f(x_{i-1})|.
$$

$f$ 在 $[a,b]$ 上的全变差为

$$
V_a^b(f) = \sup\{V(f, P) : P \text{ 是 } [a,b] \text{ 的分划}\}.
$$

若 $V_a^b(f) < \infty$，则称 $f$ 在 $[a,b]$ 上是有界变差的。记 $BV[a,b]$ 为 $[a,b]$ 上有界变差函数全体。

**基本性质**：

1. 单调函数是有界变差的：若 $f$ 单调递增，则 $V_a^b(f) = f(b) - f(a)$。
2. Lipschitz 连续函数是有界变差的。
3. 有界变差函数必有界，但反之不真（如 $f(x) = \sin(1/x)$ 在 $[0,1]$ 上有界但不是有界变差的）。
4. 有界变差函数几乎处处可导，且导函数 Lebesgue 可积。

**Jordan 分解定理**：$f \in BV[a,b]$ 当且仅当 $f$ 可以表示为两个单调递增函数之差。

## 思考过程

为什么需要研究有界变差函数？在黎曼积分理论中，可积函数类相对较宽，但有些函数虽然可积，其性质却不够"好"。有界变差函数正好填补了连续函数和绝对连续函数之间的空白。它们具有以下重要特征：

1. **可求长性**：若 $f$ 连续且有界变差，则曲线 $y = f(x)$ 是可求长的（长度有限）。
2. **傅里叶级数收敛**：有界变差函数的傅里叶级数逐点收敛到函数本身（Jordan 判别法）。
3. **Stieltjes 积分**：有界变差函数可以作为 Riemann-Stieltjes 积分的积分子。

Jordan 分解的证明思路是：定义 $f$ 的正变差和负变差函数，然后证明 $f$ 可以分解为它们的差。具体地，对 $x \in [a,b]$，定义 $P(x) = V_a^x(f)$，$N(x) = P(x) - (f(x) - f(a))$，则 $P$ 和 $N$ 都是单调递增且非负的，且 $f(x) = f(a) + P(x) - N(x)$。

## 证明过程

**定理 1（单调函数是有界变差的）**：若 $f$ 在 $[a,b]$ 上单调递增，则 $V_a^b(f) = f(b) - f(a)$。

**证明**：对任意分划 $P = \{a = x_0 < x_1 < \cdots < x_n = b\}$，

$$
V(f, P) = \sum_{i=1}^n |f(x_i) - f(x_{i-1})| = \sum_{i=1}^n (f(x_i) - f(x_{i-1})) = f(b) - f(a).
$$

因此 $V_a^b(f) = f(b) - f(a) < \infty$，$f$ 是有界变差的。$\square$

**定理 2（Jordan 分解）**：$f \in BV[a,b]$ 当且仅当存在单调递增函数 $g, h$ 使得 $f = g - h$。

**证明**：充分性显然（单调函数有界变差，差也有界变差）。

必要性：设 $f \in BV[a,b]$。对 $x \in [a,b]$，定义正变差函数 $P(x) = V_a^x(f)$，其中 $V_a^a(f) = 0$。定义负变差函数 $N(x) = P(x) - (f(x) - f(a))$。

首先，$P$ 是单调递增的：对 $a \le x < y \le b$，$V_a^y(f) = V_a^x(f) + V_x^y(f) \ge V_a^x(f)$，故 $P(y) \ge P(x)$。

其次，$N$ 也是单调递增的：对 $x < y$，

$$
N(y) - N(x) = [P(y) - P(x)] - [(f(y) - f(a)) - (f(x) - f(a))] = V_x^y(f) - (f(y) - f(x)).
$$

由定义，$V_x^y(f) \ge |f(y) - f(x)| \ge f(y) - f(x)$，故 $N(y) - N(x) \ge 0$。

因此 $f(x) = f(a) + P(x) - N(x)$，其中 $P$ 和 $N$ 均为单调递增函数。$\square$

**定理 3（有界变差函数的可导性）**：若 $f \in BV[a,b]$，则 $f$ 在 $[a,b]$ 上几乎处处可导，且 $f' \in L^1[a,b]$。

**证明**：由 Jordan 分解，$f = g - h$，其中 $g, h$ 单调递增。由 Lebesgue 单调函数可微定理，单调函数几乎处处可导。因此 $g$ 和 $h$ 几乎处处可导，从而 $f$ 几乎处处可导。且 $f'(x) = g'(x) - h'(x)$ 几乎处处成立。由 $g', h' \ge 0$ 几乎处处成立，且 $g'$ 和 $h'$ 可积，故 $f' \in L^1[a,b]$。$\square$
