# 换元积分法

> **一句话大白话**：把一个绕来绕去不好算的积分，通过换一个字母把它“化装”成标准好算的积分——学名“凑微分”，是链式法则反过来用。
>
> **小例子**：$\int 2x\cos(x^2)\,dx$，令 $u=x^2$，则 $du=2x\,dx$，原式 $=\int\cos u\,du=\sin(x^2)+C$。

## 介绍

换元积分法（Integration by Substitution）是微积分中最重要的积分技巧之一，是链式法则的逆运算。该方法通过引入新的变量简化被积函数的形式，将复杂的积分转化为标准形式。换元积分法分为第一类换元（凑微分法）和第二类换元（变量替换法），广泛应用于各类函数的积分计算中。

## 分析

**前置依赖**：链式法则、微积分基本定理

**定理内容**：

1. **第一类换元法**（凑微分法）：若 $f(u)$ 连续，$u = g(x)$ 具有连续导数，则
   $$\int f(g(x))g'(x)\,dx = \int f(u)\,du$$

   定积分形式：
   $$\int_a^b f(g(x))g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du$$

2. **第二类换元法**：若 $x = \varphi(t)$ 单调可导，$\varphi'(t) \neq 0$，且 $f(\varphi(t))\varphi'(t)$ 连续，则
   $$\int f(x)\,dx = \int f(\varphi(t))\varphi'(t)\,dt$$

   定积分形式：
   $$\int_a^b f(x)\,dx = \int_{\varphi^{-1}(a)}^{\varphi^{-1}(b)} f(\varphi(t))\varphi'(t)\,dt$$

**数学内涵**：
换元积分法是链式法则 $\frac{d}{dx}F(g(x)) = F'(g(x))g'(x)$ 的逆运算。第一类换元是将被积函数整体视为某个复合函数的导数；第二类换元则是通过引入新参数简化被积函数的形式。两种方法本质相同，都是通过变量替换来简化积分计算。

**证明策略**：利用链式法则和微积分基本定理，对复合函数求导的逆过程进行推导。

## 思考过程

第一类换元法的核心是"凑微分"：观察到 $g'(x)dx = dg(x)$，因此
$$\int f(g(x))g'(x)\,dx = \int f(g(x))\,dg(x) = \int f(u)\,du$$

第二类换元法则是反其道而行之：当 $x = \varphi(t)$ 时，$dx = \varphi'(t)dt$，代入原积分即可。

## 证明过程

**定理**（第一类换元法）：设 $f(u)$ 在区间 $I$ 上连续，$u = g(x)$ 在 $[a,b]$ 上具有连续导数，且 $g([a,b]) \subseteq I$，则
$$\int_a^b f(g(x))g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du$$

**证明**：

因为 $f$ 连续，设 $F$ 是 $f$ 的一个原函数，即 $F'(u) = f(u)$。

考虑复合函数 $F(g(x))$，由链式法则：
$$\frac{d}{dx}F(g(x)) = F'(g(x))g'(x) = f(g(x))g'(x)$$

因此 $F(g(x))$ 是 $f(g(x))g'(x)$ 的一个原函数。由牛顿-莱布尼茨公式，
$$\int_a^b f(g(x))g'(x)\,dx = F(g(x))\Big|_a^b = F(g(b)) - F(g(a))$$

另一方面，
$$\int_{g(a)}^{g(b)} f(u)\,du = F(u)\Big|_{g(a)}^{g(b)} = F(g(b)) - F(g(a))$$

因此等式成立。

**定理**（第二类换元法）：设 $x = \varphi(t)$ 在 $[\alpha, \beta]$ 上单调可导，$\varphi'(t) \neq 0$，且 $f(x)$ 在 $\varphi([\alpha, \beta])$ 上连续，则
$$\int_{\varphi(\alpha)}^{\varphi(\beta)} f(x)\,dx = \int_\alpha^\beta f(\varphi(t))\varphi'(t)\,dt$$

**证明**：

设 $F$ 是 $f$ 的一个原函数，即 $F'(x) = f(x)$。考虑复合函数 $F(\varphi(t))$，由链式法则：
$$\frac{d}{dt}F(\varphi(t)) = F'(\varphi(t))\varphi'(t) = f(\varphi(t))\varphi'(t)$$

因此 $F(\varphi(t))$ 是 $f(\varphi(t))\varphi'(t)$ 的一个原函数。由牛顿-莱布尼茨公式，
$$\int_\alpha^\beta f(\varphi(t))\varphi'(t)\,dt = F(\varphi(t))\Big|_\alpha^\beta = F(\varphi(\beta)) - F(\varphi(\alpha))$$

而
$$\int_{\varphi(\alpha)}^{\varphi(\beta)} f(x)\,dx = F(x)\Big|_{\varphi(\alpha)}^{\varphi(\beta)} = F(\varphi(\beta)) - F(\varphi(\alpha))$$

因此等式成立。

$\square$
