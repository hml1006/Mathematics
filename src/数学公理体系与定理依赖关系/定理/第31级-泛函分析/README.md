- [Baire 纲定理](./Baire纲定理.md)：在一个"完好的"空间里，可数多个又稠又开的集合交起来仍然稠密——空间不会薄到被可数多块"无处可去"的碎片拼满。
- [Tychonoff 定理](./Tychonoff定理.md)：任意多个紧空间的乘积，在乘积拓扑下仍然紧——紧性可以被"无限制地打包"到任意大小的坐标积里。
- [Khintchine 不等式](./Khintchine不等式.md)：用随机正负号把一组数随机加权相加，其结果大小的各阶矩彼此只差一个只依赖阶数的常数——$L^p$ 大小与 $L^2$ 大小是等价的。
- [Riesz 引理](./Riesz引理.md)：在一个真闭子空间外面，总能找到一个单位向量，它离这个子空间的"距离"几乎等于 $1$——无穷维空间里"正交方向"虽可能不存在，但"近似正交方向"永远存在。
- [Rayleigh 商的变分原理](./Rayleigh商的变分原理.md)：自伴算子的最大、最小特征值，正好是 Rayleigh 商在单位球上的最大、最小值——求特征值可以变成求函数的极值。
- [有界算子的谱定理](./有界算子的谱定理.md)：希尔伯特空间上的有界自伴算子，都能被"沿实谱轴铺开的一族正交投影"加权叠加出来——它就是线性代数里对角化的无穷维版本。
- [谱分解定理](./谱分解定理.md)：谱测度把整个空间按谱的取值切成一堆互相垂直的"谱块"，算子在每个块上只是数乘——空间与算子同时被"分块对角化"。
- [正交投影定理](./正交投影定理.md)：希尔伯特空间里的闭子空间都有一个"垂直影子"——任意向量都能唯一地拆成"落在子空间里的部分"与"垂直于它的部分"。
- [Alexander 子基定理](./Alexander子基定理.md)：要检查一个空间紧不紧，不必逐一验证所有开覆盖，只要验证那些由"子基"（生成拓扑的最小砖块）拼成的开覆盖就够了——这些都能抽出有限覆盖，那么一切开覆盖都能。
- [Paley-Zygmund 不等式](./Paley-Zygmund不等式.md)：一个非负随机变量不会"轻易地"远小于自己的平均值——它以可观的概率不小于平均值的一个给定份额，而这条下界的强弱由二阶矩控制。
- [Mazur定理](./Mazur定理.md)：一列点弱收敛到 $x$，虽然它们本身可能在范数下"跑偏"，但总能从它们中挑出凸组合，用范数干净利落地收敛到 $x$；等价地说，凸集在弱拓扑下的闭包就等于它在范数下的闭包。
- [Urysohn引理](./Urysohn引理.md)：在一个"足够好"的拓扑空间里，任意两个互不相交的闭集都能被一条连续函数彻底分开：一个上面恒为 $0$，另一个上面恒为 $1$，中间平滑过渡。
- [闭球套定理](./闭球套定理.md)：一列一层套一层、半径越缩越小的闭球，在"完好的"（完备）空间里必然有一个共同点，而且由于半径趋于零，这个公共点还是唯一的。
