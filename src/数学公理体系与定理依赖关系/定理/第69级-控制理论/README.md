# 第69级-控制理论

本目录收录以下定理：

- [Bellman 最优性原理](./Bellman最优性原理.md)
- [Lyapunov 稳定性定理](./Lyapunov稳定性定理.md)
- [Pontryagin 极大值原理](./Pontryagin极大值原理.md)
- [Riccati 方程与线性二次调节器（LQR）](./Riccati方程与LQR控制.md)
- [Kalman 能控性定理](./能控性定理.md)
- [Kalman 能观性定理](./能观性定理.md)
- [随机控制基础：随机动态规划](./随机控制基础.md)
- [LaSalle不变集原理](./LaSalle不变集原理.md)：即使能量函数只有 $\dot V\le0$（不增而不严格下降），系统也不会乱跑——它最终一定停在"$\dot V=0$ 的最大不变集"里。
- [能控性与能观性的对偶原理](./能控性与能观性的对偶原理.md)：一个线性系统的能控性，恰好等价于把它所有矩阵转置后得到的"对偶系统"的能观性——能控与能观是一枚硬币的两面，只是看待系统的方向相反。
