# Archimedes 性质

## 介绍

Archimedes 性质指出：对任意正实数 x，存在自然数 n 使得 n > x。换句话说，实数集中不存在"无穷大"元素——任何实数都可以被某个自然数"超越"。

Archimedes 性质在实数公理体系中通常作为定理（而非公理）出现，因为它可以从完备性公理推导出来。但它在数学中具有如此重要的地位，以至于经常被单独列出。Archimedes 性质确保了实数中没有"无穷小"或"无穷大"的非标准元素，这是实数区别于超实数 *ℝ 的关键特征。

## 分析

**形式化表述：**
$$ \forall x \in \mathbb{R} (x > 0 \rightarrow \exists n \in \mathbb{N} (n > x)) $$

**等价形式：**
- 对任意正实数 ε，存在自然数 n 使得 1/n < ε（Archimedes 性质的常用形式）
- lim_{n→∞} 1/n = 0
- 实数集是 Archimedes 有序域

**与完备性公理的关系：**
- 在域公理和序公理下，Archimedes 性质等价于 ℕ ⊆ ℝ 无上界
- 若 ℝ 满足完备性公理，则 ℕ 在 ℝ 中无上界（否则 sup(ℕ) 存在，可推出矛盾）
- 因此，Archimedes 性质可以从完备性公理推导出

**应用：**
- 证明极限理论的基本结果
- 证明有理数在实数中稠密
- 证明实数的 Archimedes 性在分析中的各种应用

## 思考过程

Archimedes 性质以古希腊数学家阿基米德命名，他在《论球与圆柱》中使用了这一原理。Archimedes 原始的表述是："对任意两个不相等的量，存在一个整数倍数使得较小量的倍数超过较大量。"

这个性质看似平凡，但它的意义深远。它确保了实数中没有"无穷小"——即不存在一个正实数 ε，使得对任意自然数 n 都有 ε < 1/n。这正是极限理论的基础。

为什么 Archimedes 性质不是一条公理？因为它可以从完备性公理推导出。但值得注意的是，在非 Archimedes 有序域（如超实数 *ℝ）中，存在无穷小和无穷大元素，完备性公理在这些结构中不成立。因此，Archimedes 性质是"实数不同于其他有序域"的重要特征之一。

## 证明过程

以下给出从完备性公理推导 Archimedes 性质的证明概要。

**证明（反证法）：**
假设 Archimedes 性质不成立，即存在正实数 x₀ 使得对所有自然数 n 都有 n ≤ x₀。这意味着 ℕ ⊆ ℝ 有上界 x₀。

由完备性公理，令 s = sup(ℕ)。由于 s 是 ℕ 的上确界，s - 1 不是 ℕ 的上界，因此存在 n ∈ ℕ 使得 n > s - 1。但此时 n + 1 > s，且 n + 1 ∈ ℕ，这与 s 是 ℕ 的上界矛盾。

因此，ℕ 在 ℝ 中无上界，Archimedes 性质成立。

**合理性：**
- 该证明依赖于完备性公理，在域公理和序公理下不能证明 Archimedes 性质
- 存在非 Archimedes 有序域（如超实数）满足域公理和序公理但不满足 Archimedes 性质
- 因此，Archimedes 性质是实数的重要特征，而非逻辑必然
