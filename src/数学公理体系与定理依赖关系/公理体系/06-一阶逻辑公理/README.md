# 一阶逻辑公理

## 概述

一阶逻辑公理（又称谓词逻辑公理）在命题逻辑公理的基础上加入量词和等号的处理，形成了完整的一阶谓词演算公理体系。一阶逻辑是数学中最重要的形式逻辑系统，几乎所有数学理论都可以在一阶逻辑中形式化。

一阶逻辑公理体系包含命题逻辑公理（A1-A3）、量词公理、等号公理，以及全称概括规则。

## 推理规则

- 肯定前件（MP）
- 全称概括规则（Generalization）

## 完备性

Gödel 完备性定理（1930）表明：一阶逻辑的公理体系是完备的，即所有一阶逻辑有效式都可以在公理体系中证明。
