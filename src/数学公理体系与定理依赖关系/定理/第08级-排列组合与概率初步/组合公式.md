# 组合公式

## 介绍

组合公式是组合数学中的基本公式：从 $n$ 个不同元素中取出 $k$ 个（$k \leq n$）的组合数为 $C(n, k) = \binom{n}{k} = \frac{n!}{k!(n-k)!}$。

## 分析

**前置依赖**：排列公式。

**定理内容**：$\binom{n}{k} = \frac{n!}{k!(n-k)!}$。

## 思考过程

组合与排列的关系可用"先排再除"来概括：从 $n$ 个元素中选出 $k$ 个并考虑顺序（排列）有 $P(n,k)$ 种方式，而选出的 $k$ 个元素内部有 $k!$ 种排列方式。由于组合不关心顺序，只需将排列数除以 $k!$ 即可，即 $\binom{n}{k} = \frac{P(n,k)}{k!} = \frac{n!}{k!(n-k)!}$。

组合数具有对称性：$\binom{n}{k} = \binom{n}{n-k}$，其直观含义是从 $n$ 个元素中选 $k$ 个保留，等价于选 $n-k$ 个排除。杨辉三角（帕斯卡三角）的每个数都等于其上方两数之和，这正是组合数递推关系 $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$ 的几何体现。

**应用场景**：抽奖选号、组队方案、二项式定理展开系数等不涉及顺序的计数问题。

## 证明过程

**证明**：从 $n$ 个元素中选 $k$ 个排列，先选 $k$ 个元素（组合）再排列它们。由乘法原理，$P(n, k) = \binom{n}{k} \cdot k!$，故 $\binom{n}{k} = \frac{P(n, k)}{k!} = \frac{n!}{k!(n-k)!}$。$\square$
