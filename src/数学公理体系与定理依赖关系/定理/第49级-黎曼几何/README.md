# 第49级-黎曼几何

> 一句话级别概述：黎曼几何在流形上以度量为基本对象，研究曲率与因几何拓扑及全局结构的联系，是现代几何与广义相对论的基石。

## 级别简介

本级别研究带黎曼度量的光滑流形，涵盖曲率张量与截面/Ricci/标量曲率、测地线与 Jacobi 场、比较定理、Hodge 理论以及嵌入与分裂等整体结果，并涉及 Ricci 流证明 Poincaré 猜想等前沿推进。

## 本级别定理

- [Bonnet-Myers定理](./Bonnet-Myers定理.md)：正曲率有界直径。
- [Rauch比较定理](./Rauch比较定理.md)：曲率比较控制Jacobi场。
- [Cartan-Hadamard定理](./Cartan-Hadamard定理.md)：非正曲率覆盖同胚欧氏空间。
- [Ricci流与Poincare猜想](./Ricci流与Poincare猜想.md)：度量流证明三维球面猜想。
- [Cheeger-Gromoll分裂定理](./Cheeger-Gromoll分裂定理.md)：非负Ricci下含直线即分裂。
- [Riemann曲率张量的对称性](./Riemann曲率张量的对称性.md)：曲率张量的代数性质。
- [Hodge分解定理](./Hodge分解定理.md)：调和形式分解上同调类。
- [截面曲率Ricci曲率标量曲率](./截面曲率Ricci曲率标量曲率.md)：各层级曲率度量。
- [Nash嵌入定理](./Nash嵌入定理.md)：黎曼流形欧氏空间等距嵌入。
- [测地线与Jacobi场](./测地线与Jacobi场.md)：局部测地行为的变分刻画。
- [Laplacian 比较定理](./Laplacian比较定理.md)：到某点的距离函数的拉普拉斯（可理解为"测地球面的平均曲率"）被空间曲率卡住了上限：曲率越大，等距球面越"往里凹"，距离函数的拉普拉斯就越小；曲率下界给出一个由模型空间决定的通用上界。
- [Hopf-Rinow 定理](./Hopf-Rinow定理.md)：黎曼流形的"完备"有好几种看似不同的说法——度量空间完备、测地线能无限延伸、有界闭集是紧的、指数映射定义在整个切空间上——它们其实说的是同一件事；而且只要完备，任意两点之间必有一条最短测地线。
- [强极大值原理](./强极大值原理.md)：一个次调和（"处处不低于周围平均"）的函数若在区域内部某点取到了最大值，那它就不可能在别处更小——整个连通区域上它只能是同一常数；换句话说，极值一旦"进到里面"，就必须"摊平"成常数。
- [Bochner 公式](./Bochner公式.md)：它是一架"守恒天平"——左边是某个函数梯度长度平方的拉普拉斯，右边被拆成三块：一块恒非负的 Hessian 平方、一块梯度与自身拉普拉斯的内积、再加一块曲率。正曲率那一块被迫为正，于是平方项只能为零，调和对象被"挤没了"。
- [极大值原理](./极大值原理.md)：次调和函数（每点都不低于周围平均）在有界区域里"涨"不到里面去，它的最大必然发生在边界上；想在里面冒尖，就只能靠边界数据抬高上限。
- [Riccati方程的比较原理](./Riccati方程的比较原理.md)：对形如 $u'+u^2+k=0$ 的方程，初值大的一直大；若只满足不等式，也会被精确解压住，于是曲率的上下界就能变成几何量的上下界。
- [Weitzenböck公式](./Weitzenböck公式.md)：同一个"拉普拉斯型"算子用不同方式写出来会相差一个纯曲率项；几何上的弯曲就藏在这两种写法的差额里。
- [第二 Bianchi 恒等式](./第二Bianchi恒等式.md)：把黎曼曲率张量再求一次协变导数，然后对三个指标做轮换求和，结果恒为零——曲率沿流形"怎么变"被一条恒等式锁死，它的缩并还直接给出 Einstein 张量的散度为零。
- [第二变分公式](./第二变分公式.md)：测地线的能量（或长度）在它附近的二阶变化是一个只含"变化率平方"与"曲率"的二次型——第一项想让它变长，第二项由曲率决定，正曲率让它变得不稳定。
- [Jacobi方程](./Jacobi方程.md)：把一条测地线整体"轻轻推一下"，相邻测地线之间的偏离向量满足一个线性二阶方程——Jacobi 方程；它把"两条近路会散开还是聚拢"完完全全交给曲率来回答。

## 前置知识

本级别依赖前序级别的如下知识：微分几何（流形、切丛、联络）、张量分析、代数拓扑（上同调）以及常微分方程基础。

## 后继用途

黎曼几何为复几何、几何分析、广义相对论（时空几何）与辛几何提供几何框架，是比较几何、曲率流与谱几何等方向的直接基础。

## 关键定理速览

- Bonnet-Myers定理：正截面曲率导致有限直径。
- Cartan-Hadamard定理：非正曲率单连通流形的几何刚性。
- Hodge分解定理：调和形式与上同调的刻画。
- Nash嵌入定理：抽象黎曼流形的欧氏实现。
- Ricci流与Poincare猜想：几何流综合三维拓扑。
