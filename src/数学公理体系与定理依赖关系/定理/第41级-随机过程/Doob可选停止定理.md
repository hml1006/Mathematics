# Doob 可选停止定理

> **一句话大白话**：对公平赌博（鞅），若你在"不看未来"的合理时刻（停止时间）收手，期望依然是本金——只要别太贪心（路径被约束等条件），"停下来时的期望 = 起点值"，正说明公平。
>
> **小例子**：对称随机游走是鞅，但对 hitting time $\tau=\inf\{n:S_n=K\}$ 可停且 $\mathbb{E}S_\tau=K\ne S_0=0$——正因 $\tau$ 无界才破坏公平，给 $\tau\le N$ 约束后 $\mathbb{E}S_{\tau\wedge N}=0$ 依旧成立。

## 介绍

Doob 可选停止定理（Doob's optional stopping theorem）是鞅理论中最重要的定理之一，由 Joseph Doob 建立。它断言，在适当的条件下，对鞅在停时处停止，其期望值保持不变。该定理是鞅方法的核心工具，广泛应用于随机分析、金融数学（期权定价）、统计序贯分析和随机游走理论中。

## 分析

**前置依赖**：鞅的定义、条件期望、停时、鞅收敛定理。

**定理内容**：设 $\{M_n\}_{n\ge0}$ 是鞅（或下鞅/上鞅），$\tau$ 是关于同一滤网的停时。则在一定条件下，$E[M_\tau] = E[M_0]$（对鞅），$E[M_\tau] \ge E[M_0]$（对下鞅），$E[M_\tau] \le E[M_0]$（对上鞅）。

**常见的充分条件**：
1. **有界停时**：$\tau$ 几乎必然有界（即存在常数 $K$ 使得 $\tau \le K$ a.s.）。
2. **可积停时 + 有界增量**：$\tau$ 可积（$E[\tau] < \infty$）且增量有界（$|M_{n+1} - M_n| \le C$ a.s.）。
3. **一致可积鞅**：$\{M_{\tau \wedge n}\}$ 一致可积。

**数学内涵**：可选停止定理保证了"公平博弈"在任意合法的停止策略下仍然是公平的——无论你选择何时停止，期望收益为零。这是"不能通过停时策略在公平博弈中获利"的严格数学表述。

**证明策略**：对停时 $\tau$ 进行截断，考虑 $\tau \wedge n$，然后利用鞅的性质和停时的定义，通过控制收敛定理取极限。

## 思考过程

Doob 可选停止定理的直观理解：如果 $\{M_n\}$ 是鞅，那么在任意时刻 $n$，$E[M_n] = E[M_0]$。如果 $\tau$ 是停时（即基于当前信息决定何时停止），我们想知道是否 $E[M_\tau] = E[M_0]$。

这并不总是成立——反例是赌徒破产问题中，如果赌徒一直玩到破产，则 $M_\tau$ 是破产时的财富（0），而 $M_0$ 是初始财富，两者期望不相等。因此需要额外的条件来保证定理成立。

证明的关键是对 $\tau$ 进行截断：$\tau \wedge n$ 是有界停时，由正态和性质 $E[M_{\tau \wedge n}] = E[M_0]$。然后令 $n \to \infty$，在适当的条件下 $\tau \wedge n \to \tau$，由控制收敛定理得 $E[M_\tau] = E[M_0]$。

## 证明过程

**定理**（Doob 可选停止定理）：设 $\{M_n\}$ 是鞅，$\tau$ 是停时。若满足以下条件之一：
1. $\tau$ 有界（$\tau \le K$ a.s.），或
2. $\tau$ a.s. 有限且 $\{M_n\}$ 一致可积，或
3. $\tau$ 可积且 $|M_{n+1} - M_n| \le C$ a.s.，
则 $E[M_\tau] = E[M_0]$。

**证明**：

**步骤 1**：有界停时情形。设 $\tau \le K$ a.s.，则
$$M_\tau = \sum_{k=0}^K M_k 1_{\{\tau = k\}}$$
由鞅性质，$E[M_k \mid \mathcal{F}_j] = M_j$ 对 $j \le k$。对 $k < K$，
$$E[M_K 1_{\{\tau = k\}}] = E[E[M_K \mid \mathcal{F}_k] 1_{\{\tau = k\}}] = E[M_k 1_{\{\tau = k\}}]$$
故
$$E[M_\tau] = \sum_{k=0}^K E[M_k 1_{\{\tau = k\}}] = \sum_{k=0}^K E[M_K 1_{\{\tau = k\}}] = E[M_K] = E[M_0]$$

**步骤 2**：一般情形。考虑 $\tau \wedge n$，它是有界停时，故 $E[M_{\tau \wedge n}] = E[M_0]$。由假设条件，$\{M_{\tau \wedge n}\}$ 一致可积或满足控制收敛条件，故
$$E[M_\tau] = \lim_{n\to\infty} E[M_{\tau \wedge n}] = E[M_0]$$

**步骤 3**：可积停时 + 有界增量情形。由 $|M_{n+1} - M_n| \le C$，
$$|M_{\tau \wedge n}| \le |M_0| + C\tau$$
由 $E[\tau] < \infty$，$|M_0| + C\tau$ 可积，由控制收敛定理得 $E[M_\tau] = \lim E[M_{\tau \wedge n}] = E[M_0]$。$\square$

**推论**（赌徒破产问题）：考虑简单随机游走 $S_n = \sum_{i=1}^n X_i$，其中 $P(X_i = 1) = p$，$P(X_i = -1) = 1-p$。
- 若 $p = 1/2$，则 $S_n$ 是鞅。令 $\tau = \inf\{n \mid S_n = a \text{ 或 } S_n = -b\}$（$a,b > 0$），则 $P(S_\tau = a) = b/(a+b)$，$P(S_\tau = -b) = a/(a+b)$，且 $E[S_\tau] = 0 = S_0$。
- 若 $p \neq 1/2$，则 $(q/p)^{S_n}$ 是鞅，可用于计算破产概率。
