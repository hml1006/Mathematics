# 条件期望的存在唯一性

## 介绍

条件期望的存在唯一性定理是概率论中条件期望理论的基石，它断言给定 $\sigma$-代数 $\mathcal{G}$ 后，对一个可积随机变量 $X$，存在唯一的 $\mathcal{G}$-可测随机变量 $E[X|\mathcal{G}]$，使得对任意 $A \in \mathcal{G}$ 有 $\int_A E[X|\mathcal{G}] dP = \int_A X dP$。该定理的证明依赖于拉东-尼科迪姆定理（Radon-Nikodym Theorem），是测度论在概率论中的核心应用之一。条件期望的存在性为鞅理论、随机过程、贝叶斯统计等提供了坚实的数学基础。

## 分析

**前置依赖**：拉东-尼科迪姆定理、测度论、$\sigma$-代数、可测函数、积分。

**数学内涵**：
- 设 $(\Omega, \mathcal{F}, P)$ 是概率空间，$\mathcal{G} \subseteq \mathcal{F}$ 是子 $\sigma$-代数，$X$ 是可积随机变量。
- 条件期望 $E[X|\mathcal{G}]$ 是满足以下条件的 $\mathcal{G}$-可测随机变量：
  1. $E[X|\mathcal{G}]$ 是 $\mathcal{G}$-可测的。
  2. 对任意 $A \in \mathcal{G}$，$\int_A E[X|\mathcal{G}] dP = \int_A X dP$。
- 存在性：定义测度 $Q(A) = \int_A X dP$，$Q$ 关于 $P|_\mathcal{G}$ 绝对连续，由拉东-尼科迪姆定理，存在密度 $dQ/dP|_\mathcal{G} = E[X|\mathcal{G}]$。
- 唯一性：若两个 $\mathcal{G}$-可测函数满足相同的积分条件，则它们几乎必然相等。

**结构**：
1. 定义有限符号测度 $Q$。
2. 证明 $Q$ 关于 $P|_\mathcal{G}$ 绝对连续。
3. 应用拉东-尼科迪姆定理得到密度函数。
4. 验证密度函数即为条件期望。
5. 证明唯一性。

## 思考过程

条件期望的存在唯一性证明充分利用了拉东-尼科迪姆定理。核心想法是：$X$ 在 $\mathcal{G}$ 上的"平均行为"可以看作是一个新的测度 $Q$ 相对于原测度 $P$ 的导数。

具体来说，对任意 $A \in \mathcal{G}$，定义 $Q(A) = \int_A X dP$。$Q$ 是 $(\Omega, \mathcal{G})$ 上的有限符号测度（如果 $X \geq 0$，$Q$ 是测度）。如果 $P(A) = 0$，则 $Q(A) = 0$，因此 $Q \ll P|_\mathcal{G}$。由拉东-尼科迪姆定理，存在 $\mathcal{G}$-可测函数 $f$ 使得 $Q(A) = \int_A f dP$ 对所有 $A \in \mathcal{G}$ 成立，这个 $f$ 就是 $E[X|\mathcal{G}]$。

## 证明过程

**定理**（条件期望的存在唯一性）：设 $(\Omega, \mathcal{F}, P)$ 是概率空间，$\mathcal{G} \subseteq \mathcal{F}$ 是子 $\sigma$-代数，$X$ 是可积随机变量（$E[|X|] < \infty$）。则存在唯一的（在几乎必然意义下）$\mathcal{G}$-可测随机变量 $Y$，使得对任意 $A \in \mathcal{G}$，
$$\int_A Y dP = \int_A X dP$$
这个 $Y$ 称为 $X$ 关于 $\mathcal{G}$ 的条件期望，记为 $E[X|\mathcal{G}]$。

**证明**：

### 1. $X \geq 0$ 的情形

假设 $X \geq 0$。定义 $Q: \mathcal{G} \to [0, \infty]$ 为
$$Q(A) = \int_A X dP,\quad \forall A \in \mathcal{G}$$

由积分的性质，$Q$ 是 $(\Omega, \mathcal{G})$ 上的测度。若 $P(A) = 0$，则 $Q(A) = 0$，故 $Q \ll P|_\mathcal{G}$。

由拉东-尼科迪姆定理，存在 $\mathcal{G}$-可测函数 $Y \geq 0$，使得对任意 $A \in \mathcal{G}$，
$$Q(A) = \int_A Y dP$$

即 $\int_A Y dP = \int_A X dP$。$Y$ 即为 $E[X|\mathcal{G}]$。

### 2. 一般情形

将 $X$ 分解为正部和负部：$X = X^+ - X^-$，其中 $X^+ = \max\{X, 0\}$，$X^- = \max\{-X, 0\}$。

由情形 1，存在 $Y^+ = E[X^+|\mathcal{G}]$ 和 $Y^- = E[X^-|\mathcal{G}]$。令 $Y = Y^+ - Y^-$，则 $Y$ 是 $\mathcal{G}$-可测的，且对任意 $A \in \mathcal{G}$，
$$\int_A Y dP = \int_A Y^+ dP - \int_A Y^- dP = \int_A X^+ dP - \int_A X^- dP = \int_A X dP$$

### 3. 唯一性

设 $Y_1, Y_2$ 都是满足条件的 $\mathcal{G}$-可测随机变量。则对任意 $A \in \mathcal{G}$，
$$\int_A (Y_1 - Y_2) dP = 0$$

取 $A = \{Y_1 - Y_2 > 0\} \in \mathcal{G}$，得 $\int_A (Y_1 - Y_2) dP = 0$，故 $P(A) = 0$。同理 $P(Y_1 - Y_2 < 0) = 0$。因此 $Y_1 = Y_2$ 几乎必然成立。$\square$

**注记**：条件期望 $E[X|\mathcal{G}]$ 是在 $\mathcal{G}$-可测函数空间中，在 $L^2$ 意义下对 $X$ 的最佳逼近（正交投影）。
