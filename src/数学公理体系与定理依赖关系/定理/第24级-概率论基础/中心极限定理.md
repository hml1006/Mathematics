# 中心极限定理

> **一句话大白话**：很多独立的小随机量加在一起（不管单个长啥样），加得足够多后，总和几乎总服从那个经典的"钟形"正态分布——大量杂乱的独立影响汇起来，自动变得规整漂亮。
>
> **小例子**：掷很多次骰子记点数之和，单次分布是均匀的，但掷上千次后，点数和近似服从钟形正态；身高由许多基因、环境小因素叠加，所以身高分布接近正态。

## 介绍

中心极限定理（Central Limit Theorem, CLT）是概率论中最著名的定理之一，它断言独立同分布随机变量和的标准化分布依分布收敛到标准正态分布。该定理由法国数学家皮埃尔-西蒙·拉普拉斯（Pierre-Simon Laplace）在 18 世纪早期形式提出，后经林德伯格（Lindeberg）、莱维（Lévy）和费勒（Feller）等人推广到更一般的条件。中心极限定理解释了正态分布在自然界和社会科学中无处不在的原因——大量独立微小随机因素的叠加效应趋于正态分布。它是统计推断中置信区间和假设检验的理论基础。

## 分析

**前置依赖**：特征函数、连续性定理（Lévy 连续性定理）、依分布收敛、正态分布。

**数学内涵**：
- 设 $X_1, X_2, \ldots$ 是独立同分布随机变量，$E[X_i] = \mu$，$\text{Var}(X_i) = \sigma^2 < \infty$。
- 令 $S_n = \sum_{i=1}^n X_i$，标准化后 $Z_n = \frac{S_n - n\mu}{\sigma\sqrt{n}}$。
- 中心极限定理：$Z_n \xrightarrow{d} N(0, 1)$，即 $\lim_{n \to \infty} P(Z_n \leq x) = \Phi(x)$，其中 $\Phi$ 是标准正态分布函数。
- 证明方法：利用特征函数，将 $Z_n$ 的特征函数展开后取极限得到 $e^{-t^2/2}$。

**结构**：
1. 计算 $Z_n$ 的特征函数。
2. 利用泰勒展开近似特征函数。
3. 取极限得到标准正态分布的特征函数。
4. 由连续性定理得到依分布收敛。

## 思考过程

中心极限定理的证明利用特征函数作为工具，非常简洁优雅。特征函数 $\varphi(t) = E[e^{itX}]$ 唯一决定了分布，且独立和的标准化特征函数可以表示为单个特征函数的幂。

对于 $Z_n = \frac{S_n - n\mu}{\sigma\sqrt{n}}$，其特征函数为 $\varphi_{Z_n}(t) = [\varphi((t)/(\sigma\sqrt{n}))]^n$，其中 $\varphi(t) = E[e^{it(X_1-\mu)}]$。将 $\varphi(s)$ 在 $s=0$ 处泰勒展开：$\varphi(s) = 1 - \frac{\sigma^2 s^2}{2} + o(s^2)$。代入 $s = t/(\sigma\sqrt{n})$ 得 $\varphi_{Z_n}(t) = (1 - \frac{t^2}{2n} + o(1/n))^n \to e^{-t^2/2}$，这是标准正态分布的特征函数。

## 证明过程

**定理**（中心极限定理）：设 $X_1, X_2, \ldots$ 是独立同分布随机变量，$E[X_i] = \mu$，$\text{Var}(X_i) = \sigma^2 \in (0, \infty)$。则
$$\frac{S_n - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0, 1)$$
其中 $S_n = \sum_{i=1}^n X_i$。

**证明**：

### 1. 标准化

令 $Y_i = \frac{X_i - \mu}{\sigma}$，则 $E[Y_i] = 0$，$\text{Var}(Y_i) = 1$。标准化和为
$$Z_n = \frac{S_n - n\mu}{\sigma\sqrt{n}} = \frac{1}{\sqrt{n}}\sum_{i=1}^n Y_i$$

### 2. 特征函数

设 $\varphi(t) = E[e^{itY_1}]$ 是 $Y_1$ 的特征函数。由独立性，$Z_n$ 的特征函数为
$$\varphi_{Z_n}(t) = E\left[\exp\left(it \cdot \frac{1}{\sqrt{n}}\sum_{i=1}^n Y_i\right)\right] = \prod_{i=1}^n E\left[\exp\left(i\frac{t}{\sqrt{n}}Y_i\right)\right] = \left[\varphi\left(\frac{t}{\sqrt{n}}\right)\right]^n$$

### 3. 泰勒展开

由于 $E[Y_1] = 0$，$E[Y_1^2] = 1$，$\varphi$ 在 $0$ 附近有二阶泰勒展开：
$$\varphi(s) = 1 + iE[Y_1]s - \frac{E[Y_1^2]}{2}s^2 + o(s^2) = 1 - \frac{s^2}{2} + o(s^2)$$

代入 $s = t/\sqrt{n}$：
$$\varphi\left(\frac{t}{\sqrt{n}}\right) = 1 - \frac{t^2}{2n} + o\left(\frac{1}{n}\right)$$

### 4. 取极限

$$\varphi_{Z_n}(t) = \left[1 - \frac{t^2}{2n} + o\left(\frac{1}{n}\right)\right]^n$$

利用 $\lim_{n \to \infty} (1 + a_n/n)^n = e^{\lim a_n}$（当 $a_n \to a$ 时），得
$$\lim_{n \to \infty} \varphi_{Z_n}(t) = e^{-t^2/2}$$

### 5. 应用连续性定理

$e^{-t^2/2}$ 是标准正态分布 $N(0, 1)$ 的特征函数。由 Lévy 连续性定理，$Z_n$ 依分布收敛到 $N(0, 1)$。$\square$
