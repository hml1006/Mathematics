# 第二类曲线积分公式

## 介绍

第二类曲线积分（Vector Line Integral）是对坐标的曲线积分，用于计算向量场沿曲线的累积效应。该公式将向量场沿曲线的积分转化为参数区间上的定积分。第二类曲线积分在物理中用于计算变力做功、环流量和通量，是格林定理、斯托克斯定理和高斯散度定理的基础。

## 分析

**前置依赖**：第一类曲线积分

**定理内容**：设 $L$ 是平面上由参数方程 $x = x(t)$，$y = y(t)$（$t \in [a,b]$）表示的光滑有向曲线，$P(x,y)$ 和 $Q(x,y)$ 在 $L$ 上连续，则
$$\int_L P\,dx + Q\,dy = \int_a^b \left[P(x(t), y(t))x'(t) + Q(x(t), y(t))y'(t)\right] dt$$

**数学内涵**：
第二类曲线积分与曲线的方向有关，改变方向会改变积分的符号。其物理意义是向量场 $\mathbf{F} = (P, Q)$ 沿曲线 $L$ 所做的功：$W = \int_L \mathbf{F} \cdot d\mathbf{r}$，其中 $d\mathbf{r} = (dx, dy)$。该积分可以通过投影到第一类曲线积分来理解：$\int_L \mathbf{F} \cdot \mathbf{T}\,ds$，其中 $\mathbf{T}$ 是曲线的单位切向量。

**证明策略**：将 $dx = x'(t)dt$ 和 $dy = y'(t)dt$ 代入积分表达式，转化为关于参数 $t$ 的定积分。

## 思考过程

第二类曲线积分 $\int_L P\,dx + Q\,dy$ 中的 $dx$ 和 $dy$ 表示曲线上的微小位移分量。在参数化下，$dx = x'(t)dt$，$dy = y'(t)dt$，代入即得关于 $t$ 的定积分。该公式也可从第一类曲线积分推导：$dx = \frac{dx}{ds}ds = \frac{x'(t)}{\sqrt{(x')^2+(y')^2}}ds$，但直接代入法更简洁。

## 证明过程

**定理**：设光滑有向曲线 $L$ 由参数方程 $x = x(t)$，$y = y(t)$（$t \in [a,b]$）给出，其中 $x'(t)$ 和 $y'(t)$ 在 $[a,b]$ 上连续且不同时为 $0$。函数 $P(x,y)$ 和 $Q(x,y)$ 在 $L$ 上连续，则
$$\int_L P\,dx + Q\,dy = \int_a^b \left[P(x(t), y(t))x'(t) + Q(x(t), y(t))y'(t)\right] dt$$

**证明**：

对参数区间 $[a,b]$ 作分割 $P: a = t_0 < t_1 < \cdots < t_n = b$，记 $\Delta t_i = t_i - t_{i-1}$，曲线上的对应分点为 $P_i = (x(t_i), y(t_i))$。

在子区间 $[t_{i-1}, t_i]$ 上任取 $\tau_i$，做 Riemann 和
$$\sum_{i=1}^n \left[P(x(\tau_i), y(\tau_i)) \Delta x_i + Q(x(\tau_i), y(\tau_i)) \Delta y_i\right]$$

其中 $\Delta x_i = x(t_i) - x(t_{i-1})$，$\Delta y_i = y(t_i) - y(t_{i-1})$。

由拉格朗日中值定理，存在 $\xi_i, \eta_i \in (t_{i-1}, t_i)$ 使得
$$\Delta x_i = x'(\xi_i)\Delta t_i, \quad \Delta y_i = y'(\eta_i)\Delta t_i$$

代入 Riemann 和得
$$\sum_{i=1}^n \left[P(x(\tau_i), y(\tau_i)) x'(\xi_i) + Q(x(\tau_i), y(\tau_i)) y'(\eta_i)\right] \Delta t_i$$

当分割的最大步长 $\|\Delta\| \to 0$ 时，由于 $P, Q, x', y'$ 连续，上述和式收敛于
$$\int_a^b \left[P(x(t), y(t))x'(t) + Q(x(t), y(t))y'(t)\right] dt$$

因此
$$\int_L P\,dx + Q\,dy = \int_a^b \left[P(x(t), y(t))x'(t) + Q(x(t), y(t))y'(t)\right] dt$$

$\square$
