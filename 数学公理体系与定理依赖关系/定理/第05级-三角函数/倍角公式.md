# 倍角公式

## 介绍

倍角公式是和角公式的直接推论，给出了二倍角的正弦、余弦与单角三角函数之间的关系：$\sin 2\theta = 2\sin\theta\cos\theta$，$\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$。这些公式在三角恒等变换、积分计算、倍角问题求解中有着广泛应用。

## 分析

**前置依赖**：和角公式。

**定理内容**：对任意 $\theta$，
- $\sin 2\theta = 2\sin\theta\cos\theta$
- $\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$

**数学内涵**：
- 倍角公式是和角公式中 $\alpha = \beta = \theta$ 的特例。
- $\cos 2\theta$ 的三种等价形式在积分化简中特别有用。
- 倍角公式是"三角恒等式"推导的核心工具。

**证明策略**：在和角公式中令 $\alpha = \beta = \theta$。

## 思考过程

倍角公式是和角公式最直接、最自然的推论。当我们在和角公式 $\sin(\alpha+\beta)$ 和 $\cos(\alpha+\beta)$ 中令 $\alpha = \beta = \theta$ 时，倍角公式便自然浮现。这一推导过程极其简洁，却能揭示出三角函数中"倍角"这一重要概念的核心意义。

在记忆上，$\sin 2\theta = 2\sin\theta\cos\theta$ 和 $\cos 2\theta = \cos^2\theta - \sin^2\theta$ 是基本形式，而 $\cos 2\theta$ 的三种等价形式——$\cos^2\theta - \sin^2\theta$、$2\cos^2\theta - 1$、$1 - 2\sin^2\theta$——各有其适用场景。第一种形式揭示了 $\cos 2\theta$ 与 $\cos^2\theta$、$\sin^2\theta$ 的直接关系；第二种形式在化简含有 $\cos^2\theta$ 的表达式时尤为便利；第三种形式则常用于将 $\sin^2\theta$ 转化为 $\cos 2\theta$ 的表达。

在实际应用中，$\cos 2\theta$ 的三种形式是积分计算中降幂技术的核心：通过 $\cos^2\theta = \frac{1+\cos 2\theta}{2}$ 和 $\sin^2\theta = \frac{1-\cos 2\theta}{2}$，可以将高次三角函数转化为一次函数，极大简化积分运算。此外，倍角公式还引出了半角公式、三倍角公式等一系列重要恒等式，是三角恒等变换的枢纽。

## 证明过程

**定理**（倍角公式）：
- $\sin 2\theta = 2\sin\theta\cos\theta$
- $\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$

**证明**：

在和角公式中令 $\alpha = \beta = \theta$：

$$
\sin 2\theta = \sin(\theta + \theta) = \sin\theta\cos\theta + \cos\theta\sin\theta = 2\sin\theta\cos\theta
$$

$$
\cos 2\theta = \cos(\theta + \theta) = \cos\theta\cos\theta - \sin\theta\sin\theta = \cos^2\theta - \sin^2\theta
$$

利用 $\sin^2\theta + \cos^2\theta = 1$，可得另外两种形式：

$$
\cos 2\theta = \cos^2\theta - (1 - \cos^2\theta) = 2\cos^2\theta - 1
$$

$$
\cos 2\theta = (1 - \sin^2\theta) - \sin^2\theta = 1 - 2\sin^2\theta
$$

$\square$

---

**正切的倍角公式**：$\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta}$。
