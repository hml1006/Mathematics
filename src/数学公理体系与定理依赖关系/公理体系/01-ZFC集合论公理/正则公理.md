# 正则公理（Axiom of Regularity）

## 介绍

正则公理（又称基础公理，Axiom of Foundation）指出：每个非空集合都存在 ∈-极小元。具体来说，对任意非空集合 A，存在 x ∈ A，使得 x 与 A 不相交（即 x ∩ A = ∅）。正则公理禁止了非良基集合（如满足 x ∈ x 的集合）的存在，确保了 ∈ 关系构成一个良基关系。

正则公理是 ZFC 中最具"技术性"的公理之一。它不像其他公理那样直接参与集合的构造，而是为集合论宇宙施加了一个"良基性"条件，使得 ∈ 关系具有层次结构，便于进行超限归纳法。

## 分析

**形式化表述：**
$$ \forall A (A \neq \emptyset \rightarrow \exists x \in A (x \cap A = \emptyset)) $$

**数学内涵：**
- 正则公理禁止了"非良基"集合的存在
- 任何集合都不能以自身为元素（x ∉ x）
- 不存在无穷递减链 ... ∈ x₃ ∈ x₂ ∈ x₁

**结构特点：**
- 正则公理使得每个集合都有一个"秩"（rank），即它出现在 von Neumann 层次 V_α 中的最小 α
- 集合论宇宙 V 可以表示为 V = ∪_{α∈Ord} V_α，其中 V_0 = ∅，V_{α+1} = 𝒫(V_α)，V_λ = ∪_{β<λ} V_β
- 正则公理保证了每个集合都在某个 V_α 中

**应用：**
- 证明超限归纳法的合法性
- 证明 ∈ 关系是良基的
- 定义集合的秩函数
- 在大多数数学实践中，正则公理不直接参与，但为集合论提供了良基基础

## 思考过程

正则公理是 ZFC 中争议性较大的公理之一。与其他公理不同，它不是在"构造"集合，而是在"限制"什么可以被视为集合。

为什么需要禁止非良基集合？考虑以下情况：
- 如果存在集合 x 满足 x ∈ x，这并不直接导致悖论，但让人感到不安
- 如果存在无穷递减链 ... x₃ ∈ x₂ ∈ x₁，这违反了"集合是有层次的"这一直观

von Neumann 在 1925 年提出了正则公理，其动机是确保集合论宇宙具有清晰的层次结构。在 von Neumann 的视角中，集合应该是在"某个阶段"构造出来的对象，而正则公理保证了这一点。

有趣的是，正则公理在大多数数学中并不直接使用。代数、分析、拓扑等领域很少需要引用正则公理。但它在集合论本身中很重要——它简化了序数和基数的理论，并且为超限归纳提供了清晰的框架。

有非良基集合论（如 Aczel 的反基础公理），它允许某些非良基集合的存在，用于研究共代数、并发系统等。

## 证明过程

正则公理是一条公理，不需要证明。以下讨论其合理性和必要性。

**合理性：**
- 正则公理符合"集合是分层次构造的"这一直观
- 它确保了 ∈ 关系是良基的，从而支持超限归纳法
- 它不会导致矛盾（在 ZFC 框架内一致）

**必要性：**
- 正则公理在大多数数学中不是必需的
- 代数、分析、几何等领域的工作通常不需要引用正则公理
- 但正则公理简化了集合论的理论，特别是序数和基数的理论
- 它使每个集合都有一个秩，便于进行递归定义

**独立性：**
- 正则公理独立于 ZFC 的其他公理
- 可以构造一个模型（如带一个非良基元素的模型），其中其他 ZFC 公理成立但正则公理不成立
- 非良基集合论（如使用 Aczel 反基础公理）是正则公理的替代方案
