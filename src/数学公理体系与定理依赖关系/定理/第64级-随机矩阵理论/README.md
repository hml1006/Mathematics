# 第64级-随机矩阵理论

本目录收录以下定理：

- [Dyson 布朗运动](./Dyson布朗运动.md)
- [Marchenko-Pastur 定律](./Marchenko-Pastur定律.md)
- [Tracy-Widom 分布](./Tracy-Widom分布.md)
- [Wigner 半圆律](./Wigner半圆律.md)
- [普适性猜想](./普适性猜想.md)
- [自由概率论基础](./自由概率论基础.md)
- [Riemann $\zeta$ 函数零点与随机矩阵的联系](./随机矩阵与数论.md)
- [Stieltjes变换的反演公式](./Stieltjes变换的反演公式.md)：想知道未知的谱分布长什么样，就在复平面上"取样"它的 Stieltjes 变换，再从上方向实轴贴近取虚部——虚部在实轴上的极限直接还原出原来的密度。
- [四矩匹配定理](./四矩匹配定理.md)：两个随机矩阵只要前四阶矩"对上号"、尾巴又不太肥，那么它们特征值的局部（精细尺度）统计几乎一模一样——更高阶矩的差别在微观尺度上会被自动抹平。
- [Lindeberg 替换法](./Lindeberg替换法.md)：要证明随机变量之和趋于正态，可以一次只把一个变量换成同方差的高斯变量，逐项估计误差；误差由三阶矩控制，全部替换完毕后和就变成了正态。
- [Riemann-von Mangoldt 显式公式](./Riemann-vonMangoldt显式公式.md)：素数的分布不是随机的秘密，而是被 Riemann ζ 函数的零点精准地"调音"出来；显式公式就是那台把零点翻译成素数计数的仪器。
- [Hanson–Wright 不等式](./Hanson-Wright不等式.md)：用亚高斯随机向量做二次型 $X^\top AX$，它偏离均值这么多所需的概率按指数分裂成两支——小偏差时像高斯的 $e^{-t^2}$，大偏差时像次指数的 $e^{-t}$，谁小听谁的。
- [Sherman-Morrison 矩阵逆引理](./Sherman-Morrison矩阵逆引理.md)：给一个可逆矩阵做一次"秩一"修补（加上外积 $uv^\top$）后，它的逆不需要从头再算，只要在原逆的基础上做一处简单的修正即可。
- [Painlevé II 方程](./PainlevéII方程.md)：有一个特殊的二阶非线性微分方程，它看起来温和，却把一个"只解一次、处处通用"的函数钉死；Tracy-Widom 分布的全部数值信息就藏在它的解里。
- [弱收敛与大数定律](./弱收敛与大数定律.md)：把抽到的样本摊成一张"经验分布表"，样本一多，这张表就整体地贴向真实分布——弱收敛说的正是这种"整体贴合"，而大数定律保证它一定贴得上。
- [自洽方程](./自洽方程.md)：随机矩阵的极限谱分布没法直接算，但它的 Stieltjes 变换 $m(z)$ 一定满足一个"自己等于自己"的方程 $m=-1/(z+m)$——未知的 $m$ 在两边各出现一次，解这个方程就得到了谱分布的全部信息。
- [行列式点过程与 Fredholm 行列式](./行列式点过程与Fredholm行列式.md)：有一类随机点过程，它的"两点、三点、任意多点同时出现的概率"都能写成一串整齐的行列式；于是"某个区域里一个点都没有"的概率就等于一个无穷维行列式 $\det(I-K)$，可积性由此而来。
