# 第75级-解析数论

本目录收录以下定理：

- [Euler 乘积公式](./Euler乘积公式.md)
- [Riemann Zeta 函数的函数方程](./RiemannZeta函数的函数方程.md)
- [素数定理](./素数定理.md)
- [Dirichlet 算术级数定理](./Dirichlet算术级数定理.md)
- [Selberg 筛法](./Selberg筛法.md)
- [Tauber 定理](./Tauber定理.md)：Tauber 定理是"Abel 极限的反向题"——通常由"部分和的极限"能推出"加权平均的极限"；Tauber 定理说，只要加上一条系数"不太大"的条件，反过来也成立：加权平均的极限能倒推出部分和的极限。
- [Mellin 变换](./Mellin变换.md)：Mellin 变换是把函数 $f(x)$ 按"幂次 $x^{s-1}$ 加权积分"的变换，它把乘法尺度 $x\to\lambda x$ 变成加性平移，从而把"乘性卷积"变成"普通乘积"。
- [Ikehara-Wiener Tauber 定理](./Ikehara-WienerTauber定理.md)：如果一个非负系数的 Dirichlet 级数在 $s=1$ 处的主要奇性只是一个留数为 $A$ 的单极点，其余部分在该直线上"规矩"（连续），那么系数的累加和就精确地按 $Ax$ 增长。
