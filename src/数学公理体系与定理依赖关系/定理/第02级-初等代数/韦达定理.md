# 韦达定理

> **一句话大白话**：方程的根不急着求——不用解方程，两根之和、两根之积直接由系数一眼看出来。
>
> **小例子**：对 $x^2-5x+6=0$，两根之和 $=5$、两根之积 $=6$，正是 $x=2,x=3$；对 $x^2+6x+8=0$，两根之和 $=-6$、积 $=8$，即 $x=-2,x=-4$。

## 介绍

韦达定理（Vieta's formulas）由法国数学家弗朗索瓦·韦达（François Viète）在 16 世纪提出，它建立了多项式方程的根与系数之间的深刻联系。对于一元二次方程 $ax^2 + bx + c = 0$，韦达定理指出：两根之和 $x_1 + x_2 = -b/a$，两根之积 $x_1 x_2 = c/a$。这一结论不仅适用于二次方程，还可以推广到任意次数的多项式方程。韦达定理是代数方程理论的基石，在因式分解、不等式证明、解析几何等领域有广泛应用。

## 分析

**前置依赖**：二次方程求根公式。

**定理内容**：
- 对于二次方程 $ax^2 + bx + c = 0$（$a \neq 0$），若 $x_1, x_2$ 是两根，则
  $$
  x_1 + x_2 = -\frac{b}{a},\quad x_1 x_2 = \frac{c}{a}
  $$
- 一般地，对于 $n$ 次方程 $a_n x^n + a_{n-1} x^{n-1} + \cdots + a_0 = 0$，若 $x_1, \ldots, x_n$ 是 $n$ 个根（计重数），则
  $$
  \sum_{i=1}^n x_i = -\frac{a_{n-1}}{a_n},\quad \sum_{i<j} x_i x_j = \frac{a_{n-2}}{a_n},\quad \ldots,\quad x_1 x_2 \cdots x_n = (-1)^n \frac{a_0}{a_n}
  $$

**数学内涵**：
- 韦达定理的实质是多项式乘法与因式分解的对应关系：将多项式写成根的形式 $(x-x_1)(x-x_2)\cdots(x-x_n)$ 展开后，比较对应系数即得。
- 它揭示了多项式系数的对称函数性质——系数是根的初等对称函数（不计符号）。
- 韦达定理是"对称多项式基本定理"在多项式方程中的特殊体现。

**结构**：
1. 将多项式写为根因式分解形式。
2. 展开后与标准形式比较系数。

## 思考过程

韦达定理的发现源自对多项式因式分解的观察。对于二次方程 $ax^2 + bx + c = 0$，如果 $x_1, x_2$ 是两根，那么多项式可以写成

$$
ax^2 + bx + c = a(x - x_1)(x - x_2)
$$

展开右边：

$$
a(x - x_1)(x - x_2) = a[x^2 - (x_1 + x_2)x + x_1 x_2]
$$

比较两边 $x$ 的系数和常数项，立即得到韦达定理。这个推导过程简单而优雅，不需要使用求根公式。

对于一般的 $n$ 次多项式，同样的思路成立：将多项式表示为 $a_n(x - x_1)(x - x_2)\cdots(x - x_n)$，展开后比较系数，就得到了 $n$ 次情形的韦达定理。

## 证明过程

**定理**（二次韦达定理）：设 $x_1, x_2$ 是二次方程 $ax^2 + bx + c = 0$（$a \neq 0$）的两个根，则

$$
x_1 + x_2 = -\frac{b}{a},\quad x_1 x_2 = \frac{c}{a}
$$

**证明**：

由于 $x_1, x_2$ 是 $ax^2 + bx + c = 0$ 的根，多项式 $ax^2 + bx + c$ 可分解为

$$
ax^2 + bx + c = a(x - x_1)(x - x_2)
$$

展开右边：

$$
a(x - x_1)(x - x_2) = a[x^2 - (x_1 + x_2)x + x_1 x_2]
$$

比较系数：

$$
\begin{aligned}
\text{二次项系数：}&\ a = a \\
\text{一次项系数：}&\ b = -a(x_1 + x_2) \\
\text{常数项：}&\ c = a x_1 x_2
\end{aligned}
$$

解得

$$
x_1 + x_2 = -\frac{b}{a},\quad x_1 x_2 = \frac{c}{a}
$$

$\square$

---

**一般情形的韦达定理**：设 $x_1, x_2, \ldots, x_n$ 是 $n$ 次方程 $a_n x^n + a_{n-1} x^{n-1} + \cdots + a_0 = 0$（$a_n \neq 0$）的 $n$ 个根（计重数），则

$$
\begin{aligned}
\sum_{i=1}^n x_i &= -\frac{a_{n-1}}{a_n} \\
\sum_{1 \leq i < j \leq n} x_i x_j &= \frac{a_{n-2}}{a_n} \\
&\ \vdots \\
x_1 x_2 \cdots x_n &= (-1)^n \frac{a_0}{a_n}
\end{aligned}
$$

**证明**：

由因式分解，

$$
a_n x^n + a_{n-1} x^{n-1} + \cdots + a_0 = a_n (x - x_1)(x - x_2)\cdots(x - x_n)
$$

展开右边，$(x - x_1)(x - x_2)\cdots(x - x_n)$ 的展开式为

$$
x^n - \left(\sum_{i=1}^n x_i\right)x^{n-1} + \left(\sum_{i<j} x_i x_j\right)x^{n-2} - \cdots + (-1)^n x_1 x_2 \cdots x_n
$$

比较两边系数即得上述公式。$\square$
