# 曼特尔定理

> **一句话大白话**：想在不出现三角形的前提下尽量多画边，最多只能到 $\lfloor n^2/4\rfloor$ 条，把点尽量"劈成两半"互取全连（完全二分图）就压到极值。
>
> **小例子**：$n=4$ 时 $\lfloor16/4\rfloor=4$，不含三角形的 4 点图最多 4 条边，极值图是 $K_{2,2}$（两个一组、组间全连、组内不连），加一条组内边就出现三角形。

## 介绍

曼特尔定理（Mantel's Theorem）是极值图论中的第一个重要结果，由荷兰数学家曼特尔于 1907 年证明。它回答了以下问题：不含三角形的 $n$ 个顶点的简单图最多能有多少条边？答案是 $\lfloor n^2/4 \rfloor$，且极值图是完全二分图 $K_{\lfloor n/2 \rfloor, \lceil n/2 \rceil}$。曼特尔定理是图兰定理的雏形，后者将问题推广到禁止 $K_{r+1}$ 子图的情形。

## 分析

**前置依赖**：图的基本定义、二分图、图兰定理。

**数学内涵**：
- 若 $G$ 是 $n$ 个顶点的简单图且不含三角形，则 $|E(G)| \leq \lfloor n^2/4 \rfloor$。
- 等号成立当且仅当 $G$ 同构于完全二分图 $K_{\lfloor n/2 \rfloor, \lceil n/2 \rceil}$。
- 曼特尔定理是图兰定理在 $r = 2$ 时的特例。

**结构**：
1. 利用顶点度数的极值论证。
2. 或利用归纳法证明。

## 思考过程

曼特尔定理的证明有多种方法。一种直观的证明是：如果 $G$ 不含三角形，则对任意相邻的顶点 $u, v$，它们的邻居集合不相交（否则形成三角形）。利用这一观察，可以推导出边数的上界。

另一种证明使用归纳法，通过删除一个顶点并分析其度数的最大值来得到边界。

## 证明过程

**定理**（曼特尔定理）：若 $G$ 是 $n$ 个顶点的简单图且不含三角形，则 $|E(G)| \leq \lfloor n^2/4 \rfloor$。等号成立当且仅当 $G$ 是完全二分图 $K_{\lfloor n/2 \rfloor, \lceil n/2 \rceil}$。

**证明一（度数法）**：

设 $G$ 不含三角形，$v$ 是 $G$ 中度数最大的顶点，$\deg(v) = d$。设 $N(v)$ 是 $v$ 的邻居集，$U = V \setminus (N(v) \cup \{v\})$。

由于 $G$ 不含三角形，$N(v)$ 中任意两点不相邻。因此 $G$ 的所有边中，一部分是 $v$ 与其邻居的边（共 $d$ 条），另一部分是 $U$ 与 $N(v)$ 或 $U$ 内部的边。

$U$ 中的顶点只能与 $N(v)$ 中的顶点相连（因为 $U$ 内部不能有边，否则若 $u_1, u_2 \in U$ 相邻，则 $u_1, u_2, v$ 形成三角形）。因此总边数满足
$$
|E(G)| \leq d + d \cdot |U| = d + d(n - 1 - d) = d(n - 1 - d) + d = d(n - d)
$$
函数 $f(d) = d(n - d)$ 在 $d = n/2$ 时取最大值 $n^2/4$。由于 $d$ 是整数，$|E(G)| \leq \lfloor n^2/4 \rfloor$。

当 $|E(G)| = \lfloor n^2/4 \rfloor$ 时，$d = \lfloor n/2 \rfloor$ 或 $\lceil n/2 \rceil$，且 $U$ 中所有顶点与 $N(v)$ 中所有顶点相连，$U$ 内部无边，$N(v)$ 内部无边，故 $G$ 是完全二分图 $K_{d, n-d}$。$\square$

**证明二（归纳法）**：

对 $n$ 进行归纳。$n = 1, 2$ 时结论成立。

假设 $n \geq 3$。设 $G$ 是 $n$ 个顶点的无三角形图，$uv$ 是 $G$ 的一条边。删除 $u, v$ 及其关联边，得 $G'$。由于 $G$ 无三角形，$u$ 和 $v$ 没有公共邻居，故 $G$ 中与 $u$ 或 $v$ 关联的边数不超过 $n - 2 + 1 = n - 1$（实际上，$u$ 的邻居、$v$ 的邻居和 $u, v$ 本身互不相交，最大边数为 $\deg(u) + \deg(v) - 1 \leq (n-2) + (n-2) - 1$，但更精确的估计为 $\deg(u) + \deg(v) - 1 \leq n - 1$）。

由归纳假设，$|E(G')| \leq \lfloor (n-2)^2/4 \rfloor$。因此
$$
|E(G)| \leq \lfloor (n-2)^2/4 \rfloor + (n-1) = \lfloor n^2/4 \rfloor
$$
$\square$
