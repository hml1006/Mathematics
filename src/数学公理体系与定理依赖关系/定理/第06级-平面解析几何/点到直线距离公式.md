# 点到直线距离公式

> **一句话大白话**：算一点到一条直线的“最短垂直距离”，把点代进直线方程取绝对值，再除以法向量长度，就是答案。
>
> **小例子**：点 $(3,1)$ 到直线 $3x+4y-5=0$：$d=\frac{|3\cdot3+4\cdot1-5|}{\sqrt{3^2+4^2}}=\frac{|9+4-5|}{5}=\frac85$。

## 介绍

点到直线距离公式是解析几何中的基本公式：点 $P(x_0, y_0)$ 到直线 $Ax + By + C = 0$ 的距离为 $d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$。该公式是解析几何中度量关系的核心工具，在几何、物理、工程等领域有广泛应用。

## 分析

**前置依赖**：两点间距离公式、向量投影。

**定理内容**：点 $P(x_0, y_0)$ 到直线 $Ax + By + C = 0$ 的距离为 $d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$。

**证明策略**：利用向量投影或垂足坐标法。

## 思考过程

点到直线距离公式有多种推导思路，每种方法都揭示了该公式的不同几何侧面：

**向量投影法（最简洁）**：直线 $Ax + By + C = 0$ 的法向量为 $\mathbf{n} = (A, B)$，点到直线的距离就是该点到直线上任意一点的向量在法向量方向上的投影长度。这一方法直观体现了"距离是最短路径"的本质——在法向量方向上的投影正是点到直线的垂线段长度。

**面积法（另一种经典思路）**：在直线上取两点与已知点构成三角形，利用三角形面积等于底乘高的一半，同时用坐标表示三角形面积（利用行列式），两者联立即可解出高（即距离）。这种方法避免了法向量的概念，适合尚未学习向量的读者。

**垂足坐标法（最直接但计算量最大）**：设垂足为 $Q(x_1, y_1)$，则 $Q$ 满足直线方程且 $PQ$ 与直线方向向量垂直，联立求解 $Q$ 的坐标，再用两点间距离公式计算 $|PQ|$。这种方法思路直接但运算繁琐。

从几何意义上看，该公式的分子 $|Ax_0 + By_0 + C|$ 衡量的是点 $P$ 相对于直线的"偏离程度"——当 $P$ 在直线上时，该值为零；$P$ 离直线越远，绝对值越大。分母 $\sqrt{A^2 + B^2}$ 则是法向量的长度，起到归一化的作用。

## 证明过程

**证明**（向量投影法）：

直线 $Ax + By + C = 0$ 的法向量为 $\mathbf{n} = (A, B)$。在直线上任取一点 $Q(x_1, y_1)$，则 $A x_1 + B y_1 + C = 0$。

点 $P$ 到直线的距离等于向量 $\overrightarrow{QP}$ 在法向量 $\mathbf{n}$ 上的投影长度：

$$
d = \frac{|\overrightarrow{QP} \cdot \mathbf{n}|}{|\mathbf{n}|} = \frac{|A(x_0 - x_1) + B(y_0 - y_1)|}{\sqrt{A^2 + B^2}} = \frac{|Ax_0 + By_0 - (Ax_1 + By_1)|}{\sqrt{A^2 + B^2}}
$$

由于 $A x_1 + B y_1 = -C$，代入得 $d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$。$\square$
