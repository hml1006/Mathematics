# Peano 公理

## 概述

Peano 公理是意大利数学家 Giuseppe Peano 于 1889 年提出的自然数公理体系，它用五条公理严格刻画了自然数的性质。这一公理体系标志着算术从直觉走向了形式化公理化，是数学基础研究的重要里程碑。

Peano 公理在 ZFC 集合论中可以被实现（von Neumann 构造），但作为一个独立的公理体系，它直接规定了自然数的基本性质，无需依赖集合论。在数学教育中，Peano 公理是学习者首次接触的形式化公理体系的典型范例。

## 公理列表

| 编号 | 公理名称 | 简要描述 | 文档 |
|------|----------|----------|------|
| PA1 | 初始元公理 | 0 是自然数 | [初始元公理](初始元公理.md) |
| PA2 | 后继公理 | 每个自然数 n 有唯一后继 S(n) | [后继公理](后继公理.md) |
| PA3 | 单射公理 | 若 S(m)=S(n) 则 m=n | [单射公理](单射公理.md) |
| PA4 | 归纳公理 | 若 P(0) 成立且 P(n)⇒P(S(n))，则 ∀n, P(n) 成立 | [归纳公理](归纳公理.md) |
| PA5 | 非后继公理 | 0 不是任何自然数的后继 | [非后继公理](非后继公理.md) |

## 公理间的关系

- **初始元公理** 和 **后继公理** 定义了自然数的基本结构
- **单射公理** 确保后继操作是单射（一一对应）
- **非后继公理** 确保自然数有一个起点
- **归纳公理** 是数学归纳法的形式化基础，使自然数能够被"穷尽"
- 这五条公理共同刻画了自然数结构 (ℕ, 0, S)，使得任何满足 Peano 公理的结构都是同构的（范畴性）

## 历史意义

Peano 公理是数学公理化运动的重要成果，它表明：
- 算术可以建立在严格的形式公理基础上
- 不需要预先假定集合论或任何其他数学理论
- 为后来的数学基础研究（如 Hilbert 纲领、Gödel 定理）提供了重要背景
