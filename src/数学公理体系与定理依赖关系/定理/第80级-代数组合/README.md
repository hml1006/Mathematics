# 第80级-代数组合

本目录收录以下定理：

- [Pólya 计数定理](./Pólya计数定理.md)
- [Möbius 反演公式](./Möbius反演公式.md)
- [Schur 函数的对称性与正交性](./Schur函数的对称性与正交性.md)
- [Littlewood-Richardson 规则](./Littlewood-Richardson规则.md)
- [Robinson-Schensted 对应](./Robinson-Schensted对应.md)
- [Burnside 引理](./Burnside引理.md)：群作用下的轨道数目，等于"每个群元素的不动点数目"的平均值——用数不动点的方式把轨道数算出来。
- [钩长公式](./钩长公式.md)：形状为 $\lambda$ 的标准杨表个数 $f^\lambda$，等于 $n!$ 除以杨图里所有格子"钩长"的乘积——一个把阶乘除成漂亮乘积的维数公式。
- [Jacobi-Trudi 行列式与 Vandermonde 行列式](./Jacobi-Trudi行列式与Vandermonde行列式.md)：Schur 函数虽然定义成"半标准表的权重和"，其实可以整个塞进一个行列式——把完全齐次对称函数 $h_k$ 按划分 $\lambda$ 的形状错位摆放、取行列式，得到的正是 $s_\lambda$；而分母上那个著名的 Vandermonde 行列式 $\prod_{i<j}(x_i-x_j)$，其实就是"置换符号"的化身，为行列式比表达式提供反对称性。
- [RSK 插入算法](./RSK插入算法.md)：RSK 插入算法是一台"边读边整理"的分拣机——每读到一个数，就从第一行开始往里塞，把撞见的更大的数"挤"到下一行，直到某行末尾有空位；每读一个数形状就长一格，位置被记录在第二张表里。
- [Young 分支规则](./Young分支规则.md)：把一个对称群的不可约表示"限制"到少一个字母的对称群上，它就像剥掉杨图的一个角格那样干净地裂开——沿着每一个可剥的角格各裂出一块，数目不多不少。
