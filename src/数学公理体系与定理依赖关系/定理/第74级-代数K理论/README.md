# 第74级-代数K理论

本目录收录以下定理：

- [Grothendieck 群 K0 的泛性质](./Grothendieck群K0的泛性质.md)
- [Whitehead 引理与 K1 群](./Whitehead引理与K1群.md)
- [Matsumoto 定理](./Matsumoto定理.md)
- [Quillen 的局部化正合序列](./Quillen的局部化正合序列.md)
- [Bass-Heller-Swan 定理](./Bass-Heller-Swan定理.md)
- [Quillen 的 Q 构造](./Quillen的Q构造.md)：$K_i(A)=\pi_i(\Omega BQA)$，其中 $Q$ 构造把正合范畴变为环路空间，给出高阶 K 群的定义。
- [Milnor $K_2$ 与 Steinberg 符号](./MilnorK2与Steinberg符号.md)：$K_2^M(F)$ 由符号 $\{a,b\}$ 生成，满足双线性、斜对称与 Steinberg 关系，并同构于 $K_2(F)$。
- [负 K 群](./负K群.md)：Bass 用环的"负维"构造定义 $K_{-n}(A)$，使局部化正合序列向负方向延伸。
- [K 理论的乘法结构](./K理论的乘法结构.md)：$K_*(A)=\bigoplus_iK_i(A)$ 带上 cup 积构成交换分次环，$K_0$ 为幺元。
- [Chern 特征与循环同调](./Chern特征与循环同调.md)：Connes-Karoubi 的 Chern 特征 $K_*(A)\to HC_*(A)$ 把 K 理论映到循环同调，是有理同构的一部分。
- [Borel 定理与 K 理论的秩](./Borel定理与K理论的秩.md)：数域整数环的 $K_i$ 的秩由 Borel 用 Bernoulli 数给出：$\mathrm{rank}\,K_{2j-1}(\mathbb Z)=1$（$j$ 偶）等。
