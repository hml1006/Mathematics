# 正切和角公式

## 介绍

正切和角公式给出了两角和的正切与两角各自的正切之间的关系：$\tan(\alpha + \beta) = \dfrac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$。该公式是正切函数的核心恒等式，在三角恒等变换、解三角方程、求角度值等问题中有着广泛应用。

## 分析

**前置依赖**：和角公式（正弦和余弦）。

**定理内容**：对任意实数 $\alpha, \beta$（使得分母不为零），

$$
\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}
$$

特别地，当 $\alpha = \beta$ 时，得到正切倍角公式：$\tan 2\theta = \dfrac{2\tan\theta}{1 - \tan^2\theta}$。

**数学内涵**：
- 正切和角公式可由正弦和角公式与余弦和角公式相除得到。
- 公式揭示了正切函数与斜率相加的几何联系：两条直线的夹角公式 $\tan\theta = \left|\dfrac{k_1 - k_2}{1 + k_1k_2}\right|$ 正是正切和角公式的变体。
- 分母 $1 - \tan\alpha\tan\beta$ 反映了正切函数在 $\pi/2$ 处的奇点——当 $\alpha + \beta = \pi/2$ 时，分母为零，正切值不存在。

**证明策略**：利用 $\tan(\alpha + \beta) = \dfrac{\sin(\alpha + \beta)}{\cos(\alpha + \beta)}$，代入和角公式后分子分母同除以 $\cos\alpha\cos\beta$。

## 思考过程

正切和角公式的推导思路非常直接：正切定义为正弦与余弦之比，因此 $\tan(\alpha + \beta) = \sin(\alpha + \beta)/\cos(\alpha + \beta)$。代入正弦和余弦的和角公式后，分子分母同时除以 $\cos\alpha\cos\beta$，即可将表达式全部转化为 $\tan\alpha$ 和 $\tan\beta$ 的形式。

从几何角度看，$\tan\alpha$ 可以理解为角度 $\alpha$ 对应的直线的斜率。正切和角公式实际上给出了两条直线斜率之和与它们夹角正切之间的关系。在解析几何中，两直线夹角公式 $\tan\theta = \left|\dfrac{k_1 - k_2}{1 + k_1k_2}\right|$ 正是正切和角公式 $\tan(\alpha - \beta) = \dfrac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$ 的直接应用。

## 证明过程

**定理**（正切和角公式）：对任意实数 $\alpha, \beta$（$\alpha, \beta, \alpha + \beta \neq \pi/2 + k\pi$），

$$
\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}
$$

**证明**：

由正切的定义 $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$，结合正弦和余弦的和角公式：

$$
\tan(\alpha + \beta) = \frac{\sin(\alpha + \beta)}{\cos(\alpha + \beta)} = \frac{\sin\alpha\cos\beta + \cos\alpha\sin\beta}{\cos\alpha\cos\beta - \sin\alpha\sin\beta}
$$

分子分母同时除以 $\cos\alpha\cos\beta$（假设 $\cos\alpha\cos\beta \neq 0$）：

$$
\tan(\alpha + \beta) = \frac{\dfrac{\sin\alpha\cos\beta}{\cos\alpha\cos\beta} + \dfrac{\cos\alpha\sin\beta}{\cos\alpha\cos\beta}}{\dfrac{\cos\alpha\cos\beta}{\cos\alpha\cos\beta} - \dfrac{\sin\alpha\sin\beta}{\cos\alpha\cos\beta}} = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}
$$

$\square$

**正切差角公式**：用 $-\beta$ 替换 $\beta$，得

$$
\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}
$$
