# 第96级-随机微分方程

> 一句话级别概述：随机微分方程（SDE）研究由布朗运动驱动的随机演化系统，将确定性微分方程理论推广到噪声环境，是金融数学、随机控制与统计物理的运算基石。

## 级别简介

本级别研究带随机扰动的微分方程，其核心是建立随机微积分的运算规则、保证解的存在唯一性，并通过测度变换与概率表示沟通随机过程与偏微分方程。涉及 Itô 引理、强解的存在唯一性、Girsanov 测度变换、Feynman-Kac 概率表示以及密度演化的 Fokker-Planck 方程等核心内容。

## 本级别定理

- [Itô引理](./Itô引理.md)：随机复合函数微分需加二阶修正项。
- [SDE解的存在唯一性定理](./SDE解的存在唯一性定理.md)：Lipschitz 条件下强解存在唯一。
- [Girsanov定理](./Girsanov定理.md)：指数鞅测度变换下漂移得以改变。
- [Feynman-Kac公式](./Feynman-Kac公式.md)：抛物 PDE 的解表为随机路径期望。
- [Fokker-Planck方程的推导](./Fokker-Planck方程的推导.md)：由 Itô 过程推得密度的前向方程。

## 前置知识

本级别依赖测度论与概率论（第98级）与随机分析（第97级），包括 Itô 积分、Brown 运动、鞅论、Radon-Nikodym 测度变换、二次变差、条件期望等概念；同时需要微积分与常微分方程中 Picard 迭代、Gronwall 引理的基础。

## 后继用途

本级别为金融数学（资产定价、Black-Scholes 与风险中性测度）、随机控制、随机偏微分方程、统计物理中的扩散理论以及随机滤波等后续方向提供运算基础。

## 关键定理速览

- Itô引理：随机微分运算的核心规则，引入二阶修正。
- SDE解的存在唯一性：保证随机模型在温和条件下有良好定义的强解。
- Girsanov定理：金融风险中性测度变换的枢纽。
- Feynman-Kac公式：联系抛物 PDE 与随机期望，支撑蒙特卡洛定价。
