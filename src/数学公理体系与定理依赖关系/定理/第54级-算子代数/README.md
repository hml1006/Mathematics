- [von Neumann 代数与双交换子定理](./vonNeumann代数与双交换子定理.md)：一个含单位、对取伴随封闭的算子代数，只要在弱（强）拓扑下闭合，就"等于它自己的双重交换子"——它把自己能"看住"的一切算子全都收编进来，不再遗漏。
- [谱半径公式](./谱半径公式.md)：算子谱中最远的那个点到原点的距离（谱半径），恰好等于它一次次做幂之后范数开 $n$ 次方所趋近的极限；也就是说，谱的"大小"完全由范数的增长速度决定。
- [谱映射定理](./谱映射定理.md)：把算子先代入多项式、再取谱，与先取谱、再把每个谱点代入同一个多项式，得到的是同一个集合——谱对多项式运算是"逐点"的。
- [Gelfand-Mazur 定理](./Gelfand-Mazur定理.md)：在一个每个非零元都可逆的复 Banach 代数（复 Banach 可除代数）里，除了单位元的倍数之外再没有任何别的元素——这样的代数只能就是复数域 $\mathbb C$。
- [投影比较定理](./投影比较定理.md)：von Neumann 代数里的两个投影，虽然未必能直接比较大小，但总可以把代数的中心"切开"，在中心分出的每一块上让其中一个不超过另一个——比较在"纤维"层次上总能做到。
- [Fekete引理](./Fekete引理.md)：若一个数列满足"分成两段再相加不会变小"（次可加），那么它除以 $n$ 之后一定收敛，且极限正好是所有 $a_n/n$ 中最小的那一个。
- [预解恒等式（Resolvent 恒等式）](./resolvent恒等式.md)：同一个算子在两个不同参数处的两个"逆"相减，等于它们相乘再乘上参数之差——于是"逆的差"这条非线性信息被化成了"逆的乘积"，可以逐项展开、求导、做估计。
