# 三角形全等判定 SSS

> **一句话大白话**：两个三角形的三条边全都一样长，那它们就一定全等——三条边一确定，三角形这架"钢筋架子"就撑不开、压不扁了。
>
> **小例子**：若 $\triangle ABC$ 和 $\triangle DEF$ 满足 $AB=DE$、$BC=EF$、$CA=FD$，则两三角形全等；随手画个三边都是 $3,4,5$ 的三角形，都一样大。

## 介绍

SSS（Side-Side-Side，边边边）全等判定定理是三角形全等的基本判定定理之一：如果两个三角形的三条边分别对应相等，则这两个三角形全等。该定理是欧几里得《几何原本》中证明的第一个三角形全等定理，也是尺规作图的基础——给定三边长度，可以唯一确定一个三角形。

## 分析

**前置依赖**：合同公理（Hilbert 公理体系中的合同公理）。

**定理内容**：在 $\triangle ABC$ 和 $\triangle DEF$ 中，若 $AB = DE$，$BC = EF$，$CA = FD$，则 $\triangle ABC \cong \triangle DEF$。

**数学内涵**：
- SSS 判定定理表明三角形的形状和大小完全由三边长度决定，即三角形具有"刚性"。
- 这一定理是"三角形稳定性"的数学基础——三条边确定的三角形是唯一的。
- 在 Hilbert 公理体系中，SSS 不是作为公理，而是作为定理从合同公理推导出来的。

**证明策略**：
- 将 $\triangle ABC$ 通过平移旋转使 $AB$ 与 $DE$ 重合。
- 证明 $C$ 与 $F$ 重合（利用合同公理中"以给定点为圆心、给定线段为半径可作圆"的性质，以及两圆相交的唯一性）。
- 或利用等腰三角形的性质构造反证法。

## 思考过程

SSS 判定的直观理解是：三条边确定一个三角形。给定三边长度，虽然可以画出两个镜像对称的三角形，但它们可以通过翻转重合，因此是全等的。

证明的思路是：将三角形 $\triangle ABC$ 移动到 $\triangle DEF$ 上，使 $AB$ 与 $DE$ 重合。然后证明 $C$ 和 $F$ 必然重合。由于 $BC = EF$ 且 $AC = DF$，$C$ 和 $F$ 都在以 $D$ 为圆心 $DF$ 为半径和以 $E$ 为圆心 $EF$ 为半径的两个圆的交点上，而两个圆的交点至多有两个（对称于 $DE$ 线），其中一个就是 $C$，另一个是 $C$ 关于 $DE$ 的镜像。但若 $C$ 和 $F$ 分别位于 $DE$ 的两侧，可以翻转其中一个三角形使它们重合。

## 证明过程

**定理**（SSS 全等判定）：若两个三角形的三条边分别对应相等，则这两个三角形全等。

**证明**：

设 $\triangle ABC$ 和 $\triangle DEF$ 满足 $AB = DE$，$BC = EF$，$CA = FD$。

将 $\triangle ABC$ 平移旋转，使 $A$ 与 $D$ 重合，$B$ 与 $E$ 重合，且 $C$ 与 $F$ 在直线 $DE$ 的同侧。

现在需要证明 $C$ 与 $F$ 重合。

由 $AC = DF$，$C$ 在以 $D$ 为圆心、$DF$ 为半径的圆上。
由 $BC = EF$，$C$ 在以 $E$ 为圆心、$EF$ 为半径的圆上。

这两个圆相交于两点（除非 $C$ 在 $DE$ 上），这两点关于直线 $DE$ 对称。由于 $C$ 和 $F$ 都在 $DE$ 的同侧，且都是两圆的交点，故 $C$ 与 $F$ 重合。

因此 $\triangle ABC$ 与 $\triangle DEF$ 完全重合，即 $\triangle ABC \cong \triangle DEF$。$\square$

---

**注**：在更严格的公理体系中（如 Hilbert 公理体系），SSS 判定定理可以通过合同公理和三角形稳定性来证明，而不依赖于"移动"这一直观操作。上述证明使用了"叠合法"（即通过平移、旋转、翻转使图形重合），这是欧几里得《几何原本》中的传统证明方法。
