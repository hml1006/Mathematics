# 二阶线性 PDE 分类

## 介绍

二阶线性偏微分方程（PDE）的分类是偏微分方程理论的基石。根据方程在给定点处的特征形式，二阶线性 PDE 可分为椭圆型、抛物型和双曲型三大类，每类方程具有截然不同的性质和解法。这一分类由二阶偏导项系数矩阵的特征值符号决定，是研究 PDE 适定性和选取求解策略的首要步骤。

## 分析

**前置依赖**：多元函数微积分、线性代数（特征值、二次型）、偏微分方程的基本概念。

**定理内容**：考虑一般二阶线性 PDE
$$Lu = \sum_{i,j=1}^n a_{ij}(x)\partial_{x_i x_j}^2 u + \sum_{i=1}^n b_i(x)\partial_{x_i}u + c(x)u = f(x)$$
其中 $a_{ij}(x)$ 是对称矩阵（即 $a_{ij}=a_{ji}$）。在点 $x_0$ 处，根据系数矩阵 $A(x_0) = (a_{ij}(x_0))$ 的特征值符号分类：

- **椭圆型**：$A(x_0)$ 的所有特征值同号（全正或全负）。例如 Laplace 方程 $\Delta u = 0$。
- **抛物型**：$A(x_0)$ 有一个特征值为零，其余特征值同号。例如热方程 $u_t - \Delta u = 0$。
- **双曲型**：$A(x_0)$ 有一个特征值与其余特征值异号，其余特征值同号。例如波动方程 $u_{tt} - \Delta u = 0$。

**对两个自变量的特殊情形**：对 $n=2$，方程可写为
$$a_{11}u_{xx} + 2a_{12}u_{xy} + a_{22}u_{yy} + \text{低阶项} = 0$$
判别式 $\Delta = a_{12}^2 - a_{11}a_{22}$ 决定类型：
- $\Delta < 0$：椭圆型
- $\Delta = 0$：抛物型
- $\Delta > 0$：双曲型

**数学内涵**：分类反映了 PDE 解的本质差异：
- 椭圆型方程描述稳态过程（如平衡态），解光滑且满足最大值原理。
- 抛物型方程描述扩散过程，解具无穷传播速度和光滑化效应。
- 双曲型方程描述波动过程，解具有限传播速度和特征曲面。

**证明策略**：分类基于线性代数中的二次型理论。通过坐标变换将二阶主部对角化，标准型由特征值符号决定。

## 思考过程

二阶线性 PDE 的分类源于对特征理论的深入分析。对 PDE 进行特征分析时，发现特征曲面的存在性和性质完全由主部系数矩阵决定。双曲型方程具有实特征曲面（即特征线/面），抛物型方程的特征曲面退化，椭圆型方程没有实特征曲面。

在物理上，这种分类对应三类基本物理过程：
- 椭圆型（如 Laplace 方程）：稳态、平衡
- 抛物型（如热方程）：扩散、衰减
- 双曲型（如波动方程）：振动、传播

## 证明过程

**定理**（二阶线性 PDE 分类）：设 $A(x) = (a_{ij}(x))$ 是对称矩阵，则通过可逆线性变换 $\xi = \xi(x)$，方程的主部可以化为标准型。

**证明**：

**步骤 1**：在固定点 $x_0$ 处，$A = A(x_0)$ 是实对称矩阵，故存在正交矩阵 $Q$ 使得
$$Q^T A Q = \operatorname{diag}(\lambda_1, \dots, \lambda_n)$$
其中 $\lambda_i$ 是 $A$ 的特征值。

**步骤 2**：作线性变换 $y = Q^T(x - x_0)$，则在新坐标下
$$\sum_{i,j} a_{ij}\partial_{x_i x_j}^2 = \sum_{i=1}^n \lambda_i \partial_{y_i}^2$$

**步骤 3**：再作缩放变换 $z_i = \sqrt{|\lambda_i|} y_i$（对 $\lambda_i \neq 0$），则主部化为
$$\sum_{\lambda_i > 0} \partial_{z_i}^2 - \sum_{\lambda_i < 0} \partial_{z_i}^2$$
即标准型为
$$\sum_{i=1}^p \partial_{z_i}^2 - \sum_{i=p+1}^{p+q} \partial_{z_i}^2 + \text{低阶项} = 0$$
其中 $p$ 是正特征值个数，$q$ 是负特征值个数，$r = n - p - q$ 是零特征值个数。

**步骤 4**：分类标准：
- 椭圆型：$p=n$ 或 $q=n$，即 $p=n, q=0$ 或 $p=0, q=n$。
- 抛物型：$r=1$ 且 $p+q=n-1$，且 $p=0$ 或 $q=0$。
- 双曲型：$p=1, q=n-1$ 或 $p=n-1, q=1$。

**对 $n=2$ 的情形**：设 $A = \begin{pmatrix} a_{11} & a_{12} \\ a_{12} & a_{22} \end{pmatrix}$，其特征值满足
$$\lambda_1 \lambda_2 = \det(A) = a_{11}a_{22} - a_{12}^2 = -\Delta$$
故 $\Delta < 0$ 时 $\lambda_1\lambda_2 > 0$（椭圆型），$\Delta = 0$ 时 $\lambda_1\lambda_2 = 0$（抛物型），$\Delta > 0$ 时 $\lambda_1\lambda_2 < 0$（双曲型）。$\square$

**注**：上述分类是逐点的。若在某区域内方程的类型一致，则称为该区域内的椭圆型/抛物型/双曲型方程。混合型方程在不同区域类型不同。
