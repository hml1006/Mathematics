# 辅助角公式

## 介绍

辅助角公式（又称合一公式）将形如 $a\sin\theta + b\cos\theta$ 的线性组合合并为一个单一的正弦或余弦函数：$a\sin\theta + b\cos\theta = \sqrt{a^2+b^2}\sin(\theta + \varphi)$，其中 $\tan\varphi = b/a$。该公式在三角函数化简、求解三角方程、求最值以及物理中的简谐振动合成中有着广泛应用。

## 分析

**前置依赖**：和角公式。

**定理内容**：对任意实数 $a, b, \theta$，存在 $\varphi$ 使得

$$
a\sin\theta + b\cos\theta = \sqrt{a^2+b^2}\sin(\theta + \varphi)
$$

其中 $\varphi$ 满足 $\sin\varphi = \frac{b}{\sqrt{a^2+b^2}}$，$\cos\varphi = \frac{a}{\sqrt{a^2+b^2}}$，即 $\tan\varphi = \frac{b}{a}$。

**数学内涵**：
- 辅助角公式本质上是和角公式 $\sin(\theta + \varphi) = \sin\theta\cos\varphi + \cos\theta\sin\varphi$ 的逆用。
- 它将两个同频三角函数的线性组合压缩为一个单一的三角函数，揭示了简谐振动合成的几何意义。
- 从向量角度看，$(a, b)$ 可视为一个二维向量，其长度为 $\sqrt{a^2+b^2}$，与 $x$ 轴夹角为 $\varphi$。

**证明策略**：提取公因子 $\sqrt{a^2+b^2}$，然后利用和角公式的逆用。

## 思考过程

辅助角公式的核心思想是"归一化"：将系数 $a$ 和 $b$ 视为一个直角三角形的两条直角边，则斜边为 $\sqrt{a^2+b^2}$。设该直角三角形的一个锐角为 $\varphi$，使得 $\cos\varphi = a/\sqrt{a^2+b^2}$，$\sin\varphi = b/\sqrt{a^2+b^2}$，那么原式就可以写成 $\sqrt{a^2+b^2}(\sin\theta\cos\varphi + \cos\theta\sin\varphi) = \sqrt{a^2+b^2}\sin(\theta + \varphi)$。

这一公式在物理中尤为重要：两个同频率的简谐振动的合成仍然是一个同频率的简谐振动，其振幅为 $\sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_1 - \varphi_2)}$，初相由辅助角公式确定。

## 证明过程

**定理**（辅助角公式）：对任意实数 $a, b, \theta$，

$$
a\sin\theta + b\cos\theta = \sqrt{a^2+b^2}\sin(\theta + \varphi)
$$

其中 $\varphi$ 满足 $\sin\varphi = \frac{b}{\sqrt{a^2+b^2}}$，$\cos\varphi = \frac{a}{\sqrt{a^2+b^2}}$。

**证明**：

设 $R = \sqrt{a^2+b^2}$。若 $R = 0$，则 $a = b = 0$，公式平凡成立。

若 $R > 0$，则

$$
\frac{a}{R}\sin\theta + \frac{b}{R}\cos\theta = \sin\theta\cos\varphi + \cos\theta\sin\varphi = \sin(\theta + \varphi)
$$

其中 $\varphi$ 定义为满足 $\cos\varphi = a/R$，$\sin\varphi = b/R$ 的角。这样的 $\varphi$ 一定存在，因为 $(a/R)^2 + (b/R)^2 = 1$，即点 $(a/R, b/R)$ 在单位圆上。

两边乘以 $R$ 即得：

$$
a\sin\theta + b\cos\theta = R\sin(\theta + \varphi) = \sqrt{a^2+b^2}\sin(\theta + \varphi)
$$

$\square$

**注**：同样地，也可以写成余弦形式：

$$
a\sin\theta + b\cos\theta = \sqrt{a^2+b^2}\cos(\theta - \psi),\quad \tan\psi = \frac{a}{b}
$$
