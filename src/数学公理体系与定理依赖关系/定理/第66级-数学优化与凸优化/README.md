# 第66级-数学优化与凸优化

本目录收录以下定理：

- [Karush-Kuhn-Tucker条件](./Karush-Kuhn-Tucker条件.md)
- [内点法收敛性](./内点法收敛性.md)
- [凸优化对偶理论](./凸优化对偶理论.md)
- [凸函数与凸集](./凸函数与凸集.md)
- [极小极大定理](./极小极大定理.md)
- [梯度下降收敛性](./梯度下降收敛性.md)
- [线性规划基本定理](./线性规划基本定理.md)
- [变分不等式](./变分不等式.md)：变分不等式把"求函数的极小值"推广成"找一个点，使得任何可行方向上的代价都不再下降"——最优性由一个不等式而非等式来刻画。
- [支撑超平面定理](./支撑超平面定理.md)：任何一个凸集的边界点，都能被一张"刚好贴着"它的平面托住，使整个凸集都躺在这张平面的一侧，这张平面就是它的支撑超平面。
- [弱极小极大不等式](./弱极小极大不等式.md)：不管你怎么交换"先取最小还是先取最大"的顺序，先取最小值再取最大值得到的结果，永远不会超过先取最大值再取最小值，顺序换了只会让对方占便宜。
- [下降引理](./下降引理.md)：只要函数的"陡峭程度"变化得不太快，那么从一点出发做一阶近似、再加一个与步长平方成正比的惩罚项，就一定是函数真实值的上界，这给了梯度法可以依赖的"下坡保证"。
- [minimax 不等式](./minimax不等式.md)：在"我先选还是你先选"的问题里，先选的人只能占便宜——先取最小再取最大（$\sup\inf$）永远不超过先取最大再取最小（$\inf\sup$）；凸凹结构下两者恰好相等，于是对偶、博弈都能"换序"。
- [函数的逐点不等式](./函数的逐点不等式.md)：一个二元函数 $f(x,y)$ 不管怎么摆，它在某一点的值总被"对 $x$ 的最小值"压住下界、被"对 $y$ 的最大值"托住上界；把这种"点对点"的比较沿某个方向一次性取完，就得到全局的上下界。
- [强凸性及其蕴含的误差界](./强凸性及其蕴含的误差界.md)：强凸就是"比凸还要凸"——函数不只弯着向上，还至少带一个正比于距离平方的"碗底坡度"；这个坡度给出了距离、梯度、函数值三者之间的定量换算，让优化算法的误差不再只能"定性收敛"。
