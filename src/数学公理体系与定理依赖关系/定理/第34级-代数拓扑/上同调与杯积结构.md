# 上同调与杯积结构

> **一句话大白话**：同调只告诉你"有哪些洞"，上同调更进一步——洞里还能"乘"出新的洞。这个叫杯积的乘法把上同调群变成戒指般的环，从而区分出仅靠洞数分辨不出的空间。
>
> **小例子**：环面 $T^2$ 上两个一维上同调类的杯积给出二维类，而球面 $S^2$ 上一维类为零，故 $T^2$ 与 $S^2$ 的乘性结构截然不同，即使洞数看着接近。

## 一、定理介绍

上同调理论是代数拓扑中的核心工具，它为拓扑空间提供了一系列代数不变量。与同调理论不同，上同调具有额外的乘法结构——杯积（cup product），使得上同调群成为分次环（graded ring）。这个环结构包含了比同调群更丰富的拓扑信息。

杯积结构的引入使得我们能够区分那些同调群相同但拓扑不同的空间，在微分拓扑、代数几何和数学物理中有深刻应用。

## 二、原理思路

**核心思想**：上同调是 Hom 函子应用到链复形上得到的，自然具有乘法结构。

**关键观察**：
1. 奇异上链是奇异链上的线性泛函，上同调群 $H^n(X; R) = H^n(\text{Hom}(C_*(X), R))$
2. 杯积通过对角映射 $\Delta: X \to X \times X$ 和 Eilenberg-Zilber 同构定义
3. 杯积满足分次交换性：$\alpha \cup \beta = (-1)^{pq} \beta \cup \alpha$（$\alpha \in H^p$, $\beta \in H^q$）
4. 杯积与连续映射的拉回交换：$f^*(\alpha \cup \beta) = f^*\alpha \cup f^*\beta$

**证明策略**：
- 在链水平定义杯积（通过 Alexander-Whitney 映射）
- 验证杯积与边缘算子相容，诱导出上同调的乘法
- 证明分次交换性（通过链同伦）

## 三、定理的严格表述

**定义（奇异上同调）**：设 $X$ 是拓扑空间，$R$ 是交换环。奇异链复形 $C_*(X; R)$ 的对偶复形 $C^*(X; R) = \text{Hom}(C_*(X), R)$ 称为**上链复形**，其边缘算子 $\delta: C^n \to C^{n+1}$ 定义为 $\delta \varphi = \varphi \circ \partial$。

第 $n$ 次**奇异上同调群**定义为
$$H^n(X; R) = \ker(\delta: C^n \to C^{n+1}) / \text{im}(\delta: C^{n-1} \to C^n)$$

**定义（杯积）**：对 $\varphi \in C^p(X; R)$ 和 $\psi \in C^q(X; R)$，定义**杯积** $\varphi \cup \psi \in C^{p+q}(X; R)$ 为
$$(\varphi \cup \psi)(\sigma) = \varphi(\sigma \circ \lambda_{p}) \cdot \psi(\sigma \circ \rho_{q})$$
其中 $\sigma: \Delta^{p+q} \to X$ 是奇异单形，$\lambda_p: \Delta^p \to \Delta^{p+q}$ 是前 $p$ 个顶点的包含，$\rho_q: \Delta^q \to \Delta^{p+q}$ 是后 $q$ 个顶点的包含。

**定理（上同调环结构）**：

1. **良定性**：杯积诱导出上同调群的映射 $\cup: H^p(X; R) \otimes H^q(X; R) \to H^{p+q}(X; R)$

2. **结合律**：$(\alpha \cup \beta) \cup \gamma = \alpha \cup (\beta \cup \gamma)$

3. **单位元**：存在 $1 \in H^0(X; R)$ 使得 $1 \cup \alpha = \alpha \cup 1 = \alpha$

4. **分次交换性**：$\alpha \cup \beta = (-1)^{pq} \beta \cup \alpha$（$\alpha \in H^p$, $\beta \in H^q$）

5. **自然性**：对连续映射 $f: X \to Y$，$f^*(\alpha \cup \beta) = f^*\alpha \cup f^*\beta$

因此 $H^*(X; R) = \bigoplus_n H^n(X; R)$ 成为**分次交换环**（graded commutative ring）。

## 四、证明过程

**定理**：杯积诱导出上同调的乘法。

**证明**：

**步骤 1**：链水平的杯积。对 $\varphi \in C^p$, $\psi \in C^q$，定义 $\varphi \cup \psi \in C^{p+q}$ 如上。

**步骤 2**：验证 Leibniz 规则。需要证明
$$\delta(\varphi \cup \psi) = \delta\varphi \cup \psi + (-1)^p \varphi \cup \delta\psi$$

对奇异单形 $\sigma: \Delta^{p+q+1} \to X$，
$$(\delta(\varphi \cup \psi))(\sigma) = (\varphi \cup \psi)(\partial \sigma) = \sum_{i=0}^{p+q+1} (-1)^i (\varphi \cup \psi)(\sigma \circ \varepsilon_i)$$

通过仔细分析 $\sigma \circ \varepsilon_i$ 的前 $p$ 个顶点和后 $q$ 个顶点，可以将求和分为两部分：前 $p+1$ 项对应 $\delta\varphi \cup \psi$，后 $q+1$ 项对应 $(-1)^p \varphi \cup \delta\psi$。

**步骤 3**：诱导出上同调映射。若 $\varphi$ 和 $\psi$ 是闭上链（$\delta\varphi = 0$, $\delta\psi = 0$），则 $\delta(\varphi \cup \psi) = 0$，因此 $\varphi \cup \psi$ 也是闭的。

若 $\varphi = \delta\eta$ 是恰当的，则 $\varphi \cup \psi = \delta\eta \cup \psi = \delta(\eta \cup \psi) - (-1)^{p-1} \eta \cup \delta\psi$。若 $\psi$ 闭，则 $\varphi \cup \psi = \delta(\eta \cup \psi)$ 是恰当的。

因此杯积在上同调水平良定。$\square$

**定理（分次交换性）**：$\alpha \cup \beta = (-1)^{pq} \beta \cup \alpha$。

**证明思路**：

**步骤 1**：构造链同伦。定义换位映射 $T: C^p \otimes C^q \to C^q \otimes C^p$ 为 $T(\varphi \otimes \psi) = (-1)^{pq} \psi \otimes \varphi$。

**步骤 2**：证明 $\varphi \cup \psi$ 和 $(-1)^{pq} \psi \cup \varphi$ 链同伦。通过构造显式的链同伦算子 $D$，使得
$$\varphi \cup \psi - (-1)^{pq} \psi \cup \varphi = \delta D(\varphi \otimes \psi) + D(\delta(\varphi \otimes \psi))$$

**步骤 3**：在闭链上，$\delta D = 0$，因此 $\varphi \cup \psi$ 和 $(-1)^{pq} \psi \cup \varphi$ 相差一个恰当上链，在上同调中相等。$\square$

**示例**：

- **环面** $T^2 = S^1 \times S^1$：$H^*(T^2) = \mathbb{Z}[\alpha, \beta]/(\alpha^2, \beta^2)$，$|\alpha| = |\beta| = 1$，$\alpha \cup \beta$ 生成 $H^2(T^2) \cong \mathbb{Z}$

- **射影空间** $\mathbb{RP}^n$：$H^*(\mathbb{RP}^n; \mathbb{Z}/2) = \mathbb{Z}/2[x]/(x^{n+1})$，$|x| = 1$

- **复射影空间** $\mathbb{CP}^n$：$H^*(\mathbb{CP}^n; \mathbb{Z}) = \mathbb{Z}[x]/(x^{n+1})$，$|x| = 2$

## 五、应用与意义

上同调环结构在多个领域有重要应用：

1. **拓扑分类**：区分同调群相同但环结构不同的空间。例如，$S^2 \vee S^1 \vee S^1$ 和 $T^2$ 的同调群相同，但上同调环不同。

2. **不动点定理**：Lefschetz 不动点定理的加强形式利用杯积结构。

3. **流形分类**：Poincaré 对偶和杯积结构用于紧致流形的分类。

4. **特征类**：Stiefel-Whitney 类、Chern 类和 Pontryagin 类通过杯积定义。

5. **同伦论**：Postnikov 不变量是上同调类，k-不变量通过杯积表达。

6. **代数几何**：代数簇的上同调环（如 Chow 环）是重要的双有理不变量。

7. **数学物理**：在拓扑量子场论中，上同调环对应可观测量代数。

上同调理论的推广包括：广义上同调（K-理论、配边理论）、等变上同调、以及上同调运算（Steenrod 运算）。
