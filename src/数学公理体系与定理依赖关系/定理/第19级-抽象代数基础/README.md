# 第19级-抽象代数基础

本目录收录以下定理：

- [PID 是 UFD](./PID是UFD.md)
- [中国剩余定理（环论）](./中国剩余定理.md)
- [唯一析因整环性质](./唯一析因整环性质.md)
- [域扩张次数定理](./域扩张次数定理.md)
- [拉格朗日定理（群论）](./拉格朗日定理.md)
- [欧几里得整环是 PID](./欧几里得整环是PID.md)
- [环同态基本定理](./环同态基本定理.md)
- [群同态基本定理](./群同态基本定理.md)
- [有限生成Abel群基本定理](./有限生成Abel群基本定理.md)：任何由有限多个元素生成的交换群，都只是一堆"整数方向"加上一堆"循环方向"拼起来的，结构完全清楚。
- [对称函数基本定理](./对称函数基本定理.md)：任何"调换变量顺序也不变"的多项式，都能用最基本的那几个（各次初等对称多项式）唯一地写出来。
- [Newton恒等式](./Newton恒等式.md)：一组数的"幂和"（各个数的 $k$ 次方之和）和"初等对称多项式"（所有 $k$ 元乘积之和）其实是一回事，可以互相换算，换算公式就是 Newton 恒等式。
- [主理想整环上有限生成模结构定理](./主理想整环上有限生成模结构定理.md)：在 PID（每个理想都由一个元素生成的整环）上，任何有限生成的模都只是一堆"自由部分"加上若干"循环扭曲块"，而且这些块的尺寸是唯一的。
- [Krull-Schmidt 定理](./Krull-Schmidt定理.md)：把一块积木拆成"不可再分的零件"的直和，无论怎么拆，零件清单（到同构）都唯一——数目相同，种类一一对应。
