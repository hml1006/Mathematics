- [无套利原理](./无套利原理.md)：天下没有免费的午餐——不可能构造出一个今天不花钱（甚至现在就赚钱）、将来在任何情况下都不亏、并且至少有一种情况下赚钱的投资组合。
- [两基金分离定理](./两基金分离定理.md)：所有“最优”投资组合都能由两个固定基金拼出来——一个无风险资产（国债）加一个固定的“切点组合”（风险资产的最优混合）；不同风险偏好的人只需调整这两者的比例，不必各自重新配置风险资产。
