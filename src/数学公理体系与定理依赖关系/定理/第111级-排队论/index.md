# 第111级-排队论

本目录收录以下定理：

- [Little定律](./Little定律.md)
- [M/M/1队列的稳态分布](./M_M-1队列的稳态分布.md)
- [Pollaczek-Khinchin公式](./Pollaczek-Khinchin公式.md)
- [Erlang-B公式](./Erlang-B公式.md)
- [Jackson网络的乘积形式解](./Jackson网络的乘积形式解.md)
- [平稳转移方程](./平稳转移方程.md)：马尔可夫链稳定下来以后，处于各个状态的概率不再随时间变化——"分别从各个状态走进某个状态的总概率"恰好等于"这个状态本身的概率"。把每个状态都这样写一条等式，就得到一组**平稳转移方程** $\pi_j=\sum_i\pi_i p_{ij}$，解它即可得稳态分布。
- [流量方程](./流量方程.md)：排队网络里每个节点的"总到达率"等于从外界直接进来的加上从别的节点转过来的；把每个节点的这种"客流进出记账"写成方程，就是**流量方程**。解这个线性方程组，就知道每个节点究竟承担多大负荷。
- [细致平衡方程](./细致平衡方程.md)：细致平衡是比"稳定"更强的条件：不仅每个状态进出的总量相等，而且**任意两个状态之间**双向的"流量"也恰好相等——从 $i$ 流向 $j$ 的流量（$\pi_i$ 乘转移率）等于从 $j$ 流向 $i$ 的流量。这样的链在时间反演下统计规律不变，称为"可逆"。
