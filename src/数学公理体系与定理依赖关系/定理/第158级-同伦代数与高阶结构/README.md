# 第158级-同伦代数与高阶结构

> 一句话级别概述：同伦代数把等式换成同伦：当结构只在同伦意义下成立时，用 A∞、E∞、∞-范畴与模型结构把差一点的代数严格化。

## 级别简介

本级别从 Quillen 模型结构与单纯集出发，引入 Joyal 模型结构与拟范畴；随后是 A∞ 代数与最小模型定理、E∞ 代数与 May 识别定理、谱代数几何；最后以同伦（余）极限、Grothendieck 构造与 Waldhausen S 构造收尾。

## 本级别定理

- [单纯集与 Quillen 模型结构](./单纯集与Quillen模型结构.md)：单纯集范畴上以弱等价（几何实现后同伦等价）、Kan 纤维化、余纤维化为三类态射构成模型结构。
- [Joyal 模型结构与拟范畴](./Joyal模型结构与拟范畴.md)：单纯集上的 Joyal 模型结构以"内 Kan 复形"为对象，其纤维化给出拟范畴的 $\infty$-范畴语义。
- [$A_\infty$ 代数与最小模型定理](./A∞代数与最小模型定理.md)：$A_\infty$ 结构在同伦等价下可迁移；每个 $A_\infty$ 代数同构于唯一（到同构）的最小模型。
- [$E_\infty$ 代数与 May 识别定理](./E∞代数与May识别定理.md)：多重环路空间 $\Omega^nX$ 同伦等价于 $E_n$ 代数的群状对象，$n\to\infty$ 给出 $E_\infty$ 结构。
- [谱代数几何的基础](./谱代数几何的基础.md)：以 $E_\infty$ 环谱为"函数环"的仿射对象构成谱概形，导出概形是其局部模型。
- [同伦极限与同伦余极限](./同伦极限与同伦余极限.md)：拟范畴中的同伦 (co)limit 由万有性质刻画，可借助单纯模型或 Bousfield-Kan 公式计算。
- [Grothendieck 构造与 $\infty$-函子](./Grothendieck构造与∞函子.md)：纤维化/余纤维化对应函子，Lurie 的 unstraightening 把这一对应提升到 $\infty$-范畴。
- [Waldhausen $S_\bullet$ 构造与代数 K 理论](./Waldhausen-S构造与代数K理论.md)：Waldhausen 的 $S_\bullet$ 构造给出 Waldhausen 范畴的 K 理论谱，且与 Quillen Q 构造一致（一致性定理）。

## 前置知识

范畴论与函子、单纯集、微分分次代数、代数拓扑与同调代数。

## 后继用途

为导出代数几何、谱代数几何、高阶表示论与代数 K 理论提供语言，是现代代数与拓扑的共同基础。

## 关键定理速览

- 模型结构 = 三类态射 + 五条公理。
- 拟范畴用内 Kan 条件编码 ∞-范畴。
- A∞ 结构可沿同伦等价迁移。
- May 识别定理：多重环路空间 = 群状 En 代数。
- Waldhausen S 构造给出代数 K 理论的谱。
