# 第01级-算术基础

> 整数与自然数的根本性质：整除、带余除法、最大公因数、素数与唯一分解，是整个数论构造的起点。

## 级别简介

本级别研究整数与自然数的基本结构：带余除法、最大公因数（辗转相除法）、素数的性质与分布、以及算术基本定理（唯一分解）。它是数论的公理起点，也是后续整个数学大厦（代数、分析、几何）所依赖的最朴素的运算规律。

## 本级别定理

- [Bezout 引理](./Bezout引理.md)：整数最大公因数的线性组合表示。
- [Euclid 引理](./Euclid引理.md)：素数整除乘积必整除某因子。
- [带余除法](./带余除法.md)：整数唯一分解为商余形式。
- [数学归纳法原理](./数学归纳法原理.md)：自然数全体命题的证明结构。
- [算术基本定理](./算术基本定理.md)：整数唯一素数分解。
- [良序原理](./良序原理.md)：非空自然数集必有最小元。
- [质数无穷定理](./质数无穷定理.md)：素数个数无限。
- [辗转相除法](./辗转相除法.md)：求最大公因数的迭代算法。

## 前置知识

本级别依赖自然数与整数的基本运算概念，以及数学归纳法原理（既有在此证明的原理，也有作为推理工具的使用）。严格说来，自然数的公理基础（皮亚诺公理）位于更基础的层面，本级别在其上展开整除理论与唯一分解理论。

## 后继用途

算术基本定理与辗转相除法为第 02 级初等代数、第 19 级抽象代数基础（整环与唯一析因）提供直接前提，也是第 07 级数列与数学归纳法的重要工具来源。

## 关键定理速览

- 辗转相除法：高效求解最大公因数，是扩展欧几里得算法与 Bezout 引理的基础。
- 算术基本定理：一切整数可唯一写成素数乘积，是整个数论的基石。
- 质数无穷定理：素数有无穷多个（欧几里得经典证明）。
- 数学归纳法原理：自然数性质证明的标准手段，与良序原理等价。
