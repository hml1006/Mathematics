# 三角形中位线定理

> **一句话大白话**：三角形两边中点的连线，跟第三边是"平行"的，而且长度正好是第三边的一半。
>
> **小例子**：$\triangle ABC$ 中 $AB$、$AC$ 的中点连成 $DE$，若 $BC=10$，则 $DE=5$，且 $DE\parallel BC$。

## 介绍

三角形中位线定理是平面几何中的一个基本定理：三角形的中位线（连接两边中点的线段）平行于第三边，且长度等于第三边的一半。该定理是相似三角形和平行四边形性质的直接推论，在几何证明和构造中有着广泛的应用，也是后续学习梯形中位线、重心定理等的基础。

## 分析

**前置依赖**：三角形相似判定AA。

**定理内容**：在 $\triangle ABC$ 中，$D$ 是 $AB$ 的中点，$E$ 是 $AC$ 的中点，则 $DE \parallel BC$ 且 $DE = \frac{1}{2}BC$。

**数学内涵**：
- 中位线定理揭示了三角形中两条中点的连线与第三边之间的平行关系和数量关系。
- 它是相似三角形判定（两边成比例且夹角相等）的直接应用。
- 该定理可推广到梯形中位线：梯形中位线平行于两底且等于两底和的一半。

**证明策略**：
- 方法一：利用相似三角形——$\triangle ADE \sim \triangle ABC$（SAS 相似）。
- 方法二：构造平行四边形——延长 $DE$ 至 $F$ 使 $EF = DE$，证明四边形 $DBCF$ 是平行四边形。

## 思考过程

中位线定理的证明非常直观。由于 $D$ 是 $AB$ 的中点，$E$ 是 $AC$ 的中点，所以 $\frac{AD}{AB} = \frac{AE}{AC} = \frac{1}{2}$，且 $\angle A$ 是公共角，因此 $\triangle ADE \sim \triangle ABC$（SAS 相似）。由相似得 $\angle ADE = \angle ABC$，故 $DE \parallel BC$；且 $\frac{DE}{BC} = \frac{AD}{AB} = \frac{1}{2}$，即 $DE = \frac{1}{2}BC$。

另一种构造性的证明方法是通过延长中位线构造平行四边形，这种方法不依赖相似三角形，适合更基础的几何教学中使用。

## 证明过程

**定理**（三角形中位线定理）：在 $\triangle ABC$ 中，$D$ 是 $AB$ 的中点，$E$ 是 $AC$ 的中点，则 $DE \parallel BC$ 且 $DE = \frac{1}{2}BC$。

**证明**（相似三角形法）：

在 $\triangle ADE$ 和 $\triangle ABC$ 中：
- $\frac{AD}{AB} = \frac{AE}{AC} = \frac{1}{2}$（$D, E$ 为中点）
- $\angle DAE = \angle BAC$（公共角）

故 $\triangle ADE \sim \triangle ABC$（SAS 相似，两边成比例且夹角相等）。

由相似得：
- $\angle ADE = \angle ABC$，故 $DE \parallel BC$（同位角相等）。
- $\frac{DE}{BC} = \frac{AD}{AB} = \frac{1}{2}$，故 $DE = \frac{1}{2}BC$。

$\square$

---

**证明**（构造平行四边形法）：

延长 $DE$ 至 $F$，使 $EF = DE$，连接 $CF$。

在 $\triangle ADE$ 和 $\triangle CFE$ 中：
- $AE = CE$（$E$ 为 $AC$ 中点）
- $DE = EF$（构造）
- $\angle AED = \angle CEF$（对顶角相等）

故 $\triangle ADE \cong \triangle CFE$（SAS），得 $AD = CF$，$\angle ADE = \angle CFE$。

由于 $\angle ADE = \angle CFE$，$AD \parallel CF$。又 $AD = BD = CF$，故四边形 $DBCF$ 是平行四边形（一组对边平行且相等）。因此 $DF \parallel BC$ 且 $DF = BC$，即 $DE \parallel BC$ 且 $DE = \frac{1}{2}DF = \frac{1}{2}BC$。$\square$

## 课堂问答

**老师**：三角形中位线定理讲了什么？为什么它成立？

**学生**：结论先行：在 $\triangle ABC$ 中，若 $D,E$ 分别是 $AB,AC$ 的中点，则 $DE\parallel BC$ 且 $DE=\frac12 BC$。理由是 $\frac{AD}{AB}=\frac{AE}{AC}=\frac12$ 且 $\angle A$ 为公共角，故 $\triangle ADE\sim\triangle ABC$（SAS 相似），对应角 $\angle ADE=\angle ABC$ 给出平行，对应边给出 $DE=\frac12 BC$。

**老师（追问）**：这里的相似凭什么是"SAS"而不是"SSA"？SSA 能判定相似吗？

**学生**：因为夹角 $\angle A$ 恰好是两边 $AD,AE$ 与 $AB,AC$ 所夹的角，正是"两边成比例且夹角相等"。SSA 一般不能判定相似，它存在歧义情形，可能对应两个不同形状的三角形。本题也可不用相似：延长 $DE$ 至 $F$ 使 $EF=DE$，由 $\triangle ADE\cong\triangle CFE$ 得 $DBCF$ 是平行四边形，同样推出结论。

**老师（拓展）**：如果改成连接梯形两腰的中点呢？

**学生**：那就推广为梯形中位线定理：中位线平行于两底，且等于两底和的一半。它正是把这里 $\frac12 BC$ 的思想搬到梯形，也解释了重心把中线分成 $2:1$ 的来源。
