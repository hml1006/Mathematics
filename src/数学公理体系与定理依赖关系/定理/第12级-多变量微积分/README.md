- [多重积分的变量替换公式](./多重积分的变量替换公式.md)：换元积分时，面积（体积）会被拉伸或压缩，补偿量就是雅可比行列式的绝对值——一元换元的 $|u'(x)|$ 在高维的推广。
- [Fubini 定理](./Fubini定理.md)：算二重积分可以"先横着切再竖着切"，两种切法结果一样——累次积分可以交换次序。
- [光滑逼近定理](./光滑逼近定理.md)：只要函数连续，就能用无限光滑的函数把它"磨"得任意接近——拿一个光滑的"平均核"去局部搅匀即可。
- [逆映射定理](./逆映射定理.md)：只要一个光滑映射在某一点的 Jacobi 矩阵可逆（各个方向都没有被"压扁"），它在这点附近就能一对一地反解回来，而且反解出来的映射同样光滑。
- [中值不等式](./中值不等式.md)：多变量函数两点之间的"位移差"，绝不会超过"路上最大的变化速度"乘以"两点距离"——一维中值定理里的"某点导数"，在向量值情形要换成"整段上导数的上界"。
