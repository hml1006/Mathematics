# 三重编码模型

> **一句话大白话**：大脑用三套相对独立的方式处理数字——"看字形"（视空编码）、"念语音"（听觉言语编码）、"掂数量"（模拟数量编码），各有分工、互相替代不了。
>
> **小例子**：背"三七二十一"靠"念经官"（言语编码），比较大小时靠"掂量官"（模拟数量），读多位数靠"看字官"（视空编码）。若某条通路受损，往往只丢其中一项能力，而其他两项照常。

## 一、定理介绍

三重编码模型（Triple Code Model）由 Dehaene（1992）提出，是数学认知神经科学的核心理论。它断言人类大脑使用三种相对独立的编码方式处理数字信息：**视空数量编码**（处理阿拉伯数字串的视觉形式，服务于多位数运算与数字比较）、**听觉言语编码**（以言语序列储存算术事实，服务于数数、乘法口诀检索）和**模拟数量编码**（以近似量的方式表征数量，服务于数量估计与数感）。三种编码分别由不同的神经通路支持，在不同数学任务中各司其职。

## 二、原理思路

该模型的直接证据来自行为与神经影像研究的"双分离"现象：不同数学能力可以被定向损伤或干预单独破坏而不影响其他能力。脑成像（fMRI）显示数字比较任务主要激活双侧顶内沟（IPS），精确算术检索激活左侧颞叶语言区，多位数运算激活枕叶视觉区。脑损伤患者的认知解剖（例如顶叶损伤损害数量感却保留计数能力）与发展研究共同支持"三条独立通路"的核心直觉。

## 三、定理的严格表述

设 $U,A,M$ 分别表示视空、听觉言语、模拟数量三种编码系统。对任意数字加工任务 $T$，存在分配函数 $f_T:\{\text{task}\}\to\{U,A,M\}$，使得：

1. $T$ 主要调用 $f_T$ 所对应的单一编码系统；
2. 三种编码由不同的神经通路支持，其损伤可独立选择性地损害 $U$、$A$ 或 $M$ 所服务的任务类（双分离）；
3. 不同编码使用不同认知资源，双任务干扰实验据此可区分它们。

## 四、证明过程

**步骤1：建立模型框架。** 依据 Dehaene（1992）定义三种编码及其对应的核心脑区——视空编码对应双侧枕叶视觉区与梭状回；听觉言语编码对应左侧颞叶语言区与基底神经节；模拟数量编码对应双侧顶内沟（IPS）。

**步骤2：脑成像证据（fMRI）。** 数字比较任务（如判断"哪个更大"）显著激活 IPS；精确算术检索（乘法口诀）显著激活左侧颞叶语言区；多位数运算则激活枕叶视觉区。Piazza 等（2004）发现 IPS 活动随数字间比例距离而非绝对差变化，直接支持"心理数轴"假说。

**步骤3：脑损伤证据（认知解剖）。** 顶叶（尤其左侧 IPS）损伤导致数量感丧失，但可能保留言语计数；左侧颞叶损伤导致算术事实检索失败（如不能回答"$3\times4$"）却保留数量比较；视觉通路损伤影响多位数运算的视觉处理。

**步骤4：双任务干扰实验。** 同步进行言语任务时，精确算术（如"$8+7$"）受干扰而数量估计不受；同步进行空间任务时，数量比较受干扰而言语算术不受。这支持不同编码占用不同认知资源。

**步骤5：发展性证据。** 模拟数量编码在婴儿期即已存在；言语编码随语言能力逐步建立；视空编码在正式学习阿拉伯数字后建立。三条轨迹时序不同，进一步表明三套系统相对独立。

**结论（$\square$）**：来自脑成像、脑损伤、行为实验与发展研究的广泛证据共同支撑三重编码模型的独立性假设。

## 五、应用与意义

三重编码模型为理解数字加工的认知神经基础提供了综合框架，解释了为何某些数学能力可被选择性损伤或强化。它为计算障碍（dyscalculia）的脑机制诊断提供了理论依据，也启发了针对性的数字教育训练设计，是数学心理学与教育神经科学的关键奠基理论。
