- [Doob-Meyer 分解定理](./Doob-Meyer分解定理.md)
- [随机积分表示定理（鞅表示定理）](./鞅表示定理.md)
- [Malliavin 导数的基本性质（链式法则）](./Malliavin导数的链式法则.md)

- [Skorokhod 积分的 Itô 引理推广](./Skorokhod积分的Itô引理推广.md)
- [对偶恒等式](./对偶恒等式.md)：Malliavin 导数 $D$ 与 Skorokhod 积分 $\delta$ 互为"转置"——把 $D$ 从等式一边搬到另一边就变成 $\delta$，这就是它们的对偶等式。
- [分部积分公式](./分部积分公式.md)：在 Malliavin 计算里，"求导"可以从一个随机变量身上搬到另一个身上，代价是把它换成 Skorokhod 积分——这正是随机版本的"分部积分"。
