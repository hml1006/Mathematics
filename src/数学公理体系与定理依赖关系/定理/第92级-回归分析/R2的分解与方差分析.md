# R2 的分解与方差分析

> **一句话大白话**：把总波动拆成"模型能解释的波动"和"解释不了的残差波动"两块，$R^2$ 就是模型能解释的那一块所占的比例。
>
> **小例子**：学生成绩波动中，如果学习时间能解释其中九成，那么 $R^2 = 0.9$，剩下的一成是噪声和其他因素。

## 一、定理介绍

> **前置依赖**：线性回归与最小二乘、帽子矩阵与正交性、平方和的展开、残差性质（残差和为零）

在线性回归中，响应变量 $Y$ 的总平方和 $\text{SST}$ 可以分解为回归平方和 $\text{SSR}$ 与残差平方和 $\text{SSE}$ 之和，即 $\text{SST} = \text{SSR} + \text{SSE}$。由此决定系数定义为 $R^2 = \text{SSR}/\text{SST} = 1 - \text{SSE}/\text{SST}$，衡量回归模型对数据的拟合优度。

## 二、原理思路

关键在于最小二乘残差与拟合值的正交性。将 $Y_i$ 拆为 $\hat{Y}_i$ 与残差 $e_i$ 之和，展开平方和时交叉项因残差与拟合值正交、且残差和为零而消失，从而得到精确的平方和分解，进而构建方差分析（ANOVA）表。

## 三、定理的严格表述

设 $\text{SST} = \sum_{i=1}^n (Y_i - \bar{Y})^2$，$\text{SSR} = \sum_{i=1}^n (\hat{Y}_i - \bar{Y})^2$，$\text{SSE} = \sum_{i=1}^n (Y_i - \hat{Y}_i)^2$，则

$$
\text{SST} = \text{SSR} + \text{SSE}, \qquad R^2 = \frac{\text{SSR}}{\text{SST}} = 1 - \frac{\text{SSE}}{\text{SST}}.
$$

## 四、证明过程

1. **展开**：
   $$
   \text{SST} = \sum_i (Y_i - \hat{Y}_i + \hat{Y}_i - \bar{Y})^2 = \text{SSE} + \text{SSR} + 2\sum_i e_i(\hat{Y}_i - \bar{Y}).
   $$
2. **正交性**：$\hat{\boldsymbol{\varepsilon}}^\top \hat{\boldsymbol{Y}} = \boldsymbol{Y}^\top(\boldsymbol{I}-\boldsymbol{H})\boldsymbol{H}\boldsymbol{Y} = \boldsymbol{Y}^\top(\boldsymbol{H}-\boldsymbol{H}^2)\boldsymbol{Y} = 0$。
3. **残差和为零**：含截距时 $\sum_i e_i = 0$，故交叉项 $\sum_i e_i(\hat{Y}_i - \bar{Y}) = 0$。
4. **结论**：代入即得 $\text{SST} = \text{SSR} + \text{SSE}$，进而得 $R^2$ 的表达式。

## 五、应用与意义

$R^2$ 是衡量回归拟合优度的最常用指标，ANOVA 表给出了各平方和、自由度与均方，并与 $F$ 检验直接衔接。$R^2$ 会随变量增加而不减，因此实际中还常用对自由度惩罚的调整 $R^2$ 以及 AIC/BIC 等准则进行模型比较与选择。
