# 第78级-丢番图逼近

> 一句话级别概述：丢番图逼近研究实数（尤以无理数与代数数）用有理数逼近时的极限精度，核心结论是以 LiouVille、Roth 定理刻画代数数的逼近次数上界，以 Dirichlet 定理与连分数给出逼近的可能界。

## 级别简介

本级别研究如何用有理数 $\frac pq$ 近似实数，以及在何种精度上代数无理数可以被逼近。核心内容包括 Dirichlet 逼近定理（分母为 $N$ 时误差可达 $1/N$）、Liouville-Roth 定理（代数无理数的逼近指数不超过 $2+\varepsilon$）、连分数的最佳逼近性质，以及基于超越性的 Gelfond-Schneider 定理。

## 本级别定理

- [Dirichlet逼近定理](./Dirichlet逼近定理.md)：无理数可用分母 $\le N$ 的分数逼近到误差 $<1/N$。
- [连分数的最佳逼近性质](./连分数的最佳逼近性质.md)：连分数渐近分数是最佳有理逼近。
- [Roth定理](./Roth定理.md)：代数无理数的有理逼近指数不超过 $2+\varepsilon$。
- [Liouville定理](./Liouville定理.md)：$d$ 次代数无理数的逼近误差至少为 $c/q^d$（由此造出超越数）。
- [Gelfond-Schneider定理](./Gelfond-Schneider定理.md)：$a^b$ 对代数数 $a,b$（$b$ 无理）为超越数。

## 前置知识

本级别依赖实数系与无理数的基础、代数数与超越数概念，以及 Dirichlet 抽屉原理、连分数与极限工具。它建立在初等数论、算术基础与实数系极限理论之上。

## 后继用途

本级别为几何数论、超越数论、丢番图方程与代数数论中的有效方法提供基础，其逼近技术也用于密码学与数值计算中的逼近分析。

## 关键定理速览

- Roth 定理：代数无理数的逼近指数不能超过 $2+\varepsilon$。
- Liouville 定理：第一次证明超越数的存在，给出逼近硬度下限。
- Dirichlet 逼近定理：逼近精度的存在性保证，组合方法经典范例。
- Gelfond-Schneider 定理：超越数论中的希尔伯特问题第 7 条。
