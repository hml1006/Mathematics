# 勾股定理

> **一句话大白话**：直角三角形的两条直角边，分别做正方形，这两个正方形的面积加起来正好等于斜边那个正方形——也就是 $a^2+b^2=c^2$。
>
> **小例子**：直角边 $3$ 和 $4$，斜边就是 $5$，因为 $3^2+4^2=9+16=25=5^2$，经典的"勾三股四弦五"。

## 介绍

勾股定理（Pythagorean theorem）是几何学中最著名的定理：在直角三角形中，两条直角边的平方和等于斜边的平方，即 $a^2 + b^2 = c^2$。该定理以古希腊数学家毕达哥拉斯命名，但早在公元前 20 世纪的古巴比伦和公元前 11 世纪的中国（《周髀算经》中"勾广三，股修四，径隅五"的记载）就已经被使用。勾股定理是三角学、解析几何、向量代数等众多数学分支的基石，也是数学中证明方法最多的定理之一（约有 400 多种不同的证明）。

## 分析

**前置依赖**：三角形相似定理、Hilbert 合同公理。

**定理内容**：在直角三角形 $\triangle ABC$ 中，设直角为 $\angle C = 90^\circ$，$a = BC$，$b = AC$，$c = AB$，则 $a^2 + b^2 = c^2$。

**数学内涵**：
- 勾股定理揭示了直角三角形三边之间的定量关系，是度量几何的核心定理。
- 它的逆定理也成立：若三角形三边满足 $a^2 + b^2 = c^2$，则它是直角三角形。
- 勾股定理的推广包括：余弦定理（$c^2 = a^2 + b^2 - 2ab\cos C$）、勾股定理在向量中的形式（$|\mathbf{u}+\mathbf{v}|^2 = |\mathbf{u}|^2 + |\mathbf{v}|^2$ 当且仅当 $\mathbf{u} \perp \mathbf{v}$）。

**证明方法**：
- 面积法：通过构造面积相等的不同图形来证明。
- 相似三角形法：通过作斜边上的高，利用相似三角形的比例关系。
- 坐标法：利用两点间距离公式。

## 思考过程

勾股定理最直观的证明之一是"面积法"：构造以 $a+b$ 为边长的正方形，内部放置四个全等的直角三角形和一个小正方形（边长为 $c$），通过计算两种方式下的面积得到等式。

另一种经典的证明是用相似三角形：从直角顶点向斜边作高，将原三角形分成两个小直角三角形，它们都与原三角形相似。由相似三角形的比例关系可得 $a^2 = c \cdot p$，$b^2 = c \cdot q$（其中 $p, q$ 是斜边被高分割的两段），相加即得 $a^2 + b^2 = c(p+q) = c^2$。

## 证明过程

**定理**（勾股定理）：在直角三角形 $\triangle ABC$ 中，$\angle C = 90^\circ$，则 $a^2 + b^2 = c^2$，其中 $a = BC$，$b = AC$，$c = AB$。

**证明**（相似三角形法）：

作 $CD \perp AB$ 于 $D$（斜边上的高）。设 $AD = p$，$BD = q$，则 $p + q = c$。

在 $\triangle ABC$ 和 $\triangle ACD$ 中：
- $\angle ACB = \angle ADC = 90^\circ$
- $\angle A$ 是公共角

故 $\triangle ABC \sim \triangle ACD$（AA 相似），得

$$
\frac{AC}{AB} = \frac{AD}{AC} \Rightarrow \frac{b}{c} = \frac{p}{b} \Rightarrow b^2 = cp
$$

同理，$\triangle ABC \sim \triangle CBD$，得

$$
\frac{BC}{AB} = \frac{BD}{BC} \Rightarrow \frac{a}{c} = \frac{q}{a} \Rightarrow a^2 = cq
$$

两式相加：

$$
a^2 + b^2 = cp + cq = c(p + q) = c^2
$$

$\square$

---

**证明**（面积法——赵爽弦图）：

构造一个边长为 $a+b$ 的大正方形，内部放置四个全等的直角三角形（直角边 $a, b$，斜边 $c$），中间留出一个边长为 $c$ 的小正方形。

大正方形面积：$(a+b)^2 = a^2 + 2ab + b^2$。

四个直角三角形面积之和：$4 \times \frac{1}{2}ab = 2ab$。

小正方形面积：$c^2$。

由面积关系：$(a+b)^2 = 4 \times \frac{1}{2}ab + c^2$，即 $a^2 + 2ab + b^2 = 2ab + c^2$，故 $a^2 + b^2 = c^2$。$\square$
