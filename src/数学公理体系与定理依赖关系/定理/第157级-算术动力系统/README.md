# 第157级-算术动力系统

> 一句话级别概述：算术动力系统研究数域上的迭代：把动力系统与高度函数结合，用算术信息（高度、约化、等分布）回答轨道中有多少有理点、周期点如何分布。

## 级别简介

本级别以高度函数与 Northcott 有限性定理起步，建立典范高度与算术等分布；随后讨论良好约化、Morton-Silverman 一致有界性猜想、Baker-DeMarco 有界轨道定理，最后进入 p 进动力系统与动力系统 Mordell-Lang 猜想。

## 本级别定理

- [高度函数与 Northcott 有限性定理](./高度函数与Northcott有限性定理.md)：对数 Weil 高度 $h$ 满足：给定次数上界 $d$ 与高度上界 $B$，$\{P:h(P)\le B,\ [\mathbb Q(P):\mathbb Q]\le d\}$ 有限。
- [算术动力系统的典范高度](./算术动力系统的典范高度.md)：对次数 $d\ge2$ 的态射 $f$，$\hat h_f(P)=\lim_{n\to\infty}h(f^n(P))/d^n$ 存在，且 $\hat h_f(f(P))=d\,\hat h_f(P)$（Call-Silverman）。
- [算术等分布定理](./算术等分布定理.md)：射影空间中高度趋于 $0$ 的无穷点列在 Julia 集上按平衡测度等分布（Bilu）。
- [良好约化与算术动力系统](./良好约化与算术动力系统.md)：除有限个素点外 $f$ 有良好约化，且周期点在这些素点下约化为周期点（Silverman）。
- [Morton-Silverman 一致有界性猜想](./Morton-Silverman一致有界性猜想.md)：固定次数 $d\ge2$ 与数域 $K$，$K$ 上次数 $d$ 态射的预周期点个数应一致有界（未决猜想）。
- [Baker-DeMarco 有界轨道定理](./Baker-DeMarco有界轨道定理.md)：代数曲线上的态射族，若逃逸速率一致有界，则该族参数空间中存在稠密开集使轨道有界。
- [$p$ 进动力系统的约化与 Julia 集](./p进动力系统的约化与Julia集.md)：$p$ 进 Julia 集的填补性质与典范约化，给出非阿基米德情形下"小高度点"的分布。
- [动力系统 Mordell-Lang 猜想](./动力系统Mordell-Lang猜想.md)：半阿贝尔簇上有限生成子群的动力轨道与子簇的交应为有限个轨道的并（部分情形已证）。

## 前置知识

数域与绝对值、射影空间、Weil 高度、复动力系统与势论。

## 后继用途

为丢番图几何、算术几何中的高度方法、以及动力系统与数论交叉问题提供框架。

## 关键定理速览

- Northcott：次数与高度双上界 ⇒ 有限。
- 典范高度满足分解式 ĥ(f(P)) = d·ĥ(P)。
- Bilu 等分布：小高度点在 Julia 集上等分布。
- 一致有界性仍是猜想，仅有部分结果。
- p 进 Julia 集的填补性质刻画非阿基米德动力。
