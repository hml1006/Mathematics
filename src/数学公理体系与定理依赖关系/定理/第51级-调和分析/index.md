# 第51级-调和分析

本目录收录以下定理：

- [Bochner-Riesz 平均](./Bochner-Riesz平均.md)
- [Fourier 乘子定理（Mikhlin 乘子定理）](./Fourier乘子定理.md)
- [Fourier 变换的 $L^2$ 理论（Plancherel 定理）](./Fourier变换的L2理论.md)
- [Hardy 空间 $H^p$ 理论](./Hardy空间理论.md)
- [Kakeya 猜想与 Besicovitch 集](./Kakeya猜想.md)
- [Littlewood-Paley 分解理论](./Littlewood-Paley分解.md)
- [Calderón-Zygmund 奇异积分算子理论](./奇异积分算子理论.md)
- [Plancherel 定理](./Plancherel定理.md)：傅里叶变换在平方可积函数上"不改变长度"——它把 $L^2$ 空间里的每个函数旋到一个新函数，二者能量（平方积分）一样大，而且变换可逆；于是 $L^2$ 上的傅里叶变换是一个完美的"旋转"。
- [Young 卷积不等式](./Young卷积不等式.md)：两个函数卷积之后，它的"平均大小"会被两个因子的可积性同时卡住——只要把三个指数满足 $\frac1p+\frac1q=1+\frac1r$，卷积的 $L^r$ 范数就不超过两个因子各自 $L^p$、$L^q$ 范数的乘积。
- [覆盖引理](./覆盖引理.md)：一堆互相重叠的球看着乱，其实里头总能挑出一小撮"互不重叠"的球，把它们各自放大三倍就能盖住原来所有的球——重叠是假的，不交的骨架才是真的。
- [Fourier变换与逆变换公式](./Fourier变换与逆变换公式.md)：把函数拆成不同频率的波，每个频率配一个系数；逆变换公式说，用这些系数把波重新叠回去，能原封不动地还原原来的函数。
- [Parseval恒等式](./Parseval恒等式.md)：用函数本身算"能量"和用它的频率系数算"能量"，结果一样；这不过是勾股定理在无穷维空间里的版本。
- [Riemann-Lebesgue引理](./Riemann-Lebesgue引理.md)：一个可积函数的高频傅里叶分量一定越来越小，振荡越快、正负抵消越彻底，最终任何频率上的振幅都趋于零。
