# 半角公式

## 介绍

半角公式是倍角公式的逆用，用 $\cos\theta$ 表示 $\sin^2\frac{\theta}{2}$ 和 $\cos^2\frac{\theta}{2}$：$\sin^2\frac{\theta}{2} = \frac{1 - \cos\theta}{2}$，$\cos^2\frac{\theta}{2} = \frac{1 + \cos\theta}{2}$。这些公式在积分换元、三角恒等式化简和半角问题求解中有重要应用。

## 分析

**前置依赖**：倍角公式。

**定理内容**：对任意 $\theta$，
- $\sin^2\frac{\theta}{2} = \frac{1 - \cos\theta}{2}$
- $\cos^2\frac{\theta}{2} = \frac{1 + \cos\theta}{2}$
- $\tan\frac{\theta}{2} = \frac{1 - \cos\theta}{\sin\theta} = \frac{\sin\theta}{1 + \cos\theta}$

**数学内涵**：
- 半角公式是倍角公式 $\cos 2\alpha = 1 - 2\sin^2\alpha = 2\cos^2\alpha - 1$ 中令 $\alpha = \frac{\theta}{2}$ 得到。
- 半角公式在积分中常用于"万能代换"：$t = \tan\frac{x}{2}$。

## 思考过程

半角公式与倍角公式本质上是同一关系的两面——倍角公式将 $\cos 2\alpha$ 表示为 $\sin^2\alpha$ 或 $\cos^2\alpha$ 的函数，而半角公式则反向将 $\sin^2\frac{\theta}{2}$ 和 $\cos^2\frac{\theta}{2}$ 表示为 $\cos\theta$ 的函数。理解这一"互逆"关系，是掌握半角公式的关键。

一个值得特别注意的问题是符号判断。半角公式给出的 $\sin^2\frac{\theta}{2}$ 和 $\cos^2\frac{\theta}{2}$ 是平方形式，因此本身不涉及符号问题。但当需要求 $\sin\frac{\theta}{2}$ 或 $\cos\frac{\theta}{2}$ 本身时，必须根据 $\frac{\theta}{2}$ 所在的象限确定正负号。例如，$\sin\frac{\theta}{2} = \pm\sqrt{\frac{1-\cos\theta}{2}}$，符号由 $\frac{\theta}{2}$ 的终边位置决定。这一细节在解题中极易被忽略，需要格外留意。

半角公式在积分计算中有着极为重要的应用，最著名的当属"万能代换"：令 $t = \tan\frac{x}{2}$，则 $\sin x = \frac{2t}{1+t^2}$，$\cos x = \frac{1-t^2}{1+t^2}$，$\mathrm{d}x = \frac{2}{1+t^2}\mathrm{d}t$。这一代换可以将任意三角有理函数的积分化为有理函数的积分，是积分学中最为强大的技巧之一。其核心正是半角公式中 $\tan\frac{\theta}{2}$ 的两种等价形式。

## 证明过程

**定理**（半角公式）：

$$
\sin^2\frac{\theta}{2} = \frac{1 - \cos\theta}{2},\quad \cos^2\frac{\theta}{2} = \frac{1 + \cos\theta}{2}
$$

**证明**：

由倍角公式 $\cos 2\alpha = 1 - 2\sin^2\alpha$，令 $\alpha = \frac{\theta}{2}$，得

$$
\cos\theta = 1 - 2\sin^2\frac{\theta}{2} \Rightarrow \sin^2\frac{\theta}{2} = \frac{1 - \cos\theta}{2}
$$

由 $\cos 2\alpha = 2\cos^2\alpha - 1$，得

$$
\cos\theta = 2\cos^2\frac{\theta}{2} - 1 \Rightarrow \cos^2\frac{\theta}{2} = \frac{1 + \cos\theta}{2}
$$

对于正切：

$$
\tan\frac{\theta}{2} = \frac{\sin\frac{\theta}{2}}{\cos\frac{\theta}{2}} = \frac{\sin\frac{\theta}{2}\cos\frac{\theta}{2}}{\cos^2\frac{\theta}{2}} = \frac{\frac{1}{2}\sin\theta}{\frac{1 + \cos\theta}{2}} = \frac{\sin\theta}{1 + \cos\theta}
$$

同理，$\tan\frac{\theta}{2} = \frac{1 - \cos\theta}{\sin\theta}$。$\square$
