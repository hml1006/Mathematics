# 夹逼定理

## 介绍

夹逼定理（Squeeze theorem）是极限理论中判定数列极限的重要工具：若 $a_n \leq b_n \leq c_n$ 且 $\lim a_n = \lim c_n = L$，则 $\lim b_n = L$。该定理不要求 $b_n$ 的表达式，只需将其夹在两个已知极限的数列之间即可。

## 分析

**前置依赖**：极限定义。

## 思考过程

夹逼定理（也称"三明治原理"或"迫敛性"）的直观理解非常自然：如果数列 $b_n$ 被夹在 $a_n$ 和 $c_n$ 之间，而 $a_n$ 和 $c_n$ 都趋近于同一个极限 $L$，那么 $b_n$ 也被迫趋近于 $L$——就像三明治的馅料被两片面包夹住一样。

在求极限的实践中，夹逼定理具有极高的实用价值。许多无法直接计算极限的数列，可以通过寻找合适的放缩不等式，将其夹在两个已知极限的数列之间来求解。经典应用包括：

- $\lim_{n\to\infty} \frac{\sin n}{n} = 0$（由 $-\frac{1}{n} \leq \frac{\sin n}{n} \leq \frac{1}{n}$ 得证）
- $\lim_{n\to\infty} \sqrt[n]{n} = 1$（通过二项式展开放缩）
- 重要极限 $\lim_{x\to 0} \frac{\sin x}{x} = 1$ 的证明也依赖于夹逼原理

## 证明过程

**证明**：对任意 $\varepsilon > 0$，$\exists N_1$，$n > N_1$ 时 $|a_n - L| < \varepsilon$，即 $L - \varepsilon < a_n < L + \varepsilon$。$\exists N_2$，$n > N_2$ 时 $|c_n - L| < \varepsilon$，即 $L - \varepsilon < c_n < L + \varepsilon$。取 $N = \max(N_1, N_2)$，则 $n > N$ 时 $L - \varepsilon < a_n \leq b_n \leq c_n < L + \varepsilon$，故 $|b_n - L| < \varepsilon$。$\square$
