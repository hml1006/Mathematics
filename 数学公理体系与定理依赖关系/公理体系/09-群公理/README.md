# 群公理

## 概述

群是抽象代数中最基本的代数结构之一。群公理定义了集合 G 上的二元运算 · 满足封闭性、结合律、单位元和逆元四条性质。群的概念广泛应用于数学、物理学、化学等领域。

## 公理列表

| 编号 | 公理名称 | 简要描述 | 文档 |
|------|----------|----------|------|
| G1 | 封闭性 | 对任意 a,b∈G，a·b∈G | [封闭性](封闭性.md) |
| G2 | 结合律 | (a·b)·c = a·(b·c) | [结合律](结合律.md) |
| G3 | 单位元 | 存在 e∈G 使得 a·e = e·a = a | [单位元](单位元.md) |
| G4 | 逆元 | 对每个 a∈G，存在 a⁻¹∈G 使得 a·a⁻¹ = a⁻¹·a = e | [逆元](逆元.md) |
