# 第81级-加性组合

本目录收录以下定理：

- [Ruzsa 三角不等式](./Ruzsa三角不等式.md)
- [Plünnecke 不等式](./Plünnecke不等式.md)
- [Roth 定理](./Roth定理.md)
- [Szemerédi 定理](./Szemerédi定理.md)
- [Freiman 定理](./Freiman定理.md)
- [Ruzsa 建模引理](./Ruzsa建模引理.md)：一个"和集不大"的整数集，总能在适当放大后"缩小取模"成某个 $\mathbb{Z}_p$ 里的集合，而加法的所有关系被完整保留——于是可以把 $\mathbb{Z}$ 上的难题搬到有限的钟表盘 $\mathbb{Z}_p$ 上研究。
- [Bogolyubov 引理](./Bogolyubov引理.md)：只要一个集合密度不低，那么把"两次和减两次差"反复组合起来，就必然盖住一大块"频率一致"的区域（Bohr 集）——零散的加法结构里藏着规则的周期结构。
- [Plünnecke-Ruzsa 引理](./Plünnecke-Ruzsa引理.md)：如果 $A$ 与自己相加只放大到 $K$ 倍（小和集），那么把 $A$ 与自己相加、相减任意多次，也只会放大到 $K$ 的幂倍——"小和集"这一性质在反复相加下稳定不变。
- [超图正则性引理](./超图正则性引理.md)：任意大的 $k$-均匀超图，都能被切成不多块，使得"绝大多数 $k$ 块组合"内部的边分布像随机一样均匀——图的正则引理被推广到"边是 $k$ 元组"的高阶情形。
- [计数引理](./计数引理.md)：若几块顶点之间的边分布"像随机的"，那么跨越它们的三角形（小图案）数目就几乎等于"按密度估算"的期望值——正则性让局部随机保证整体计数可预测。
- [Szemerédi正则引理](./Szemerédi正则引理.md)：任何足够大的图，都能被切成"有界多块"，使得绝大多数块对之间的边像随机图一样均匀——可谓"万图皆近似随机"。
- [全方差公式](./全方差公式.md)：一个随机变量的"总起伏"可以拆成两块——"在已知信息之下仍存在的平均起伏"，加上"已知信息的平均值本身就是随机所带来的起伏"；两块之和恰好等于原来的总起伏。
