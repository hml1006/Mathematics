# 命题逻辑公理

## 概述

命题逻辑公理是命题演算的形式公理体系，通常采用三条公理模式加上一条推理规则（肯定前件）。这一体系由 Hilbert 和 Ackermann 等人发展，是数理逻辑的基础组成部分。

命题逻辑研究命题之间的逻辑关系，使用逻辑连接词（如 ¬, →, ∧, ∨）来构建复合命题。这里的公理体系仅使用 ¬（否定）和 →（蕴涵）作为基本连接词，其他连接词通过定义引入。

## 推理规则

- **肯定前件（Modus Ponens）**：从 φ 和 φ → ψ 可推出 ψ
- 这是唯一一条推理规则，所有证明都基于公理和 MP 规则

## 完备性

命题逻辑公理体系是**完备的**：所有重言式（tautology）都可以在这一体系中证明。这是 Gödel 完备性定理在命题逻辑中的体现。
