- [递归定理（Kleene 递归定理）](./递归定理（Kleene递归定理）.md)

- [s-m-n 定理](./s-m-n定理.md)：可以把一部分输入“焊死”进程序里——给定一个接受 $m+n$ 个数的程序，就能可计算地（而且一对一地）造出一个新程序的编号，这个新程序只接受 $n$ 个数，但会自动把 $m$ 个固定参数补在前面，再运行原程序。
- [程序填充引理](./程序填充引理.md)：同一个可计算函数有无穷多个"换汤不换药"的程序——在程序里塞进任意多段无用代码（空操作或永远执行不到的死代码）并不改变它的功能，因此每个部分可计算函数都有无穷多个编号。
