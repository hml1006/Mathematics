# 第17级-实分析

本目录收录以下定理：

- [一致连续定理](./一致连续定理.md)
- [勒贝格控制收敛定理](./勒贝格控制收敛定理.md)
- [单调收敛定理](./单调收敛定理.md)
- [卢津定理](./卢津定理.md)
- [叶戈罗夫定理](./叶戈罗夫定理.md)
- [实数完备性定理的等价性](./实数完备性定理的等价性.md)
- [有界变差函数](./有界变差函数.md)
- [法图引理](./法图引理.md)
- [海涅-博雷尔定理](./海涅-博雷尔定理.md)
- [绝对连续函数](./绝对连续函数.md)
- [里斯-费舍尔定理](./里斯-费舍尔定理.md)
- [里斯表示定理](./里斯表示定理.md)
- [Hölder 不等式](./Hölder不等式.md)：函数乘积的积分，被"一个函数的 $p$ 次方积分"和"另一个函数的 $q$ 次方积分"以 $\frac1p+\frac1q=1$ 的方式共同控制住。
- [Jordan 分解定理](./Jordan分解定理.md)：一个可正可负的"符号测度"，总能唯一地拆成"正的部分"减去"负的部分"，而且正负两部分各自住在互不相交的两块地盘上。
- [Lebesgue 单调函数可微定理](./Lebesgue单调函数可微定理.md)：单调函数再"毛糙"，也几乎处处是光滑的——不可导的点加起来"没有长度"。
- [Minkowski 不等式](./Minkowski不等式.md)：$L^p$ 意义下的"长度"满足三角形不等式——两个函数之和的长度，不超过它们各自长度之和。
- [Hahn分解定理](./Hahn分解定理.md)：一个可以取正、也可以取负的"符号测度"，总能被一刀切成两块地盘：在一块上它从不取负值（正集），在另一块上它从不取正值（负集）。
- [Rademacher 定理](./Rademacher定理.md)：Lipschitz 函数纵使"起皱打折"，褶皱也只能落在没有体积的极小集合上——它在几乎每一点都可微。
