# 和差化积公式

> **一句话大白话**：把两个三角函数的“加减式子”变成“乘式子”，相当于把两股波合成或拆开成一股波。
>
> **小例子**：$\sin30^\circ+\sin0^\circ=2\sin15^\circ\cos15^\circ$。右端 $2\sin15^\circ\cos15^\circ=\sin30^\circ=\frac12$，而左端 $\frac12+0=\frac12$，两边对得上。

## 介绍

和差化积公式将三角函数的和或差转化为乘积形式，是三角恒等变换中最有力的工具之一。例如，$\sin\alpha + \sin\beta = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$。这些公式在积分计算、解三角方程以及信号处理等领域有广泛应用。

## 分析

**前置依赖**：和角公式。

**定理内容**：
- $\sin\alpha + \sin\beta = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$
- $\sin\alpha - \sin\beta = 2\cos\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$
- $\cos\alpha + \cos\beta = 2\cos\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$
- $\cos\alpha - \cos\beta = -2\sin\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$

**证明策略**：在和角公式中令 $A = \frac{\alpha+\beta}{2}$，$B = \frac{\alpha-\beta}{2}$，则 $\alpha = A+B$，$\beta = A-B$，代入和角公式展开再合并。

## 思考过程

和差化积公式实现了从"加法"到"乘法"的转换，这一变换在三角学中具有里程碑式的意义。将两个三角函数的和或差转化为乘积形式，往往能揭示出隐藏在三角函数表达式中的周期性和对称性结构。

这一公式的推导思路巧妙而简洁：通过引入两个新变量 $A = \frac{\alpha+\beta}{2}$ 和 $B = \frac{\alpha-\beta}{2}$，将原来的 $\alpha$ 和 $\beta$ 表示为 $A+B$ 和 $A-B$，然后利用和角公式展开，正负项恰好相消或相加，得到简洁的乘积形式。这种"变量替换"的思路本身就是一种重要的数学思想方法。

在解三角方程时，和差化积公式能将 $\sin\alpha + \sin\beta = 0$ 这样的方程转化为 $2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2} = 0$，从而转化为两个更简单的方程分别求解。在积分计算中，和差化积能将不易积分的形式转化为容易积分的形式。此外，这组公式还有一套广为流传的记忆口诀：

- **正加正，正在前**：$\sin\alpha + \sin\beta = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$
- **正减正，余在前**：$\sin\alpha - \sin\beta = 2\cos\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$
- **余加余，余并肩**：$\cos\alpha + \cos\beta = 2\cos\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$
- **余减余，负正弦**：$\cos\alpha - \cos\beta = -2\sin\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$

这四句口诀概括了四个公式的规律，其中"正"指正弦，"余"指余弦，口诀既说明了结果中乘积的形式，也暗示了系数的符号。

## 证明过程

**定理**（和差化积公式）：

对任意 $\alpha, \beta$：
$$
\sin\alpha + \sin\beta = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}
$$

**证明**：

设 $A = \frac{\alpha+\beta}{2}$，$B = \frac{\alpha-\beta}{2}$，则 $\alpha = A + B$，$\beta = A - B$。

$$
\begin{aligned}
\sin\alpha + \sin\beta &= \sin(A+B) + \sin(A-B) \\
&= (\sin A\cos B + \cos A\sin B) + (\sin A\cos B - \cos A\sin B) \\
&= 2\sin A\cos B = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}
\end{aligned}
$$

类似地：

$$
\begin{aligned}
\sin\alpha - \sin\beta &= \sin(A+B) - \sin(A-B) = 2\cos A\sin B = 2\cos\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2} \\
\cos\alpha + \cos\beta &= \cos(A+B) + \cos(A-B) = 2\cos A\cos B = 2\cos\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2} \\
\cos\alpha - \cos\beta &= \cos(A+B) - \cos(A-B) = -2\sin A\sin B = -2\sin\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}
\end{aligned}
$$

$\square$
