# 实数公理

## 概述

实数公理是刻画实数集 ℝ 的完整公理体系，通常包含三组公理：域公理、序公理和完备性公理。这组公理完全刻画了实数结构，使得 ℝ 成为唯一的完备有序域（在同构意义下）。

实数公理体系是数学分析（微积分）的基础。在实数公理建立之前，微积分依赖几何直观，缺乏严格的逻辑基础。19 世纪，经过 Cauchy、Weierstrass、Dedekind、Cantor 等人的努力，实数被严格定义，微积分被"算术化"，奠定了现代分析学的基础。

## 公理列表

| 编号 | 公理名称 | 简要描述 | 文档 |
|------|----------|----------|------|
| R1 | 域公理 | (ℝ,+,·) 构成域：加法交换律、结合律、逆元；乘法交换律、结合律、逆元；分配律 | [域公理](域公理.md) |
| R2 | 序公理 | (ℝ,<) 构成全序集，且序与运算相容 | [序公理](序公理.md) |
| R3 | 完备性公理（确界原理） | ℝ 的非空有上界子集必有上确界 | [完备性公理（确界原理）](完备性公理（确界原理）.md) |
| R4 | Archimedes 性质 | 对任意正实数 x，存在自然数 n 使得 n > x | [Archimedes性质](Archimedes性质.md) |

## 公理间的关系

- **域公理** 规定了 ℝ 上的代数结构
- **序公理** 规定了 ℝ 上的序结构
- **完备性公理** 是实数公理的核心，它区分了 ℝ 和 ℚ（有理数也满足域公理和序公理，但不满足完备性公理）
- **Archimedes 性质** 可以从完备性公理推导出，因此严格来说是定理而非公理，但在此列出以强调其重要性

## 历史意义

实数公理体系的建立完成了微积分的严格化工作，解决了困扰数学家多年的"无穷小"问题。实数公理使得极限理论、连续性、可微性等概念都可以建立在严格的逻辑基础上，无需依赖几何直觉或模糊的"无穷小"概念。
