# 第102级-大偏差理论

本目录收录以下定理：

- [Cramér定理](./Cramér定理.md)
- [Gärtner-Ellis定理](./Gärtner-Ellis定理.md)
- [Schilder定理](./Schilder定理.md)
- [Varadhan引理](./Varadhan引理.md)
- [Freidlin-Wentzell定理](./Freidlin-Wentzell定理.md)
- [切比雪夫型指数不等式](./切比雪夫型指数不等式.md)：把马尔可夫不等式用到指数函数 $e^{\theta X}$ 上，再对参数 $\theta$ 取最优，就得到尾部概率的指数型上界。
- [Pinelis 极大不等式](./Pinelis极大不等式.md)：对一列有界的鞅差，不只是最后一项的部分和，连整个部分和序列在任意时刻达到过的最大值，都以指数速度远离零，而且界的形式与 Hoeffding 不等式完全一致。
