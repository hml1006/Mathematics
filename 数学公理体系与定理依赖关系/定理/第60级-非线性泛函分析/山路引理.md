# 山路引理

## 一、定理介绍

山路引理（Mountain Pass Theorem）由 Ambrosetti 与 Rabinowitz 于 1973 年提出，是非线性泛函分析中变分方法最基本、最重要的定理之一。它将非线性偏微分方程弱解的存在性问题转化为 Banach 空间上泛函临界点的存在性问题。

定理的直观图景是：若泛函 $I$ 在原点处形成"山谷"，在某点 $e$ 处也较低，而在原点与 $e$ 之间的所有路径上必存在"山峰"（高于二者的点），则在适当紧性条件下，存在一条临界高度的"山路"，其顶点恰为 $I$ 的临界点。

山路引理开创了大范围变分方法的现代理论，成为研究半线性椭圆方程、Hamilton 系统、波动方程、几何变分问题等的核心工具。

## 二、原理思路

山路引理的核心思想可以归纳为以下几点：

1. **几何条件**：原点是局部极小值，且存在远离原点的点 $e$ 使 $I(e)$ 低于 $I(0)$，则 $0$ 与 $e$ 之间的任意连续路径必穿越一道"山脊"。

2. **极小极大方法**：考虑所有连接 $0$ 与 $e$ 的连续路径构成的集合 $\Gamma$，定义"山脊高度"
$$c = \inf_{\gamma \in \Gamma} \max_{t \in [0,1]} I(\gamma(t)).$$
关键问题在于 $c$ 这个值是否对应于真实的临界点。

3. **紧性恢复**：通过 (PS) 条件（Palais-Smale 条件）弥补无穷维空间中单位球非紧的缺陷，使极小化序列收敛到临界点。

4. **形变引理**：若 $c$ 不是临界值，则可以利用负梯度流将泛函值降低，从而与 $c$ 的极小性矛盾，故 $c$ 必为临界值。

## 三、定理的严格表述

设 $X$ 是 Banach 空间，$I \in C^1(X, \mathbb{R})$。假设：

(i) **几何条件**：存在 $\rho, \alpha > 0$ 及 $e \in X$，$\|e\| > \rho$，使得
$$I(u) \geq \alpha \quad \text{当 } \|u\| = \rho,$$
且 $I(0) = 0$，$I(e) < 0$。

(ii) **Palais-Smale 条件**：任意满足 $I(u_n)$ 有界且 $I'(u_n) \to 0$（强收敛到 $0$）的序列 $\{u_n\} \subset X$ 都有收敛子列。

定义路径族
$$\Gamma = \{\gamma \in C([0,1], X) \mid \gamma(0) = 0,\ \gamma(1) = e\},$$
以及"山路值"
$$c = \inf_{\gamma \in \Gamma} \max_{t \in [0,1]} I(\gamma(t)).$$

则 $c \geq \alpha$，且 $c$ 是 $I$ 的临界值，即存在 $u^* \in X$ 使得
$$I(u^*) = c, \quad I'(u^*) = 0.$$

## 四、证明过程

**步骤 1：$c \geq \alpha$ 的证明**

对任意 $\gamma \in \Gamma$，由于 $\gamma(0) = 0$，$\gamma(1) = e$ 且 $\|e\| > \rho > 0$，由连续性，存在 $t_0 \in (0,1)$ 使 $\|\gamma(t_0)\| = \rho$。由几何条件，$I(\gamma(t_0)) \geq \alpha$，故 $\max_{t} I(\gamma(t)) \geq \alpha$，从而 $c \geq \alpha > 0$。

**步骤 2：构造极小化序列**

取 $\{\gamma_n\} \subset \Gamma$ 使 $\max_t I(\gamma_n(t)) \to c$。需证明 $c$ 是临界值。

**步骤 3：Ekeland 变分原理的应用**

由 Ekeland 变分原理可以构造近似极小路径 $\tilde\gamma_n$，使得沿该路径存在 $u_n = \tilde\gamma_n(t_n)$ 满足
$$I(u_n) \to c, \quad \|I'(u_n)\| \to 0.$$
具体地，在 $\Gamma$ 上赋予一致度量后，对泛函 $J(\gamma) = \max_t I(\gamma(t))$ 应用 Ekeland 原理，得到近似最优路径，并利用形变引理导出 $u_n$。

**步骤 4：(PS) 条件的应用**

序列 $\{u_n\}$ 满足 $I(u_n) \to c$（有界）且 $I'(u_n) \to 0$，由 (PS) 条件，存在子列（仍记为 $u_n$）和 $u^* \in X$ 使 $u_n \to u^*$。由 $I \in C^1$，
$$I(u^*) = c, \quad I'(u^*) = 0.$$

**步骤 5：反证法（标准证明）**

假设 $c$ 不是临界值，即 $K_c = \{u \in X \mid I(u) = c,\ I'(u) = 0\} = \emptyset$，其中 $K_c$ 是临界点集。

由形变引理（Deformation Lemma），存在 $\varepsilon > 0$ 与同胚 $\eta: X \to X$，满足：
- $\eta(u) = u$ 当 $I(u) \notin [c - \varepsilon, c + \varepsilon]$；
- $I(\eta(u)) \leq c - \varepsilon$ 当 $I(u) \in [c - \bar\varepsilon, c + \bar\varepsilon]$（其中 $0 < \bar\varepsilon < \varepsilon$）。

取 $\gamma \in \Gamma$ 使 $\max_t I(\gamma(t)) \leq c + \bar\varepsilon$。考虑 $\tilde\gamma = \eta \circ \gamma$，则 $\tilde\gamma(0) = 0$，$\tilde\gamma(1) = e$，故 $\tilde\gamma \in \Gamma$。

但对任意 $t$，若 $I(\gamma(t)) \leq c - \varepsilon$，则 $I(\tilde\gamma(t)) = I(\eta(\gamma(t))) \leq I(\gamma(t)) \leq c - \varepsilon$；若 $I(\gamma(t)) \geq c - \bar\varepsilon$，则 $I(\gamma(t)) \in [c - \bar\varepsilon, c + \bar\varepsilon]$，由形变性质 $I(\tilde\gamma(t)) \leq c - \varepsilon$。故
$$\max_t I(\tilde\gamma(t)) \leq c - \varepsilon < c,$$
与 $c$ 的定义矛盾。故 $K_c \neq \emptyset$，即 $c$ 是临界值。$\square$

## 五、应用与意义

**理论意义**：

1. **大范围变分方法的基石**：山路引理是极小极大方法中最基本的存在性定理，开启了无需全局凸性也能获得临界点的思路。

2. **从几何到存在的桥梁**：仅需泛函的几何性质与紧性条件，无需显式求解即可获得临界点，是变分法的核心思想体现。

**应用领域**：

1. **半线性椭圆方程**：考虑
$$-\Delta u = f(u), \quad u \in H_0^1(\Omega),$$
当 $f$ 满足适当增长条件（如超线性 Ambrosetti-Rabinowitz 条件 $0 < \mu F(s) \leq s f(s)$）时，对应能量泛函
$$I(u) = \frac{1}{2}\int_\Omega |\nabla u|^2 dx - \int_\Omega F(u)\, dx$$
满足山路几何条件，从而得到非平凡弱解。

2. **Hamilton 系统周期解**：用于证明 Hamilton 系统周期解的存在性。

3. **几何变分问题**：在 Yamabe 问题、极小曲面、调和映射等几何问题中提供临界点存在性。

4. **非线性波动与 Schrödinger 方程**：用于寻找孤立波解、驻波解。

**发展**：山路引理有许多推广，包括局部山路引理、对称山路引理、喷泉定理（给出无穷多解）、无界泛函的广义山路引理等，构成非线性泛函分析的重要工具体系。
