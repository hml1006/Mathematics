# 格林定理

> **一句话大白话**：看一块平面区域里的“旋转总强度”，其实不用算里面，只沿它的边界绕一圈就全知道——里面跑出的旋度，等于边界上的总量。
>
> **小例子**：对区域 $D$，$\oint_{\partial D}P\,dx+Q\,dy=\iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dA$，把沿边界的曲线积分换算成里面的二重积分。

## 介绍

格林定理（Green's Theorem）由英国数学家乔治·格林（George Green）于1828年在其著作《论数学分析在电磁理论中的应用》中提出，是向量微积分中的基本定理之一。该定理建立了平面区域上的二重积分与其边界上的曲线积分之间的联系，是斯托克斯定理和散度定理的二维特例。格林定理在电磁学、流体力学、复分析等领域有广泛应用。

## 分析

**前置依赖**：二重积分、曲线积分、微积分基本定理（牛顿-莱布尼茨公式）、区域分解

**定理内容**：设 $D$ 是 $\mathbb{R}^2$ 中的有界区域，其边界 $\partial D$ 是分段光滑的简单闭曲线，方向取正向（逆时针）。若 $P(x,y)$ 和 $Q(x,y)$ 在包含 $D$ 的开区域上具有连续偏导数，则
$$\oint_{\partial D} P\,dx + Q\,dy = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right) dA$$

**等价形式**：
$$\oint_{\partial D} \mathbf{F}\cdot d\mathbf{r} = \iint_D (\nabla\times\mathbf{F})\cdot\mathbf{k}\,dA$$
其中 $\mathbf{F}=(P,Q)$，$\mathbf{k}$ 是 $z$ 轴方向的单位向量。

**前置知识**：
- 二重积分的定义和性质
- 微积分基本定理（牛顿-莱布尼茨公式）

**数学内涵**：
格林定理是微积分基本定理在二维空间中的推广。它将边界上的积分（曲线积分）与内部的积分（二重积分）联系起来，体现了"整体等于边界之和"的深刻思想。该定理同时也揭示了"旋度"的积分含义。

## 思考过程

格林定理的证明通常分两步：先证明对 $x$ 型区域和 $y$ 型区域分别成立，再通过区域分解推广到一般区域。

对于 $x$ 型区域 $D=\{(x,y)\mid a\le x\le b,\varphi_1(x)\le y\le\varphi_2(x)\}$，考虑
$$\iint_D\frac{\partial P}{\partial y}dA = \int_a^b\int_{\varphi_1(x)}^{\varphi_2(x)}\frac{\partial P}{\partial y}dy\,dx = \int_a^b[P(x,\varphi_2(x))-P(x,\varphi_1(x))]dx$$

而边界积分 $-\oint_{\partial D}P\,dx$ 正好等于上式右边。类似地，对 $y$ 型区域可证 $\iint_D\frac{\partial Q}{\partial x}dA=\oint_{\partial D}Q\,dy$。

## 证明过程

**证明**：

**第一步：证明对 $x$ 型区域成立。**

设 $D$ 是 $x$ 型区域：
$$D=\{(x,y)\mid a\le x\le b,\ \varphi_1(x)\le y\le\varphi_2(x)\}$$
其中 $\varphi_1,\varphi_2$ 在 $[a,b]$ 上连续。

计算二重积分：
$$\iint_D\frac{\partial P}{\partial y}dA = \int_a^b\int_{\varphi_1(x)}^{\varphi_2(x)}\frac{\partial P}{\partial y}dy\,dx = \int_a^b[P(x,\varphi_2(x))-P(x,\varphi_1(x))]dx$$

另一方面，计算边界曲线积分 $-\oint_{\partial D}P\,dx$。边界 $\partial D$ 由四部分组成：
- 下边界 $y=\varphi_1(x)$，$x$ 从 $a$ 到 $b$（正向为右）
- 右边界 $x=b$，$y$ 从 $\varphi_1(b)$ 到 $\varphi_2(b)$（正向为上）
- 上边界 $y=\varphi_2(x)$，$x$ 从 $b$ 到 $a$（正向为左）
- 左边界 $x=a$，$y$ 从 $\varphi_2(a)$ 到 $\varphi_1(a)$（正向为下）

在右边界和左边界上，$dx=0$，因此
$$-\oint_{\partial D}P\,dx = -\left(\int_a^b P(x,\varphi_1(x))dx + \int_b^a P(x,\varphi_2(x))dx\right)$$
$$= \int_a^b[P(x,\varphi_2(x))-P(x,\varphi_1(x))]dx$$

因此
$$\iint_D\frac{\partial P}{\partial y}dA = -\oint_{\partial D}P\,dx$$
即
$$-\iint_D\frac{\partial P}{\partial y}dA = \oint_{\partial D}P\,dx$$

**第二步：证明对 $y$ 型区域成立。**

类似地，对 $y$ 型区域 $D=\{(x,y)\mid c\le y\le d,\ \psi_1(y)\le x\le\psi_2(y)\}$，可证
$$\iint_D\frac{\partial Q}{\partial x}dA = \oint_{\partial D}Q\,dy$$

**第三步：合并结果。**

若 $D$ 既是 $x$ 型又是 $y$ 型区域，则
$$\iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dA = \iint_D\frac{\partial Q}{\partial x}dA - \iint_D\frac{\partial P}{\partial y}dA = \oint_{\partial D}Q\,dy + \oint_{\partial D}P\,dx = \oint_{\partial D}P\,dx+Q\,dy$$

对于一般区域，可将其分解为有限个既是 $x$ 型又是 $y$ 型的小区域，在每个小区域上应用格林定理再求和，内部边界上的积分相互抵消，最终得到整体结果。

$\square$

## 课堂问答

**老师**：平面区域内部的旋度积分与边界环量有何联系？

**学生**：取正向边界时两者相等：
$$\oint_{\partial D}P\,dx+Q\,dy=\iint_D\Big(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\Big)dA .$$
它是牛顿–莱布尼茨公式在二维的推广，也是斯托克斯定理的平面特例。

**老师（追问）**：怎么证明一般区域？

**学生**：先对 $x$ 型区域 $D=\{a\le x\le b,\ \varphi_1(x)\le y\le\varphi_2(x)\}$ 证一半：由累次积分
$$\iint_D\frac{\partial P}{\partial y}dA=\int_a^b\big[P(x,\varphi_2(x))-P(x,\varphi_1(x))\big]dx=-\oint_{\partial D}P\,dx,$$
其中左右两侧竖边上 $dx=0$ 不贡献。同理对 $y$ 型区域得 $\iint_DQ_x\,dA=\oint_{\partial D}Q\,dy$。一般区域分解为有限个既是 $x$ 型又是 $y$ 型的小区域，内部公共边界方向相反、积分两两抵消，求和即得。

**老师（拓展）**：为什么说它是另两个定理的特例？

**学生**：取 $\mathbf{F}=(P,Q)$，格林定理即 $\oint\mathbf{F}\cdot d\mathbf{r}=\iint_D(\nabla\times\mathbf{F})\cdot\mathbf{k}\,dA$。它既是斯托克斯定理在平面上的特例，也可组合出二维散度定理形式。三者统一为广义斯托克斯定理 $\int_{\partial M}\omega=\int_M d\omega$，区别只在维数与 $\omega$ 的阶数。
