# 第67级-逼近论与样条理论

本目录收录以下定理：

- [B-样条基](./B样条基.md)
- [Chebyshev 逼近理论](./Chebyshev逼近理论.md)
- [Jackson 定理与 Bernstein 定理](./Jackson定理与Bernstein定理.md)
- [Weierstrass 逼近定理](./Weierstrass逼近定理.md)
- [小波逼近](./小波逼近.md)
- [样条插值误差估计](./样条插值误差估计.md)
- [正交多项式理论](./正交多项式理论.md)
- [Cox-de Boor 递推公式](./Cox-deBoor递推公式.md)：B-样条基函数不必背公式，它们是一层一层"加权平均"出来的：零阶是一格一格的小方波，$p$ 阶基函数由相邻两个 $(p-1)$ 阶基函数按线性权重拼成。
- [Bernstein 三角多项式导数不等式](./Bernstein三角多项式导数不等式.md)：一个 $n$ 次三角多项式不管长什么样，它的变化速度都被次数锁死：导数最多是把原函数放大 $n$ 倍，再想更快就得提高次数。
- [Bramble-Hilbert 引理](./Bramble-Hilbert引理.md)：只要一个线性泛函把所有低次多项式都"看不见"（作用为零），那么它对任意函数的作用就被该函数的最高阶导数控制——因为去掉低次多项式后剩下的部分只能靠最高阶导数来度量。
- [Rodrigues 公式](./Rodrigues公式.md)：Rodrigues 公式把 Legendre 多项式（以及一般经典正交多项式）写成一个"高次多项式求 $n$ 阶导"的显式表达式，不必层层递推就能直接构造出第 $n$ 个正交多项式。
- [Christoffel-Darboux公式](./Christoffel-Darboux公式.md)：把 $0$ 到 $n$ 次正交多项式两两相乘再相加，这一大堆"看上去没法算"的核函数可以缩成一个漂亮的差商式子——分子只有相邻两个多项式的反对称组合，分母是 $x-y$。
- [Bernstein 多项式的定义与恒等式](./Bernstein多项式的定义与恒等式.md)：Bernstein 多项式是一族"权重函数"，它们在 $[0,1]$ 上非负、且对每个 $x$ 之和恒为 1，因此把函数在采样点上的值按这些权重加权平均，就得到一条紧贴原函数的曲线。
