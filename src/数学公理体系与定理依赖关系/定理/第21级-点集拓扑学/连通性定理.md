# 连通性定理

## 介绍

连通性是拓扑学中描述空间"整体性"的基本概念。一个连通空间不能分解为两个非空不相交的开集的并集。连通空间的连续像是连通的，这一结论表明连通性也是一个拓扑不变性质。该定理在分析学中有着重要应用，例如介值定理就是连通性在 $\mathbb{R}$ 上的直接推论：$\mathbb{R}$ 中的连通子集正是区间，而连续函数保持连通性意味着区间在连续函数下的像仍是区间，从而函数必须取遍介于两端点之间的所有值。

## 分析

**前置依赖**：连通空间的定义、连续映射的定义、开集、闭集。

**数学内涵**：
- 空间 $X$ 是连通的，如果它不能表示为两个非空不相交的开集之并。
- 等价定义：$X$ 中既开又闭的子集只有 $\varnothing$ 和 $X$ 本身。
- 定理断言：若 $X$ 连通，$f: X \to Y$ 连续，则 $f(X)$ 连通。
- 证明采用反证法：假设 $f(X)$ 不连通，则存在 $f(X)$ 中的既开又闭的非平凡子集，通过原像得到 $X$ 中的既开又闭的非平凡子集，与 $X$ 连通矛盾。

**结构**：
1. 假设 $f(X)$ 不连通，存在 $A, B \neq \varnothing$ 开集使 $f(X) = A \cup B$，$A \cap B = \varnothing$。
2. 考虑 $f^{-1}(A)$ 和 $f^{-1}(B)$，它们都是 $X$ 中的开集（由连续性）。
3. $f^{-1}(A) \cap f^{-1}(B) = \varnothing$，$X = f^{-1}(A) \cup f^{-1}(B)$。
4. 由于 $A, B$ 非空，$f^{-1}(A)$ 和 $f^{-1}(B)$ 也非空，这与 $X$ 连通矛盾。

## 思考过程

"连通空间的连续像是连通的"这一结论的直观理解非常自然：如果 $X$ 是一个"整体"，连续映射不会将其撕裂，因此 $f(X)$ 也应该是一个"整体"。

证明的思路是反证法——如果 $f(X)$ 可以被分割成两个非空不相交的开集，那么通过原像映射，$X$ 也会被分割成两个非空不相交的开集，这与 $X$ 的连通性矛盾。这一证明的关键在于连续映射保证开集的原像是开集，从而"分割"可以通过原像回传到 $X$。

这种证明模式与紧致空间的连续像定理非常相似，都是利用连续映射保持开集原像这一性质，将目标空间中的构造拉回到原空间，再利用原空间的性质得出结论。

## 证明过程

**定理**：设 $X$ 是连通拓扑空间，$Y$ 是拓扑空间，$f: X \to Y$ 是连续映射，则 $f(X)$ 是 $Y$ 的连通子空间。

**证明**：

假设 $f(X)$ 不连通，则存在 $f(X)$ 中的非空开集 $A, B$（在子空间拓扑下），使得
$$f(X) = A \cup B,\quad A \cap B = \varnothing$$

由于 $A, B$ 是 $f(X)$ 中的开集，存在 $Y$ 中的开集 $U, V$ 使得 $A = U \cap f(X)$，$B = V \cap f(X)$。

由 $f$ 的连续性，$f^{-1}(U)$ 和 $f^{-1}(V)$ 是 $X$ 中的开集。易见
$$f^{-1}(A) = f^{-1}(U \cap f(X)) = f^{-1}(U)$$
$$f^{-1}(B) = f^{-1}(V \cap f(X)) = f^{-1}(V)$$

于是 $f^{-1}(A)$ 和 $f^{-1}(B)$ 是 $X$ 中的开集。由于 $f(X) = A \cup B$，且 $f^{-1}(f(X)) = X$，我们有
$$X = f^{-1}(A) \cup f^{-1}(B)$$

又因为 $A \cap B = \varnothing$，所以 $f^{-1}(A) \cap f^{-1}(B) = \varnothing$。

由于 $A \neq \varnothing$，存在 $y \in A$，则存在 $x \in X$ 使得 $f(x) = y$，于是 $x \in f^{-1}(A)$，故 $f^{-1}(A) \neq \varnothing$。同理 $f^{-1}(B) \neq \varnothing$。

因此 $X$ 可表示为两个非空不相交开集 $f^{-1}(A)$ 和 $f^{-1}(B)$ 的并集，这与 $X$ 连通矛盾。故 $f(X)$ 连通。$\square$

**推论**（介值定理）：设 $f: [a, b] \to \mathbb{R}$ 连续，$f(a) < r < f(b)$，则存在 $c \in (a, b)$ 使得 $f(c) = r$。

**证明**：$[a, b]$ 连通（作为 $\mathbb{R}$ 中的区间），$f$ 连续，由本定理 $f([a, b])$ 连通。$\mathbb{R}$ 中的连通子集必为区间，故 $f([a, b])$ 是包含 $f(a)$ 和 $f(b)$ 的区间，从而包含 $f(a)$ 和 $f(b)$ 之间的所有值，特别地包含 $r$。$\square$
