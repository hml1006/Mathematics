# 第82级-代数图论

本目录收录以下定理：

- [图的谱定理](./图的谱定理.md)
- [Perron-Frobenius定理](./Perron-Frobenius定理.md)
- [Cheeger不等式](./Cheeger不等式.md)
- [强正则图的谱分类](./强正则图的谱分类.md)
- [Ramanujan图的构造](./Ramanujan图的构造.md)
- [Courant–Fischer 定理](./Courant–Fischer定理.md)：对称矩阵的第 $k$ 个特征值不用解方程，它等于"在所有 $k$ 维子空间里，把最大可能的 Rayleigh 商压到最低"的那个值；换个方向看，也是"在所有 $(n-k+1)$ 维子空间里，把最小可能的 Rayleigh 商抬到最高"的那个值。
- [Alon–Boppana 定理](./Alon–Boppana定理.md)：$d$-正则图再怎么设计，第二大特征值都不可能小于 $2\sqrt{d-1}$（允许无穷小误差）——这是所有扩张图能谱间隙的理论天花板。
- [Lagrange 四平方和定理](./Lagrange四平方和定理.md)：每个自然数都能写成四个整数平方之和，比如 $7=4+1+1+1$、$31=25+4+1+1$。用三个平方做不到对所有数都成立，四个恰好够。
