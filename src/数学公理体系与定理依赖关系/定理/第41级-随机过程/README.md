# 第41级-随机过程

> 一句话级别概述：随机过程研究随时间演化的一族随机变量，是概率论从静态分布走向动态模型的延伸，也是金融、物理与工程的数学内核。

## 级别简介

本级别研究依时间变化的随机现象，涵盖 Markov 链、Poisson 过程、Brown 运动等基本过程，以及鞅、Itô 积分与随机微分等核心工具，建立随机过程的构造、平稳性、连续性条件与收敛理论。

## 本级别定理

- [Brown运动的存在性](./Brown运动的存在性.md)：连续随机游走的构造。
- [Doob可选停止定理](./Doob可选停止定理.md)：停时下鞅期望不变。
- [Itô公式](./Itô公式.md)：随机微分的链式法则。
- [Itô积分](./Itô积分.md)：关于Brown运动的随机积分。
- [Kolmogorov-Chentsov连续性定理](./Kolmogorov-Chentsov连续性定理.md)：矩条件保证样本连续。
- [Kolmogorov扩张定理](./Kolmogorov扩张定理.md)：有限维分布构造随机过程。
- [Markov链平稳分布](./Markov链平稳分布.md)：长期演化的不变分布。
- [Markov链状态分类](./Markov链状态分类.md)：状态常返/周期结构。
- [Poisson过程](./Poisson过程.md)：独立增量计数过程。
- [鞅收敛定理](./鞅收敛定理.md)：有界鞅几乎必然收敛。

## 前置知识

本级别依赖前序级别的如下知识：测度论与概率论（条件期望、独立性）、实分析（积分与收敛定理）以及初等概率统计。

## 后继用途

随机过程为随机分析、随机微分方程、金融数学（资产定价）以及排队论、信息论等应用级别提供理论工具，是第 96 级随机微分方程等后续方向的直接基础。

## 关键定理速览

- Kolmogorov扩张定理：由相容有限维分布构造随机过程。
- 鞅收敛定理：有界鞅几乎必然收敛并刻画停时。
- Doob可选停止定理：鞅在可停时下的期望保持。
- Itô公式：随机积分中的微分法则。
- Brown运动存在性与Kolmogorov-Chentsov定理：样本路径的构造与正则性。
