# 海涅定理

> **一句话大白话**：在封闭有界的区间上，连续函数不仅在每个点"不跳变"，而且整个区间的变化幅度被罩住——整体步子稳，不会忽大忽小。
>
> **小例子**：$f(x)=\sin x$ 在 $[0,2\pi]$ 上连续且被 $\pm1$ 罩住；再如 $f(x)=x^2$ 在 $[0,10]$ 上最大不过100，整个取值范围都被框住。

## 介绍

在点集拓扑学中，海涅定理（Heine's Theorem）通常指紧致度量空间上连续函数必一致连续的结论。该定理由德国数学家爱德华·海涅（Eduard Heine）于 1872 年提出，是分析学中连接"连续性"与"一致连续性"的桥梁。在一般度量空间中，连续函数不一定一致连续，但若定义域是紧致的，则二者等价。该定理在数学分析、数值计算和函数逼近论中有重要应用，例如在傅里叶分析中用于证明三角级数的一致收敛性等。

## 分析

**前置依赖**：紧致性定义（海涅-博雷尔性质）、度量空间、连续函数、一致连续的定义。

**数学内涵**：
- 函数 $f: X \to Y$ 在 $X$ 上一致连续的定义是：$\forall \varepsilon > 0, \exists \delta > 0$，使得对任意 $x, y \in X$，$d_X(x, y) < \delta$ 蕴含 $d_Y(f(x), f(y)) < \varepsilon$。
- 一致连续性比逐点连续性更强：它不仅要求对每个点存在 $\delta$，还要求 $\delta$ 可以统一选取（不依赖于 $x$）。
- 海涅定理断言：若 $X$ 是紧致度量空间，$Y$ 是度量空间，$f: X \to Y$ 连续，则 $f$ 一致连续。
- 证明的关键是利用紧致性将逐点连续的 $\delta$ 统一化。

**结构**：
1. 对 $\varepsilon > 0$，对每个 $x \in X$，由连续性存在 $\delta_x > 0$。
2. 开球族 $\{B(x, \delta_x/2)\}_{x \in X}$ 覆盖 $X$。
3. 由紧致性取有限子覆盖 $\{B(x_i, \delta_{x_i}/2)\}_{i=1}^n$。
4. 令 $\delta = \min\{\delta_{x_i}/2\}$，验证 $\delta$ 满足一致连续的要求。

## 思考过程

海涅定理的证明思想非常优雅：从逐点连续性出发，每个点 $x$ 对应一个 $\delta_x$，这些 $\delta_x$ 可能随着 $x$ 的变化而趋于 $0$。如果 $X$ 是紧致的，我们可以用有限个开球覆盖 $X$，每个开球对应一个 $\delta_{x_i}$。取这些 $\delta_{x_i}$ 的最小值，就能保证在整个 $X$ 上统一适用。

这里的关键是取 $\delta_x/2$ 而不是 $\delta_x$ 作为半径构造开球。为什么？因为当我们取有限个开球 $\{B(x_i, \delta_{x_i}/2)\}$ 覆盖 $X$ 后，如果 $d(x, y) < \min\{\delta_{x_i}/2\}$，那么 $x$ 属于某个 $B(x_i, \delta_{x_i}/2)$，从而 $d(x_i, x) < \delta_{x_i}/2$，结合三角不等式可推出 $d(x_i, y) < \delta_{x_i}$，于是 $d(f(x_i), f(y)) < \varepsilon/2$，$d(f(x_i), f(x)) < \varepsilon/2$，从而 $d(f(x), f(y)) < \varepsilon$。

## 证明过程

**定理**（海涅）：设 $X$ 是紧致度量空间，$Y$ 是度量空间，$f: X \to Y$ 连续，则 $f$ 在 $X$ 上一致连续。

**证明**：

给定 $\varepsilon > 0$。对每个 $x \in X$，由 $f$ 在 $x$ 处的连续性，存在 $\delta_x > 0$ 使得
$$d_X(x, y) < \delta_x \quad \Rightarrow \quad d_Y(f(x), f(y)) < \frac{\varepsilon}{2}$$

考虑开球族 $\{B(x, \delta_x/2)\}_{x \in X}$，它们构成 $X$ 的开覆盖。由 $X$ 的紧致性，存在有限子覆盖
$$X \subseteq \bigcup_{i=1}^n B\left(x_i, \frac{\delta_{x_i}}{2}\right)$$

令 $\delta = \min\limits_{1 \leq i \leq n} \frac{\delta_{x_i}}{2} > 0$。

现在证明对任意 $x, y \in X$，$d_X(x, y) < \delta$ 蕴含 $d_Y(f(x), f(y)) < \varepsilon$。

设 $x, y \in X$ 满足 $d_X(x, y) < \delta$。由于 $\{B(x_i, \delta_{x_i}/2)\}$ 覆盖 $X$，存在某个 $i$ 使得 $x \in B(x_i, \delta_{x_i}/2)$，即 $d_X(x, x_i) < \delta_{x_i}/2$。

由三角不等式，
$$d_X(x_i, y) \leq d_X(x_i, x) + d_X(x, y) < \frac{\delta_{x_i}}{2} + \delta \leq \frac{\delta_{x_i}}{2} + \frac{\delta_{x_i}}{2} = \delta_{x_i}$$

因此 $d_X(x_i, y) < \delta_{x_i}$，由 $\delta_{x_i}$ 的选取得 $d_Y(f(x_i), f(y)) < \varepsilon/2$。

又 $d_X(x_i, x) < \delta_{x_i}/2 < \delta_{x_i}$，故 $d_Y(f(x_i), f(x)) < \varepsilon/2$。

最后由三角不等式，
$$d_Y(f(x), f(y)) \leq d_Y(f(x), f(x_i)) + d_Y(f(x_i), f(y)) < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$$

因此 $f$ 在 $X$ 上一致连续。$\square$

**注记**：本定理中的紧致性条件是本质的。例如，$f(x) = x^2$ 在 $\mathbb{R}$ 上连续但非一致连续，因为 $\mathbb{R}$ 不是紧致的。$f(x) = 1/x$ 在 $(0, 1]$ 上连续但非一致连续，因为 $(0, 1]$ 不是紧致的（不完备）。
