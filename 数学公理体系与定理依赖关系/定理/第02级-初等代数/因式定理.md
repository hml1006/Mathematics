# 因式定理

## 介绍

因式定理（Factor Theorem）是多项式理论中的一个基本定理：多项式 $f(x)$ 有因式 $(x - a)$ 当且仅当 $f(a) = 0$。这一结论将多项式的求值与因式分解紧密联系起来，是多项式恒等定理、有理根定理、多项式方程求解的理论基础。因式定理提供了寻找多项式因式的一种实用方法——通过试探根来获得因式分解。

## 分析

**前置依赖**：带余除法（多项式除法）。

**定理内容**：设 $f(x)$ 是系数在数域 $F$ 上的多项式，$a \in F$。则 $(x - a)$ 是 $f(x)$ 的因式当且仅当 $f(a) = 0$。

**数学内涵**：
- 因式定理是多项式带余除法的直接推论：$f(x) = (x - a)q(x) + r$，其中余数 $r$ 是常数。代入 $x = a$ 得 $f(a) = r$。
- 因此，"$f(a) = 0$"与"$(x - a)$ 整除 $f(x)$"等价。
- 这一定理适用于任何数域上的多项式，包括整数、有理数、实数、复数系数。
- 因式定理可以推广到重根情形：$(x - a)^k$ 整除 $f(x)$ 当且仅当 $f(a) = f'(a) = \cdots = f^{(k-1)}(a) = 0$。

**结构**：
1. 由多项式带余除法，$f(x) = (x - a)q(x) + r$。
2. 代入 $x = a$ 得 $f(a) = r$。
3. 若 $f(a) = 0$，则 $r = 0$，故 $(x - a)$ 整除 $f(x)$。
4. 反之，若 $(x - a)$ 整除 $f(x)$，则 $f(a) = 0$。

## 思考过程

因式定理的发现源于对多项式除法与求值关系的观察。当我们用 $(x - a)$ 去除多项式 $f(x)$ 时，余数是一个常数（因为除式是一次式）。这个余数等于多少？一个自然的想法是代入 $x = a$：由于 $x - a = 0$，余数就是 $f(a)$。

这个简单的观察产生了深刻的结论：判断 $a$ 是否为多项式 $f(x)$ 的根，等价于判断 $(x - a)$ 是否为 $f(x)$ 的因式。这为多项式因式分解提供了实用方法——先猜根（比如试有理根），然后用多项式除法降次。

## 证明过程

**定理**（因式定理）：设 $f(x)$ 是系数在数域 $F$ 上的多项式，$a \in F$。则 $(x - a)$ 是 $f(x)$ 的因式当且仅当 $f(a) = 0$。

**证明**：

由多项式带余除法，存在多项式 $q(x)$ 和常数 $r \in F$，使得

$$
f(x) = (x - a)q(x) + r
$$

其中 $r$ 是余数，次数小于 $(x - a)$ 的次数，故 $r$ 为常数。

代入 $x = a$：

$$
f(a) = (a - a)q(a) + r = 0 \cdot q(a) + r = r
$$

因此 $r = f(a)$。

**必要性**：若 $(x - a)$ 是 $f(x)$ 的因式，则 $r = 0$，故 $f(a) = r = 0$。

**充分性**：若 $f(a) = 0$，则 $r = f(a) = 0$，故 $f(x) = (x - a)q(x)$，即 $(x - a)$ 是 $f(x)$ 的因式。$\square$

---

**例**：设 $f(x) = x^3 - 3x^2 - x + 3$。由于 $f(1) = 1 - 3 - 1 + 3 = 0$，故 $(x - 1)$ 是 $f(x)$ 的因式。做多项式除法得 $f(x) = (x - 1)(x^2 - 2x - 3) = (x - 1)(x + 1)(x - 3)$。

**推论**（余数定理）：多项式 $f(x)$ 除以 $(x - a)$ 的余数为 $f(a)$。
