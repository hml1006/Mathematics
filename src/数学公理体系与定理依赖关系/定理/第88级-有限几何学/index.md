# 第88级-有限几何学

- [有限射影平面的基本性质](./有限射影平面的基本性质.md)
- [Bruck-Ryser定理](./Bruck-Ryser定理.md)
- [仿射平面与射影平面的扩展](./仿射平面与射影平面的扩展.md)
- [Desargues定理](./Desargues定理.md)
- [有限广义四边形的基本性质](./有限广义四边形的基本性质.md)
- [Hasse–Minkowski 局部-全局原理](./Hasse–Minkowski局部-全局原理.md)：一个有理系数的二次方程（二次型）在有理数里有没有解，只要看它在每个"局部世界"（实数与所有 $p$ 进数）里有没有解就够了——局部处处有解，则整体必有解。
- [初等数论中的平方和定理](./初等数论中的平方和定理.md)：一个自然数能否写成若干平方数之和，有初等的判别法：两平方看质因数中 $4k+3$ 型素数指数是否为偶，三平方排除 $4^a(8b+7)$ 型，四平方则永远可以。
- [射影平面的对偶原理](./射影平面的对偶原理.md)：在射影平面里，"点"与"直线"地位完全对等——把命题中的点和线互换、把"在……上"与"经过"互换，得到的仍是成立的命题。
