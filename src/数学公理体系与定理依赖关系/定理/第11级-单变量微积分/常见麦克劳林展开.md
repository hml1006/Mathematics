# 常见麦克劳林展开

> **一句话大白话**：把不容易直接算值的函数在 $0$ 附近“翻译”成一串好算的多项式，取的项越多就越像原函数。
>
> **小例子**：$e^x\approx 1+x+\frac{x^2}{2}$，所以 $e^{0.1}\approx 1+0.1+0.005=1.105$（真实值约 $1.10517$）。

## 介绍

麦克劳林展开（Maclaurin Expansion）是泰勒定理在 $x=0$ 处的特例，它将函数表示为幂级数的形式。常见函数的麦克劳林展开是微积分和数学分析中的基本工具，在数值计算、函数逼近、微分方程求解和物理建模中有着广泛应用。掌握这些展开式对于理解和应用级数理论至关重要。

## 分析

**前置依赖**：泰勒定理

**定理内容**：以下为常见函数的麦克劳林展开式（在收敛域内成立）：

1. **指数函数**：
   $$e^x = \sum_{n=0}^\infty \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots, \quad x \in \mathbb{R}$$

2. **正弦函数**：
   $$\sin x = \sum_{n=0}^\infty \frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots, \quad x \in \mathbb{R}$$

3. **余弦函数**：
   $$\cos x = \sum_{n=0}^\infty \frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots, \quad x \in \mathbb{R}$$

4. **自然对数**：
   $$\ln(1+x) = \sum_{n=1}^\infty \frac{(-1)^{n-1} x^n}{n} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots, \quad |x| < 1$$

5. **几何级数**：
   $$\frac{1}{1-x} = \sum_{n=0}^\infty x^n = 1 + x + x^2 + x^3 + \cdots, \quad |x| < 1$$

**数学内涵**：
麦克劳林展开用多项式逼近函数，展开式的系数由函数在 $x=0$ 处的各阶导数决定。这些展开式揭示了初等函数与幂级数之间的内在联系，为函数值的近似计算提供了理论依据。例如，$e^x$ 的展开系数 $1/n!$ 反映了指数函数增长速率与阶乘的关系，而 $\sin x$ 和 $\cos x$ 的展开则体现了三角函数的奇偶性和周期性。

**证明策略**：利用泰勒定理计算各阶导数在 $x=0$ 处的值，代入泰勒公式并验证收敛性。

## 思考过程

由泰勒定理，函数 $f(x)$ 在 $x=0$ 处的 $n$ 阶麦克劳林多项式为
$$P_n(x) = \sum_{k=0}^n \frac{f^{(k)}(0)}{k!} x^k$$

逐一计算各函数的 $k$ 阶导数在 $0$ 处的值，代入即可得到展开式。收敛域可通过比值判别法或根值判别法确定。

## 证明过程

**定理**：设 $f(x)$ 在 $x=0$ 处具有任意阶导数，则 $f(x)$ 可展开为麦克劳林级数 $\sum_{k=0}^\infty \frac{f^{(k)}(0)}{k!} x^k$ 当且仅当余项 $R_n(x) \to 0$（$n \to \infty$）。

**证明**：

**1. $e^x$ 的展开**

$f(x) = e^x$，则 $f^{(k)}(x) = e^x$，$f^{(k)}(0) = 1$。代入泰勒公式得
$$e^x = \sum_{k=0}^n \frac{x^k}{k!} + R_n(x)$$

其中 Lagrange 余项 $R_n(x) = \frac{e^{\xi}}{(n+1)!} x^{n+1}$，$\xi$ 介于 $0$ 和 $x$ 之间。对任意固定的 $x$，$\lim_{n\to\infty} \frac{x^{n+1}}{(n+1)!} = 0$，故 $R_n(x) \to 0$，因此
$$e^x = \sum_{n=0}^\infty \frac{x^n}{n!}, \quad x \in \mathbb{R}$$

**2. $\sin x$ 的展开**

$f(x) = \sin x$，则
$$f^{(k)}(x) = \sin\left(x + \frac{k\pi}{2}\right)$$
$$f^{(k)}(0) = \sin\left(\frac{k\pi}{2}\right) = \begin{cases} 0, & k = 2m \\ (-1)^m, & k = 2m+1 \end{cases}$$

代入泰勒公式得
$$\sin x = \sum_{m=0}^n \frac{(-1)^m x^{2m+1}}{(2m+1)!} + R_{2n+1}(x)$$

余项 $R_{2n+1}(x) = \frac{\sin^{(2n+2)}(\xi)}{(2n+2)!} x^{2n+2}$，其绝对值不超过 $\frac{|x|^{2n+2}}{(2n+2)!}$，趋于 $0$。因此
$$\sin x = \sum_{n=0}^\infty \frac{(-1)^n x^{2n+1}}{(2n+1)!}, \quad x \in \mathbb{R}$$

**3. $\cos x$ 的展开**

类似地，$f(x) = \cos x$，$f^{(k)}(0) = \cos\left(\frac{k\pi}{2}\right)$，得
$$\cos x = \sum_{n=0}^\infty \frac{(-1)^n x^{2n}}{(2n)!}, \quad x \in \mathbb{R}$$

**4. $\ln(1+x)$ 的展开**

$f(x) = \ln(1+x)$，则
$$f'(x) = \frac{1}{1+x}, \quad f''(x) = -\frac{1}{(1+x)^2}, \quad f^{(k)}(x) = \frac{(-1)^{k-1}(k-1)!}{(1+x)^k}$$
$$f(0) = 0, \quad f^{(k)}(0) = (-1)^{k-1}(k-1)!$$

代入得
$$\ln(1+x) = \sum_{k=1}^n \frac{(-1)^{k-1} x^k}{k} + R_n(x)$$

由比值判别法，收敛半径为 $1$。当 $|x| < 1$ 时，可证 $R_n(x) \to 0$，因此
$$\ln(1+x) = \sum_{n=1}^\infty \frac{(-1)^{n-1} x^n}{n}, \quad |x| < 1$$

**5. $\frac{1}{1-x}$ 的展开**

$f(x) = \frac{1}{1-x}$，则 $f^{(k)}(x) = \frac{k!}{(1-x)^{k+1}}$，$f^{(k)}(0) = k!$。代入得
$$\frac{1}{1-x} = \sum_{n=0}^\infty x^n, \quad |x| < 1$$

这是等比级数求和公式的直接结果，收敛域 $|x| < 1$ 由比值判别法确定。

$\square$
