# 第131级-数学心理学

本目录收录以下定理：

- [三重编码模型（Triple Code Model）](./三重编码模型.md)
- [数感的认知发展理论](./数感的认知发展理论.md)
- [数学焦虑的认知-动机模型](./数学焦虑的认知-动机模型.md)
- [数学问题解决的认知模型](./数学问题解决的认知模型.md)
- [韦伯定律](./韦伯定律.md)：人能分辨的“最小刺激差别”不是一个固定的绝对量，而是与刺激强度成正比的固定比例——刺激越强，要察觉差别就需要越大的改变量。
- [脑功能定位原理](./脑功能定位原理.md)：大脑不是一锅均匀的粥——特定的心理功能由特定的神经区域“分管”，某个区域受损，就只有它负责的功能出问题，别的功能照常。
- [判别概率与判别准则](./判别概率与判别准则.md)：判断"两个刺激是否不同"时，心里先形成一个连续的"差别感"，超过某个门槛就报"不同"。判别概率就是这个感觉量越过门槛的概率，而最佳门槛由似然比决定。
- [Cauchy 函数方程及其连续解](./Cauchy函数方程及其连续解.md)：如果一个函数满足"和的函数值 = 函数值的和"，那么在有理数上它只能是对应的正比函数 $f(x)=cx$；再加上哪怕一丁点儿"连续性"（或单调、或有界），这条直线结论就会铺满整个实数轴——不加这种温和条件，还会冒出无比怪异的解。
