# 拟范畴的基本性质

> **一句话大白话**：拟范畴是一种"放松了结合律"的范畴——它把几何上最难缠的 Simplex 结构压成集合，使所有结合律只在同伦意义下成立，却能照常谈论对象、态射与复合。
>
> **小例子**：拟范畴的对象是 $0$-单形，态射是 $1$-单形，态射复合满足结合律到同伦，且对任意 $n\ge2$，$n$-单形对应可复合态射的交换图。

## 一、定理介绍

> **前置依赖**：单纯集合、内填角填充公理、Kan复形、态射空间构造、Lurie的填单引理

拟范畴（quasi-category，又称 $\infty$-范畴的"外形"）是对范畴概念在同伦意义下的推广：一个拟范畴是一个单纯集合 $C$，其任意 $k$-维 null 边界的内填单人问题（$0<k<n$）都有解。其基本性质确定了如何在拟范畴中做对象、态射、复合、逆与各种高阶操作，奠定了 $\infty$-范畴论的基础。

## 二、原理思路

拟范畴的"基本性质"指一组结构性事实：对象是 $0$-单形，态射是 $1$-单形对应；复合存在且满足结合律到同伦；态射空间（如 $\mathrm{Hom}_C(x,y)$）构成 Kan 复形，从而可谈同伦等价/不可逆态射；$n$-单形提供高阶复合的交织；“同伦都是 kan 化”使得标准的 $\infty$-范畴形式化成为可能的基底。

## 三、定理的严格表述

设 $C\in\text{sSet}$ 为拟范畴（内填单人性质对所有 $0<k<n$ 成立）。则：
(1) $C$ 的 $0$-单形为对象，态射为 $1$-单形。
(2) 对 $x,y\in C$，态射空间 $\mathrm{Hom}_C(x,y)$（如 $\mathrm{Hom}^{\mathrm{R}}_{C}$）是 Kan 复形。
(3) 复合是良好定义的，结合律成立到同伦。
(4) 对 $n\ge2$，$C$ 中的 $n$-单形 $x_0\to x_1\to\cdots\to x_n$ 给出相应的可复合态射图。

## 四、证明过程

这些性质通常由拟范畴的填单公理直接推出：用 $0<k<n$ 的填单人给出态射复合与结合性的存在；用特殊的单纯/-colimit 再现态射空间的 Kan 结构；借助内填人性质构造对换与等同关系，逐条验证 (1)-(4)。书中呈现常用如 Joyal/Lurie 的范畴化引理来严格化每一步。

## 五、应用与意义

拟范畴为现代高阶代数几何、导出代数几何与稳定 $\infty$-范畴提供统一语言，是 Lurie《Higher Topos Theory》及其后续的基石。它以放松结合律换来对无穷结构的处理能力，广泛应用于代数拓扑、同伦论与导出范畴理论。

## 课堂问答

**老师**：拟范畴的定义只有一条填充公理，凭什么能从中读出一个"范畴"的全部结构？

**学生**：结论：因为内填角填充公理恰好编码了复合与结合律的存在。定义：$C$ 是拟范畴，若对每个 $n\ge2$、$0<k<n$，每个内角 $\Lambda^n_k\to C$ 都能延拓为 $\Delta^n\to C$。于是 $0$-单形是对象、$1$-单形是态射；$\Lambda^2_1$ 的填充给出复合。与普通范畴不同，结合律不是等式而是由 $\Lambda^3_1,\Lambda^3_2$ 的填充给出的同伦。常见误区是想在 $0$-单形集合上直接定义 Hom，其实要先构造态射空间。

**老师（追问）**：态射空间 $\mathrm{Hom}_C(x,y)$ 为什么是 Kan 复形，而不是随便某个单纯集合？

**学生**：因为拟范畴的填充公理保证了它满足 Kan 条件：构造 $\mathrm{Hom}_C(x,y)$（如右 Hom）时，每个角 $\Lambda^n_k\to\mathrm{Hom}_C(x,y)$ 都对应于 $C$ 中某个内角填充问题，可用填单引理解出。Kan 复形意味着它"所有态射可逆"，这正是同伦等价可定义的前提。所以 (1)$0$-单形是对象、(2)$\mathrm{Hom}_C(x,y)$ 是 Kan 复形、(3) 复合良定义且结合到同伦、(4) 对 $n\ge2$ 的 $n$-单形给出可复合态射图，四条性质都由填单公理直接推出。

**老师（拓展）**：拟范畴和"放松结合律"的关系，怎样一句话说清？

**学生**：拟范畴把结合律从"等式"降级为"高维单形给出的同伦"，从而能承载无穷结构。它与 Joyal 模型结构、Lurie 的《Higher Topos Theory》框架共同构成现代高阶代数几何与稳定 $\infty$-范畴的统一语言；同一填充思路推广出去就是 $(\infty,n)$-范畴与 $\infty$-算畴中更高维的填充结构。
