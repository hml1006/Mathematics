# 竞赛专题总览

> 本专题面向各类数学竞赛，按学段分级：小学奥数、初中奥数、高中奥数、大学数学竞赛。每个学段均配套「教程」（方法精讲 + 例题）与「题库」（基础 / 进阶 / 挑战 / 探究 四档习题 + 答案与解析）。可结合全书教材（第一阶段 ~ 第七阶段）交叉学习。

---

## 分级导学

- **[01 · 小学奥数](01-小学奥数/README.md)**：从计算与速算、应用题与行程、几何初步、数论初步（整除与余数）、计数原理到逻辑推理与趣味数学，建立数学敏感度与思维习惯。
- **[02 · 初中奥数](02-初中奥数/README.md)**：因式分解与恒等变形、平面几何五大定理与经典模型、函数与方程、数论（同余、质合数）、组合与抽屉原理，衔接中学联赛。
- **[03 · 高中奥数](03-高中奥数/README.md)**：代数（不等式、数列、多项式）、平面几何（几何变换与纯几何法）、数论（同余、不定方程）、组合（容斥、抽屉、图论初步）、复数，瞄准高中数学联赛（一试 / 加试）。
- **[04 · 大学数学竞赛](04-大学数学竞赛/README.md)**：数学分析（极限、积分、级数、不等式）、高等代数（矩阵、多项式、线性空间）、组合与数论高阶、综合专题，兼顾大学生数学竞赛数学类与非数学类。

## 教程与题库的对应关系

每个学段下均划分两大部分：

- **教程/**：按主题讲解核心方法、常用技巧与定理，配「例题精讲」，适合系统学习与查漏补缺。
- **题库/**：围绕教程主题配置四档习题（基础题 / 进阶题 / 挑战题 / 探究题），每档独立连续编号，附答案与解析，适合阶段自测与拔高训练。

> **学习建议**：先通读对应学段的「教程」，掌握方法后再进入「题库」按档位循序渐进；高学段若跳级，建议以「题库」先行自测，再针对薄弱点返回「教程」精读。

## 难度映射

| 学段 | 参考竞赛/考试 | 对应难度 |
| --- | --- | --- |
| 小学奥数 | 华杯赛、希望杯、迎春杯（小学组） | ★：培养兴趣与数感 |
| 初中奥数 | 全国初中数学联赛、中考压轴 | ★★：夯实基础、方法入门 |
| 高中奥数 | 全国高中数学联赛（一试/加试） | ★★★：方法系统化、能力进阶 |
| 大学数学竞赛 | 全国大学生数学竞赛、PCMS 等 | ★★★★：分析/代数整合、高阶技巧 |
