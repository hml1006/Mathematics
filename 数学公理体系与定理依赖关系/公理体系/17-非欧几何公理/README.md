# 非欧几何公理 (Non-Euclidean Geometry Axioms)

## 介绍

非欧几何公理是对欧几里得几何中平行公理的修正和推广。欧几里得的《几何原本》中有五条公设，其中第五公设（平行公设）长期以来被认为可能可以从其他公设推导出来。19 世纪，Lobachevsky、Bolyai 和 Riemann 分别独立地发现了非欧几何，证明了平行公设的独立性。

非欧几何主要分为双曲几何和椭圆几何两大类。

## 分析

非欧几何公理在欧几里得几何的前四条公设基础上，用不同的平行公理替代了第五公设：

1. **双曲平行公理**：过直线外一点，在该直线和该点所确定的平面内，至少存在两条直线与该直线不相交。
2. **椭圆平行公理**：过"直线外一点"，不存在与该直线不相交的直线；等价地，任意两条"直线"都相交。
3. **线无界性修正**：椭圆几何中的"直线"模型为大圆，是有限但无边的（boundaryless）。

## 思考过程

非欧几何的发现是数学史上的一次革命。两千多年来，数学家们试图证明第五公设，但始终未能成功。Lobachevsky 和 Bolyai 独立地假设第五公设不成立，推导出了自洽的几何体系——双曲几何。Riemann 则发展了椭圆几何，提出了黎曼几何的一般框架。

非欧几何的发现深刻改变了人们对数学和空间本质的理解，为爱因斯坦的广义相对论提供了数学基础。

## 证明过程

非欧几何公理是定义性的，不需要证明。其合理性体现在：
- 非欧几何在逻辑上是自洽的，可以通过模型（如双曲几何的庞加莱圆盘模型、椭圆几何的球面模型）证明其一致性。
- 非欧几何的发现证明了平行公设的独立性，即欧几里得几何不是唯一的自洽几何体系。
