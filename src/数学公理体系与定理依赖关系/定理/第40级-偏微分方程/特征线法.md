# 特征线法

> **一句话大白话**：一阶偏微分方程虽然处处都在动，但可以沿一组"信息高速路"（特征线）把方程化成普通的常微分方程，沿路慢慢解——难题瞬间变成沿曲线积分。
>
> **小例子**：传输方程 $\partial_t u + c\,\partial_x u=0$ 沿直线 $x-ct=\text{const}$ 上值不变，故 $u(t,x)=u_0(x-ct)$，即初始波形以速度 $c$ 原样平移。

## 介绍

特征线法（Method of Characteristics）是求解一阶偏微分方程的基本方法，它将 PDE 沿特征曲线转化为常微分方程（ODE）来求解。该方法的核心思想是将 PDE 的解沿着某些特定的曲线（称为特征曲线）传播，在这些曲线上 PDE 退化为 ODE，从而可以逐条求解。特征线法不仅适用于线性一阶 PDE，也可推广到拟线性一阶 PDE。

## 分析

**前置依赖**：常微分方程、链式法则、方向导数、一阶偏微分方程。

**定理内容**：考虑一阶拟线性 PDE
$$a(x,y,u)u_x + b(x,y,u)u_y = c(x,y,u)$$
带有初始条件 $u(x,0) = u_0(x)$（即 Cauchy 问题）。

特征方程组为
$$\frac{dx}{dt} = a(x,y,u),\quad \frac{dy}{dt} = b(x,y,u),\quad \frac{du}{dt} = c(x,y,u)$$
初始条件为 $x(0,s) = s$，$y(0,s) = 0$，$u(0,s) = u_0(s)$。

**结论**：在特征曲线不相交的区域，上述 Cauchy 问题存在唯一解，且解由特征曲线携带。

**对一阶线性 PDE 的特殊情形**：对线性方程 $a(x,y)u_x + b(x,y)u_y = c(x,y)u + d(x,y)$，特征曲线由
$$\frac{dx}{dt} = a(x,y),\quad \frac{dy}{dt} = b(x,y)$$
给出，且沿特征曲线有 $u$ 的 ODE。

**数学内涵**：特征线法揭示了 PDE 解沿特征曲线传播的物理本质。对于输运方程 $u_t + v u_x = 0$，特征线 $x - vt = \text{const}$ 就是物理扰动的传播路径。

**证明策略**：通过参数化特征曲线，将 PDE 沿曲线方向的方向导数表达出来，从而转化为 ODE 系统。利用 ODE 解的存在唯一性定理得到 PDE 解的存在唯一性。

## 思考过程

特征线法的核心思想是"降维"：将 PDE 沿着特征方向转化为 ODE。考虑一阶 PDE
$$a(x,y)u_x + b(x,y)u_y = c(x,y,u)$$
左边是 $u$ 在方向 $(a,b)$ 上的方向导数。因此，如果我们沿曲线 $(x(t),y(t))$ 满足 $(x',y') = (a,b)$，则 PDE 变为
$$\frac{du}{dt} = c(x,y,u)$$
这是一个 ODE！

因此，求解 PDE 的步骤是：
1. 求解特征 ODE 系统，得到特征曲线族。
2. 沿每条特征曲线求解 ODE 得到 $u$ 的值。
3. 将 $u$ 表达为 $(x,y)$ 的函数。

## 证明过程

**定理**（特征线法）：设 $a,b,c$ 在区域内适当光滑，则 Cauchy 问题
$$a(x,y,u)u_x + b(x,y,u)u_y = c(x,y,u),\quad u(x,0) = u_0(x)$$
在特征曲线不相交的邻域内存在唯一解。

**证明**：

**步骤 1**：建立特征方程组。参数化特征曲线 $(x(t),y(t))$，使得
$$\frac{dx}{dt} = a(x,y,u),\quad \frac{dy}{dt} = b(x,y,u)$$
则沿此曲线，由链式法则
$$\frac{du}{dt} = u_x\frac{dx}{dt} + u_y\frac{dy}{dt} = a u_x + b u_y = c(x,y,u)$$
故 $u$ 沿特征曲线满足 ODE $\frac{du}{dt} = c(x,y,u)$。

**步骤 2**：初始条件参数化。用参数 $s$ 标记初始曲线上的点：
$$x(0,s) = s,\quad y(0,s) = 0,\quad u(0,s) = u_0(s)$$

**步骤 3**：求解特征 ODE 系统。由 ODE 解的存在唯一性定理，对每个 $s$，存在唯一的解 $(x(t,s), y(t,s), u(t,s))$。

**步骤 4**：证明由 $(t,s)$ 到 $(x,y)$ 的变换是可逆的。计算 Jacobian
$$J = \det\begin{pmatrix} x_t & x_s \\ y_t & y_s \end{pmatrix}\Big|_{t=0} = \det\begin{pmatrix} a(s,0,u_0(s)) & 1 \\ b(s,0,u_0(s)) & 0 \end{pmatrix} = -b(s,0,u_0(s))$$
若 $b(s,0,u_0(s)) \neq 0$，则在 $t=0$ 附近 $(t,s) \mapsto (x,y)$ 是局部微分同胚，可反解出 $t = t(x,y)$，$s = s(x,y)$。

**步骤 5**：构造 PDE 的解。定义 $u(x,y) = u(t(x,y), s(x,y))$，则 $u$ 满足 PDE 和初始条件。由构造过程，$u$ 沿特征曲线由 ODE 唯一确定，故解唯一。$\square$

**例**（输运方程）：求解 $u_t + v u_x = 0$，$u(x,0) = u_0(x)$。
特征方程：$\frac{dx}{dt} = v$，$\frac{du}{dt} = 0$。
特征曲线：$x = x_0 + vt$，沿特征曲线 $u$ 为常数。
故解为 $u(x,t) = u_0(x - vt)$。$\square$
