# 第76级-代数数论

本目录收录以下定理：

- [数域整数环是 Dedekind 整环](./数域整数环是Dedekind整环.md)
- [理想唯一分解定理](./理想唯一分解定理.md)
- [理想类群的有限性定理](./理想类群的有限性定理.md)
- [Dirichlet 单位定理](./Dirichlet单位定理.md)
- [二次互反律](./二次互反律.md)
- [Kronecker-Weber 定理](./Kronecker-Weber定理.md)
- [Kronecker 定理](./Kronecker定理.md)：一个代数整数，如果它的所有共轭的模长都不超过 $1$，那它一定是个单位根——没有"模都不大却永远转不回原地"的代数整数。
- [素理想分解与分歧惯性定理](./素理想分解与分歧惯性定理.md)：用分歧指数和惯性次数刻画素数在数域中的分解，并给出次数守恒式 $n=\sum_i e_if_i$。
- [Dedekind–Kummer 定理](./Dedekind-Kummer定理.md)：在 $p$ 不整除指数时，将素理想分解化为极小多项式模 $p$ 的分解，并说明 Eisenstein 等可用条件。
