- [Morrey-Kohn-Hörmander 恒等式](./Morrey-Kohn-Hörmander恒等式.md)：把 $\bar\partial u$ 与 $\bar\partial^u$ 的 $L^2$ 范数平方加起来，可以通过分部积分被"拆开"成一个全导数项（可控制）、一个权重（度规）曲率项和一个边界 Levi 形式项——只要这两项非负，就得到 $\bar\partial$-Neumann 问题的基本估计。
