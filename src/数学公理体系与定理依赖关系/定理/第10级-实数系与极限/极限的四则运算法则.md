# 极限的四则运算法则

> **一句话大白话**：各自收敛的数列做加减乘除，可以先“把极限算进去”：$\lim(a_n+b_n)=\lim a_n+\lim b_n$，积同理，除法要保证分母的极限不为零。
>
> **小例子**：$a_n=\frac{n+2}{n}\to1$，$b_n=\frac{2n-1}{n}\to2$，则 $\lim(a_n+b_n)=1+2=3$，恰好等于两个极限相加。

## 介绍

极限的四则运算法则是极限理论中的基本运算规则：若 $\lim a_n = A$，$\lim b_n = B$，则 $\lim (a_n \pm b_n) = A \pm B$，$\lim (a_n b_n) = AB$，且当 $B \neq 0$ 时 $\lim \frac{a_n}{b_n} = \frac{A}{B}$。这些法则使得极限计算可以转化为简单的代数运算。

## 分析

**前置依赖**：极限定义。

## 思考过程

极限的四则运算法则将单个数列的极限运算推广到多个数列之间的代数运算，其基本思路是：若两个数列分别收敛，则它们的和、差、积、商（分母极限不为零）的极限等于极限的和、差、积、商。

证明中常用的 $\varepsilon/2$ 技巧（以及更一般的 $\varepsilon/k$ 技巧）是分析学中的标准方法：为了控制整体误差在 $\varepsilon$ 以内，只需分别控制每一项的误差在 $\varepsilon/2$ 以内。这种"分而治之"的思想在分析证明中随处可见。

使用这些法则时需注意条件：参与运算的数列必须各自收敛（除法时分母的极限不能为零）。若不满足条件，运算法则可能失效。例如，$a_n = n$，$b_n = -n$ 均发散，但 $a_n + b_n$ 收敛于 $0$，这不能由加法法则直接得出。

## 证明过程

**证明**（加法法则）：对 $\forall \varepsilon > 0$，$\exists N_1$，$n > N_1$ 时 $|a_n - A| < \varepsilon/2$；$\exists N_2$，$n > N_2$ 时 $|b_n - B| < \varepsilon/2$。取 $N = \max(N_1, N_2)$，则 $n > N$ 时 $|(a_n + b_n) - (A + B)| \leq |a_n - A| + |b_n - B| < \varepsilon$。

**证明**（乘法法则）：$|a_n b_n - AB| = |a_n b_n - a_n B + a_n B - AB| \leq |a_n||b_n - B| + |B||a_n - A|$。由于 $\{a_n\}$ 收敛，存在 $M$ 使 $|a_n| \leq M$。对 $\varepsilon > 0$，取 $N$ 使 $|a_n - A| < \frac{\varepsilon}{2(|B|+1)}$，$|b_n - B| < \frac{\varepsilon}{2M}$，则 $|a_n b_n - AB| < \varepsilon$。

**证明**（除法法则）：由乘法法则，只需证 $\lim \frac{1}{b_n} = \frac{1}{B}$。由于 $B \neq 0$，存在 $N_1$，$n > N_1$ 时 $|b_n - B| < \frac{|B|}{2}$，故 $|b_n| > \frac{|B|}{2}$。$|\frac{1}{b_n} - \frac{1}{B}| = \frac{|b_n - B|}{|b_n||B|} \leq \frac{2|b_n - B|}{|B|^2}$，由 $b_n \to B$ 即得。$\square$

## 课堂问答

**老师**：两个数列分别收敛，它们的和、差、积、商的极限等于极限的和、差、积、商吗？

**学生**：结论：若 $\lim a_n = A, \lim b_n = B$，则 $\lim(a_n \pm b_n) = A \pm B$、$\lim(a_n b_n) = AB$，且当 $B \neq 0$ 时 $\lim\frac{a_n}{b_n} = \frac{A}{B}$。

**老师（追问）**：加法好说，乘法里 $|a_n|$ 不受控怎么办？除法又是怎么绕开 $b_n$ 可能为零的？

**学生**：乘法先插项：$|a_n b_n - AB| \le |a_n||b_n - B| + |B||a_n - A|$，收敛数列有界给出 $|a_n| \le M$，再让两个误差分别小于 $\frac{\varepsilon}{2M}$ 与 $\frac{\varepsilon}{2(|B|+1)}$。除法先证 $\lim\frac1{b_n} = \frac1B$：由 $B \neq 0$ 取 $N_1$ 使 $|b_n - B| < \frac{|B|}{2}$，得 $|b_n| > \frac{|B|}{2}$，于是 $|\frac1{b_n} - \frac1B| \le \frac{2|b_n - B|}{|B|^2}$，再用 $b_n \to B$。

**老师（拓展）**：使用时最该当心什么？

**学生**：必须保证参与运算的数列各自收敛，除法还要求分母极限不为零，否则法则可能失效。例如 $a_n = n$、$b_n = -n$ 都发散，但 $a_n + b_n \to 0$，结论成立却无法由加法法则本身推出。要防的误区是"未定式"直接套法则：$\frac{\infty}{\infty}$、$0\cdot\infty$ 这类情形不满足前提，需要另行放缩或变形。
