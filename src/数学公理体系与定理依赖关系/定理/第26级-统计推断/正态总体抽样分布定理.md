# 正态总体抽样分布定理

> **一句话大白话**：从正态总体抽样，样本均值 $\bar X$ 服从正态 $N(\mu,\frac{\sigma^2}{n})$，样本方差通过 $\frac{(n-1)S^2}{\sigma^2}\sim\chi^2_{n-1}$ 兜底，而且 $\bar X$ 与 $S^2$ 彼此独立——这是 t/F 检验的根基。
>
> **小例子**：$X_1,\dots,X_n\sim N(\mu,\sigma^2)$，则 $Z=\frac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$ 且与 $\frac{(n-1)S^2}{\sigma^2}$ 独立，两边独立才保证后面的 t 统计量有标准 t 分布。

## 介绍

正态总体抽样分布定理（Sampling Distribution Theorems for Normal Populations）是数理统计中关于正态分布样本的统计量精确分布的一系列经典结果。这些定理指出：设 $X_1, \ldots, X_n$ 是来自正态分布 $N(\mu, \sigma^2)$ 的独立同分布样本，则样本均值 $\bar{X}$ 与样本方差 $S^2$ 具有确定的分布，且二者相互独立。具体而言，$\bar{X} \sim N(\mu, \sigma^2/n)$，$(n-1)S^2/\sigma^2 \sim \chi^2_{n-1}$，且 $\bar{X}$ 与 $S^2$ 独立。这些定理是 t 检验、F 检验和方差分析等经典统计方法的基础，为小样本精确推断提供了理论依据。

## 分析

**前置依赖**：正态分布、卡方分布、独立性的概念、线性代数（正交变换）。

**数学内涵**：
- 设 $X_1, \ldots, X_n \overset{\text{i.i.d.}}{\sim} N(\mu, \sigma^2)$。
- $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$，$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$。
- $\bar{X} \sim N(\mu, \sigma^2/n)$。
- $(n-1)S^2/\sigma^2 \sim \chi^2_{n-1}$。
- $\bar{X}$ 与 $S^2$ 相互独立。
- $\frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t_{n-1}$。

**结构**：
1. 样本均值的分布。
2. 样本方差的分布。
3. 样本均值与样本方差的独立性。
4. t 统计量的分布。

## 思考过程

正态总体抽样分布定理的核心技术是正交变换方法。将样本向量 $X = (X_1, \ldots, X_n)^T$ 通过正交变换 $Y = QX$ 转化为独立同分布的正态随机变量，其中 $Q$ 的第一行取为 $(1/\sqrt{n}, \ldots, 1/\sqrt{n})$。这样 $Y_1 = \sqrt{n}\bar{X}$，而 $Y_2, \ldots, Y_n$ 与 $Y_1$ 独立且与 $X$ 同分布。

由于 $\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=2}^n Y_i^2$，这立即推出样本方差与样本均值独立，且 $(n-1)S^2/\sigma^2$ 是 $n-1$ 个独立标准正态变量的平方和，即服从 $\chi^2_{n-1}$。

## 证明过程

**定理**（正态总体抽样分布）：设 $X_1, \ldots, X_n \overset{\text{i.i.d.}}{\sim} N(\mu, \sigma^2)$，$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$，$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$。则

1. $\bar{X} \sim N(\mu, \sigma^2/n)$。
2. $(n-1)S^2/\sigma^2 \sim \chi^2_{n-1}$。
3. $\bar{X}$ 与 $S^2$ 相互独立。
4. $\frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t_{n-1}$。

**证明**：

### 1. 样本均值的分布

由于 $X_1, \ldots, X_n$ 独立且服从 $N(\mu, \sigma^2)$，正态分布的线性组合仍为正态分布：
$$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i \sim N\left(\mu, \frac{\sigma^2}{n}\right)$$

### 2. 正交变换方法

构造 $n \times n$ 正交矩阵 $Q$，其第一行为：
$$q_1 = \left(\frac{1}{\sqrt{n}}, \frac{1}{\sqrt{n}}, \ldots, \frac{1}{\sqrt{n}}\right)$$

令 $Y = QX$，即 $Y_i = \sum_{j=1}^n Q_{ij}X_j$。由于 $Q$ 是正交矩阵，$Y_1, \ldots, Y_n$ 相互独立且 $Y_i \sim N(\mu_i, \sigma^2)$，其中 $\mu_i$ 是 $Q$ 第 $i$ 行与 $(\mu, \ldots, \mu)^T$ 的内积。

特别地：
$$Y_1 = \frac{1}{\sqrt{n}}\sum_{i=1}^n X_i = \sqrt{n}\bar{X} \sim N(\sqrt{n}\mu, \sigma^2)$$

对于 $i \geq 2$，由于 $Q$ 的第一行与其余行正交，且每行元素和为 $0$（因为与第一行正交），有：
$$\mu_i = \sum_{j=1}^n Q_{ij}\mu = \mu\sum_{j=1}^n Q_{ij} = 0, \quad i = 2, \ldots, n$$

故 $Y_2, \ldots, Y_n \overset{\text{i.i.d.}}{\sim} N(0, \sigma^2)$。

### 3. 样本方差的分布

计算样本离差平方和：
$$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n X_i^2 - n\bar{X}^2 = \|X\|^2 - n\bar{X}^2$$

由于正交变换保持欧氏范数，$\|X\|^2 = \|Y\|^2 = \sum_{i=1}^n Y_i^2$，且 $n\bar{X}^2 = Y_1^2$，因此：
$$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n Y_i^2 - Y_1^2 = \sum_{i=2}^n Y_i^2$$

于是：
$$\frac{(n-1)S^2}{\sigma^2} = \frac{1}{\sigma^2}\sum_{i=2}^n Y_i^2 = \sum_{i=2}^n \left(\frac{Y_i}{\sigma}\right)^2 \sim \chi^2_{n-1}$$

### 4. 独立性

由于 $Y_1 = \sqrt{n}\bar{X}$ 与 $Y_2, \ldots, Y_n$ 独立，而 $S^2$ 只是 $Y_2, \ldots, Y_n$ 的函数，故 $\bar{X}$ 与 $S^2$ 相互独立。

### 5. t 统计量的分布

由以上结果：
$$\frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0, 1), \quad \frac{(n-1)S^2}{\sigma^2} \sim \chi^2_{n-1}$$

且二者独立。根据 t 分布的定义：
$$\frac{\bar{X} - \mu}{S/\sqrt{n}} = \frac{(\bar{X} - \mu)/(\sigma/\sqrt{n})}{\sqrt{\frac{(n-1)S^2}{\sigma^2}/(n-1)}} \sim t_{n-1}$$

$\square$

**注**：这一定理是经典统计推断的基石。其中 $\bar{X}$ 与 $S^2$ 的独立性是正态分布特有的性质——对于非正态分布，样本均值与样本方差一般并不独立。
