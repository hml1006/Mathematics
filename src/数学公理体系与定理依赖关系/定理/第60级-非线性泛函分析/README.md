# 第60级-非线性泛函分析

本目录收录以下定理：

- [Ekeland变分原理](./Ekeland变分原理.md)
- [Leray-Schauder度理论](./Leray-Schauder度理论.md)
- [Moser-Nash迭代](./Moser-Nash迭代.md)
- [Schauder不动点定理](./Schauder不动点定理.md)
- [喷泉定理](./喷泉定理.md)
- [对偶变分原理](./对偶变分原理.md)
- [山路引理](./山路引理.md)
- [Borsuk-Ulam 定理](./Borsuk-Ulam定理.md)：球面上无论怎样连续地测量不超过球面维数的几个数值，总存在一对正对面的点，测出来的结果完全一样——这种"巧合"是拓扑强制的，躲不掉。
- [截断函数与 Young 不等式](./截断函数与Young不等式.md)：乘积 $ab$ 可以用两个幂次 $a^p$、$b^q$ 的加权和来"压住"（Young 不等式）；而把局部信息限制在小球内的光滑"开关"（截断函数），则让这种估计能逐尺度地局部化。
- [凸集与 Mazur 定理](./凸集与Mazur定理.md)：弱收敛比强收敛"虚"，但对凸集而言两者其实一样严：一个弱收敛的序列，总能通过取适当的"加权平均"（凸组合）把它拉回范数意义下的强收敛。
- [Nash-Moser隐函数定理](./Nash-Moser隐函数定理.md)：当方程的线性化"求逆会丢导数"、经典隐函数定理失效时，用一族磨光算子把中间量先磨滑，每走一步牺牲一点精度换取可逆性，再用牛顿迭代把损失补回来，最终仍然能把方程局部解出来。
- [形变引理](./形变引理.md)：如果能量函数在高度区间 $[a,b]$ 上没有"卡住不动"的临界点，就可以把"高度不超过 $b$"这一整块区域顺着梯度流连续地压到"高度不超过 $a$"里去，而且过程中每一点的能量只降不升。
