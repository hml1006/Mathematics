# 向量空间公理

## 概述

向量空间（又称线性空间）是线性代数的核心研究对象。向量空间公理定义了向量加法与标量乘法两种运算及其满足的八条基本性质。向量空间的概念广泛应用于数学、物理学、工程学等领域。

## 结构

向量空间是一个二元组 (V, F)，其中 V 是向量集合，F 是标量域（通常为 ℝ 或 ℂ）。八条公理分为两组：前四条关于加法（V 在加法下构成 Abel 群），后四条关于标量乘法。
