# 第99级-统计学习理论

本目录收录以下定理：

- [VC维的泛化界](./VC维的泛化界.md)
- [Rademacher复杂度的泛化界](./Rademacher复杂度的泛化界.md)
- [PAC学习的基本定理](./PAC学习的基本定理.md)
- [SVM的泛化界](./SVM的泛化界.md)
- [稳定性与泛化](./稳定性与泛化.md)
- [Sauer-Shelah 引理](./Sauer-Shelah引理.md)：一个 VC 维为 $d$ 的假设空间，即使它能对任意 $n$ 个点产生很多种分类方式，分类方式的总数也不会超过把 $n$ 个点中最多 $d$ 个点挑出来的所有组合数之和。
- [McDiarmid 不等式](./McDiarmid不等式.md)：不止是"和"，任何由一组相互独立随机变量决定的函数，只要单个变量改动对函数值的影响有限，那么函数值偏离期望的概率就指数式衰减。
- [Hoeffding 不等式](./Hoeffding不等式.md)：一组相互独立且有界的随机变量，它们的和偏离期望的概率随偏离量增大而指数式变小，衰减快慢完全由每个变量取值范围的长度决定。
- [期望与概率界](./期望与概率界.md)：想说明"某个随机量很难偏离它的平均值"，只要掌握三条基本工具——期望的线性与单调、把平均值与尾概率挂钩的马尔可夫/切比雪夫不等式、以及凸函数下的 Jensen 不等式。
- [联合界](./联合界.md)：一堆事件里"至少发生一个"的概率，不会超过它们各自概率之和——因为重叠的部分会被重复计算，所以加起来只会更大。
