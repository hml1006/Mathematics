- [Chern 类与分裂原理](./Chern类与分裂原理.md)：复向量丛的"陈类"是刻画丛扭曲程度的拓扑不变量；而"分裂原理"说，为了验证关于陈类的任何恒等式，可以放心地假设丛是若干线丛的直和——因为总能把丛拉回到一个更大的空间里把它拆成线丛，而拉回映射在上同调上是单射（拆开不丢信息）。
- [覆盖同伦定理](./覆盖同伦定理.md)：纤维丛具有"提升同伦"的能力——把底空间里一段连续移动的路子，连同它在丛里给定的起始位置，一起连续地"抬"到丛上去，抬升后的轨道始终投影回原来的移动。
- [Swan 定理](./Swan定理.md)：紧空间上的向量丛与它上面"连续函数环"上的有限生成投射模是同一件事——丛的连续截面构成一个模，反过来每一个这样的模都唯一地来自一个丛。
