- [Poincaré-Birkhoff 定理](./Poincaré-Birkhoff定理.md)：圆环面上一个保持面积、并把内圈和外圈朝相反方向扭转的映射，一定至少有两个不动点——"扭转"本身逼出了不动点。
- [Gromov 紧性定理](./Gromov紧性定理.md)：一列总能量有界的伪全纯曲线，在不损失能量的地方总能"收敛"；能量集中的地方会炸出新的曲线（气泡），把气泡和极限一起记下来，就得到紧致性——模空间的紧化就是把结点曲线添进来。
- [Gromov 单调性引理](./Gromov单调性引理.md)：全纯曲线经过一点时，在围绕该点的球内"必须占用"至少与球面积成正比的一点能量；它没法把能量藏得无限稀疏——因此曲线不可能无限次地挤过同一点而不付出能量代价。
- [Gromov可去奇点定理](./Gromov可去奇点定理.md)：一条"能量有限"的伪全纯曲线，如果只在一点上没有定义，那么这一点其实不是真奇点——把它补上之后曲线依然光滑，并未被"撕开"。
