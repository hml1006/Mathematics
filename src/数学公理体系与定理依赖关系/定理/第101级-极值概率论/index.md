# 第101级-极值概率论

本目录收录以下定理：

- [Fisher-Tippett-Gnedenko定理](./Fisher-Tippett-Gnedenko定理.md)
- [极值指数与MDA的刻画（von Mises条件）](./极值指数与MDA的刻画（von_Mises条件）.md)
- [Pickands-Balkema-de Haan定理](./Pickands-Balkema-de_Haan定理.md)
- [极值指标估计的渐近性质](./极值指标估计的渐近性质.md)
- [von Mises 条件与吸引域](./vonMises条件与吸引域.md)：$F$ 属于 Fréchet/Weibull/Gumbel 吸引域当且仅当相应的尾函数满足正则变差条件（von Mises 条件）。
- [超阈值方法与广义 Pareto 分布](./超阈值方法与广义Pareto分布.md)：对充分高的阈值 $u$，超出量 $(X-u)^+$ 的条件分布近似为广义 Pareto 分布（Pickands-Balkema-de Haan）。
- [极值 copula 与多元极值](./极值copula与多元极值.md)：多元极值的极限分布由极值 copula 刻画，$C(u)=u_1+\cdots+u_d$ 的凸函数表示给出相依结构。
- [极值过程的谱测度表示](./极值过程的谱测度表示.md)：平稳极值过程可由谱测度表示，极值指标与谱测度的质量互为倒数。
- [Karamata 正则变差理论](./Karamata正则变差理论.md)：慢变函数 $L$ 满足 $L(tx)/L(t)\to1$，尾分布正则变差指数决定极值指标 $\xi=1/\alpha$。
- [Hüsler-Reiss 模型](./Hüsler-Reiss模型.md)：高斯过程极值的极限是 Hüsler-Reiss 分布，参数由协方差函数的变差给出。
