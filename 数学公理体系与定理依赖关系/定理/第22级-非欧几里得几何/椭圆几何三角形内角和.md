# 椭圆几何三角形内角和

## 介绍

椭圆几何（又称黎曼几何或球面几何）是另一种重要的非欧几何，由黎曼（Riemann）在 19 世纪中期创立。在椭圆几何中，平行公理被替换为"不存在平行线"——任何两条直线都相交。椭圆几何最自然的模型是球面几何：在球面上，"直线"是大圆（测地线），任意两个大圆都相交于对径点。椭圆几何中三角形内角和大于 $180^\circ$，这是与欧氏几何和双曲几何都截然不同的结论。这一发现进一步丰富了人们对几何可能性的理解，并在航海、天文学和广义相对论中有着重要应用。

## 分析

**前置依赖**：椭圆几何平行公理、球面几何、大圆与测地线的概念。

**数学内涵**：
- 在椭圆几何中，平行公理表述为：过直线外一点，不存在与给定直线不相交的直线（所有直线都相交）。
- 椭圆几何的标准模型是球面 $S^2$，其中"直线"是大圆（球面与过球心的平面的交线）。
- 椭圆三角形内角和 $\alpha + \beta + \gamma > \pi$。
- 角盈 $\varepsilon = (\alpha + \beta + \gamma) - \pi$ 与面积成正比：$S = R^2 \cdot \varepsilon$，其中 $R$ 是球面半径。
- 球面几何中，三角形的面积公式为 $S = R^2(\alpha + \beta + \gamma - \pi)$。

**结构**：
1. 在球面模型中分析椭圆三角形。
2. 利用球面几何的性质推导内角和大于 $\pi$。
3. 建立角盈与面积的关系。

## 思考过程

椭圆几何中三角形内角和大于 $180^\circ$ 在球面模型上非常直观。在球面上，取赤道上的两个点 $A$ 和 $B$（相距 $90^\circ$ 经度），以及北极点 $C$，则 $\triangle ABC$ 的三个角都是 $90^\circ$，内角和为 $270^\circ$。这显然大于 $180^\circ$。

更一般地，球面三角形的面积公式 $S = R^2(\alpha + \beta + \gamma - \pi)$ 表明，角盈与面积成正比。当三角形面积很小时，内角和趋近于 $\pi$（局部近似于欧氏平面）；当三角形很大时，内角和可以接近 $3\pi$（如果三个角都接近 $\pi$）。

## 证明过程

**定理**：在椭圆几何（球面几何）中，任意三角形的内角和大于 $\pi$（即 $180^\circ$）。

**证明**（使用球面模型）：

设球面 $S^2$ 的半径为 $R$，球面上的"直线"是大圆。考虑球面三角形 $\triangle ABC$，其边是大圆弧。

### 方法一：利用球面三角形面积公式

球面三角形的面积公式为：
$$S = R^2(\alpha + \beta + \gamma - \pi)$$

由于面积 $S > 0$（非退化三角形），因此 $\alpha + \beta + \gamma > \pi$。

### 方法二：利用球面二角形（对偶）

考虑球面三角形 $\triangle ABC$，将其各边延伸为大圆，这三个大圆将球面分割为八个三角形。通过对称性分析可得内角和大于 $\pi$。

具体地，设 $\alpha, \beta, \gamma$ 是 $\triangle ABC$ 的内角。考虑大圆 $AB$ 和 $AC$，它们将球面分成两个二角形，每个二角形的面积为 $2\alpha R^2$。类似地考虑其他边。

通过构造对偶三角形，可以证明球面三角形内角和与 $\pi$ 的差值等于 $S/R^2$，从而 $\alpha + \beta + \gamma - \pi = S/R^2 > 0$。$\square$

**推论**：在半径为 $R$ 的球面上，三角形 $\triangle ABC$ 的面积为
$$S = R^2(\alpha + \beta + \gamma - \pi)$$

**证明**：由上述定理，内角和大于 $\pi$，且面积公式是高斯-博内定理在球面上的直接推论。对于曲率 $K = 1/R^2$ 的球面，高斯-博内定理给出：
$$\int_{\triangle} \frac{1}{R^2} \, dA = 2\pi - \sum_{i=1}^3 (\pi - \alpha_i)$$
$$\frac{S}{R^2} = 2\pi - 3\pi + (\alpha + \beta + \gamma) = (\alpha + \beta + \gamma) - \pi$$
故 $S = R^2(\alpha + \beta + \gamma - \pi)$。$\square$
