# 环同态基本定理

## 介绍

环同态基本定理（Fundamental Theorem of Ring Homomorphisms）是环论中最基本的定理之一，它是群同态基本定理在环论中的类比。定理断言：若 $\varphi: R \to S$ 是环同态，则 $R/\ker\varphi \cong \text{Im}\varphi$（作为环同构）。这个定理揭示了环同态与商环之间的深刻关系，是理解环论中理想、商环和同态之间关系的基础。

## 分析

**定理的精确表述**：设 $\varphi: R \to S$ 是环同态，$\ker\varphi = \{r \in R: \varphi(r) = 0_S\}$ 是核，$\text{Im}\varphi = \{\varphi(r): r \in R\}$ 是像。则

$$
R/\ker\varphi \cong \text{Im}\varphi.
$$

**更具体地**：定义 $\overline{\varphi}: R/\ker\varphi \to \text{Im}\varphi$ 为 $\overline{\varphi}(r + \ker\varphi) = \varphi(r)$，则 $\overline{\varphi}$ 是环同构。

**证明要点**：
1. $\ker\varphi$ 是 $R$ 的理想，故 $R/\ker\varphi$ 是商环。
2. $\overline{\varphi}$ 是良定义且保持加法和乘法。
3. $\overline{\varphi}$ 是双射。

## 思考过程

环同态基本定理与群同态基本定理的证明思路完全类似，但需要额外验证乘法结构的保持性。核 $\ker\varphi$ 不仅是加法子群，还是理想——它不仅对加法封闭，还对乘法有吸收性质：$\forall r \in R, \forall k \in \ker\varphi$，有 $rk, kr \in \ker\varphi$。这保证了商环 $R/\ker\varphi$ 的乘法运算是良定义的。

这个定理的一个典型应用是：$\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}_n$，其中同态 $\varphi: \mathbb{Z} \to \mathbb{Z}_n$ 定义为 $\varphi(k) = k \bmod n$，核为 $n\mathbb{Z}$。

## 证明过程

**证明**：设 $\varphi: R \to S$ 是环同态。

**步骤 1**：证明 $\ker\varphi$ 是 $R$ 的理想。
- $\ker\varphi$ 是加法子群：若 $a, b \in \ker\varphi$，则 $\varphi(a-b) = \varphi(a) - \varphi(b) = 0 - 0 = 0$，故 $a-b \in \ker\varphi$。
- 吸收性：对任意 $r \in R$，$k \in \ker\varphi$，$\varphi(rk) = \varphi(r)\varphi(k) = \varphi(r) \cdot 0 = 0$，故 $rk \in \ker\varphi$。同理 $kr \in \ker\varphi$。

**步骤 2**：定义 $\overline{\varphi}: R/\ker\varphi \to \text{Im}\varphi$ 为 $\overline{\varphi}(r + \ker\varphi) = \varphi(r)$。

**良定义性**：若 $r_1 + \ker\varphi = r_2 + \ker\varphi$，则 $r_1 - r_2 \in \ker\varphi$，故 $\varphi(r_1 - r_2) = 0$，即 $\varphi(r_1) = \varphi(r_2)$。

**加法保持性**：$\overline{\varphi}((r_1 + \ker\varphi) + (r_2 + \ker\varphi)) = \overline{\varphi}((r_1 + r_2) + \ker\varphi) = \varphi(r_1 + r_2) = \varphi(r_1) + \varphi(r_2) = \overline{\varphi}(r_1 + \ker\varphi) + \overline{\varphi}(r_2 + \ker\varphi)$。

**乘法保持性**：$\overline{\varphi}((r_1 + \ker\varphi)(r_2 + \ker\varphi)) = \overline{\varphi}(r_1r_2 + \ker\varphi) = \varphi(r_1r_2) = \varphi(r_1)\varphi(r_2) = \overline{\varphi}(r_1 + \ker\varphi)\overline{\varphi}(r_2 + \ker\varphi)$。

**单位元保持性**：若 $R$ 有单位元 $1_R$，则 $\overline{\varphi}(1_R + \ker\varphi) = \varphi(1_R) = 1_S$（若 $\varphi$ 是保单位元的环同态）。

**单射性**：若 $\overline{\varphi}(r + \ker\varphi) = 0$，则 $\varphi(r) = 0$，故 $r \in \ker\varphi$，即 $r + \ker\varphi = \ker\varphi$（商环中的零元）。

**满射性**：对任意 $s \in \text{Im}\varphi$，存在 $r \in R$ 使得 $\varphi(r) = s$，则 $\overline{\varphi}(r + \ker\varphi) = s$。

因此 $\overline{\varphi}$ 是环同构，$R/\ker\varphi \cong \text{Im}\varphi$。$\square$

**例**：$\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}_n$。

**证明**：定义 $\varphi: \mathbb{Z} \to \mathbb{Z}_n$ 为 $\varphi(k) = k \bmod n$。$\varphi$ 是环同态，$\ker\varphi = n\mathbb{Z}$，$\text{Im}\varphi = \mathbb{Z}_n$。由环同态基本定理，$\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}_n$。$\square$
