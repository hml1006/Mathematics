# 欧几里得算法

> **一句话大白话**：求最大公约数就反复做"大数减/除小数取余"，把问题越缩越小，余数为 0 时最后的除数就是答案（辗转相除法）。
>
> **小例子**：$\gcd(252,105)$：$252=2\cdot105+42$，$105=2\cdot42+21$，$42=2\cdot21+0$ $\Rightarrow \gcd=21$。

## 介绍

欧几里得算法（Euclidean Algorithm），又称辗转相除法，是求解两个整数最大公约数（GCD）的最古老且最有效的算法之一。该算法最早出现在欧几里得的《几何原本》中，至今已有两千多年的历史。其核心思想是反复利用带余除法，将较大数逐步缩小，直至余数为零，此时除数即为所求的最大公约数。欧几里得算法不仅是数论中最基本的工具，也是现代密码学（如 RSA 算法）和计算数论的重要基石。

## 分析

**前置依赖**：带余除法、整数除法、最大公约数的定义。

**数学内涵**：
- 对于任意整数 $a, b$（$b \neq 0$），存在唯一整数 $q, r$ 使得 $a = bq + r$，其中 $0 \leq r < |b|$。
- 欧几里得算法的核心性质：$\gcd(a, b) = \gcd(b, r)$，其中 $r = a \bmod b$。
- 算法步骤：
  1. $a = bq_1 + r_1, \quad 0 \leq r_1 < b$
  2. $b = r_1q_2 + r_2, \quad 0 \leq r_2 < r_1$
  3. $r_1 = r_2q_3 + r_3, \quad 0 \leq r_3 < r_2$
  4. $\cdots$
  5. $r_{n-2} = r_{n-1}q_n + r_n, \quad 0 \leq r_n < r_{n-1}$
  6. $r_{n-1} = r_nq_{n+1} + 0$
- 当余数为零时，$r_n$ 即为 $\gcd(a, b)$。

**结构**：
1. 证明 $\gcd(a, b) = \gcd(b, a \bmod b)$。
2. 证明算法终止性（余数严格递减）。
3. 证明算法正确性（最终余数即为最大公约数）。

## 思考过程

欧几里得算法的发现源于对"求最大公约数"这一问题的几何直观。在古希腊，数被视为线段长度，最大公约数对应于能同时度量两条线段的最长线段。如果 $a$ 和 $b$ 是两条线段，我们可以用 $b$ 去量 $a$，得到余数 $r$；然后用 $r$ 去量 $b$，如此反复。由于每次余数都在减小，最终必然得到一条能同时度量 $a$ 和 $b$ 的最长线段。

这一过程的关键洞察在于：$a$ 和 $b$ 的公约数集合与 $b$ 和 $a \bmod b$ 的公约数集合完全相同。因此，最大公约数在每一步保持不变。这一性质使得算法将问题规模逐步缩小，最终达到平凡情形。

## 证明过程

**定理**：设 $a, b$ 是整数且 $b \neq 0$，则欧几里得算法在有限步后终止，且输出 $\gcd(a, b)$。

**引理 1**：设 $a, b$ 是整数，$a = bq + r$，其中 $0 \leq r < |b|$，则 $\gcd(a, b) = \gcd(b, r)$。

*证明*：设 $d = \gcd(a, b)$，则 $d \mid a$ 且 $d \mid b$。由 $r = a - bq$，得 $d \mid r$，故 $d$ 是 $b$ 和 $r$ 的公约数。反之，设 $d' = \gcd(b, r)$，则 $d' \mid b$ 且 $d' \mid r$。由 $a = bq + r$，得 $d' \mid a$，故 $d'$ 是 $a$ 和 $b$ 的公约数。因此 $\gcd(a, b) = \gcd(b, r)$。$\square$

**算法过程**：
$$
\begin{aligned}
a &= bq_1 + r_1, \quad 0 \leq r_1 < b \\
b &= r_1q_2 + r_2, \quad 0 \leq r_2 < r_1 \\
r_1 &= r_2q_3 + r_3, \quad 0 \leq r_3 < r_2 \\
&\ \vdots \\
r_{n-2} &= r_{n-1}q_n + r_n, \quad 0 \leq r_n < r_{n-1} \\
r_{n-1} &= r_nq_{n+1} + 0
\end{aligned}
$$

**终止性**：由于 $b > r_1 > r_2 > \cdots > r_n \geq 0$，余数序列严格递减且非负，故算法在有限步内终止。

**正确性**：由引理 1 反复应用：
$$
\gcd(a, b) = \gcd(b, r_1) = \gcd(r_1, r_2) = \cdots = \gcd(r_{n-1}, r_n) = \gcd(r_n, 0) = r_n
$$
因此 $r_n = \gcd(a, b)$。$\square$
